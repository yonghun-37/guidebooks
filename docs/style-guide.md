# 이론편 문체 기준 — Phase 8s 초안

대상은 사전 지식 없는 한국어 독자다. 3장 샘플 A/B/C에 적용한 초안이며, 책 전체 개편안 확정은 검수 후 결정한다.

1. **결론 먼저.** 절의 첫 문장으로 제목의 질문에 답한다. “보너스 초대 없는 새 계정은 100만 조회만으로 받는 돈이 0원입니다.”처럼 범위까지 짧게 넣는다. 근거 없이 ‘없다’를 확정하지 않는다.
2. **쉬운 말.** 지급자→누가 돈을 보내나, 대가→무엇을 해 주면 돈을 받나, 현금 잔액→받은 돈에서 비용을 빼고 남는 돈, 적격→신청 조건을 갖춤. 꼭 필요한 용어만 처음 한 번 풀어 쓴다.
3. **숫자는 단위와 계산으로.** “받은 Stars 1,000개×$0.01=$10”. 선물 개수와 Stars 수를 바꾸어 쓰지 않는다. 공식 수치·사업자 참고 범위·가상 입력을 구별한다. 약한 근거는 ‘참고용’+범위+출처를 한 번에 제시한다. 제품 가격은 현금 수입으로 표시하지 않는다.
4. **주의는 절 끝 한 상자에.** 본문은 설명을 이어 가고, 예외·자료 상충·확인 실패는 작은 ‘확인할 점’ 상자 하나에 모은다. 다만 본문 결론의 범위를 뒤집을 조건은 첫 문장에도 넣는다. 각 문장에 ‘미확인·별개·단정할 수 없다’를 반복하지 않는다.
5. **각주는 작게, 근거는 정확히.** 사실 문장 끝에 작은 S번호를 달고 같은 페이지 하단의 출처·확인 범위로 연결한다. research 노트·FACT-SHEET·SOURCES와 대응한다. 날짜 미상은 그대로 적고 접근일을 게시일로 바꾸지 않는다. 정책은 ‘2026년 10월 조사 기준’으로 명시한다.
6. **행동으로 끝낸다.** 각 수익 축·질문·성장 단계에 ‘지금 할 일’을 하나 둔다. 장 마지막도 독자가 오늘 남길 메모나 다음 장 행동으로 끝낸다.

## 구성 원칙

- 기존 9블록 순서(질문→그림→설명→체험→사례→직접 정리→인물 노트→요약→퀴즈)를 유지한다. 표제는 독자 질문으로 바꿀 수 있다.
- 한 샘플에는 시뮬레이터 하나만 둔다. 두 번째 블록의 그림은 정적인 돈의 흐름을 보여 준다. 퀴즈는 짧은 확인 문제로 둔다.
- 계산기는 수입이 생기는 행동을 입력받는다. 팔로워를 자동 월수입으로 바꾸지 않는다. 가정값·계산식·비용/세금 포함 범위는 도구 옆에 공개한다.
- 이론은 ‘왜·어떻게·얼마’를 설명한다. 계정 설정·파일 생성의 실제 조작은 기존 실습편 링크로 연결한다.
- 사실 확인의 한계를 숨기지 않되 독자가 문서 검증 절차를 먼저 배워야 답을 얻는 구성은 피한다.
