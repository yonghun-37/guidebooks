# ReelsBook 초보자 독립 검토

검토자: Codex · 검토일: 2026-10-26 · 대상: 현재 작업 트리의 `site/`, `starter-kit/`. 코딩·마케팅·영상 편집 경험이 없는 직장인을 가정했다. 기존 작성자 판정을 인수하지 않고 본문·브라우저·새 키트 실행을 기준으로 판단했다. 읽기·검토 작업이며 사이트·키트·프로젝트 상태 문서는 수정하지 않았다. 시작할 때 있던 루트 `README.md` 수정은 보존했다. commit/push 없음.

## 핵심 판정

**조건부 가능. 뉴스카드는 이 책의 지시만으로 오늘 AI 서비스에서 만들어 앱으로 올릴 수 있을 만큼 구체적이다. 모든 영상 유형까지 초보자가 막힘없이 완주한다는 판정은 보류한다.**

ChatGPT의 입력창·요약/카드 프롬프트, Canva의 캔버스·텍스트 교체·전체 다운로드, 파일 검수와 Instagram 앱의 게시 경로가 연결된다. 실제 원문과 사용 권한, 무료 잔여량을 확보한 독자라면 카드 경로를 따라갈 수 있다. 모션 영상은 파일 경로는 이어지지만 첫 모션 조작 설명이 짧다. 해설 영상은 표 형태 대본을 음성 입력용으로 바꾸는 과정과 9:16 장면 준비가 빠져 있다.

**차단 0 · 혼란 11 · 사소 2, 총 13건.** 차단은 기본 경로 전체를 진행할 수 없고 책 안에 대안도 없는 경우로 한정했다. 무료 한도·메뉴 차이 때문에 중단될 가능성을 실제 발생한 오류로 세지 않았다. 차단 0은 서비스 가입·생성·게시 성공을 확인했다는 뜻이 아니다. STYLE-GUIDE 및 DESIGN의 전체 품질 통과 판정은 아니다.

## 수행 범위와 증거

- `AGENTS.md`, guidebook-writing/pipeline Skill, STYLE-GUIDE 5절, DESIGN 12절, 학습자 질문, 키트 README를 읽었다.
- `python3 -m http.server 8647 --bind 127.0.0.1 --directory site`로 띄웠다. Playwright가 실제 Chromium 149 브라우저를 실행했다. 실습 0~10·E2E → 이론 15장 → 프롬프트·모델/비용·실험실·용어집·표지, 총 32페이지를 열고 접힌 본문도 펼쳐 읽었다. 1280/375/360px에서 본문 가로 넘침 0, 이 열람의 콘솔/페이지/로컬 HTTP 오류 0이었다.
- 퀴즈 57문항의 정답 버튼을 직접 눌렀다. 수입·카드 편집·영상 타임라인·가상 게시·증거 검수의 본문/실습 도구와 실험실 연결은 기존 회귀 스크립트를 **임시 사본에서 이번 서버 경로로 바꿔 재실행**해 877검사 통과. 별도 조작은 나머지 장 도구, 도구 지도, 프롬프트 복사 6개, 모델 검색/빈 결과/초기화, 비용 조합 27개, 용어 검색, 진행 저장, 실험실 선택을 포함해 105검사 통과했다. 검사의 수는 사용자 수나 독립 사용성 실험 수가 아니다.
- 모델 부록은 구독 24개 서비스와 모델/기능 274행을 열람했다. 범주는 텍스트 70·이미지 75·영상 63·음성 35·음악 25·편집 6이다. 서비스별 현재 가격·약관을 외부 원문으로 전수 재조사한 작업은 아니다.
- 정적 검사: 40페이지·내부 참조 3,325개·실습 43키·퀴즈 57개, 오류 0. 문체 자동 검사: 고정 기준선 25파일 및 신규/부록 6파일 모두 통과. 새 장을 옛 기준선에 억지로 추가하지 않았다.
- 키트는 `/tmp/reelsbook-R-insta/starter-kit`에 새로 복사했다. `.venv`, 캐시, 출력물, `.env`는 가져오지 않았다. Linux x86_64/Python 3.11.15에서 새 가상환경과 README의 pip 설치로 시작했다. 실제 명령 결과는 아래 표와 [검증 요약](phase-R-insta/verification.json)에 남겼다.
- 외부 서비스 로그인·결제·Instagram 게시·토큰 입력·API live 호출·OS 예약 등록은 하지 않았다. Windows/macOS 명령의 실기기 실행도 하지 않았다. 브라우저 읽기와 메뉴 지시의 구체성 평가를 실제 서비스 성공과 구분한다.

검토용 실행 스크립트·전체 텍스트 추출·로그는 `/tmp/reelsbook-R-insta/`에 있다. 임시 경로는 영구 보관을 보장하지 않으므로 판정·명령·한계와 핵심 실행 결과는 이 기록에 함께 남겼다.

## STYLE-GUIDE 5절 독립 채점

○ 충족 / △ 부분(불통과) / × 미충족 / — 해당 없음·기준선 없음. 질문은 `docs/learner-questions.md`의 순서를 현재 장 번호로 대응했다. 새 AI 도구 지도는 현재 FAQ 5개를 적용했다. **관련 설명만 있고 직답·예·할 일 중 하나가 없으면 답함으로 세지 않았다.**

| 기준 | 독립 판정 | 근거 |
|---|---|---|
| 1. 질문 5개 각각 직답+숫자/예+할 일 | △ | 이론 8의 무료 사진/폰트 광고 이용, 이론 9의 무료 AI 음성 상업 이용은 구체적인 허용/제한 예가 부족하다(RI-06/07). 나머지는 FAQ만 짧아도 같은 장 본문의 구체 예·행동으로 보완되는지 확인했다. |
| 2. 금지어·내부 용어 0 | × | 자동 검사에서는 31파일 0개지만 모델 부록의 B3/B5/B11/B15/B17 노출은 독자에게 불필요한 내부 참조다(RI-10). 자동 통과를 사람 판정으로 복사하지 않았다. |
| 3. 상자 밖 지정 단서 장당 2회 이하 | ○ | 재실행한 자동 검사에서 지정 표현 0. 실제 서비스 한계 설명도 주로 확인 상자에 모여 있다. |
| 4. 축마다 같은 틀 반복 | ○ | 기존 설명은 정의/흐름/기준/조건/언제/지금 할 일, 제작 레시피는 무엇/입출력/시간비용/조건/지금 할 일을 반복한다. |

실험실·용어집은 질문 5개/축 반복/축약률을 억지 적용하지 않았다. 검색·선택·실험실 임베드가 작동하고 가정 안내가 있다. 프롬프트 부록은 입력·좋고 나쁜 결과·다음 행동을 제공한다. 모델 부록은 비용 체계·식은 갖췄지만 ②와 ⑦에서 보완이 필요하다(RI-09/10).
