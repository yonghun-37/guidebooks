# Phase B3 — BlogBook 뼈대와 샘플 두 장

기준일: 2026-10-26. **작성·로컬 검증 완료, Claude Code 검수 대기**. 전체 집필·실계정 발행·커밋·배포는 수행하지 않았다. Level 2 기록은 기존 프로젝트 관례대로 이 결과 문서와 PROJECT_STATE를 사용한다.

## 요청 범위와 구현 방침

- `STYLE-GUIDE.md`를 최우선으로, `DESIGN-blog.md` 11절의 B2 확정 결정·예시를 적용했다. 설계서 4·5절의 이론/실습 트랙과 학습 결과를 먼저 등록하고 **이론 2장·실습 7만 샘플**로 집필했다.
- ShortsBook의 현재 공통 외곽을 복사해 바닐라 HTML/CSS/JS를 유지했다. 새 프레임워크·빌드·의존성·발행 API를 도입하지 않았다. 준비중 장은 트랙별 `pending.html?chapter=slug`로 연결한다. 장을 완성할 때 `book.js` 상태와 실제 파일을 함께 바꾼다.
- 수정 범위는 `site-blog/`, 배포·서가·README, 검사기와 해당 테스트, 블로그 조사 공백 보완, 이 결과·상태 문서다. `site/`·`site-shorts/`·`starter-kit/`·`shorts-kit/`·`blog-kit/`는 편집하지 않았다. 시작 시 이미 존재한 다른 작업의 변경은 유지했다.

## 인물과 관통 예시

- **수아**: 퇴근 후 하루 1시간을 쓰는 초보 회사원. **태오**: 블로그 6년 차 운영 멘토. 두 사람과 성과는 가상이며 실적 숫자를 만들지 않았다.
- 블로그 **‘퇴근 후 생활 정보’**: 대표 정보 글은 ‘청년·직장인 지원 제도, 신청 전에 확인할 것’. 실제 제도명·지원 금액을 지어내지 않고 본인이 확인한 공공 자료로 채우도록 했다.
- 같은 블로그에서 생활 가전 실사용 후기·비교와 주말 여행 경험으로 확장할 목차를 마련했다. 제휴 예시는 브랜드 없는 생활 가전 범주다. 수입·주문·판매 예시는 모두 가상 계산으로 표시했다.

## 출처와 집필 검수

- 기존 `research-blog/FACT-SHEET.md`·`SOURCES.md`·주제 노트·QUESTION-MAP을 근거로 `[B###]` 각주를 달았다. 본문에 BL 사실 ID나 작업 단계명을 넣지 않았다.
- 발행 후 수정/삭제·태그 공백은 공식 도움말을 직접 열어 B205~B207, BL-UI-12~13으로 보완했다. 네이버 PC 글 관리·태그는 본문 확인, 티스토리 수정은 B168 공식 본문 재확인, 삭제는 **2008년 과거 기능 안내**까지만 확인했다. 현행 UI·복구 보장 근거로 확대하지 않았다. 관련 노트·질문 연결표도 갱신했다.
- 광고 RPM·네이버 발행·티스토리 저장/발행·현행 공정위 표시 지침 원문도 다시 열어 대조했다. 새 정책이나 평균 수익 숫자를 만들지 않았다.
- 학습자 질문 T02/P07 각각 5개를 FAQ의 첫 문장 직답·계산/예·행동 링크로 답했다. 이론 9블록·축 반복, 실습 결과물·성공 기준·오류 대응을 수동 점검했다.
- 두 원고가 신규이므로 개편 전 분량의 70% 기준선은 없다. 임의 기준선을 만들지 않았으며 해당 항목은 **미적용**이다.
