# Phase 6a · 초보자 관점 따라 하기 검토

검토일: 2026-10-26. 검토자: Codex 독립 독자 역할. 코딩·마케팅 경험이 없는 31세 직장인을 가정했다. 작성자의 이전 검증 결과나 `learner-questions.md`의 기존 판정을 이번 점수로 사용하지 않았다.

**판정: 독자 게이트 보류. 차단 1건·혼란 12건·사소 2건.** 로컬 제작·사람 검수·드라이런은 재현된다. 그러나 DESIGN 1절의 ‘예약 실행되는 생성→검수→업로드 파이프라인 설정’은 따라 하기만으로 완성되지 않는다. 실제 계정 가입·로그인·게시·예약 발행은 수행하지 않았으므로 ‘오늘 실제 게시 성공’으로 판정하지 않는다.

## 검토 범위와 증거

- `python3 -m http.server 8576 --bind 127.0.0.1 --directory site`로 제공한 페이지를 실제 Chromium 149.0.7827.55에서 읽었다. 실습 0→10→E2E, 이어 이론 1→14→실험실→용어집→출처 순서다. 29페이지의 렌더링 본문과 퀴즈를 읽었고 1280·375·360px에서 확인했다. [브라우저 기록](phase-6a/browser-reading.json).
- 이론 14개 도구와 실습 4·5·6·8의 공용 도구를 조작했다. 특히 3장은 네 수익 경로·구매 0·적자·빈칸, 7장은 넘침→문장 축약·전후 비교·크기·색, 8장은 재생·프레임·반복·역전 시간·빠른 자막 복구, 10장은 정상 및 세 실패 상황, 12장은 두 사례의 증거 확인·수정 전후 판단을 확인했다. [조작 기록 93건](phase-6a/interactions.json).
- 실험실 선택기의 원본 항목 28개도 각각 열었고 보이는 입력 도구를 조작했다. 14장 변경 입력이 한 달 요약으로 이어졌으며, 용어 검색·검색 결과 없음·E2E 체크의 페이지 간 저장·OS 탭 키보드 전환을 확인했다. [추가 기록](phase-6a/extra-browser-checks.json).
- 주검토용 `/tmp/reelsbook-6a-fb1xgz8a/starter-kit`에 원본을 새로 복사했고, 셸의 `mktemp -d`로 만든 `/tmp/reelsbook-6a-clean.FEAaWg/starter-kit`에서도 설치·첫 생성·문안 검증을 확인했다. 기존 가상환경·캐시·출력·개인 `.env`를 가져오지 않고 Python 3.11.15의 새 `.venv`에 README의 pip 경로로 설치했다. `python3`는 3.10.12여서 버전을 확인한 뒤 `python3.11`을 선택했다. 기존 실행 환경을 재사용하지 않았다.
- README 첫 실행, 실습의 `output/first-post` 생성→프롬프트→직접 문안 편집→구조 검증→카드·영상 재생성→검수표 편집→approve→publish 드라이런, `prepare_hosting.py`, URL 지정 드라이런을 실행했다. README의 개별 fetch/write/render/make 명령도 실행했다. [명령과 출력](phase-6a/commands.md), [키트 결과](phase-6a/kit-walkthrough.json).
- 다섯 PNG와 다섯 JPEG를 열어 제목·본문·출처·합성 표시를 확인했다. 영상은 로컬 서버 8577에서 **20초 끝까지 실제 브라우저 재생**하고 다섯 장면 중간 화면도 확인했다. H.264/AAC·1080×1920·24fps·20초, 무음 트랙을 확인했다. [재생 기록](phase-6a/media-playback.json), [장면 예](phase-6a/reel-mid-6.png).
- 이론의 작업실 노트는 실제로 채워 [독자 작업 메모](phase-6a/learner-notes.md)에 남겼다. 외부 응답·구매 의향·계정·게시 주소·매출을 꾸며 쓰지 않았다. 외부 작업은 안내 구체성만 판단했다.

[독립 점수표](phase-6a-scorecard.md)에 이론 70개 질문의 직답·숫자/예·행동 근거와 7개 기준의 장별 점수, 실습편의 별도 판정을 남겼다. 현재 원고의 70개 질문은 모두 세 요소를 찾을 수 있었다. 이전 작성자 판정의 ‘부분 29개’를 그대로 반복하지 않았다.
