## 검증 초점

- 1장: 순서를 바꾸어도 단계마다 필요한 재료를 설명하며, 누락을 게시 성공으로 표시하지 않는다.
- 3장: 문장 교체 전후 그림은 동일하다. 정지·재생·끝·키보드 스크럽 및 동작 줄이기를 지원한다.
- 4장: 빈 값·0·음수·비정상 입력에서 이전 결과를 지우며, 공백/문장부호 포함 글자 수와 같은 방식의 샘플 읽기 시간을 쓴다.
- 5장: 소리는 클릭 후 시작하고 정지·화면 이탈에 멈춘다. 뮤트/솔로 우선순위와 두 트랙 무음 상태를 글자로 표시한다. 합성음은 실제 발음 판정 도구로 설명하지 않는다.
- 모든 도구는 네이티브 입력·텍스트 결과·가정값·극단값을 제공한다. 외부 미디어·플랫폼 UI를 사용하지 않는다.

## 결과

### 집필과 도구

- **[1장](../../site-shorts/chapters/01-map.html)**: 스마트폰 시작·얼굴/목소리 없는 구성·첫 연습 길이·제작 순서·무료 경로에 직답한다. 대본→소리·촬영→편집·자막→출력·재생→게시를 설명한다. 도구는 단계 선택과 녹음/장면/자막 누락을 연결하고 모두 빠진 극단값을 제공한다.
- **[3장](../../site-shorts/chapters/03-hook.html)**: 좁은 주제·첫 그림과 문장·짧은 이야기·유행·게시 전 이해 점검을 설명한다. 자체 SVG 케이블 장면의 그림·동작을 그대로 두고 첫 문장만 교체한다. 재생/정지·첫 화면·문장 없음·키보드 스크럽을 지원하며 3초 종료/화면 이탈에 멈춘다. 첫 3초는 연습 구간이다.
- **[4장](../../site-shorts/chapters/04-script.html)**: 본인 읽기 시간·AI 보조와 수익화·축약·원출처 확인·말/장면/자막 표를 담았다. 글자 수/내 샘플 읽기 속도/추가 쉼으로 예상 시간을 계산하고 빈 값·범위 오류를 처리한다. 공백·기호를 포함하고 줄바꿈을 제외해 센다. 120자÷20초 등의 수치는 가상 계산으로 표시했다.
- **[5장](../../site-shorts/chapters/05-audio.html)**: 본인 녹음·한국어 TTS와 상업 이용권·소리 균형·음악 사용권·주장/경고를 구분한다. Web Audio로 자체 합성한 말 리듬과 배경음을 분리해 듣는다. 자동 재생·외부 음원·음성 서비스 호출이 없다. 소스의 최고 크기를 맞춘 뒤 가상 음량 막대를 곱한다. 이 막대는 실제 dB나 체감 음량의 배수가 아니다.

도윤·서진과 책상 정리 예제를 승인 샘플에서 이어 갔다. 각 장은 9블록·같은 설명 축 틀·FAQ5·정리3·퀴즈3을 갖췄다. 정책·기능·비용 문장은 사실표와 Y 각주로 연결하고, 첫 연습 길이·글자 수·음량은 가상 설정 또는 직접 측정으로 구분했다. 수익화·오디오 보관함·AI 공개·훅 대담의 공식 원문을 다시 열어 관련 사실과 대조했다.

### 검토에서 발견해 수정한 것

별도 읽기 전용 검토를 받았다. AI 대본 수익화 질문에 허용 여부를 직접 답하도록 보강했다. 무효 입력 뒤 진행 막대의 이전 접근성 읽기값이 남는 문제, 음악 솔로를 음악 과다로 평가하는 안내를 실패하는 회귀 검사로 재현하고 수정했다. 추가 검사에서는 영속 페이지 이벤트 뒤 닫힌 오디오 장치를 재사용하는 문제를 재현했다. 닫힌 장치는 다음 재생 때 새로 만들어 복구한다. 모두 최종 검사에 반영했으며 미해결 리뷰 항목은 없다.

문체 검사기의 “장부” 부분 문자열이 “문장부호”까지 잡는 사례는 검사기를 바꾸지 않고 학습자 문장을 “공백·기호”로 고쳐 통과시켰다. 초기 정적 검사 중 다른 작업자의 새 자산 생성 전 파일 누락을 봤으나, 그 파일을 수정하지 않고 생성 후 재검사해 오류 0을 확인했다.

### 파일 소유·문서·통합 대기

수정 범위는 담당 HTML 네 개와 이 결과 묶음뿐이다. 다른 작업자의 Y4b/Y4c/Y4k·키트 파일을 보존했다. 공통 자산·표지·용어집·출처와 프로젝트 상태·진행 현황은 수정하지 않았다. 이 기록이 담당 묶음의 현황이며, 전체 프로젝트 상태 갱신은 통합 담당자가 수행한다.

- [공통 통합 요청](phase-Y4a-requests.md): 장 데이터·완료 상태·링크/제목 처리의 적용 가능한 diff와, 통합 출처에 추가할 19개 항목의 삽입 diff.
- [새 용어 후보](phase-Y4a-glossary.md): 15개 용어와 설명·첫 등장 장·권장 앵커.
- [검증 명령](phase-Y4a/commands.md), [브라우저 결과](phase-Y4a/browser-check.json), [도구 결과](phase-Y4a/tools-check.json), [경계 결과](phase-Y4a/edge-check.json).

**남은 통합 사항:** 실제 `book.js`는 승인된 샘플만 본문으로 연결하므로 공통 목차·상태와 브라우저 탭 제목에 준비중이 남는다. 본문 네 개와 장 안의 직접 상대 링크는 사용 가능하다. 통합 요청 diff 적용 후 전체 목차·표지·용어집·통합 출처를 함께 검수한다.

실제 OS/휴대폰의 녹음·TTS 음질·편집기 설치·사용자 계정 업로드는 실행하지 않았다. 도구의 합성 신호는 실제 한국어 발음의 명료도를 판정하지 않으며, 본인 녹음과 완성 MP4에서 다시 듣도록 안내한다. commit·push·배포·유료 호출은 하지 않았다.
