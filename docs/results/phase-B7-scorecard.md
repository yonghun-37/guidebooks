## 1. STYLE-GUIDE 5절 채점

원래 기준은 가중치 없는 충족/미충족이다. 장별로 기준 하나를 충족하면 1점, 미충족이면 0점으로 세었다. 질문 기준은 5개 모두 충족해야 그 장에 1점을 준다. 신규 원고에 개편 전 분량 기준선을 만들어 소급 적용하지 않았다.

| 기준 | 점수/판정 | 근거 |
|---|---|---|
| 1. 질문마다 첫 문장 직답 + 숫자 또는 예 + 할 일 | **22/24장 충족** | 아래 120문항 중 118 충족·2 부분. 이론 9장 T09-4와 실습 8 P08-3은 미충족. 관련 안내·외부 링크만으로 직답을 대신한 부분을 감점했다. |
| 2. 금지어·내부 용어 0 | **24/24장 충족** | 독립 실행한 style_lint: 검사 대상 전체 34파일 통과, forbidden 0·internal 0. 출처·내비게이션·코드 속성 등 검사 제외 범위는 검사기 규칙을 따른다. |
| 3. 상자 밖 지정 단서 표현 2회 이하 | **24/24장 충족** | style_lint 지정 표현의 상자 밖 일치 0. 정책 조건과 확인 행동을 항목 끝에 모았다. |
| 4. 축별 같은 틀 반복 | **24/24장 충족** | 이론 1~5·8~13의 정의/흐름/기준/조건/때/행동, 6·7장의 제작 입력/출력/검수 틀이 일관된다. 실습은 이 기준을 지금 할 일/이유/단계/성공/문제 대응의 반복으로 평가했다. |
| 5. 개편 전 70% 이하 | **해당 없음** | 이론은 신규 집필이며 비교 기준선이 없다. 자동 검사 ratio도 null. 축약 통과로 계산하지 않았다. 실습에는 원래 해당하지 않는다. |
| 6. 숫자에 출처 또는 가상·계산식 | **24/24장 충족** | 수익률·가격·지급 조건은 B각주, 예제 입력·작업시간은 가상/수업 예산과 계산으로 표시한다. 키트 성공 출력은 직접 재현했다. 이 판정은 출처 연결·가정 표시의 충족이며 모든 현행 가격·법률·정책 원문을 새로 검증했다는 뜻은 아니다. |
| 7. 3분 안에 다음 행동을 말할 수 있음 | **24/24장 충족** | 절 첫 답과 ‘지금 할 일’, 실습 첫 결과물·시간·다음 버튼에서 다음 행동을 찾을 수 있다. 예: 질문 선택, 메모를 새 대화에 넣기, 공개 설정 뒤 최종 발행, 첫 7일 표 저장. 실제 초보자 대상 3분 사용성 실험은 아니며 검토자 판단이다. |

적용 가능한 항목 합계는 **142/144점**이다. **평균 점수가 장별 통과를 대신하지 않는다.** 엄격 기준상 이론 9장과 실습 8은 수정 후 재검토해야 한다. 나머지 장도 6·7절의 시각자료·예시 보완 사항까지 통과했다는 뜻은 아니다.

## 3. STYLE-GUIDE 6·7절 추가 판단

| 관점 | 판정 | 근거 |
|---|---|---|
| 6절: 흐름·비교·표시 위치 | 충족 | 글 제작/수익 흐름, UV/PV와 지수 비교, 표시 문구의 앞/뒤 비교, 썸네일 제목 도구가 이해를 돕는다. |
| 6절: 앱에서 누를 위치 | **보완 필요** | 실습 2·5·6·8의 ‘위치 안내도’ 다수가 본문의 번호 목록을 상자로 다시 쓴다. 화면 틀 속 위치·조작 대상이 빠져 있다(B7-03). |
| 6절: 작은 화면·접근성 구조 | 확인 범위 충족 | 주요 31페이지를 Chromium 1280/360px에서 열어 문서 가로 넘침 0, 페이지 JS 오류 0. 정적 검사 오류 0. 그림 캡션·이름 구조도 검사했다. 모든 OS·보조기기의 접근성 인증은 아니다. |
| 7절: 현실적인 장르·윤리 | 충족 | 지원 제도·생활 가전 후기·여행은 독자가 이해할 만한 소재이며 허위 사용·가짜 성과를 금지한다. 생성 삽화와 증거 사진도 구분한다. |
| 7절: 올릴 만한 완성 결과물 | **보완 필요** | 정책 글 예는 실제 공고·조건·출처가 빈칸이고, 완성 샘플은 공고 읽는 법이다. 채운 자료가 실제 원고로 변하는 한 바퀴가 부족하다(B7-01). |
| 7절: 장을 넘는 같은 예시 | **보완 필요** | 제습기→공기청정기/필터, 대표 첫 글→여행 전환으로 따라가던 결과물이 달라진다(B7-02). |

그림의 개수 부족을 지적한 것이 아니다. 화면 위치가 필요한 그림의 정보와 완성 사례의 구체성을 평가했다.

## 4. 직접 실행한 검증

### 환경·격리

- Linux, **Python 3.11.15**. 원본은 `/tmp/blogbook-b7-986x8d7d/blog-kit`, 동봉 ZIP은 `/tmp/blogbook-b7-zip-6s6bdfvj/blog-kit`에 각각 새로 복사/해제했다. 각 폴더에 독립 `.venv`를 만들었다.
- 런타임 패키지 없이 기본 명령을 먼저 실행했다. 개발자 테스트 때만 README대로 `python -m pip install -r requirements-dev.txt`를 실행했다.
- 키트의 실제 서버 전송 `--live`, 인증 정보 입력, OS 예약 등록 명령은 실행하지 않았다. 예약 **안내 생성**만 실행했다.
- 아래 로그·스크린샷은 `/tmp` 임시 증거다. 영구 검토 기록은 이 문서의 실행 명령과 결과이며, 임시 파일을 보존된 산출물로 약속하지 않는다.
