# Phase 5c 용어 제안

기존 glossary.html은 수정하지 않았다. 현재 존재하는 API 앵커만 `#api`로 연결하고, 아래 신규 용어는 용어집 페이지 자체로 연결했다. 통합 시 아래 앵커를 추가하고 해당 `data-term` 링크를 앵커로 좁히면 된다. 본문의 쉬운 설명·툴팁은 지금도 제공된다. 기술·회계 용어는 교육용 정의이며 세무 판정이 아니다.

| 용어 | 쉬운 설명 | 처음 나온 장 | 관련 사실 ID |
| --- | --- | --- | --- |
| 드라이런 (`dry-run`) | 실제 게시 없이 보낼 요청 내용을 미리 확인하는 연습. 여기서는 로컬 키트 기능 | 10 | API-08, NOCODE-05; 키트 publish.py 실행 확인 |
| 컨테이너 (`container`) | 게시할 미디어의 처리 상태를 관리하는 API 준비 단위 | 10 | API-08, API-09 |
| 액세스 토큰 (`access-token`) | 서비스 요청 권한을 증명하는 비밀 값 | 10 | API-10 |
| 해시 (`hash`) | 파일 내용이 달라졌는지 비교하는 디지털 지문 | 10 | 운영 설계 제안(NOCODE-05), review.py 구현 확인 |
| 조회 (`views`) | 콘텐츠가 재생되거나 표시된 횟수. 고유 사람 수와 다름 | 11 | GROW-03, METRIC-02 |
| 도달 (`reach`) | 콘텐츠를 본 고유 계정 수의 추산치 | 11 | GROW-03, METRIC-02 |
| 인사이트 (`insights`) | 계정과 게시물의 반응을 보여 주는 통계 정보 | 11 | GROW-06, METRIC-04 |
| 2단계 인증 (`two-factor`) | 비밀번호 외의 추가 확인 수단으로 로그인을 보호하는 방식 | 12 | SEC-01 |
| 원천징수 (`withholding`) | 지급자가 대금을 줄 때 세금을 미리 떼어 납부하는 방식. 최종세금과 구분 | 12 | TAX-09 |
| 교차 게시 (`cross-posting`) | 같은 소재를 플랫폼별 조건에 맞춰 각각 게시하는 일 | 13 | XPLAT-01~05 |

‘처음 나온 장’은 이번 담당 원고 안의 첫 사용이다. 다른 담당자가 2~9장에 먼저 정의했을 수 있으므로 통합 시 중복을 합치고 책 전체의 첫 장 번호를 조정해야 한다.
