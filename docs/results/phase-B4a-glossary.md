# B4a 새 용어 통합 후보

현재 공용 용어집의 UV·PV·RPM과 중복하지 않는 항목이다. 본문은 쉬운 말로 설명했고, 아직 없는 용어 앵커를 만들지 않았다. 통합 시 다른 묶음과 중복을 합친다.

| 용어·권장 앵커 | 쉬운 정의 | 첫 연결 위치 | 근거·범위 |
|---|---|---|---|
| 키워드 `keyword` | 독자가 검색창에 넣는 단어나 질문 | 5장 #topic | 편집 설명 |
| 검색 의도 `search-intent` | 검색한 사람이 실제로 알고 싶거나 하려는 일 | 5장 #intent | B033 |
| 월간검색수 `monthly-searches` | 키워드 도구가 한 달 기준으로 보여 주는 검색 횟수 | 5장 #numbers | B054·기기·기준일 기록 |
| 상대지수 `relative-index` | 같은 비교 조건에서 관심도의 높낮이를 나타내는 값 | 5장 #numbers | B055·B056·횟수와 구분 |
| 광고 경쟁도 `ad-competition` | 광고 도구의 광고 경쟁 지표로 블로그 순위 점수와 다름 | 5장 #intent | B054·B057 |
| API `api` | 프로그램이 서비스에 정해진 방식으로 요청하는 통로 | 4장 #question | B010·B012·공식 지원과 권한 필요 |
| 도메인 `domain` | 사이트를 찾아가는 인터넷 주소의 이름 | 4장 #question | B068·B070 |
| 호스팅 `hosting` | 글·사진을 인터넷에서 열 수 있도록 보관·운영하는 서비스 | 4장 #question | B015·B017 |
| DNS `dns` | 도메인 이름이 어느 사이트로 이어질지 정하는 주소 설정 | 4장 #blogger | B068 |
| 백업 `backup` | 원고·사진 등을 나중에 쓸 수 있도록 따로 보관한 사본 | 4장 #case | B071·B200·B133·주소/순위 이전과 구분 |
| 템플릿 `template` | 글·디자인을 만들 때 내용만 바꿔 쓸 수 있는 기본 틀 | 3장 #image | 편집 설명·소재 이용 조건 확인 |
| WordPress.com·설치형 `wordpress-types` | 호스팅 포함 서비스와 직접 서버에 설치하는 소프트웨어의 구분 | 4장 #wordpress | B015·B017 |
