# Y4a 새 용어 후보

통합 담당자가 기존 용어와 겹치는지 확인한 뒤 용어집에 반영한다. 현재 본문에는 첫 등장 자리의 짧은 설명을 넣었으며, 아직 없는 용어집 앵커는 연결하지 않았다.

| 용어 | 쉬운 설명 | 처음 사용하는 장 | 권장 앵커 |
|---|---|---|---|
| 쇼츠 | 정사각형 또는 세로·최대 길이 등 분류 조건을 갖춘 짧은 영상 형식 | 1 | shorts |
| 편집 프로젝트 | 장면·소리·자막 배치 등 작업을 이어 가기 위한 편집 문서 | 1 | project |
| MP4 | 완성 영상을 재생·업로드할 때 쓰는 영상 파일 형식 | 1 | mp4 |
| 출력·내보내기 | 편집한 내용을 재생할 완성 파일로 저장하는 일 | 1 | export |
| 훅 | 처음에 볼 이유를 주는 장면이나 문장 | 3 | hook |
| 대본 | 무엇을 말하고 어떤 장면을 보여 줄지 정리한 글 | 4 | script |
| 자막 | 말이나 핵심 내용을 화면에서 읽도록 보여 주는 글자 | 4 | captions |
| 내레이션 | 장면을 설명하는 말 | 5 | narration |
| TTS | 글자를 음성으로 바꾸는 기능 | 5 | tts |
| 트랙 | 소리·영상 등을 따로 조절하는 작업 줄 | 5 | track |
| 뮤트 | 선택한 트랙의 소리를 끄는 기능 | 5 | mute |
| 솔로 | 선택한 트랙만 듣는 기능 | 5 | solo |
| Content ID 소유권 주장 | 자동으로 찾은 일치 콘텐츠에 대해 권리자가 사용·차단·수익화 등을 설정하는 것 | 5 | content-id |
| 저작권 위반 경고 | 유효한 법적 삭제 요청으로 콘텐츠가 삭제될 때 받는 경고 | 5 | copyright-strike |
| 저작자 표시 | 음원 등에서 요구하는 원작자·출처 정보를 남기는 일 | 5 | attribution |

쇼츠·상업 이용권·저작권 관련 정의는 각 장의 Y 각주 및 `research-shorts/FACT-SHEET.md`의 해당 사실을 따른다. 화면의 “음량 막대 차이”는 이 도구의 가상 설정 차이이며 실제 음량 단위로 새 용어화하지 않는다.
