## 공통 구현·정리

- `assets/figures.css`: figure/캡션, 반응형 2칸 비교, 단계 띠, 차트, SVG·번호·라이트/다크.
- `assets/figure-components.svg`: 직접 그린 화면 틀·번호 원·손/물건 등 재사용 도형. 화면 배치는 학습용임을 명시한다. 작은 폭에서는 2칸을 같은 크기의 위아래 비교로 바꿔 글자를 보존한다.
- 모든 새 SVG는 제목·설명, figure·결론 캡션을 둔다. 복잡한 그림의 번호는 밖의 글 설명과 연결한다.
- 이전의 장 머리 인물 삽화 전부와 쓰지 않는 SVG 사본·래스터를 제거한다. AI 예시를 새로 생성하지 않으며 유지한 실제 결과의 프롬프트만 남긴다.
- 기존 본문·명령·입력·제어·도구 ID는 대조 검증한다. 공통 검사기는 실행만 하며 다른 책·키트·조사·문체 기준은 수정하지 않는다.
