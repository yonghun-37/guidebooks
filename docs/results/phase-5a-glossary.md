# Phase 5a 용어 인계

2026-10-26. 2~5장의 `data-term` 설명과 대조했다. 새 항목의 본문 링크는 현재 `../glossary.html`로 연결한다. 미구현 앵커를 만들어 링크를 깨뜨리지 않았다. 아래 항목을 통합한 뒤 해당 링크에 앵커를 붙일 수 있다. 기존 `carousel`·`api`는 기존 앵커를 사용한다.

| 용어 | 쉬운 설명 | 처음 나온 장 | 관련 사실 ID |
| --- | --- | --- | --- |
| 알고리즘 (`algorithm`) | 여러 신호를 바탕으로 무엇을 보여 줄지 정하는 처리 방식. 공개된 고정 성공 공식과 구분한다. | 2 | ALG-01 |
| 캐러셀 (`carousel`, 기존) | 여러 이미지나 영상을 한 게시물 안에서 넘겨 보는 묶음. | 1, 2에서 보완 | ALG-07 |
| API (`api`, 기존) | 정해진 형식으로 서비스에 요청하고 응답받는 연결 방식. 앱과 지원 규격이 다를 수 있다. | 1, 2에서 보완 | API-05·07, ALG-06 |
| 조회 (`views`) | 콘텐츠가 재생되거나 표시된 횟수. 고유 사람 수와 다르다. | 2 | METRIC-02·03 |
| 도달 (`reach`) | 콘텐츠를 본 고유 계정 수의 추산치. 기간·집계 단위·광고 포함 여부를 함께 본다. | 2 | METRIC-02, GROW-03 |
| 브랜디드 콘텐츠 (`branded-content`) | 브랜드 등과 가치 교환이 있는 콘텐츠. 현금 외 제공 제품·서비스·제휴 수수료도 관계될 수 있다. | 3 | REV-01 |
| 제휴 마케팅 (`affiliate`) | 링크 등을 거친 인정 구매나 행동에 대해 수수료를 받는 방식. 실제 인정·취소·지급 조건을 따로 확인한다. | 3 | REV-05, GAP-04 |
| 현금 잔액 (`cash-balance`) | 이 교재에서는 같은 기간의 현금 수입에서 환불·현금 비용을 뺀 연습값. 회계·세무상 순이익과 범위가 다르다. | 3 | 교육용 장부 정의, 외부 사실 아님 |
| 니치 (`niche`) | 특정 독자의 구체적인 필요에 집중하는 주제 범위. 점수는 성장 예측이 아니다. | 4 | 교육용 기획 정의, GROW-07 |
| RSS (`rss`) | 새 글의 제목·링크·짧은 설명 등을 모아 받을 수 있는 피드 형식. 이용 권리 허락과는 별개다. | 5 | NEWS-05, LAW-08; 키트 fetch_news.py |
| 인용 (`quotation`) | 다른 저작물의 일부를 내 설명 속에서 정당한 목적·범위로 이용하는 것. 출처 표시만으로 요건이 모두 충족되지는 않는다. | 5 | LAW-02 |
| 공정 이용 (`fair-use`) | 목적·저작물 성격·분량과 중요성·시장 영향 등을 고려하는 판단. 고정 글자 수 면책 규칙이 아니다. | 5 | LAW-03 |
| 공공누리 (`kogl`) | 공공저작물의 출처·상업 이용·변경 조건을 표시하는 이용허락 체계. 저작물별 표식을 확인한다. | 5 | ASSET-03, NEWS-05 |

프로페셔널 계정·Gifts·구독·워터마크·라이선스·Atom은 첫 등장 주변에서 괄호 또는 쉬운 말로 풀었다. 외부 약관·권리의 미확인을 용어 정의로 해소한 것처럼 쓰지 않는다.
