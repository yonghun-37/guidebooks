## AI 이미지

**imagegen 스킬의 내장 이미지 생성 기능**으로 두 번 생성했다. CLI/API 키를 사용하지 않았다. 생성 원본은 도구 기본 저장소에 두고, 프로젝트에는 WebP 변환본만 넣었다. 기존 임시 Python 환경의 Pillow로 크기·포맷을 변환했으며 내용 합성·보정은 하지 않았다.

| 파일 (`site-blog/assets/img/ai-examples/`) | 내용 | 실제 크기 | 바이트 |
|---|---|---|---|
| `support-desk.webp` | 지원 제도 글의 준비물 책상 삽화 | 1280×640 | 52,816 |
| `weekend-river.webp` | 당일치기 글의 강변·열차 분위기 삽화 | 1200×800 | 140,880 |

모두 400KB 이하, 의미 있는 alt·실제 width/height·lazy loading·figure/figcaption·‘AI 생성 예시’ 표시를 갖췄다. **실제 사용 프롬프트 전문은 7장 `#generate`**에 있다. 종이 공예풍·크림/자주/세이지 색·제목 여백·글자/로고/실존 장소 배제를 요청했다. 두 파일을 직접 열어 소재·여백·문자/로고 부재를 확인했다.
