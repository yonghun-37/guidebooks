# Y4p — AI 제작 우선 실습편

## 요구사항과 구현 계획

승인된 실습 8의 도윤·서진, 단계별 행동·성공 확인·문제 해결·OS 탭과 FAQ를 따른다. 실습 0~7·9·10·E2E를 작성하고 실습 8은 연결만 수정한다. 기본 제작 경로는 ChatGPT 무료 → 녹음/선택 TTS → 촬영/스톡/AI 이미지/AI 영상 → Clipchamp → 자동 자막 교정 → 출력 → 공식 업로드다. shorts-kit는 각 단계의 자동화·무료 대안이다.

- [x] 지정 설계·문체·질문·조사·승인 샘플·키트 결과와 F01~F15를 읽는다.
- [x] 무료 조건·권리·한국 가용성을 기존 사실표/AI 제작 노트와 대조한다.
- [x] 유형 선택·복사 프롬프트·파일 전달·실제 자료 분기·전체 시간·E2E를 작성한다.
- [x] 깨끗한 임시 키트에서 설치·생성·수정·재출력·검수·승인·드라이런을 실행한다.
- [x] 문체·정적 링크·1280/375/360px·콘솔·키보드·저장 복원을 확인한다.
- [x] 결과·화면·공통 변경 diff·용어 요청을 남기고 지정 알림을 전송한다.

공통 자산·표지·용어집·출처·상태 문서는 수정하지 않는다. 관련 통합 제안은 `phase-Y4p-requests.md`에 남긴다. 기존 미추적 `docs/prompts/phase-Y4ai.md`는 보존한다. 계정 로그인·유료 API·실제 게시·커밋·푸시는 실행하지 않는다.

## 남은 확인과 통합

- 공통 book.js는 실습 0·8 외를 준비중으로 표시하고 공통 목차·자동 pager·브라우저 제목에 그 상태가 남는다. 수정 금지 범위를 지켰으며 [phase-Y4p-requests.md](phase-Y4p-requests.md)에 적용할 diff를 남겼다. 새 원고는 자체 실습 내비게이션·앞뒤 연결·E2E로 직접 이동할 수 있다.
- 상태 문서·표지·출처·용어집·서가 진행표의 공통 통합은 담당자가 수행해야 한다. 용어는 [phase-Y4p-glossary.md](phase-Y4p-glossary.md)에 있다. 기존 결과 기록을 재사용했으며 별도 ADR이나 중복 feature 문서를 만들지 않았다.
- Windows/macOS·폰 실기기에서의 설치·녹음·파일 전송·Clipchamp/Create/Vrew/Flow/Runway의 한국 계정 메뉴·무료 접근·TTS 품질은 실행하지 않았다. 서비스 절차는 공식 조사에 근거한 안내이며 Linux 브라우저의 교과서 화면 검증과 구별한다.
- 실제 OAuth 로그인·API 전송·Studio 게시·공개·권리 판정·지표 관찰은 사용자가 수행한다. 독립 초보자 검수와 공통 통합 검수도 남는다. 유료 API·결제·커밋·푸시는 실행하지 않았다.
