# Phase 9d 통합 요청

담당 실습 HTML·검증 기록·지정된 메뉴 확인표만 수정했다. `book.css`·`book.js`·`common.js`·`practice.js` 변경은 필요하지 않았다. 공통 부품은 기존 파일을 연결해 사용한다. 상태·부록·생성기는 다른 범위이므로 아래를 통합 작업자에게 남긴다.

## 이전 실습 생성기 실행 중지

`scripts/build_practice.py`는 개편 이전 문안과 확인표를 다시 써서 이번 12페이지와 조사 결과를 덮어쓴다. 이번 HTML이 현재 원고다. 생성기를 그대로 실행하지 말고, 통합 때 아래 최소 보호 변경을 적용하거나 생성 데이터를 현재 원고에 맞춰 갱신해야 한다. 이 파일은 작업 시작부터 존재하던 미추적 파일이므로 직접 수정하지 않았다.

```diff
--- a/scripts/build_practice.py
+++ b/scripts/build_practice.py
@@
 if __name__=='__main__':
-    build()
+    raise SystemExit(
+        '현재 원고는 site/practice/*.html입니다. '
+        '이전 생성기는 개편 원고·조사 확인표를 덮어쓰므로 실행을 중지합니다.'
+    )
```

## 현재 상태 반영

`docs/PROJECT_STATE.md`의 ‘실습 본문 미개편’·‘18개 메뉴 모두 후보’ 설명은 통합 시 아래 현재 상태로 대체한다. 다른 작업자의 상태 문서를 직접 수정하지 않았다.

```diff
--- a/docs/PROJECT_STATE.md
+++ b/docs/PROJECT_STATE.md
@@
+- Phase 9d: 실습 0~10·E2E 본문 개편과 작성자 검증 완료. 단계 35개와 저장 키·기존 앵커를 유지하고 페이지별 결과물·FAQ 5개를 추가했다. 재조사의 한국어 메뉴·계정 10개·예약 30일/25개·인사이트 기간을 반영했다. 메뉴 18개는 문서 근거를 반영했으며 실기기 확인 속성은 유지한다. 문체 검사 12페이지 통과, 12페이지×3개 폭 브라우저 검사와 깨끗한 Python 3.11 환경 명령 검증을 완료했다. 실제 계정·Windows/macOS 검증은 남아 있다. 결과: docs/results/phase-9d.md. 이전 scripts/build_practice.py는 재실행하지 않는다.
```

새 출처는 각 실습의 페이지 안 각주에서 완결된다. 공통 `credits.html`의 실습 인용 집계 갱신은 통합 시 기존 부록 생성 관례로 처리한다. 이론편 동시 작업 결과·현황 페이지·연구 원문·키트·배포 파일은 수정하지 않았다.
