# Y4c — 이론 10~14장

## 범위와 구현 전략

사용자가 승인한 이론 2장·실습 8을 기준으로, 도윤·서진의 책상 정리 영상 제작을 이어 간다. [문체 기준](../STYLE-GUIDE.md), [설계](../DESIGN-shorts.md), [학습자 질문](../learner-questions-shorts.md), [사실표](../../research-shorts/FACT-SHEET.md)를 따른다. 신규 원고이므로 이전 분량 대비 70% 비교는 적용하지 않는다.

- [x] 10~14장: 9블록·같은 축별 틀·질문별 직답과 예·행동·FAQ5·정리3·퀴즈3 작성
- [x] 전용 자산 `operations.js`·`operations.css`로 제작 흐름·메타데이터·곡선·정책·날짜별 계획 구현
- [x] 정책·수치를 Y각주와 연결하고, 가상 시간·곡선·계산은 가상으로 표시
- [x] 문체·정적 검사와 브라우저 1280/375/360px·키보드·경계값 검사 완료
- [x] 결과·화면·공통 파일 요청 diff·용어 제안을 보존하고 완료 알림 전송

공통 파일·승인 샘플·조사 자료·프로젝트 상태는 수정하지 않는다. 작성 중 다른 담당자의 Y4a/Y4b/Y4k 산출물이 생겼으며 해당 파일은 건드리지 않는다. 원고 간 이동은 실제 10~14장 파일에 직접 연결한다. 공통 목차의 준비중 연결은 통합 담당자에게 별도로 요청한다. commit·push·실계정 로그인·업로드·유료 호출은 하지 않는다.

## 구현한 학습 도구

- 10장: 대본→녹음→자막→편집→검수→출력. 누락·불일치가 처음 나타난 단계에서 멈추고 기대 입력·수정할 내용을 표시한다.
- 11장: 승인 샘플의 시청자층·AI·음악 분기를 재사용한다. 제목과 직접 그린 장면·설명·필수 표시·공개 범위·예약 시간대의 미결 항목도 함께 센다.
- 12장: 가상 곡선·원자료 표·시점 슬라이더·장면 도식으로 하락/상승 구간을 살핀다. 원인 가설을 선택하면 다음 편 편집안을 제시한다. 데이터 없음에서는 판단을 멈춘다.
- 13장: 재사용·양산형·AI 공개·음악을 독립적으로 판단한다. 조치가 없어도 승인·허가로 표현하지 않는다. 아동용·협찬·지급·세금은 본문과 실습으로 연결한다.
- 14장: 시작일·하루 확보 시간·활동일로 날짜별 30행을 만든다. 검수·메모용 가상 10분을 먼저 뺀 뒤 작업을 순서대로 나눈다. 남은 작업과 점검일·내보낼 메모를 제공한다. 체크는 세션 화면에서만 유지한다.

## 검증 및 남은 사항

공통 목차·완성 상태 반영과 용어집 통합은 별도 담당자 작업이다. 실제 계정 UI·게시·세무 개인 판정은 검증 범위가 아니다.

## 발견과 수정

- 공통 목차의 준비중 링크는 담당 범위 밖이므로 미적용 diff로 남겼다. 공통 데이터를 우회 변경하거나 다른 장의 상태를 완성으로 표시하지 않는다.
- 실제 생성 링크를 따라가며 11장의 AI 설정 메모가 가리키는 `#ai-step` 앵커 누락을 발견했다. 관련 설명에 앵커를 추가한 뒤 전체 브라우저 검사를 통과했다.
- 30일 계획은 다음 작업을 남는 분에 자동으로 당겨 넣지 않는다. 작업별 가상 배정·잔여·여유 분을 보이고 미완료를 남겨, 가상의 완성 속도를 약속하지 않는다.
- 화면 검토에서 공통 CSS가 곡선을 작게 제한하고 모바일 입력을 두 열로 만드는 것을 확인했다. 이 묶음의 전용 CSS에서 곡선 폭과 모바일 한 열 입력을 지정하고 화면 검사를 다시 실행했다.
- 국세청·YouTube의 수익화·업로드·미국 세금 원문을 재열람했다. 본문은 기존 사실표 범위 안에서 작성하며 개인별 세율·사업 유형을 단정하지 않는다.

## 통합 인계와 한계

- [공통 변경 요청 diff](phase-Y4c-requests.md)와 [용어 제안](phase-Y4c-glossary.md)을 작성했다. 공통 목차·완성 상태·용어집·프로젝트 상태·서가 반영은 통합 담당자에게 남긴다. 이번 원고를 직접 열면 읽고 도구를 조작할 수 있다.
- 실제 Windows/macOS·Android/iPhone 앱, 본인 계정 메뉴·권리 판정·게시·지급은 실행하지 않았다. 브라우저 연습은 실제 게시나 정책 승인을 뜻하지 않는다.
- API 잠금과 긴 쇼츠 Content ID의 공식 문서 차이는 확인할 점 상자에 모았다. 학습자는 공식 업로드 경로·제한사항·권리 확인 음원을 통해 다음 행동을 정한다.
- commit·push하지 않았다. 다른 담당자의 산출물·조사 자료·공통 자산을 수정하지 않았다.
