# Phase E-shorts — ShortsBook 예시 전면 교체

2026-10-26. 구현·로컬 검증 완료, Claude Code 검수 대기. [교체 전 목록](phase-E-shorts-before.md), [검증·화면 폴더](phase-E-shorts/)를 함께 본다. 기준은 STYLE-GUIDE 7절의 실제로 만들고 싶은 예시와 6절의 설명에 필요한 시각자료다.

## 바꾼 예시와 이유

가상 채널은 도윤의 **「자취생 10분 생존법」**이다. 세 영상을 섞지 않고 각 영상의 기획→훅 3안→대본→장면표→음성→장면→편집·자막→출력→제목·설명→업로드→지표 해석을 장과 실습 사이에 연결했다.

| 유형 | 끝까지 이어 쓰는 영상 | 조정 이유 |
|---|---|---|
| ② 대표 해설 | **월급날 10분, 돈을 네 칸으로 나누기** | 통장 개설이나 배분 비율 대신 월세·생활비·비상금·목표의 생활 메모로 한정했다. 금액·절약액·수익을 만들지 않았다. 10분은 메모 활동에 잡은 시간이다. |
| ① 직접 촬영 + AI 편집 | **퇴근 후 한 그릇, 간장 계란밥** | 전자레인지 출력·용기·조리 시간을 검증하지 않은 상태에서 “5분”을 약속하지 않았다. 익힌 밥·익힌 달걀·간장을 직접 찍고 완성 그릇으로 끝내는 구성이다. |
| ③ AI 상상 이야기 | **펭귄 택배기사의 하루** | 큰 소포→들기 시도→썰매로 방법 바꾸기→현관 배달의 이야기다. 노란 목도리·청록 가방·크림색 단추·얼굴을 기준 이미지로 맞춘다. 채널의 별도 상상극장 연습으로 구분한다. |

대표 샘플은 36초다. 기존 30초·45초·12초 비교 도구의 숫자와 계산은 유지하고, 같은 소재를 줄이거나 늘리는 연습이라고 설명했다. 실제 금융·요금·영양·성과 주장은 추가하지 않았다. 기존 정책·가격·수익 계산·각주를 유지했다.

## 구현

- `site-shorts/` 이론·실습·표지·프롬프트·모델/비용·실험실·크레딧과 JS 예문을 교체했다. `prompts.html#three-videos`에 세 영상의 훅·확정 대본·장면표·제목·설명을 모았고 각 단계에서 같은 영상으로 연결한다.
- 좋은/나쁜 대본·자동 자막·제목, 자막 속도 극단값, 분석 곡선 시점의 장면 설명도 새 소재로 바꿨다. 네 칸 메모를 설명하는 시뮬레이터의 계산·이벤트·입력 규격은 유지했다.
- V-shorts 도식의 촬영 샷은 계란밥과 손, 자막·편집 영역·압축 비교는 네 칸 메모로 다시 그렸다. 다크 테마에서도 노른자가 읽히도록 색 변수를 추가했다. 자막 좋은 예의 용도 이름은 오른쪽 가림 영역에 닿지 않게 조정했다.
- AI 예시 **6장**을 내장 `image_gen`으로 새로 생성했다. 펭귄 기준 1장+같은 기준 참조 키프레임 3장, 대표 해설 그림 1장, 요리 완성 구도 참고 1장이다. 전부 WebP이며 장당 **48,006~119,672바이트**다. 비례 축소·형식 변환만 했고 생성 원본은 공개 저장소에 넣지 않았다.
- 사용하지 않는 이전 PNG/WebP 5개를 삭제했다. 각 이미지에 AI 생성 고지·의미 있는 alt·실제 사용 프롬프트 링크를 붙였다. `prompts.html#actual-image-prompts`와 `assets/img/ai-examples/y4ai-prompts.json`에 실제 요청 전문·참조 관계·파일 규격을 공개했다. 크레딧·visual-provenance도 맞췄다.
- `shorts-kit/`는 `write_script.example()`의 데이터와 prompts·README·samples를 교체했다. 기본 오프라인 대본과 공개 샘플의 script.json이 같다. 테스트의 이전 예문 검사는 새 자막으로 바꿨고 렌더·승인·OAuth·업로드 로직은 변경하지 않았다.
- 샘플 장면의 자체 도식 원본은 `shorts-kit/samples/create_scenes.py`다. 샘플 재현은 기존 run/validate/render 명령을 그대로 사용한다. 사이트 표지의 동봉 MP4·미리보기·SRT도 같은 결과로 교체했다.

## 한계와 후속 확인

- 공개 샘플은 **의도한 무음 AAC**이며 녹음·TTS 결과가 아니다. 실제 게시물은 본인 음성·내용·권리를 넣고 검수해야 한다. 이미지 6장은 정지 이미지다. Flow/Runway 생성 클립과 실제 요리 촬영을 실행한 것으로 서술하지 않았다.
- 펭귄의 얼굴·목도리·가방은 이어지지만 장면별 소포의 상대 크기와 시간대 빛에는 차이가 있다. 실제 클립 생성 전 검수할 항목으로 캡션에 명시했다.
- `scripts/build_appendices_shorts.py`의 크레딧 템플릿에는 옛 예시가 남는다. scripts는 이번 담당 범위 밖이므로 수정·실행하지 않았다. 부록 재생성 때 이 결과의 새 크레딧과 lab 안내를 먼저 반영해야 한다. 현재 수정한 정적 HTML이 배포 원본이다.
- Claude Code 검수·커밋·배포·실제 휴대폰/서비스 계정의 최종 확인은 남아 있다. 이 작업은 다른 책·키트·research*·서가를 수정하지 않았다. 동시에 진행된 다른 작업의 변경은 보존했다. commit/push·유료 API·로그인·게시를 하지 않았다.

완료 알림은 `scripts/notify.py`로 디스코드에 전송했다(**HTTP 200**). 펭귄 썰매 WebP와 375px 샘플 화면을 첨부했다. `docs/PROJECT_STATE.md`의 쇼츠 현황·샘플·부록 재생성 주의만 갱신하고 다른 작업의 상태는 보존했다.
