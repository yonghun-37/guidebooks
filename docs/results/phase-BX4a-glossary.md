# BX4a 용어집 통합 후보

기존 JSON·API·터미널·AI 토큰·페이지 RPM·가상환경(`venv`)·애플리케이션 비밀번호(`application-password`)·OAuth 항목은 재사용한다. 아래는 심화편 새 항목 후보이며 용어집 공통 파일은 수정하지 않았다. 새 `data-term` 링크는 통합 전까지 만들지 않았다.

| 후보 ID | 용어 | 쉬운 뜻 | 대표 연결 |
|---|---|---|---|
| mock | mock | 외부 서비스의 일부 동작을 내 컴퓨터에서 흉내 내는 연습 방식 | `advanced/01-environment.html#answer` |
| rest-api | REST API | 프로그램이 주소로 요청하고 응답을 받는 통로 | `advanced/02-wordpress.html#server` |
| schema | 스키마 | JSON에 있어야 할 이름과 값의 종류를 정한 규칙 | `advanced/03-topics.html#schema` |
| structured-outputs | 구조화 출력 | 응답이 지정한 JSON 구조를 따르게 하는 기능. 사실 검토는 따로 필요 | `advanced/04-drafts.html#draft` |
| experience-slot | 경험 칸 | AI가 비워 두고 사람이 직접 겪은 내용만 쓰는 자리 | `advanced/04-drafts.html#experience` |
| content-gate | 품질 관문 | 원고·사진·출처·표시·제품 자료를 검사해 다음 행동을 알려 주는 절차 | `advanced/05-gates.html#gate` |
| exif | EXIF | 사진에 붙을 수 있는 위치·기기 등의 부가 정보 | `advanced/05-gates.html#review` |
| sqlite | SQLite | 한 파일에 상태와 기록을 저장하는 데이터베이스 | `advanced/04-drafts.html#experience` |
| approval-hash | 승인 해시 | 승인한 내용이 바뀌었는지 확인하는 지문 같은 값 | `advanced/06-publish.html#approve` |
| post-id | post_id | 서버가 저장한 글에 부여한 번호. 재개할 때 보존 | `advanced/06-publish.html#prepare` |
| wp-cron | WP-Cron | 방문 요청을 계기로 기한이 된 예약 작업을 실행하는 WordPress 기능 | `advanced/06-publish.html#schedule` |
