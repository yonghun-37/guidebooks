# Phase N8 — 육아 편 N7 수정과 최종 로컬 게이트

2026-10-27. 작업자: Codex 단독. 기준은 [설계 12절](../DESIGN-baby.md#12-n7-검토-반영-claude-검수-2026-10-27), [건강 정보 안전 검토](phase-N7-safety.md), [초보 부모 검토](phase-N7-parent.md)다. 원고·도구·그림을 고치고 아래 로컬 게이트를 통과했다. Claude 최종 검수·배포는 별도다.

## 범위와 구현 원칙

- 대상은 `site-baby/`와 그 생성기·검증·육아 조사/설계/상태 문서다. 다른 세 책·kit·서가·배포 설정은 수정하지 않았다. 기존 미추적 `docs/prompts/phase-N8.md`를 보존했다. commit/push하지 않았다.
- 응급 문구는 `assets/emergency-data.js`가 원본이다. `scripts/build_baby_emergency.py`가 장·실습·인쇄의 HTML에 문구·각주·측정부위 주의·③ 상자를 넣는다. 런타임 JS는 이를 덮어쓰지 않는다. `--check`와 단위 테스트가 데이터/HTML 불일치를 검출한다.
- 손 동작은 기존 방식인 직접 그린 인라인 SVG로 구현했다. 모바일 한 칸 배치·접촉 부위 확대·실선/점선 손 구별을 사용한다. 기관 로고·화면 캡처·사진·유료 API는 사용하지 않았다.
- 새 동작·발달·메뉴의 근거는 `research-baby/SOURCES.md` N126~N133과 FACT-SHEET 보완 표에 남겼다. 출처 부록은 실제 인용 **108개**, 용어 **40개**, 도구 **15개**다. 판본 세부의 접근 불가 자료 N079를 다시 확인한 것으로 쓰지 않았다.

## 남은 확인과 제한

- 로컬 수정/게이트 완료이며 출판 승인·실제 배포 완료라고 표시하지 않는다. Claude 최종 검수가 남는다.
- 실제 아기에게 수유·씻기·터미타임 수행, 의료 전문가의 도해 검수, 새 초보 부모의 재현 시험, 기관 로그인·지원 신청·실제 전화 예약·실물 프린터 출력은 실행하지 않았다. 모의 입력/동작 설명과 브라우저 PDF 확인의 범위를 넘겨 주장하지 않는다.
- 공식 사이트 인증 이후의 실제 화면/개인 자격·실시간 진료 수용은 독자가 공식 기관에서 확인한다. 문구가 안 보일 때 JS를 켜라는 응급 대체 안내는 제거했다.

요청한 `python3 scripts/notify.py "✅ [육아 편 수정 완료] ..."` 보고를 실행했고 HTTP 200을 확인했다.
