B8 재생성은 저장소 루트에서 **`python3 docs/results/phase-B8/rebuild.py`**다. 공유 생성기를 그대로 호출한 뒤 웹 README 경로·추가 TXT 메모의 ZIP 포함·CPC 용어 정의를 보정한다. **공유 `build_appendices.py --site site-blog`만 단독 실행하면 이 보정이 덮어써진다.** 담당 밖 공유 생성기·이전 단계 인계 문서를 편집하지 않기 위해 B8 진입점에 모았다. 키트 원고를 고치면 먼저 `python3 blog-kit/render.py samples/article.md --output samples/rendered`와 필요 시 `python3 blog-kit/brief.py --notes samples/info-notes.txt --output samples/brief.md`를 실행한다.

브라우저 재현: 루트에서 `python3 -m http.server 8638 --bind 127.0.0.1`을 열고 위 세 `.mjs`를 Node로 실행한다. 기존 Playwright/Chromium의 경로는 각 파일 머리에 명시되어 있다. `verify-kit.py`는 pytest가 설치된 Python 3.11로 실행하며 원본을 새 임시 폴더에 복사하고 ZIP도 별도로 해제한다. 이번 테스트는 기존 `/tmp/blogbook-b6-py311/bin/python` 환경을 재사용했고 두 키트 작업 폴더를 분리했다. 독립 가상환경 2개를 새로 만들었다는 뜻은 아니다.

남은 확인: Claude Code 최종 검수·커밋·배포, 실제 계정의 가입/AI 생성/발행/검색/광고 신청·정산, Windows/macOS 실기기·실제 예약 등록. 네이버의 개별 광고+제휴 배치 허용은 공식 답변이 필요한 외부 확인 사항이다. 현재 구현·문서의 보류 항목은 없으며, 알려지지 않은 허용 여부를 사실로 만들지 않았다. 새 의존성·아키텍처 변경이 없어 별도 ADR은 만들지 않았다.
