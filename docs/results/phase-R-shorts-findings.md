# ShortsBook 초보자 독립 검토

검토일: 2026-10-26. 검토자: Codex. 코딩·마케팅·영상 편집 경험이 없는 직장인에게 **오늘 첫 콘텐츠를 만들고 게시할 다음 행동이 명확한가**를 기준으로 읽었다. 작성자의 기존 통과 판정을 채점 근거로 사용하지 않았다.

## 핵심 판정

**부분 충족, 전체 통과 보류. 차단 1건·혼란 6건·사소 2건.**

PC의 기본 무료 경로는 지시상 이어진다. ChatGPT 새 채팅 → 검수한 `script.txt` → 본인 녹음·촬영 → Clipchamp의 9:16 프로젝트·분할·자동 자막 → `exports/short.mp4` → Studio 업로드·공개·주소 확인까지 안내가 있다. 생성 한도에 막히면 본인 촬영·녹음으로 돌아갈 수도 있다.

그러나 **휴대폰만 가진 독자의 필수 편집 절차**, **AI 생성형의 한 편으로 연결되는 입력 예**, **비현실적 AI 장면의 설정 연습**은 보완이 필요하다. 특히 모바일 경로는 필요한 조작 메뉴를 독자가 다른 도움말에서 찾아야 한다. “모든 유형·기기에서 이 책만 따라 오늘 게시할 수 있다”는 판정은 내리지 않는다.

이 판정은 **안내의 구체성과 로컬 실행 결과**에 관한 것이다. 외부 서비스에 로그인하지 않았고, ChatGPT 무료 계정·Vrew·Flow·Runway·Clipchamp·Create의 실계정 실행이나 실제 YouTube 공개 성공을 검증한 것은 아니다.

## 키트·프롬프트 실제 실행

### 깨끗한 키트 복사본

README 순서의 핵심 명령을 다음과 같이 실행했다. `python`은 모두 새 `.venv/bin/python`으로 바꿨다.

| 실제 실행 | 실제 결과 |
|---|---|
| `python3 -m venv .venv`, pip로 `requirements.txt` 설치, `run_pipeline.py run --output output/first` | 설치·생성 성공. 안내대로 `영상 생성 완료`, `검수 대기`, `미리보기`와 파일 경로 출력 |
| `run_pipeline.py run --mode prompt --output output/my-script` | `prompt.md` 생성. 이 시점에 `script.json`이 없는 것은 응답을 저장해야 하는 정상 절차 |
| 생성된 프롬프트의 형식으로 Codex가 JSON 작성·저장 → `validate output/my-script` → `render output/my-script` | 형식 검사·36초 MP4·SRT·미리보기 생성 성공. [응답과 실행 범위](phase-R-shorts/llm-prompt-response.json). 별도 ChatGPT 소비자 계정에서 실행한 것이 아니며 낭독 길이 보장은 검증하지 않음 |
| README대로 `config.example.yaml`을 복사·수정 → `render output/my-script --config config.yaml` → `render output/my-script` | 자체 도형 PNG 3장과 36초 AAC 시험 신호를 연결. 두 명령 모두 성공. 결과 설정 사본 사용도 확인. 실제 사람 음성·TTS·ASR 검증은 아님 |
| 체크하지 않은 `REVIEW.md`로 `approve` | 안내대로 여섯 칸 확인 요구로 거부 |
| 여섯 칸을 체크하되 아동용·AI 값을 `null`로 유지한 `approve` | 안내대로 미결정 공개 판단을 거부 |
| 두 값을 검토용 자료에 맞게 결정 → `render` → 시험자료 검수·여섯 칸 체크 → `approve`, `upload.py output/my-script` | 승인 파일·드라이런 생성. `mode: dry-run`, `network_calls: 0`, `privacyStatus: private` 확인. 실제 전송 없음 |
| `daily.py --date 2026-10-26 --output-root output/daily` | 날짜별 MP4·검수 목록 생성. 자동 승인·업로드하지 않음 |
| `schedule_setup.py --os windows --time 09:30`, `--os macos --time 09:30` | 등록·확인·수동 실행·삭제 안내 생성. OS 예약 작업 자체는 등록하지 않음 |
| `requirements-dev.txt` 설치 → `python -m pytest` | **38 passed in 7.92s** |

첫 영상과 내 JSON 영상은 브라우저에서 실제 MP4 재생을 시작했고 둘 다 **36초·1080×1920**으로 읽혔다. 후자는 생성 정보에서 **H.264·30fps·AAC·경고 없음**도 확인했다. [재생 화면](phase-R-shorts/kit-my-script-1280.png).

기본 Python HTTP 서버에서는 장면 탐색 버튼이 비활성 상태였다. README에 이미 안내된 대로 `preview.html`을 파일로 직접 열자 **두 번째 장면 12초 이동, 다음 프레임 12.033333초, 반복·안전 영역 체크**가 동작했다. 대안이 실제 작동하므로 신규 차단 건으로 세지 않았다. [조작 결과](phase-R-shorts/media-controls.json).

`--mode api --allow-api`, `oauth_setup.py`, `upload.py --live`는 외부 인증·사용자 계정·API 이용이 필요해 실행하지 않았다. Windows/macOS 예약 명령의 실등록과 실제 게시도 검증 범위 밖이다.

### 이미지·복사 프롬프트

실습 5의 **한국어 기준 이미지 프롬프트를 보강 없이 그대로** 내장 `image_gen`에 한 번 실행했다. [원문·판정](phase-R-shorts/image-check.json), [생성 PNG](phase-R-shorts/prompt-image.png).

- 초록 종이 로봇 왼쪽·갈색 화분 오른쪽·왼쪽 아침빛·상단 제목 공간을 확인했다. 글자·숫자·로고·실존 인물은 보이지 않는다.
- 배경 식물·책 등 요청하지 않은 소품은 추가됐다. 결과는 콘텐츠 장면으로 쓸 수 있으나 다음 샷의 참조로 고정하고 불필요한 소품을 검수해야 한다.
- 파일은 **941×1672 PNG**, 약 9:16이다. 정확한 최종 출력 비율은 편집기에서 맞춰야 한다. 본문도 실제 치수 확인을 요구한다.
- 책의 기존 기준 그림·관찰 그림 두 장도 열어 외형·색·화분·빛의 연속성을 확인했다. 정지 이미지이며 실제 생성 영상으로 판정하지 않았다.
- 부록의 독자용 10개와 실제 이미지 생성 원문 2개, 합계 **12개 복사 버튼**을 실제 클립보드로 시험했다. 이미지 외 LLM 프롬프트는 입력·출력 구조를 읽었으며, 키트 JSON 형식 응답 작성·검사 외에 별도 외부 모델 호출 품질 실험을 했다고 주장하지 않는다. TTS 발음·영상 생성 품질·무료 서비스 한도는 미검증이다.
