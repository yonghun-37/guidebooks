## 검토 중 수정과 한계

A7/A8 실행 결과 제목의 일본어 잔재를 한국어로 고쳤고, A10 보고서 구역 수를 네 구역으로 맞췄다. E2E의 좁은 별도 검토에서 설정 파일 생성 누락과 긴 메모 인쇄 잘림을 발견했다. 예제 설정 복사 순서를 추가했고, 메모 보관은 전체 내용을 개인 메모로 옮기도록 고쳤다. 인쇄로 긴 입력 내용 보존을 약속하지 않는다. 또한 360px 진행표에서 공통 고정 열 서식과 체크/입력 최소 폭이 충돌해 셀 내용이 겹치는 것을 직접 확인했다. 전용 표 최소 폭과 가로 스크롤 안내를 추가하고 셀 침범0·방향키 스크롤 검사를 추가했다. 수정 후 본문·명령·브라우저 검사를 다시 수행했다.

정책·API·법률은 기존 BRIEFING·FACT-SHEET·SOURCES·노트와 공식 원문 재열람을 사용했다. Google 자격/광고 위치/ads.txt/CMP, 쿠팡 가이드, 현행 공정위 지침, GA4/GSC API, Actions schedule, Google 스팸, 국세청 원고료/등록/신고 등을 대조했다. 이번 재열람에 실패한 식품 별표/네이버 약관·공공누리·고용보험 시행규칙의 일부 URL은 기존 BX 조사 확인 범위를 사용했다. 새로 직접 열었다고 표시하지 않았다. 모든 정책은 장 머리 기준월 한 번, 문장 끝 BX 각주·장 끝 공식 링크로 제시한다.

실행 환경은 Linux/Python3.11.15/Chromium이다. Windows·macOS 실기기, OS 실제 예약 등록·다음날 실행·절전, Docker/실제 호스팅, GA4/GSC/광고/제휴 실인증, 외부 알림 수신, 실제 WordPress DB+uploads 복구, 광고 심사·노출·입금, 세금 신고는 이 단계에서 실행하지 않았다. 실제 서비스 연결은 선택 과제로 남겼다. 건강·협찬·제휴·아이 정보·갱신 글의 무응답 자동 승인은 제공하지 않는다.
