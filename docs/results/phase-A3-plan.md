# 인스타 심화편 집필·구현 계획

목표: 확정된 [설계](../DESIGN-advanced.md)와 [문체](../STYLE-GUIDE.md)에 따라 API 전자동 운영을 배우는 A0~A9·E2E를 작성한다. 기존 정적 HTML·CSS·바닐라 JS를 재사용한다. 사용자가 집필 실행과 공통 연결의 최소 변경을 명시했으므로 설계 재승인·별도 샘플 선택·커밋은 하지 않는다.

## 범위와 작업

- [x] 조사·설계·질문·기존 사이트·auto-kit 코드 읽기, 임시 복사본 mock 실행.
- [x] `site/advanced/00-start.html`~`09-safety.html`·`e2e.html`: 질문 5개·직답·명령·실출력·오류·비용·확인할 점·도식·퀴즈.
- [x] `site/assets/advanced.css`·`advanced.js`: 반응형 도식, 비용 계산, 독립 진행 저장. 공통 OS 탭·퀴즈·테마 재사용.
- [x] `site/assets/book.js`·`index.html`·`glossary.html`·`credits.html`·`practice.js`: 세 번째 트랙·용어·A출처만 연결.

- [x] 결과·스크린샷·실환경 한계 기록, 지정 Discord 완료 보고.

## 구현 판단·검토 초점

- 가상 계정 「출근길 3분 생활 뉴스」의 「청년 지원금, 신청 전 확인할 3가지」를 관통 예시로 사용한다. 실제 공고 사실을 만들지 않는다.
- 비용은 조사 가정과 실행 예약 상한을 구분한다. 실제 키트의 이미지 옵션은 장면마다 생성하므로 조사 비교안의 배경 1장 비용을 실제 옵션 전체 비용으로 쓰지 않는다.
- 사후 확인은 인스타 로컬 대기 후 발행이며 예약 시각 tick이 있어야 한다. 전자동 승격은 사람이 설정을 바꾸는 편집 운영안이다.
- 결과 불명은 새 게시 금지, 기존 ID 대조. `exception`은 승인 우회 금지. 드라이런을 live로 승격하지 않는다.
- 터미널 명령은 auto-kit cwd·Python 3.11+·독립 --state를 명시한다. Windows/macOS 실기기는 미실행으로 결과에 남긴다.
- 체크리스트는 `reelsbook:advanced:v1`에만 저장하고 손상/차단에도 읽기·체크를 유지한다.
- 다른 책·키트·research·공통 상태/서가 문서는 수정하지 않는다. 상태 반영 요청은 A3 결과에 남긴다.

검증: 비용 계산의 빈값/음수/극단값, 실제 명령 출력, A출처 대응을 별도 검사한다. `style_lint.py site/advanced/*.html`·`check_site.py --site site` 후 Chromium으로 1280/375/360px·light/dark를 검사한다. 기존 검사기가 A출처를 다루지 않는 점은 결과에 명시하고 A출처 독립 검사를 함께 실행한다.
