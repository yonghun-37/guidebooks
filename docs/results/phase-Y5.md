# Y5 — ShortsBook 통합

## 요구와 구현 계획

[요청](../prompts/phase-Y5.md)·[설계](../DESIGN-shorts.md)·[AI 제작 기준](../DESIGN.md#12-ai-제작-핵심-모듈-사용자-지적-2026-10-26-두-책-공통최우선)·[문체](../STYLE-GUIDE.md)와 Y4a/b/c/k/p/ai 인계 문서를 따른다. 기존 단계 결과 기록을 기능 기록으로 재사용한다.

- [x] 공통 목차를 이론 1~15·실험실·용어집, 실습 0~10·E2E, 부록 3개로 통합한다. 도구 지도를 3장으로 넣고 slug를 보존하며 본문·퀴즈·이동 번호를 대조한다.
- [x] 원본 도구를 iframe으로 재사용하는 실험실, 중복을 합친 용어집·첫 사용 링크, 실제 인용 Y번호만 모은 출처를 재생성한다.
- [x] 표지의 AI 제작 진입·질문별 경로·실습 시작·키트 샘플 미리보기를 연결한다.
- [x] 정적·문체·1280/375/360px·라이트/다크·키보드·콘솔·키트 pytest를 실행하고 결과·스크린샷을 보존한다.
- [x] 프로젝트 상태를 실제 구현과 맞추고 표지 화면을 첨부해 지정 알림을 전송한다.

구현은 기존 정적 HTML/CSS/바닐라 JS·로컬 저장 규칙을 유지한다. 생성기는 `scripts/build_appendices.py --site site-shorts`로 명시적으로 선택하며 ReelsBook의 기본 생성 동작을 보존한다. 용어·출처는 인계 표와 현재 원고에서 읽고 계산 로직은 복제하지 않는다.

**검증 초점:** 새 3장 앞뒤 이동·숫자와 slug의 일치, 이미지 수/fps와 장 번호의 구별, 용어 앵커와 인증/AI 토큰의 의미 구별, 실제 인용만 포함한 출처, 임베드의 모든 도구·테마·키보드·높이, 저장 차단·JS 없는 읽기, 샘플의 실제 재생과 배포 내부 경로.

범위: `site-shorts/`, 관련 생성기·검증 및 이 결과·프로젝트 상태. `site/`·`shelf/`·다른 작업자의 프롬프트는 수정하지 않는다. commit/push·유료 호출·실계정 게시를 하지 않는다. 서가 상태 갱신은 사용자의 수정 금지 지시 때문에 이 단계에서 제외한다.


## 구현 결과

- **목차·번호:** AI 도구 지도를 3장으로 넣어 기존 3~14장을 4~15장으로 옮겼다. 파일 slug·도구 ID를 유지했다. 이론 15장·실험실·용어집, 실습 0~10·E2E, 부록 3개 모두 `완성` 상태와 실제 파일을 사용한다. 이전 준비중 URL은 실제 장으로 연결된다. 번호를 적은 본문·정적 이동·퀴즈 해설도 대조했다.
- **공통 요청:** `book.js`가 상태·장 정보·이전/다음·목차·출처 진입을 관리한다. `operations.js`의 임시 제목 우회를 제거했다. `book.css`는 표지 진입·키트·실험 선택과 화면 안 용어 설명을 보강했다. `common.js`의 쓰지 않는 과거 책 시나리오 안내를 쇼츠 문맥으로 바꿨다. `practice.js`는 기존 체크·주소·OS 탭 구현을 그대로 재사용하며 E2E에 전체 기록·주소 삭제 버튼을 연결했다.
- **실험실:** 이론 15장의 그림·도구 31개를 현재 HTML에서 찾아 원본 장을 iframe으로 불러온다. 계산·도구 HTML을 복제하지 않는다. 선택한 도구 공유 URL·원본 링크·자동 높이·테마 전달·JS 없는 전체 목록을 제공한다. 임베드에서 숨긴 설명·각주로 향하는 링크는 전체 장의 목적지를 연다.
- **용어집·출처:** Y4a/b/c/k/p/ai 요청을 48개 용어로 합쳤고 본문 첫 사용 43개를 `data-term`과 동일 앵커로 연결했다. 로그인 토큰과 AI 비용 단위 MTok, fps와 프레임, 모델과 서비스를 구분했다. 출처는 장·실습·AI 부록의 실제 각주 링크에서 Y번호를 모아 중복 없이 299개와 역링크를 제공한다. 연구 출처에 있던 내부 조사자 표기는 공개 날짜에서 제거했다.
- **표지:** ‘영상 제작에 집중한 쇼츠 입문서’, AI 도구 지도·세 레시피·비용 총정리, 실습 시작·질문별 짧은 경로·프롬프트·전체 목차를 연결했다. `shorts-kit/samples`의 MP4·SRT·미리보기 원본 3개를 사이트 내부에 복사해 `/shorts/` 배포 경로에서도 재생한다. 키트 MIT·글꼴 OFL을 함께 제공한다.
- **조사 인계:** Y4b의 인코딩 설정 보충은 기존 Y003 확인 기록을 YT-090으로 옮겼다. 자동 자막/SRT 보충은 같은 내용을 다루는 기존 YT-AIP-035에 Y066을 합쳐 중복 행을 만들지 않았다. 새 웹 조사나 앱 실행으로 기록하지 않았다.
- **생성기:** `scripts/build_appendices_shorts.py`가 쇼츠 생성 로직을 맡고 기존 `build_appendices.py --site site-shorts`에서 호출한다. 기본 ReelsBook 경로는 다른 작업자의 변경을 보존한다. 새 의존성·아키텍처 변경·ADR을 추가하지 않았다.

## 발견과 수정

1. 정의 툴팁의 숨긴 절대 위치 상자가 1280px 화면의 오른쪽을 4px 넓혔다. 화면 안 고정 위치를 사용해 가로 넘침을 없앴다.
2. 새 도구 지도의 `data-chapter`가 없어 장 제목·현재 장 정보가 적용되지 않았다. 공통 장 식별자를 넣었다.
3. 제작 7~10장에는 기존 묶음 이동 버튼만 있고 이전/다음 공통 pager가 없었다. 정적 대체 링크와 공통 pager를 추가하고 JS 없는 장 번호도 맞췄다.
4. 임베드에서 경로·축 링크가 숨긴 다른 절로 이동했다. 해당 장의 전체 문서로 이동하도록 바꾸고 실제 레시피 이동을 회귀 검사했다.
5. E2E에 기존 저장 구현을 호출할 삭제 버튼이 없었다. 전체 체크·주소를 삭제하는 버튼을 추가하고 복원·삭제를 검사했다.

별도 읽기 전용 리뷰에서 2~4번을 대조했다. 리뷰는 격리 복사본에서 생성기를 두 번 실행해 현재 산출물과 차이 없음을 확인했다. 구현자가 최종 게이트에서 수정 후 회귀를 확인했다. 테스트 스크립트의 ‘준비’ 부분 문자열·OS 탭이 없는 페이지 선택은 검사 오류였으며 실제 페이지 제목과 탭 위치에 맞게 고쳤다.

## 문서와 남은 확인

- `docs/PROJECT_STATE.md`의 쇼츠 항목을 통합·검증 완료로 갱신했다. 다른 담당자가 갱신한 ReelsBook 상태는 보존했다. `shelf/` 수정 금지에 따라 진행 페이지는 갱신하지 않았다.
- Claude Code 최종 검수·독립 초보자 검토·커밋·배포가 남는다. Codex는 commit/push하지 않았다.
- Windows/macOS·모바일 실기기, 실제 한국 서비스 계정의 메뉴·무료 제공·TTS/영상 생성, 실제 OAuth·업로드·공개·권리 판단·지표 관찰은 실행하지 않았다. 검증은 Linux·Chromium·로컬/오프라인·모킹 범위다. 새 유료 API·결제·실계정 로그인/게시를 하지 않았다.

재현 명령은 [commands.md](phase-Y5/commands.md)에 있다.
