# Phase A3 결과 — ReelsBook API 전자동 심화편

2026-10-26 · Codex. **A0~A9·전체 진행표 집필·구현과 로컬 검증 완료. Claude Code 검수·A5 초보자 검토 및 사용자 실계정 검증 대기.**

## 구현 결과

- [시작 장](../../site/advanced/00-start.html)부터 [전체 진행표](../../site/advanced/e2e.html)까지 11페이지를 작성했다. 가상 계정 「출근길 3분 생활 뉴스」의 「청년 지원금, 신청 전 확인할 3가지」를 원문→RSS→JSON 문안→카드/릴스→관문→게시→지표로 연결한다. 실제 제도명·금액·마감일·성과를 만들지 않았다.
- 각 장에 직답·만드는 것·축별 설명과 할 일·Windows/macOS 명령·실제 mock 성공 표시·오류 해결표·날짜 있는 편당/월 비용 상자·확인할 점·FAQ 5개·정리·퀴즈 3개를 넣었다. 지정 학습자 질문 50개를 본문·FAQ·연결 절에서 다룬다. 화면 편집 웹 도구 조작은 넣지 않았다.
- 플랫폼 설명은 Instagram Login을 기본으로 한다. Facebook/Unified 비교, 계정·앱·권한·토큰, 공개 JPEG/MP4 URL, 한도 계정 조회, 자식 처리→부모 발행, 컨테이너/게시 ID 차이, 결과 불명 조회·reconcile, 로그인별 AI/협찬/음악 기능을 구분했다. 실제 live 명령은 본인의 준비 후 실행하는 별도 절에 두었다.
- 전자동 목표와 승인제→사후 확인→전자동 전환을 명시했다. 최근 10편 중 9편 통과·미해결 예외 0건, 이어지는 10편 전부 통과·거부/중복/사실 오류 0건은 **편집 권장 운영 기준**이다. 자동 승격 기능·플랫폼 안전 보장값으로 쓰지 않았다. 인스타 사후 확인은 기본 2시간 로컬 대기 후 다음 tick 발행이다.
- 클릭 가능한 전체 파이프라인, 실패 재개·예외·불명 상태도, 폴더 구조, 키/비용 흐름, 비용 계산·상한 막대, 실제 렌더 카드, 직접 그린 콘솔 위치, API 시퀀스, 가상 한도 게이지, 검사별 예외 분기, 실행 방식 선택, 하루 타임라인, 대시보드·알림 예, 분석 반복 고리를 구현했다. SVG/HTML은 공통 테마 변수를 사용한다. 개발자 콘솔 캡처는 없다.
- 비용 계산기는 공급자·편수·입출력 토큰·이미지 수·추가 생성 여유·상한을 비교한다. 조사 가정과 실제 요청 예약액을 구분했다. 특히 조사 비교안의 AI 배경 1장 재사용과 **현재 키트의 장면별 이미지 생성**을 구분해 5장 옵션 비용을 별도로 계산했다.
- `advanced.js`는 비용 계산과 `reelsbook:advanced:v1` 진행 기록만 맡는다. E2E는 mock·문서상 요건·사용자 실제 계정 확인을 나눠 체크한다. 기존 실습 저장 키를 수정하지 않는다.
- 공통 변경은 `book.js`의 세 번째 트랙·장 이동, 표지 진입/목차, 용어 7개, 실제 인용 A출처 62개와 제작 크레딧 연결뿐이다. `practice.js`는 OS 탭만 사용하는 심화편에서 기존 실습 저장 키를 생성·재작성하지 않도록 입력이 없는 경우의 종료 조건만 추가했다. `book.css`·`common.js`는 수정하지 않았다.

## 검토와 수정

별도 읽기 전용 검토에서 Important 2건을 확인해 수정했다. 완료에서 실패로 이어지던 상태도는 제작 단계 실패/연기→재개, 관문→예외, 발행→결과 불명으로 다시 연결했다. A9에는 지정 질문인 템플릿 반복과 수익화, API/AI 표시의 도달 영향에 대한 직답·예·확인 행동을 복구했다. FAQ 해시 펼침 클래스와 R2용 live 의존성 설치도 점검했다. 마지막 저장소 검사에서 공통 practice.js가 탭만 사용하는 페이지에도 빈 실습 키를 쓰는 것을 재현해, 실습 입력이 없는 경우에만 저장 로직을 건너뛰도록 고쳤다. 신규 심화 방문의 키 생성 없음·기존 유효 실습 기록 보존을 회귀 검사에 추가했다. 수정 후 정적·문체·브라우저 검사를 다시 통과했다. 이 검토는 A5의 실제 초보자 따라 하기 검수를 대신하지 않는다.

## 범위·남은 확인

- 작업한 파일은 `site/advanced/`, 전용 assets/img, 공통 연결 파일 5개, A3 계획/결과/검증 기록뿐이다. 시작 시 Git은 깨끗했으며 작업 중 나타난 다른 책·키트·research·스크립트·서가 변경은 다른 작업자의 것으로 보존했다. 이를 되돌리거나 커밋하지 않았다.
- 실계정 로그인·토큰 발급/갱신·Instagram 실제 limit 응답·공개 URL의 Meta 수신·게시 가시성·AI 라벨·실제 분석, 유료 생성/청구, OS 다음 날·절전·Actions/R2 실제 복원·알림 승인은 미실행이다. 본문 E2E에서 사용자 확인 항목으로 남겼다.
- 관문의 문자열·유사도·Boolean 검사는 문맥·권리·표시 판단의 완전 검증이 아니다. 전자동에서도 주간 표본 점검·예외 처리가 필요하다.
- 공통 상태·서가 문서는 통합 작업자 소유라 수정하지 않았다. **통합 시 PROJECT_STATE와 서가에 A2 mock/모킹 완료, A3 집필·로컬 게이트 완료, A5·Claude 검수 및 실계정 확인 대기를 반영해야 한다.**
- commit/push·배포는 하지 않았다. 새 키 사용·결제도 하지 않았다.
