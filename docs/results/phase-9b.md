## 바뀐 내용과 근거

- **5장**: 공식 기관에서 찾는 시작 예, 게시물에 쓸 출처 문구, 원문 대조·오류 발견 뒤 행동을 앞세웠다. `R2-LAW-01~02`에 따라 고정 인용 비율·문장 수로 허용을 판단하지 않도록 쓰고, 대법원 97도2227(S212)의 시장 대체 판단을 추가했다. 공공누리 조건(S128)·법률(S010)·기사와 사진 구분(S080) 각주를 유지했다.
- **6장**: 지시문의 순서, 카드/영상 문장 차이, 딱딱한 한국어 전후 비교를 넣었다. 현재 copy.json 전체를 함께 주고 필드·출처를 보존하도록 했다. 외부 AI가 없는 offline, 지시문만 만드는 prompt, 선택 API를 구분했다. `R2-LABEL-01`의 ‘AI 레이블 추가’(S183)를 반영했다.
- **7장**: 첫 카드 질문과 본문 points 수정 행동을 분명히 했다. 합성 예제의 크기·장수는 동봉 파일 각주, 글자 수·크기·줄 수는 가상 모형 계산식으로 구분했다. `R2-PUB-01`의 ‘여러 항목 선택’·최대 20개(S068), 수익화 형식 제한(S012)을 반영했다. 일반 글자 대비 4.5:1·큰 글자 3:1의 범위를 유지했다(S121).
- **8장**: 무음→시간 배분→권리 순서로 묶고 첫 장면의 전후 문구를 추가했다. `R2-PUB-02~03`의 Android 보이스오버 메뉴(S244), `R2-LABEL-01`의 AI 레이블 추가(S183)를 반영했다. `R2-POLICY-01~02`의 공식 한국어 금지 형식 네 가지와 브랜디드 도구의 정책 준수를 명시했다(S012·S240). 한국어 메뉴의 문서 근거를 실기기 성공으로 쓰지 않았다.
- **9장**: 카드 넘침·문안 형식·음원 경로·게시 응답 유실의 재개 표를 만들었다. 로컬 승인 무효화와 원격 게시 상태 확인을 구분했다. `R2-RISK-01`의 반복 게시 스팸 위험(S220)을 반영했다. 노코드 공개 조합의 빠진 작업과 Make credits(S044·S153)를 설명하고 가상 월 비용 계산식을 공개했다.

사실은 [FACT-SHEET](../../research/FACT-SHEET.md)와 [재조사 결과](phase-1c.md)에 있는 범위만 사용했다. 이번에는 S212의 공식 판결과 S121의 W3C 해설을 직접 다시 열었다. 새 정책 사실을 만들거나 공유 연구 파일을 수정하지 않았다.

## 도구와 퀴즈

| 장 | 남긴 도구 | 결과 형태 |
|---|---|---|
| 5 | 원자료·사실·이용 근거 기록 개수 | 숫자 하나 + 비어 있는 기록부터 채우기 |
| 6 | 자료·추가 금지·대조 준비 개수 | 숫자 하나 + 원문과 다시 대조하기 |
| 7 | 가상 본문 줄 수 | 숫자 하나 + 휴대폰에서 읽거나 문장 나누기 |
| 8 | 가상 자막 글자/초 | 숫자 하나 + 직접 읽고 빠르면 줄이기 |
| 9 | 가상 한 달 외부 서비스 비용 | 숫자 하나 + 포함한 비용의 해석 |

각 도구는 계산식·가정값과 기본값/극단값 버튼을 갖춘다. range 입력은 현재 값을 표시한다. 기존 전용 JS(`ch05.js`, `ch6-writing.js`, `ch7-cards.js`, `ch8-reels.js`, `ch9-pipeline.js`)는 SHA256 변화 없이 남기고 장의 연결만 끊었다. 새 도구는 각 장의 인라인 JS다. 퀴즈 15문항의 정답·해설·텍스트 정답을 새 본문과 대조했다.

## 남은 통합 작업과 제약

- [공통 파일 요청 diff](phase-9b-requests.md): book.js의 5·6·9장 결과물 메타데이터, catalog.js의 실험실 목록 제목을 새 내용과 맞춰야 한다. 기존 embed는 정상 동작한다. 담당 파일 제한에 따라 이 공통 데이터는 직접 수정하지 않았다.
- PROJECT_STATE·진행 현황·출처 부록 재생성은 통합 작업자 소관이다. 기존 각주 주소는 ‘함께 읽을 자료’에 유지해 부록 링크를 보존했다. book.css·book.js·common.js는 시작 시 해시와 동일하다. 다른 작업자의 원고·실습·문서 변경을 건드리지 않았다.
- 실제 계정별 UI 배치·AI 표시 결과·게시/수익화 심사와 지급, 실제 초보자의 독립 따라 하기는 검증 범위 밖이다. 출처의 개별 사안 적용 한계는 유지한다. 작성자 채점은 독립 검수를 대신하지 않는다.
- 커밋·푸시·배포하지 않았다.
