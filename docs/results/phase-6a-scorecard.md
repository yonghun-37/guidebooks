# Phase 6a · 독립 독자 점수표

검토일: 2026-10-26. 기준: `docs/STYLE-GUIDE.md` 5절과 `docs/learner-questions.md`의 질문 **목록**. 기존 작성자 점수·답함/부분 판정은 채택하지 않았다. 현 브라우저 본문·FAQ·조작 결과를 읽은 독립 판정이다.

**문체 기준 통과와 책의 최종 성공은 다른 판정이다.** 이론 14장은 아래 문체 기준을 만족하지만 [검토 결과](phase-6a-findings.md)의 차단 1·혼란 12·사소 2 때문에 전체 독자 게이트는 보류한다.

## 채점 규칙

- C1: 질문마다 D(첫 문장 직답)·E(숫자 또는 구체적인 예)·A(독자가 할 일)를 각각 1점으로 세었다. 세 요소가 있어야 답함(3/3)이다. 2점 이하는 부분/안 함이며 해당 장 C1은 0점이다. 절 링크로 이어지는 실제 설명도 읽었다. 질문 다섯 개가 전부 3점이어야 C1 1점을 준다.
- C2: 금지어·내부 용어 0. C3: 상자 밖 지정 단서 표현 2회 이하. C4: 축별 설명/실습 단계가 같은 틀. C5: 이론 분량 70% 이하. C6: 숫자의 각주·예제/가상 표시와 정책 근거 연결. C7: 처음 읽는 역할에서 3분 안에 첫 행동을 정할 수 있는가.
- C7은 비전공자 역할의 검토 판단이며 실제 사람 대상 3분 사용성 실험은 아니다. C6은 인용 여부·관련성 판정이다. 모든 정책의 현행 원문·국가·실계정 적용을 새로 실증했다는 점수가 아니다.
- 적용되지 않는 기준은 N/A이며 점수 분모에서 뺐다. 하나라도 적용 기준 0이면 문체 불통과다. 조작 공백은 문체 점수와 별도 findings에서 관리한다.
