# B4c 용어집 통합 요청

공통 용어집은 수정하지 않았다. 기존 UV·PV·페이지 RPM은 유지하고 아래 항목을 병합한다. 본문은 용어를 처음 쓴 자리에서 풀어 설명하므로 이 요청 적용 전에도 읽을 수 있다.

| 제안 ID | 용어 | 학습자용 설명 | 처음 설명한 곳·근거 |
|---|---|---|---|
| template | 템플릿 | 매번 바뀌지 않는 질문과 빈칸을 저장한 글쓰기 양식입니다. 자료와 직접 경험은 새로 채웁니다. | `chapters/10-automation.html#templates` |
| schedule | 예약 발행 | 사람이 완성한 글을 정한 시각에 공개하도록 맡기는 기능입니다. | `chapters/10-automation.html#schedule` · B002/B170 |
| api | API | 프로그램이 정해진 방식으로 서비스에 요청을 보내는 통로입니다. 글쓰기 권한과 인증이 필요합니다. | `chapters/10-automation.html#api` · B012/B010 |
| oauth | OAuth | 사용자가 동의한 권한으로 프로그램이 서비스에 접근하게 하는 인증 방식입니다. | `chapters/10-automation.html#api` · B014 |
| token | 인증 토큰 | 사용자가 동의한 권한을 증명하는 비밀값입니다. 초안·명령줄·공유 파일에 적지 않습니다. | `chapters/10-automation.html#api` · B014 |
| application-password | 애플리케이션 비밀번호 | WordPress 사용자 프로필에서 만드는 도구 전용 비밀번호입니다. 주 로그인 비밀번호와 다릅니다. | `chapters/10-automation.html#api` · B011 |
| dry-run | 드라이런 | 서버로 보내지 않고 요청 내용만 보여 주는 실행 연습입니다. | `chapters/10-automation.html#kit` · 실제 blog-kit |
| visit | 방문수·세션 | 사용자가 찾아온 한 방문 묶음의 수입니다. 묶는 방법은 통계 도구의 정의를 따릅니다. | `chapters/11-analytics.html#visits` · research-blog/06-keywords-analytics |
| search-ctr | 검색 클릭률(CTR) | 같은 기간의 검색 클릭을 검색 노출로 나누고 100을 곱한 비율입니다. 광고 클릭률과 구분합니다. | `chapters/11-analytics.html#search` · research-blog/06-keywords-analytics·14-operating-plan |
| cpc | CPC | 광고 클릭당 비용·보고 단가입니다. 광고주의 입찰가를 내 광고 수입으로 바꾸지 않습니다. | `chapters/11-analytics.html#money` · B054 |
| disclosure | 광고 관계 표시 | 제품·원고료·제휴 수수료 등 글에 영향을 줄 수 있는 관계를 독자가 알아보게 적는 일입니다. | `chapters/12-policy.html#disclosure` · B037 |
| withholding | 원천징수 | 돈을 주는 쪽이 지급할 때 세금을 미리 공제하는 방식입니다. 최종 신고 여부는 따로 확인합니다. | `chapters/12-policy.html#tax` · B152/B153 |

프롬프트의 API 토큰과 AI 사용량 단위인 토큰을 같은 항목으로 합치지 않는다. 공통 파일 반영 시 첫 사용 링크를 붙이고 전체 앵커 검사를 다시 수행한다.
