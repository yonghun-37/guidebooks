대표 결과는 숫자 하나와 해석 한 문장이다. 입력값·가정식·상태 기록은 결과와 구분해 보여 준다. 숫자는 가상 연습값이며 정책 숫자를 새로 만들지 않았다. 기존 각주·조사 기준월은 유지했다.

## 접근성과 화면 배치

모든 선택은 네이티브 버튼/셀렉트이며 `aria-pressed`, 선택 옵션, 게시 단계의 `aria-current`를 반영한다. 그림을 눌러야만 바꿀 수 있는 값은 없다. 시간·크기에는 숫자 입력, 시간 탐색에는 프레임 앞뒤 버튼을 제공한다. 별도 드래그 전용 경로는 넣지 않았다. 결과는 `aria-live=polite`·`aria-atomic=true`이고, 증거 단서와 재생 상태도 문장으로 알린다. 재생 헤드는 매 프레임 음성 알림을 내지 않는다.

360px에서 도구 제목부터 대표 결과의 끝까지 R01 약 **522px**, R02 **720px**, R03 **614px**, R04 **501px**, R05 **430px**다. 카드 미리보기는 모바일에서 가로 264px로 크게 두었다. 세부 시간·크기·증거 로그·수정 행동은 펼쳐 보며, 모든 설정이 한 화면에 들어간다고 주장하지 않는다. 측정 뷰포트 높이는 850px이다.

재생은 사용자가 눌러야 시작한다. `prefers-reduced-motion`에서는 전환·애니메이션을 제거하고 재생 헤드 갱신을 약 250ms 간격으로 줄인다. 실제 시각은 같은 시계를 사용한다. 탭 숨김/페이지 이탈 시 재생과 자동 진행을 멈춘다.

## 선택 P1과 통합

- **R07:** 표지에 카드 첫 제작·빠른 자막 수정·수익 구조 질문별 짧은 경로와 남는 결과물을 추가했다.
- **R09:** 현재 카드의 수정 전 상태 고정, 수정 후와 비교, 축소 보기를 제공한다. 별개의 예제 두 개를 전후처럼 보여 주지 않는다.
- **R10:** 빠른 자막 예→문장만 짧게 복구→같은 구간 재생으로 이어진다.
- **R15:** 관련 오답 해설에 `toolPreset` 링크를 붙였다. 조회 수입 오해·카드 편집·자막 시간·게시 응답 끊김·권리 증거를 해당 상태에서 다시 실험한다. 기존 퀴즈 점수/초기화는 유지한다.

`site/assets/sim/interactions.js`와 `site/assets/interactions.css`가 이론·실습의 공용 구현이다. HTML은 도구 제목·가정·대체 안내를 담고, JS가 조작 화면을 붙인다. 입력은 페이지 안에서만 유지하며 사용자 문자열은 `textContent`/`value`로 넣는다. 새 라이브러리·빌드·저장 형식·네트워크 API는 없다.

`book.js`에는 오답 재실험 링크와 절 전체를 가리키는 옛 `?embed=simulator` 호환만 추가했다. 실제 도구를 가리키는 새 embed와 기존 `publishing-sim`/`safety-sim` 주소도 동작한다. 부록 생성기·`catalog.js`·`lab.html`을 맞췄으며 실험실은 **축 그림 14개+입력/판단 도구 14개+한 달 요약 1개=29개**다. 용어 24개·실제 인용 출처 98개는 유지했다.

## 남은 범위와 인계

실제 음성 재생·녹음 정렬·MP4/PNG 파일 생성은 기존 키트에서 한다. 타임라인의 음성 트랙은 무음 연습이며 브라우저 편집 결과와 키트 렌더링의 일치를 주장하지 않는다. 검수는 가상 사례 판단이고 실제 자료의 이용 허락·계정 안전·게시 승인이 아니다. 실제 로그인·게시·토큰·유료 API·결제는 하지 않았다.

실물 휴대폰·다른 브라우저·스크린리더 청취·독립 초보자·Claude Code 검수는 남아 있다. DOM 접근성 속성과 키보드 조작 확인을 보조기기 실사용 검증으로 간주하지 않는다. 키트 코드는 바꾸지 않아 키트 테스트를 다시 실행하지 않았다. 배포 경로 전체의 이전 검증은 Phase 9 기록을 따르며 이번에는 상대 경로·사이트 링크·실험실 원본 재사용을 검사했다.
