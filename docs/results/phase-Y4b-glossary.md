# Y4b 용어집 통합 요청

본문에서는 첫 등장 자리에서 설명한다. 공용 용어집 링크/등록은 통합 담당자가 적용한다.

| 제안 ID | 용어 | 쉬운 설명 | 최초 위치 |
|---|---|---|---|
| safe-area | 안전 영역 | 버튼·설명에 가리지 않도록 중요한 내용을 두는 화면 안쪽 공간. 고정 여백이 아니라 현재 플레이어에서 확인한다. | 6장 촬영, 8장 크기·위치 |
| cut | 컷 | 앞 장면을 끝내고 다음 장면으로 바꾸는 편집 지점. | 7장 컷과 전환 |
| track | 트랙 | 장면·자막·음성·음악처럼 종류별 재료를 놓는 시간축의 줄. | 7장 시간 맞추기 |
| playhead | 재생 헤드 | 지금 보고 있는 영상의 시간 위치를 가리키는 표시. | 7장 타임라인 |
| burn-in | 화면에 구운 자막 | 영상의 그림에 함께 넣어 출력한 글자. | 8장 자막의 두 형태 |
| srt | SRT | 자막 문장과 표시 시작·끝 시간을 담는 파일. | 8장 자막의 두 형태 |
| resolution | 해상도 | 화면을 채우는 가로·세로 점의 수. | 9장 비율과 해상도 |
| fps | fps | 1초에 담는 화면 수. | 9장 fps와 움직임 |
| codec | 코덱 | 영상 데이터를 압축하고 풀어 읽는 방식. | 9장 파일과 압축 |
| bitrate | 비트레이트 | 영상이 1초에 쓰는 데이터 양. | 9장 파일과 압축 |
