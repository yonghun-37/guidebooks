정적 HTML/CSS/바닐라 JS를 유지한다. `site/`는 수정하지 않는다. 기존 변경인 `research/FACT-SHEET.md`, `research/SOURCES.md`, 조사 노트와 Y3 프롬프트를 보존한다. Git 쓰기가 금지된 환경이므로 현재 작업 디렉터리에서 진행하며 commit·push를 하지 않는다.

## 이번에 정한 설정

- 도윤: 첫 영상을 만드는 가상 초보 제작자. 직접 촬영한 책상 정리 영상을 만든다.
- 서진: 영상 편집자 역할의 가상 멘토. 한 편을 끝내고 직접 재생·검수하는 습관을 안내한다.
- 테마: 따뜻한 주황·짙은 자주색과 자체 필름/세로 프레임 도형. 플랫폼 로고·UI·브랜드 이미지는 사용하지 않는다.
- 모든 장 데이터의 편집 상태는 `준비중`으로 유지한다. 이론 2·실습 8에만 `sample` 표시를 더해 ‘확인용 샘플’ 링크를 연다. 사용자 선택 전 전 장 완성으로 표시하지 않는다.
- 첫 게시 순서: 공유 가능한 영상은 일부 공개로 재생을 확인하고 공개로 전환하도록 제안한다. 일부 공개는 비밀 보관이 아니므로 민감한 영상은 비공개로 확인한다. 이는 공개 범위 문서에 근거한 교재의 연습 순서이며 플랫폼 의무가 아니다.
- 새 책용 키트의 별도/확장 선택은 이번 샘플 확인 뒤로 남긴다. 기존 키트가 쇼츠용으로 완성됐다고 안내하지 않는다.

## 검증 계획

기존 검사기 23개 테스트를 시작 전 실행해 통과했다. 정적 검사기의 ShortsBook 선택 경로·Y 출처 검증은 실패하는 fixture부터 추가한다. 브라우저는 실제 DOM에서 계산 경계값·설정 미응답/변경/초기화·탭·퀴즈·저장 차단·동적 링크·다크 모드와 가로 넘침을 확인한다. 실제 계정 로그인·게시·실기기 UI 검증은 수행하지 않는다.

## 구현 결과

- `site-shorts/` 7개 HTML: 표지·출처, 이론/실습 준비중 화면, 실습 시작 안내, 이론 2장·실습 8 샘플이다. 실습 시작은 준비중 범위를 알리고 업로드 샘플로 연결한다.
- 공통 `book.css`, `book.js`, `sim/common.js`, `practice.js`를 복사했다. 책 데이터·테마·저장 이름공간을 바꿨다. `shorts.css`·`shorts.js`와 자체 `upload-flow.svg`를 추가했다. 외부 글꼴은 기존과 같은 버전 고정 Pretendard이며 사용 라이선스를 동봉했다.
- 이론 2장은 9블록을 유지한다. 광고·후원·쇼핑·협찬·내 상품을 같은 틀로 설명한다. 공개 사례는 몸치탈출연구소·오!모 아트의 제작 형식만 인용했다. 가상 계산과 실제 단가를 구분하며 USD를 원화로 임의 환산하지 않는다. 2027년 변경 예고는 현재 단계표와 분리했다.
- RPM 도구는 유효 조회수·RPM·광고 공유 상태를 바꾼다. 무효 입력에 이전 금액을 남기지 않으며, 0회·광고 미가입 예를 제공한다. 계산은 `조회수 ÷ 1,000 × RPM`이며 45%를 중복 적용하지 않는다.
- 실습 8은 파일 선택부터 공개·쇼츠 구분·주소 기록까지 11단계다. 각 단계의 지금 하는 일/왜/따라 하기/성공/문제 해결 틀, Windows·macOS·모바일 탭, 표지·예약 FAQ를 제공한다. 실제 앱 이미지 대신 직접 만든 순서 도식만 썼다.
- 업로드 설정 도구는 아동용·AI 사용·음악 권리를 각각 묻는다. 미응답과 판단 불가를 통과로 처리하지 않는다. AI 표시를 해도 음악 권리 확인은 남는다. 어떤 답도 실제 게시나 계정 설정 변경을 실행하지 않는다.
- Pages 조립에 `/shorts/`를 추가하고 서가·진행표를 연결했다. `check_site.py --site site-shorts`를 추가하되 기존 기본 모드의 13장·E2E 검사를 유지했다. `style_lint.py`는 YT 사실 ID를 내부 용어로 인식한다. 새 분량 기준선은 만들지 않았다.

## 발견과 수정

- 정적 검사로 누락된 Pretendard 라이선스 파일을 발견해 공식 배포판의 라이선스를 동봉했다.
- 네이티브 form reset 이벤트의 microtask 시점에는 입력값이 아직 이전 값이었다. 다음 task에서 결과를 갱신해 초기화 뒤 낡은 설정 메모가 남지 않게 했다.
- 별도 읽기 전용 검토: Critical 0·Important 0·Minor 1. 주소 기록 삭제 뒤 저장 안내가 남는 문제를 실패하는 브라우저 검증으로 재현한 뒤 수정했다. 전체 집필·키트·실계정 게시와 기존 사용자 변경은 검토 범위에서 제외했다.
- 실제 글꼴을 불러오는 검사에서 서가의 자동 favicon 요청 404를 발견했다. 두 서가 페이지에 빈 favicon을 명시해 요청을 없앴다.

## 남은 확인

- 샘플의 문체·구성에 대한 사용자 선택과 Claude Code 단계 검수가 남는다. 승인 전 전체 집필과 키트 확장을 진행하지 않는다.
- 실제 Windows/macOS·Android/iPhone의 한국어 계정 UI·설치·로그인·업로드·게시를 실행하지 않았다. 공개 공식 문서와 Linux Chromium으로 안내·도구·레이아웃만 확인했다.
- 한국 RPM은 AIR의 2025년 사업자 참고치다. 개인 수입 보장이나 2026년 한국 전체 평균으로 쓰지 않는다. 쇼핑·후원·AI 메뉴·표지는 본인 Studio와 공식 도움말에서 확인하도록 안내했다.
- 배포 워크플로와 로컬 조립만 확인한다. 실제 GitHub Actions 배포·commit·push는 수행하지 않는다.
