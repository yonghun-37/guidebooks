# Phase 7w — 7v 앱 메뉴 확인 목록

2026-10-26. 7r에서 본문/실기기 화면을 확보하지 못한 후보를 실제 원고의 `data-verify="app-menu"`에서 추출했다. 사용자 테스트 계정을 제공받는 7v에서만 확인한다. 현재 문서 근거는 오른쪽 조사 열을 따른다. 가입·전환·보관/삭제의 근거는 각각 구분하고, 실제 기기 확인은 별도로 남긴다.

**Phase 1c 보강(2026-10-26):** 오른쪽 열의 ‘확인됨’은 Hermes가 확보한 공식 한국어 본문 또는 명시한 검색 발췌의 문자열이다. 실제 한국 앱 화면·OS/앱 버전·계정별 성공 확인과 다르다. 원래 7w 후보 문구는 이력으로 보존했으며, 7v에서 미확인 속성을 제거할 때는 실기기 증거가 필요하다. [재조사 결과](phase-1c.md).

확인 시 OS·앱 버전·언어·계정 유형·확인일·정확한 메뉴와 성공/보류 결과를 기록한다. 라벨·예약·지표는 지원 여부와 실제 적용을 따로 확인한다. 개인정보·QR·토큰·연락처는 남기지 않는다. 확인된 블록만 근거/문구를 갱신하고 미확인 속성을 제거한다. 개발 모드 일반 공개와 테스터 초대 수락도 별도 실증이 필요하다.
