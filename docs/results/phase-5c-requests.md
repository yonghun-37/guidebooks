## 2. 모바일 용어 설명의 가로 넘침

첫 375px 검사에서 10장 문서 폭이 482px이었다. 화면 오른쪽 용어의 `.term-tip`이 `left:0`으로 배치되며 숨김 상태에서도 문서 폭을 늘렸다. 담당 다섯 HTML의 모바일 로컬 스타일로 고쳤다. Phase 5b의 같은 요청과 **중복 적용하지 않는다.**

```diff
--- a/site/assets/book.css
+++ b/site/assets/book.css
@@
 @media (max-width: 680px) {
+  .chapter .term-tip {
+    position: fixed;
+    left: 22px;
+    bottom: 24px;
+    width: calc(100vw - 44px);
+    max-width: 320px;
+  }
   body { font-size: 16px; line-height: 1.85; }
```

공통 적용 시 담당 장 `<style>` 안의 동일 `.chapter .term-tip` 규칙만 제거한다. 각 장의 입력·표·캘린더 스타일은 그대로 필요하다. 공통 JS 개선이나 새 의존성은 필요하지 않았다.

## 3. 용어·실험실·출처

- [용어 표](phase-5c-glossary.md)의 신규 용어를 합친다. 현재는 없는 앵커를 만들지 않고 용어집 페이지 자체로 연결했다. 항목이 생기면 표의 제안 앵커로 링크를 좁힌다. 다른 장의 먼저 나온 정의와 중복을 정리한다.
- 실험실에서 연결할 상대 경로는 `chapters/10-publishing.html#simulator`, `chapters/11-analytics.html#simulator`, `chapters/12-safety.html#simulator`, `chapters/13-roadmap.html#simulator`, `chapters/14-plan.html#simulator`이다. 입력·가정·무너뜨리기가 함께 있는 절에 연결한다.
- 출처·크레딧은 기존 FACT-SHEET ID와 SOURCES 번호를 재사용한다. 담당 HTML 각주는 원문 URL로 연결되어 Pages 바깥 `research/` 경로를 요구하지 않는다. 신규 사실 ID·출처는 만들지 않았다.

## 4. 현재 현황 통합
