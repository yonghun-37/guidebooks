# Phase 9c · 이론편 10~14장 개편 결과

상태: **집필·작성자 검증 완료, 통합·독립 검수 대기**. 확정 STYLE-GUIDE와 v2 템플릿을 적용했다. 담당 장 5개·전용 JS 3개와 이 단계의 결과 문서만 작성했다. 공통 파일·다른 장·실습·연구·키트·배포는 수정하지 않았고 커밋하지 않았다.

## 전후 채점

기준별 충족 1점, 부분·미충족 0점이며 7개 모두 충족해야 통과다. [수정 전 평가](phase-9c-before.md)와 같은 기준이다. ①은 질문 5개 각각의 첫 문장 직답·숫자 또는 예·행동을 읽고 판정했다. ⑦은 작성자의 독해 점검이며 실제 초보자의 3분 사용성 실험은 아니다.

## 본문에서 바꾼 점

- **10장**: 첫 게시는 앱으로 한다고 직답했다. API는 계정·권한·공개 JPEG 주소를 준비하는 선택 경로로 정리했다. PC가 꺼진 예약과 재실행 시 중복 여부에 답했다. 앱 30일 전·하루 25개, 옵션 이름과 Suite 플래너를 반영했다.
- **11장**: 첫 주 기록을 도달·저장·공유로 좁혔다. 가상 A/B 계산, 표지 질문을 고치는 예, 빈칸과 측정된 0의 처리를 나눴다. 인사이트 메뉴 이름과 90일 기간을 반영했다.
- **12장**: 권리·광고·AI·대응·세금의 다섯 축으로 정리했다. 제품 제공 문구, AI·협찬 메뉴, 공식 복구 입구, 등록·원천징수 예를 앞세웠다. Android 문서의 확인 범위를 명시했다.
- **13장**: 독자를 찾는 행동, 첫 제안문, 월 30만 원의 가상 거래 계산을 추가했다. 500·1만의 기능 조건과 1천의 점검 구간을 단계표로 나눴다. 한국어 19세, TikTok 한국어 1만·영문 5만의 차이, 레뷰의 AI 제한을 반영했다.
- **14장**: 첫 주부터 제작·게시·기록까지 단계표를 만들었다. 하루 30분의 작업 분할, 밀린 일의 이동, 계속·축소·중단 판단을 FAQ로 답했다. 기존 완료 결과물은 이어 쓰도록 했다.

모두 기존 9블록을 유지하고, 각 축은 정의→흐름→얼마·기준→조건→언제→지금 할 일의 여섯 행을 반복한다. 장마다 FAQ 다섯 개·핵심 정리 세 줄을 뒀다. 실습 조작은 링크로 연결했다. 각 장 HTML에 새 제목·결과물을 직접 넣어 공통 JS가 옛 정보로 덮어쓰는 문제를 피했다.

## 도구 정리와 검증

- 10·12장은 불필요한 수치 도구를 정적 질문 연습으로 바꿨다. 기존 JS 파일은 보존하고 연결만 끊었다.
- 11장은 `(저장+공유)÷도달×100`, 13장은 `올림((목표+비용)÷제안 가격)`, 14장은 `활동일 수×max(하루 분−점검 10분, 0)`만 계산한다. 성공 결과는 **숫자 하나와 해석 한 문장**이다. 빈칸·잘못된 값·0 분모는 계산하지 않는다.
- 14장 입력 ID와 저장·실험실 전달은 유지했다. 전체 자동 캘린더 대신 단계표·직접 옮길 메모를 남긴 변경은 의도한 단순화다.
- `style_lint.py` 종료 0, 5장 모두 통과. 공백 제외 기준선은 재생성하지 않았다.
- [정적 검사](phase-9c/static-check.json): 담당 5장 내부 링크·자산 **197개**, 기존 ID **313개** 보존, 중복 ID·누락 파일·앵커 오류 **0**.
- [브라우저 검사](phase-9c/browser-check.json): **617개 검사 통과**, 5장×1280/375/360px 가로 넘침·콘솔/페이지 오류 **0**. 펼친 FAQ, 축 키보드 이동·초점, 각 퀴즈 오답·정답·초기화, 계산 기본값·극단값·빈칸·음수·방향키, 14장 저장 복원·실험실 전달, 기존 embed, 다크 모드·인쇄·JS 없는 FAQ를 확인했다.
- 모바일 검사에서 발견한 11장 메모의 가로 넘침은 기존 `.code-box`로 고치고 다시 통과했다. 전용 JS 세 파일은 `node --check` 통과.
- 퀴즈 정답은 본문과 수동 대조했다. 10장 앱·공개 URL·재시도, 11장 지표·가상 5%·빈칸, 12장 권리·제공·가상 체험·원천징수, 13장 가상 4건·구독·언어판 차이, 14장 가상 20분·미완료 이동·미게시와 일치한다.
- 담당은 이론편이며 실행 명령을 새로 싣지 않았다. 실습 파일·키트는 수정·재실행하지 않았고, 실계정 로그인·게시·예약·결제도 수행하지 않았다.

재현: 저장소 루트에서 다음 명령을 사용한다. 브라우저 검사는 기존 Playwright·Chromium 캐시를 사용하며 외부 폰트는 빈 CSS로 대체한다.
