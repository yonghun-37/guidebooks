# BX4a · BlogBook 심화편 A0·A2~A6 집필

2026-10-28. **A0·A2~A6 본문과 A0 계산기·A5 관문 연습 도구를 완성했다.** A1의 동일 명령 탭 7개를 공통 블록으로 합치고 다음 장을 A2로 연결했다. 키트 재현·문체·브라우저 검증은 통과했다. **원본 check_site는 공통 출처 등록 수정이 남아 있다.** 커밋·push는 하지 않았다.

## 범위·구현 전략

- 기존 `DESIGN-blog-advanced.md` 전체와 8절, `DESIGN-baby.md` 8절, STYLE-GUIDE, 학습자 질문, 조사 브리핑·사실표·출처·주제별 노트, BX3/BX3k 결과와 A1/A9 샘플을 기준으로 작성했다. 기존 단계 기록을 이어 쓰며 새 ADR·중복 사양은 만들지 않았다.
- 장 하나의 결과물을 먼저 정하고 샘플의 순서를 유지했다. 만드는 것 → 그림 → 시작 복원 → 명령/실제 예상 출력 → 실제 코드 발췌/읽는 법 → 설정 변경 → 오류 → 체크포인트 → 확인할 점 → 정리다.
- 공통 HTML 외곽과 공통 CSS/JS는 사용만 했다. 새 동작은 `advanced-00-start.css/js`, `advanced-05-gates.css/js`에만 있다. 그림은 정적 HTML 위치 그림·흐름도여서 JS가 없어도 읽힌다. 관리자·광고·제휴 화면 캡처는 없다.
- 신규 본문 명령은 `course/commands.md`와 같으며 OS 공통 블록 하나로 표시했다. 시작·체크 명령과 바꿔 보기의 반복 실행도 실제 실행했다. A1의 가상환경/파일 복사처럼 다른 명령만 OS 탭으로 유지했다.
- 첫 검사 때 예전 이론편 baseline에는 신규 심화 파일이 없어 입력 오류가 났다. 심화편은 신설 실습 트랙이므로 최종 lint는 baseline 없이 실행했다. 이론편 분량 70% 항목은 적용되지 않는다.
