## 완료 범위와 제한

Phase 1의 질의·원응답 보존·주제별 노트·통합 출처·사실표·직접 검증·정합성 검사를 마쳤다. **Git add/commit은 실행 환경의 `.git` 읽기 전용 제한으로 미완료다.** **조사 단계 완료가 모든 정책·한국 계정 동작·법률 적용의 검증 완료를 뜻하지 않는다.** 원문을 얻지 못한 항목은 `미확인/추가 조사 필요`로 남겼다.

- 초기 주제 12회 + 실패한 저작권 주제 재시도 1회 + 보충 3회 = **16회**. 실패 재시도는 1회만 했다.
- 명령 종료 기준 **15회 exit 0, 1회 exit 1**. 시각 구간을 대조한 최대 동시 실행은 **4개**다.
- 초기 저작권 실행의 exit 1은 공급자 응답 스트림 타임아웃이다. 재시도는 exit 0이나 웹 중계 프록시 403으로 원문을 확보하지 못했다.
- 초기 광고·세금/성장 및 보충 광고·세금/성장도 exit 0이지만 검증 자료가 없었다. 음성·영상 보충은 일부 문서 앞부분만 얻었다. **exit 0을 조사 품질 성공으로 집계하지 않았다.**
- 보충 3회는 원문 공백이 큰 광고·세금, 음성·영상 라이선스, 성장 벤치마크에 배정했다. 한국 수익화·예약·실패 사례의 남은 공백은 한도 소진 후 사실표에 남겼다.
- Codex가 원응답의 공식 출처·후보를 직접 열어 보완한 부분은 Hermes 확인과 구분했다. 도움말의 제목/로그인 셸만 반환된 HTTP 200은 본문 확인으로 처리하지 않았다.
- 실제 로그인·게시·토큰 발급·유료 API·컨테이너 재시작·Hermes 코드/config/runtime 수동 변경은 하지 않았다. 다른 Phase 파일도 수정하지 않았다.

## 목차·설계 조정 제안

다음은 Claude Code 검수를 위한 제안이며 DESIGN.md·다른 Phase 구현은 변경하지 않았다.

1. **2장 포맷 표를 앱/추천/API로 나누기.** 릴스20분 도움말·3분 초과 추천 경고·API15분은 다른 범위이며 한국 계정 실증도 별개다. 캐러셀 API10개 고정 서술 대신 직접 확인20개와 남은 문서 충돌을 표기한다.
2. **3장 수익 구조에 지급 주체와 자격의 축 추가.** Meta 지급·협찬·제휴·자체 판매·외부 트래픽을 구분하고 팔로워별 보장 단가·전환율을 넣지 않는다.
3. **7장 PNG 결과물과 게시용 JPEG를 구분.** 학습 산출물은 설계대로PNG여도 API 제출에는 별도JPEG 준비가 필요하다. 규격·파일 변환의 필요를 후속 구현에 전달한다.
4. **8장 TTS를 권리 확인 후 선택 경로로 검토.** 직접 녹음·무음 대안을 두고, Whisper는 음성 인식이지 TTS가 아님을 분명히 한다. 카드 슬라이드쇼를 만들었다는 실습 결과와 Meta 직접 수익화 적격은 별도다.
5. **10장 로그인 비교에 Unified Login 추가 검토.** 현행 Overview가 새 통합에 권장하는 경로·비즈니스 포트폴리오 조건과 기존 Instagram/Facebook Login을 비교한 뒤 후속 구현 경로를 결정한다.
6. **10장 한도 계산기를 고정 수치 정답으로 만들지 않기.** 공식100/50 충돌, 계정 사용량 조회·컨테이너 생성/만료·일반 호출 제한을 구분한다. 검증하지 않은 실효값은 사용자 확인값으로 다룬다.
7. **10·12장 표시를 분리.** API AI자기공개, 파트너십 라벨의 로그인별 지원, 국내 경제적 이해관계, AI가상인물 광고, AI서비스사업자 의무를 별도 질문으로 구성한다.
8. **12장에2026 공정위 가상인물 개정 반영.** 과거2024 가이드만으로 최신 규정을 설명하지 않는다. 법 시행과 계도·개정판 시행일도 구분한다.
9. **13장 ‘0→1천→1만’을 목표 점검 단계로 표현.** 달성 기간·수익을 보장할 한국 자료가 없으므로 독자 상태별 실험·전환 경로 점검으로 설명한다.

- 사이트·스타터 키트 코드나 실제 게시 테스트는 Phase1 범위가 아니므로 실행하지 않았다.

Phase1 자료조사 산출물은 완료했고 미확인 항목을 완료 사실로 바꾸지 않았다. 검증 공백이 있는 수치·가격·사례는 후속 집필의 확정 근거로 사용하지 않는다.

## Git 마무리 제한

19개 소유 파일의 로컬 Markdown 파일 링크 검사가 통과했다. 기존 staging은 비어 있었으며 Phase1 파일만 대상으로 `git add -- ...`를 실행했다. 그러나 `.git/index.lock` 생성에서 `Read-only file system`(exit128)이 발생해 staging과 `Phase 1: research notes` 커밋을 완료하지 못했다. 커밋 명령은 실행되지 않았다. 읽기 전용 경계를 우회하거나 권한/컨테이너를 변경하지 않았다.

후속 조치: `.git` 쓰기가 허용된 정상 작업 환경에서 `research/`의17개 파일과 `docs/results/phase-1.md`, `docs/PROJECT_STATE.md`만 검토·추가하고 `Phase 1: research notes` 메시지로 커밋한다. `docs/reference-analysis.md`, `docs/results/phase-2.md` 및 다른 Phase 파일은 이번 커밋 범위가 아니다. push는 하지 않는다.
