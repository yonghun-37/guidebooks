# Y4ai 용어집 통합 제안

공통 용어집은 수정하지 않았다. 기존 용어와 겹치면 기존 항목을 재사용한다.

| 용어 | 초보자 설명 | 처음 설명하는 곳 |
|---|---|---|
| 모델 / 서비스 | 모델은 생성 엔진의 이름, 서비스는 그 모델을 쓰는 앱이나 웹사이트입니다. | ai-models.html 첫 답 |
| TTS | 글자를 읽어 음성으로 만드는 기능입니다. | 5장 AI 음성 레시피 |
| 기준 그림 / 참조 이미지 | 다음 그림·영상에서도 같은 외형을 유지하도록 다시 넣는 승인된 그림입니다. | 6장 기준 그림 |
| 이미지→영상 | 정지 그림을 입력해 피사체·카메라의 움직임이 있는 짧은 클립을 생성하는 작업입니다. | 6장 Flow·Runway |
| 크레딧 | 생성 모델·길이·출력 수에 따라 차감하는 서비스 내부 포인트입니다. | ai-models.html 요금 읽는 법 |
| 토큰 / MTok | 모델이 글 등을 처리하는 작은 단위이며 MTok는 100만 토큰입니다. 글자 수나 낭독 초와 같지 않습니다. | ai-models.html 요금 읽는 법 |
| 구독료 배분액 | 월요금을 사용량에 나눠 계산한 값입니다. 한 편을 만들 때 실제 결제하는 금액과 다릅니다. | ai-models.html 비용 시나리오 |
| SRT | 자막 글자와 표시 시간을 저장한 별도 파일입니다. | 8장·기존 설명 재사용 |

용어 앵커·`data-term` 연결은 통합 담당자가 전체 용어집과 맞춘 뒤 적용한다.
