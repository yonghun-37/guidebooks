# Y4p 용어 통합 제안

본문의 첫 사용에서 풀어 썼다. 공통 용어집은 수정하지 않았다.

| 용어 | 쉬운 설명 | 처음 연결할 위치 |
|---|---|---|
| 샷 | 카메라가 끊기기 전까지의 한 화면 | `practice/05-scenes.html#choose` |
| 기준 이미지 | 다음 생성에서도 외형·색·빛을 맞추기 위해 다시 넣는 승인 그림 | `practice/05-scenes.html#image` |
| 크레딧 | AI 생성 요청에 쓰는 서비스 잔여량 | `practice/05-scenes.html#video` |
| TTS | 글을 음성으로 읽어 주는 도구 | `practice/04-voice.html#tts` |
| 타임라인 | 시간 순서대로 영상·음성을 놓는 줄 | `practice/06-edit.html#project` |
| SRT | 글과 표시 시간이 들어 있는 자막 파일 | `practice/06-edit.html#captions` |
| fps·프레임 | 1초의 화면 수·한 장의 화면 | `practice/07-export.html#export`, `practice/06-edit.html#captions` |
| OAuth·토큰 | 비밀번호를 넘기지 않고 작업을 허용하는 로그인 방식·허용한 권한을 증명하는 비밀 파일 | `practice/09-api.html#cloud`, `#oauth` |
| 드라이런 | 실제 전송 전에 요청 내용만 확인하는 예행연습 | `practice/09-api.html#dry-run` |

이미 있는 용어는 중복 항목을 만들지 말고 첫 사용 연결만 추가한다.
