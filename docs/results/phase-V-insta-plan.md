## 구현·검증

- `assets/figures.css`에 figure·단계 띠·같은 크기 비교·차트·번호 스타일을 정리하고, `assets/img/fig/screen-frame.svg`를 실제 그림이 공유하는 화면 틀로 사용한다. 화면 도식은 실제 서비스 UI 배치를 재현하지 않는다.
- 기존 본문·링크·입력·퀴즈·진행 키·시뮬레이터를 유지한다. 기존 표를 비교 그림으로 바꿀 때 원문 정보는 보존한다.
- 새 정책·가격을 조사하거나 추가하지 않는다. 본문/연구 노트의 숫자만 사용하고, 정책·가격 캡션은 같은 출처와 조사 기준일을 붙인다. 가상 예에는 가상·계산식을 명시한다.
- 기존 `library-evening.webp`는 AI 생성 고지와 바로 뒤의 원래 프롬프트를 함께 유지한다. 이번 단계에는 새로운 AI 래스터를 생성하지 않는다. 사용되지 않은 이전 신규 파일은 삭제한다.
- `check_site.py`의 그림 수량·최소·shortages·`--fig-warn`을 제거한다. caption·img alt·SVG 제목 접근성과 site-blog 지원은 유지한다.
- 문체·두 사이트 정적 검사·검사기 회귀, ReelsBook 전 HTML 1280/375/360px × 라이트/다크의 가로 넘침·그림 글자·콘솔 오류를 확인한다. 대표 그림 스크린샷과 재현 검증을 `docs/results/phase-V-insta/`에 보관한다.
- 다른 책·키트·research·STYLE-GUIDE는 수정하지 않는다. commit/push·실계정 작업은 하지 않는다.
