## 통합 판단

- 사용자 지정 5a/5b/5c 분할과 이번 5d가 PLAN의 과거 분할보다 우선한다.
- 툴팁은 모든 data-term에 적용하는 고정 위치·화면 안 폭 보정을 채택한다. 5a의 전체 적용 범위와 5b/5c의 최대 320px 제한을 합친다. 장별 보정의 선택자 차이로 생길 누락을 막는다.
- 실험실은 iframe 하나에서 선택한 원본 장의 해당 9블록 절만 표시한다. DOM/계산 코드를 복제하거나 동적 스크립트를 중복 실행하는 대신 기존 ID·모듈·가정·복사 기능을 그대로 유지한다. 직접 장 링크도 제공한다.
- 장 입력 저장은 이번 요청으로 추가하는 기능이다. 3·4·14장의 해당 도구에만 한정하며 브라우저 안에 저장됨을 표시하고 삭제 기능을 둔다. 저장 불가 환경에서는 같은 방문 중 동작을 유지하고 미저장임을 표시한다. 초기값과 독자 입력을 구별한다.

## 구현 내역

- `book.js`: 2~14장의 요청 시간·난이도·완성 상태와 15·16장·출처 상태를 통합했다. 14개 장의 임시 메타·pager 내용을 공통 훅으로 대체했고, 자바스크립트가 꺼진 경우에만 최소 이전/다음 링크를 제공한다. 생성 링크도 상대 경로로 바꿨다.
- `book.css`: 13개 장의 중복 인라인 스타일을 공통 스타일로 모았다. 모바일 툴팁을 화면 안에 배치하고 부록·표지·실험실 스타일을 추가했다. 장별 도표·입력 기능은 보존했다.
- `common.js`·`lab.js`: 3장 장부·4장 니치/주당 시간·14장 계획의 변경 입력과 원본 결과를 버전 있는 로컬 스냅샷으로 전달한다. 빈칸은 0으로 바꾸지 않는다. 저장 차단 알림·손상 구조 무시·저장 입력 삭제·초기 예시값 구별을 제공한다. 프레임과 부모의 테마도 동기화한다.
- `scripts/build_appendices.py`: 원본 모듈의 mount ID와 원고 제목으로 **원본 도구 28개 + 실험실 전용 1개 = 29개** 목록을 만든다. 계산식이나 도구 DOM을 복제하지 않는다. 그림에 별도 제목이 없는 10~14장은 해당 그림 절 제목을 사용한다. 정적 부록 생성은 유지보수 도구이며 사이트 실행에 빌드는 필요 없다.
- 용어집은 **31개**를 가나다순으로 통합했다. 영문 약어는 한국어 발음 순서이며 검색과 7개 분류를 조합한다. 본문 `data-term`은 앵커 ID로, 기존 쉬운 설명은 `data-term-description`으로 보존했다. **41개** 링크가 일치한다. 드라이런·해시는 9장, 조회·도달은 2장처럼 전체 책에서 먼저 정의한 장을 우선한다.
- 출처는 실제 각주의 **126개**만 SOURCES 원래 번호·제목·기관·날짜·확인 수준·등급·인용 장과 함께 싣는다. 본문에서 참조하지 않은 각주가 없는지도 대조했다. 폰트·도구 크레딧은 [별도 근거](../../research/tool-licenses.md)에 보존했고 Noto 폰트 고지·샘플 MIT 전문을 동봉했다.
- 1장의 게시·수익화·법/표시·사례 대기를 기존 사실표로 교체했다. API 로그인 경로와 문서 한도 충돌, 한국 기능의 현행 미확인, 인용과 광고 표시의 분리, 뉴닉 사업 구조의 제한된 사례를 설명한다. 확정할 수 없는 수치를 새로 만들지 않았다. 사이트의 `fact-pending`은 0개다.
- 표지는 데이터에서 **16개 장·29개 도구**를 계산하고 완전 초보/코딩 가능/계정 운영 중 경로를 제공한다. 샘플 PNG 5개·MP4·SRT·합성 JSON 2개를 원본 그대로 복사했고, 샘플 MIT를 포함한 총용량은 **1,574,799바이트**다. 영상의 한글 자막·무음·합성 고지를 명시했다.

## 검증 중 발견·수정

1. 10~14장 그림은 `.simulator` 클래스가 없어 초기 임베드 조건에서 빠졌다. 해당 절만 보여야 하는 재현 검사의 실패를 확인한 뒤, 그림/입력 절을 기준으로 표시하도록 고쳤다. 모든 원본 도구의 선택을 검사한다.
2. 손상된 저장 구조가 요약에 들어올 수 있었다. 문자열 values fixture의 실패를 확인하고 버전·객체·필드 문자열·결과·유효성 타입을 검사하도록 수정했다.
3. 부모에서 테마를 바꾸면 이미 열린 프레임이 이전 테마에 남았다. 재현 검사의 실패를 확인하고 공통 테마 저장 이벤트를 받아 갱신하도록 수정했다.
4. 전체 검사 첫 실행의 상대 URL goto와 프레임 전환 중 body가 아직 없는 경우는 **검사기 문제**였다. 절대 탐색 URL로 해석하고 프레임의 새 문서 body를 기다리도록 검사기를 고쳤다. 사이트 실패를 숨기는 예외 처리는 넣지 않았다.

최종 검토는 작성자의 별도 diff·요구사항 자체 검토다. Phase 6의 독립 초보자 검토는 수행하지 않았다. 작업 중 외부에서 추가된 `docs/DESIGN.md`, `docs/PLAN.md`, `docs/prompts/phase-6a.md`, `phase-6b.md`, `phase-7r.md`는 수정·되돌리지 않았다. 추가로 나타난 Phase 7r의 연구 원고·FACT-SHEET/SOURCES 추가분·검증 자료도 변경하지 않았다. 새 이론/실습편·ShortsBook 범위를 미리 구현하지 않았다.
