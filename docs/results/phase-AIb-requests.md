## 추가 변경이 필요 없는 파일

공통 CSS·시뮬레이터 JS·실습 JS·표지·용어집 변경은 필요 없다. B-roll은 첫 등장에 “보조 장면”, TTS는 “글→음성”으로 풀었다. 실계정·결제·게시나 유료 생성 호출을 수행하지 않았다.
