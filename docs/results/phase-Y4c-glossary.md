# Y4c 용어집 반영 제안

공통 용어집은 수정하지 않았다. 다른 묶음의 제안과 중복을 정리한 뒤 통합한다.

| 용어 | 쉬운 설명 | 처음 설명한 장 |
|---|---|---|
| 템플릿 | 다음 편에서 복사해 쓸 빈 작업 틀 | 10장 |
| 메타데이터 | 영상을 소개하는 제목·설명 같은 정보 | 11장 |
| 일부 공개 | 주소를 아는 사람이 볼 수 있는 공개 범위 | 11장 |
| 비공개 잠금 | 일반 비공개 설정과 달리 정책·API 제한으로 공개 전환이 막힌 상태. 영상 제한사항과 공식 도움말로 확인한다 | 11장 |
| 유효 조회수 | 재생 시작을 세는 공개 조회수와 구분하는 머문 시청 지표. engaged views·참여 조회수라는 표현도 쓴다. 가입에 인정되는 실적은 수익 창출 화면에서 따로 확인한다 | 12장 |
| 평균 조회율 | 영상 길이에 대한 평균 시청 비율 | 12장 |
| 시청 지속률 곡선 | 영상의 시간에 따라 어느 구간을 떠나거나 다시 보는지 살펴보는 그래프 | 12장 |
| Content ID 주장 | 일치 콘텐츠를 찾아 권리자의 차단·수익화·추적 정책을 적용하는 알림. 저작권 위반 경고와 구분한다 | 13장 |
| 양산형 콘텐츠 | 독창적 가치 없이 반복하거나 대량생산하는 콘텐츠. 플랫폼 수익화 정책에서 판단한다 | 10·13장 |
| 시간 예산 | 내가 확보한 시간 안에서 제작·검수·메모에 쓸 분을 나눈 계획 | 14장 |
