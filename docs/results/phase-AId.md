# AId · ReelsBook AI 제작 모듈 통합

2026-10-26 · 통합·검증 완료, Claude Code 최종 검수 대기. 기준: STYLE-GUIDE, DESIGN 12절, AIa·AIb·AIc 결과/통합 요청, AI 제작 조사·사실표·출처표. 이 문서가 기존 단계별 기능 기록을 잇는 Level 2 통합 기록을 겸한다. 정적 사이트 구조·의존성 변경은 없어 ADR은 추가하지 않는다.

## 요구사항과 실행 계획

- [x] `book.js`에 6장 AI 도구 지도·두 부록과 레시피/실습 메타를 통합한다. 기존 slug는 유지하고 뒤 장 번호·이전/다음·선행 장·표지·상호 참조를 갱신한다.
- [x] 표지의 AI 제작 진입 버튼, 실습 1→3 기본 이동, 서비스 파일의 실습 6 검수→7 게시 경로를 연결한다. 기존 키트 승인·드라이런과 진행 저장 키는 유지한다.
- [x] 부록 생성기의 장 번호·새 장/부록 검색 범위·용어·AI 이미지 고지를 갱신하고 실험실·용어집·출처를 재생성한다. 실험실 구분에 쓰던 숫자는 slug로 바꿔 새 15장과의 충돌을 없앤다.
- [x] 정적/문체/검사기 테스트·키트 테스트와 전체 브라우저 1280/375/360px·콘솔·키보드·링크·부록 재생성 동일성을 확인하고 화면을 보존한다.
- [x] PROJECT_STATE와 두 책 진행 현황을 실제 파일·검증 기록 기준으로 갱신하고 알림을 보낸다.

공통 파일 수정은 이번 사용자 지시로 허용됐다. 현재 작업 폴더에서 단독 통합하며 `.git` 쓰기·커밋·푸시는 하지 않는다. 시작 시 있던 `docs/prompts/phase-AId.md` 변경과 `docs/prompts/phase-Y5.md`는 보존한다. ShortsBook 원고·공통 자산은 수정하지 않으며 상태는 담당 단계 결과와 현재 파일을 구분해 적는다. 실계정·결제·유료 생성·게시 검증은 수행하지 않는다.


## 구현 결과

- AIa/b/c 요청을 적용했다. 이론 **6장 AI 도구 지도**, **7장 AI 문안**, **8장 뉴스카드**, **9장 릴스 레시피**이며 뒤 장은 하나씩 이동했다. 실험실·용어집은 16·17이다. 기존 파일명·앵커·시뮬레이터 ID는 유지했다. 새 도우미에는 `ai-tools-sim`을 부여했다.
- `book.js`의 번호/제목/결과물·표지 목차·장 상단·선행 장·이전/다음과 본문/실습의 정적 ‘N장’ 참조를 맞췄다. 프롬프트·모델/사용처/비용 부록을 등록하고 두 부록의 빠진 pager도 추가했다. 이론 수에 실험실·용어집이 더해지지 않게 15장으로 표시한다. 표지에 **AI로 무엇을 어떻게 만드나**와 부록 링크를 뒀다.
- 서비스 기본 경로는 **0→1→3→4→선택5→6→7→10**, 키트2·API8·매일생성9는 별도 진입이다. 실습6/7은 Canva/CapCut 파일·review.txt·게시 설명문을 받는다. 키트 묶음 검수·승인·드라이런 명령과 기존 진행키38개+신규5개=43개를 보존한다.
- 생성기가 새 장·두 부록까지 읽고 표시 번호는 `book.js`에서 가져온다. **도구31개·용어39개·인용출처329개**로 재생성했다. 새 15장과 충돌하던 실험실의 숫자 구분은 slug로 바꿨다. 용어집 루트 상대 링크·인증/AI 사용량 토큰 구분, AI 이미지 라이선스 고지도 반영했다. 연구의 조사 도구 이름은 독자용 출처 날짜에서 빼고 연구 원문에는 보존했다.
- `PROJECT_STATE.md`, 두 책 진행 페이지와 서가의 낡은 ‘쇼츠 샘플 두 장’ 안내, README의 두 책/배포 경로를 갱신했다. ShortsBook은 Y4 단계 작성·담당 검증 완료, Y5 통합 검증 중으로 기록하며 해당 담당자의 최종 판정을 대신하지 않는다. 작업 중 나타난 쇼츠 원고·자산·검증 파일은 보존했다. 생성기의 `--site site-shorts` 연결도 함께 유지했다.
- 기존 전용 `ai-guide.css/js`·AIb 삽화와 서비스별 입력/출력·복사용 프롬프트·좋은/나쁜 예·시간/비용·2026년10월 각주를 그대로 연결한다. 새 서비스 추천·근거 없는 수치·로고/화면 캡처·유료 호출을 추가하지 않았다. `book.css`·`practice.js`는 수정이 필요 없었다.
