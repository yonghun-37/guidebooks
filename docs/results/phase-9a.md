## 도구·파일

수정한 본문은 `site/chapters/01-map.html`부터 `04-niche.html`까지다. 새 전용 JS는 다음 네 개다.

| 파일 | 질문에 답하는 계산·점검 | 정상 결과 형식 |
|---|---|---|
| `map-guide.js` | 확보·준비·한 편 시간을 나눠 주간 편수 계산 | 편수 하나 + 해석 한 문장 |
| `formats-guide.js` | 설명 항목+표지+요약의 카드 구성 | 장수 하나 + 해석 한 문장 |
| `revenue-guide.js` | 가상 5만 원 상품의 인정 구매×3% | 수수료 하나 + 해석 한 문장 |
| `niche-guide.js` | 독자·소개·제안 질문을 적은 항목 수 | 개수 하나 + 해석 한 문장 |

전용 JS는 `site/assets/sim/`에 있다. 가정·계산식을 가까이 두고 극단값 버튼을 제공했다. 빈칸·음수·0 분모·소수 구매 건수는 계산하지 않고 입력을 안내한다. 기존 `map.js`, `ch02.js`, `ch03.js`, `ch04.js`는 파일을 그대로 보존하고 담당 장의 연결만 끊었다. 새 도구는 입력을 영구 저장하지 않으며 작업실 메모와 완료 체크만 기존 방식을 사용한다.

## 남은 문제·인계

[공통 파일 요청](phase-9a-requests.md)에 미적용 diff와 확인 결과를 남겼다. `book.js`의 목차·브라우저 제목, 실험실 목록 생성기·옛 한 달 요약 문구는 통합 담당자의 변경이 필요하다. 현재 목록의 이전 도구 이름과 저장값 설명은 새 도구를 아직 설명하지 못한다. 본문·도구는 동작하며 기존 진입 앵커를 유지한다. 공통 CSS·common.js 수정은 필요하지 않았다.

`PROJECT_STATE.md`는 통합 작업자 소유이므로 수정하지 않았다. 연구·설계·샘플·다른 장·실습·키트·공통 파일은 보존했다. 현재 한국 보너스 운영·기능 노출·실지급·쿠팡 실시간 요율의 미해결 범위는 그대로이며 새 예측 수치를 만들지 않았다. commit·push하지 않았다.

마지막 범위 확인에서 기존 전용 JS 4개가 HEAD와 동일하고, 개편 전 해시 4개가 보존된 기준선과 일치함을 확인했다. 담당 HTML의 `git diff --check`도 통과했다. 요청한 완료 알림은 `scripts/notify.py`로 대표 스크린샷을 첨부해 전송했으며 **HTTP 200**을 확인했다.
