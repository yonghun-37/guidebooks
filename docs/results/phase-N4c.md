## 통합 요청

1. **장 상태·목차:** book.js의 10~13장을 완성으로 전환하고 10장의 샘플 표기를 해제한다. 실제 파일은 `10-benefits.html`, `11-parents.html`, `12-safety.html`, **`13-hundred-days.html`**이다. 기존 13장 slug가 `13-next`이므로, 현재 본문의 `data-chapter="13-next"`는 공통 메타·사이드바를 불러오도록 유지했다. 통합 시 book.js slug를 `13-hundred-days`로 바꾸면서 **본문 data-chapter도 함께 변경**하거나 기존 slug의 링크를 새 파일로 연결한다. 현재 장 이동은 공용 데이터의 준비중 안내를 따른다.
2. **실험실:** 10장의 기존 `10-benefits:benefits-tool` ID는 유지했다. 표시 이름을 월별 비교임이 보이게 고친다. 11장에 `{chapter:11, slug:'11-parents', id:'sleep-shifts', title:'교대 수면 시간표', section:'simulator'}`를 등록한다. 위기 카드는 계산 도구로 등록하지 않는다.
3. **출처:** 장 끝 `.chapter-sources`에 해당 장에서 사용한 N번호·기관·원문 링크가 모두 있다. 공용 credits에 이를 병합하고 각주 목적지를 한곳으로 옮길 수 있다. 그전에도 현재 로컬 각주는 정상 작동한다. 중복 목록을 줄이는 작업은 공용 출처 통합과 동시에 한다.
4. **용어:** `바우처`(카드로 정해진 곳에 쓰는 지원), `소급`(지난 대상 월부터 지급), `수리`(신고가 받아들여져 등록 처리됨), `뒤보기`(차량 뒤쪽을 보고 앉는 방향), `리콜`(결함 제품의 회수·수리 등 조치). 현재 본문과 FACT-SHEET 의미를 대조해 용어집에 반영한다.
5. **공용 검증:** N3 `scripts/test_baby_browser.cjs`는 이전 `#benefits-form`, `[name=daycare]`와 단면 결과 문구를 사용한다. 새 도구는 `#ch10-form`, `[name=transition]`, `#ch10-months tbody tr` 24행이다. 새 검사 `assets/ch10.test.cjs`, `ch11.test.cjs`와 본 단계 브라우저 검사를 통합 회귀에 연결하고, 기존 브라우저 검사의 계산기·실험실 기대 문구도 갱신한다. 공용 benefits.js와 그 23개 검사는 보존했다.
