# BX4b 용어집 통합 후보

공통 용어집은 수정하지 않았다. BX5에서 기존 용어와 중복을 합치고 해당 장 첫 설명에 연결한다. API·JSON 등 기존 기본 용어도 중복 등록하지 않는다.

| 용어 | 쉬운 풀이 | 첫 설명 위치 |
|---|---|---|
| ads.txt | 광고 판매를 허용한 판매자를 적은 텍스트 파일 | advanced/07-ads.html#steps |
| CMP | 방문자의 정보 처리 동의를 묻고 관리하는 도구 | advanced/07-ads.html#steps |
| CSV | 쉼표로 열을 나눈 표 파일 | advanced/08-affiliate.html#steps |
| 딥링크 생성 | 상품 주소를 제휴 활동용 주소로 바꾸기 | advanced/08-affiliate.html#steps |
| sponsored | 링크의 유료 관계를 검색 서비스에 알리는 속성 | advanced/08-affiliate.html#steps |
| 세션 | 사이트 이용을 하나로 묶어 세는 방문 단위 | advanced/10-analytics.html#overview |
| 서비스 계정 | 사람이 로그인하는 대신 프로그램이 쓰는 전용 신원 | advanced/10-analytics.html#collection |
| OAuth | 사용자가 프로그램의 자료 읽기에 동의하는 방식 | advanced/10-analytics.html#collection |
| 할당량 | 일정 기간 서비스가 허용하는 요청·작업량 | advanced/10-analytics.html#delay |
| 빈 행 | 요청은 처리됐지만 조건에 맞는 자료 행이 없는 결과 | advanced/10-analytics.html#delay |
| 드라이런 | 실제 전송 대신 실행 계획이나 기록만 만드는 연습 실행 | advanced/11-operations.html#steps |
| runner | 자동화 명령을 실행하는 컴퓨터 | advanced/11-operations.html#schedule |
| 영속 상태 | 다음 실행에서도 이어 읽도록 보존한 기록 | advanced/11-operations.html#schedule |
| WP-Cron | WordPress 방문 요청을 계기로 기한이 지난 작업을 실행하는 방식 | advanced/11-operations.html#cron-delay |
| post_id | 서버가 글을 구분하기 위해 붙인 번호 | advanced/11-operations.html#retry |
| YMYL | 건강·안전·경제적 안정에 크게 영향을 주는 주제 | advanced/12-policy.html#search |
| E-E-A-T | 경험·전문성·권위·신뢰를 살펴보는 관점 | advanced/12-policy.html#search |
| EXIF | 사진 파일에 붙는 촬영 정보 | advanced/12-policy.html#privacy |
| 현물 | 돈 대신 받은 물건 | advanced/12-policy.html#tax |
| assert | 기대한 조건이 틀리면 실행을 멈추는 코드 검사 | advanced/e2e.html#read |
