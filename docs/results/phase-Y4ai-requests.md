번호 변경은 book.js만으로 끝나지 않는다. 전체 장·실습·실험실·표지에 남은 `3장`~`14장`의 링크 문구와 `data-chapter-link` 숫자를 **대상 slug 기준**으로 대조해 함께 바꾼다. 제목에 숫자가 없는 프롬프트·부록 링크는 그대로 둔다. 현재 작업은 통합 전이므로 기존 장 번호를 유지했다. 새 장은 번호 없는 “AI 도구 지도”로 표시한다.

기존 book.js는 준비중 상태를 title·공통 목차에 강제 적용한다. 따라서 현 단계의 4~8장 브라우저 제목·전체 목차에 준비중이 남는다. 로컬 AI 제작 내비게이션·본문 장 이동은 완성 원고에 직접 연결했다. `book.css`, `assets/sim/common.js`, `assets/practice.js` 변경은 필요 없다. 추가 스타일·검색/경로 도구는 `assets/ai-production.css/js`에 한정했다.
