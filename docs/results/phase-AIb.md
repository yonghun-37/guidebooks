# AIb 결과 · 이론 6~8장 제작 레시피

## 문제와 구현 범위

“정확히 어떤 서비스·도구로 어떤 과정을 거쳐 만드는지 빠졌다”는 지적을 반영했다. `docs/DESIGN.md` 12절·`docs/STYLE-GUIDE.md`·`research/ai-production.md`를 기준으로 실제 서비스의 메뉴, 단계별 입력·출력, 복사용 요청, 시간·비용, 좋은/나쁜 결과를 본체로 올렸다. 기존 아홉 블록·FAQ 다섯 개·정리 세 줄·퀴즈 세 문항과 인터랙션을 유지했다. Level 2 작업 기록은 이 문서와 공통 변경 요청으로 통합하며 별도 ADR은 필요 없다.

| 담당 파일 | 구현한 결과 |
|---|---|
| [6장](../../site/chapters/06-writing.html) | ChatGPT·Claude·Gemini·Perplexity 선택표. 새 대화→원문 요약→출처 직접 열기→이름·날짜·숫자·단위·대상·예외 대조→사실표→카드 문안·대본. 복사용 요청 두 개와 가상 대출/증정 비교. |
| [7장](../../site/chapters/07-cards.html) | 약 60분 뉴스카드 레시피. ChatGPT 문안→Canva/미리캔버스 템플릿→선택 이미지→PNG/JPG 검수. 무료 요소·한도·소재 권리 안내, 좋은/나쁜 가상 카드, 실제 생성 삽화와 프롬프트. 카드 편집기와 연결. |
| [8장](../../site/chapters/08-reels.html) | 카드→모션 약 35분, 얼굴 없는 해설 약 60분, Flow 생성 영상 약 70분+대기. 녹음/타입캐스트→본인 촬영·허용 스톡·AI 삽화→Clipchamp/Vrew 교정 자막. Flow의 참조·동작 지시·모델·비율·8초·출력수·크레딧→클립 연결→자막·음악·MP4. 타임라인 유지. |

시간은 독자가 잡는 연습 일정이며 실제 서비스 처리시간·숙련자 평균으로 쓰지 않았다. 무료는 무료 요소·본인 소재·남은 한도 안의 추가 지출을 뜻한다. 영상 생성은 `3샷×2안×20=120크레딧`, 월 구독과 크레딧을 구별했다. 스타터 키트의 필드 설명은 각 장 마지막 “자동화·무료 대안” 상자에 모았다.

## 근거와 이미지

R3 조사 노트와 SOURCES/FACT-SHEET의 기존 근거를 사용했다. 관련 사실 묶음은 6장 AIP-001~008, 7장 AIP-010·018~023·067~068, 8장 AIP-007·027~028·034~040·053·061이다. 내부 사실 ID는 교과서 본문에 쓰지 않았다. 서비스 품질 순위·고정 무료 장수를 새로 만들지 않았다. 공식 ChatGPT 검색, Canva 카드뉴스, 미리캔버스 AI, Clipchamp 가격·자막, Flow 크레딧·지원국, 타입캐스트 가격도 직접 재열람했다.

- [가상 도서관 삽화](../../site/assets/img/ai-examples/library-evening.webp): 내장 `image_gen`으로 실제 생성 후 960×1200 WebP·109,058바이트로 압축했다. 400KB 이하이며 서비스 화면·로고·실존 인물·브랜드는 없다.
- 본문에 **AI 생성 예시**와 실제 사용 프롬프트를 표시한다. 생성 지시·파일 크기·해시는 [image-provenance.json](phase-AIb/image-provenance.json)에 보존한다. 카드·요약·영상 전후 문안은 가상 비교이며 서비스의 실제 생성 성공 사례로 서술하지 않았다.
- 원래 크레딧이 가리키는 각주 주소는 담당 장의 “함께 읽을 자료”에 유지했다.

## 남은 통합과 검증 한계

- [공통 변경 요청](phase-AIb-requests.md)에 장 제목·결과물 메타, 실험실 목록, 크레딧/AI 이미지 고지, 프로젝트 상태 diff를 남겼다. 공통 파일·상태 문서는 수정하지 않았다. 공통 JS가 현재 제목·메타를 넣으므로 통합 전에는 기존 장 이름이 표시된다.
- 실제 외부 서비스 로그인·메뉴 조작·결제·음성/영상 생성·인스타 게시를 실행하지 않았다. 메뉴는 조사 문서 기반이며 버튼 변경 안내와 공식 각주를 제공한다. 생성 영상의 품질·발음·실처리시간을 검증했다는 뜻은 아니다. 실제 생성한 것은 동봉 삽화다.
- 작성자의 질문별 검수와 자동 검증이며 별도 초보자 사용자 실험은 아니다. Claude Code의 통합·검수가 남아 있다.
- 작업 중 실습편·ShortsBook의 다른 변경이 나타났다. 해당 파일은 수정하거나 되돌리지 않았으며, 정적 검사는 마지막 시점의 통합 작업 공간을 검사했다. commit·push는 시도하지 않았다.
