## 안전·저장 설계

- `FACT-SHEET`의 확인 사실을 각주로 연결했다. 담당 정적 HTML이 인용하는 출처 56개 모두 `research-baby/SOURCES.md`에 있다. 원문 재열람은 N001·N010·N073·N102를 확인했다. 조사 문서는 변경하지 않았다.
- 분유 조유, 속싸개·공갈젖꼭지, 통목욕의 국내/국외 차이를 양쪽 각주와 한 상자에 적었다. 목욕물 온도는 같은 국내 포털의 차이도 숨기지 않고 두 출처를 함께 적었다.
- 응급 안전 판정, 분유 권장량 계산, 약 이름·용량, 황달/변 사진 진단, 발달 합격표를 만들지 않았다. 사례는 가상 연습이며 증상이 있으면 연습보다 연락을 먼저 한다.
- 날짜 계산은 출생일부터 일수·주령·달력 월령을 구분한다. 월의 같은 날짜가 없으면 말일을 **참고일**로 표시한다. 로타 첫 접종 상한은 14주 6일(출생일 +104일)이다. 법정 마감이나 개인 검진 종료일을 확정하지 않는다. 공단 대상조회·기접종 간격·산모 검사·미숙아 여부는 기관에서 대조한다.
- 생년월일은 달력 계산 화면에서만 사용하고 저장하지 않는다. `babybook:booking:v1`에는 기관·예약 목적·날짜·통화 상태·준비물만 저장한다. 대기와 예약 확정을 구분한다.
- `babybook:care-log:v1`에는 실제 관찰 기록만 저장한다. 오늘 요약은 기록 횟수이며, 수면 시작·끝 횟수를 따로 표시한다. 모유 mL 추정과 정상/위험 판정은 없다.
- 저장 읽기·쓰기·삭제에 예외 처리를 둔다. 차단 시 현재 화면에서 계속 기록하고 CSV/종이로 옮기게 한다. CSV는 UTF-8 BOM·따옴표 이스케이프와 수식 시작 문자 처리를 적용한다. 내려받기에는 Blob만 사용하고 외부 전송하지 않는다.
- 기기/탭 사이 동기화는 없다. 한 기기·한 탭과 교대 때 최근 기록을 읽는 방법을 안내한다. E2E·실습 체크는 현재 페이지에서만 표시하며 인쇄로 보관한다.

## 남은 검토·제한

공용 통합 후 `check_site`와 실제 목차·앞뒤 링크를 다시 검사해야 한다. N7 독립 초보 부모/건강 안전 검토와 N8 전체 게이트는 별도 단계다. 기관에 직접 전화하거나 아기를 돌보는 실기, 실제 프린터·휴대폰·타 브라우저 검증은 수행하지 않았다. 실제 로그인을 통한 접종 기록/검진 대상조회와 예약 완료는 독자가 본인 상황에서 진행한다.

작업 시작 시 미추적 프롬프트와 병렬 작성자의 원고·전용 자산·결과 문서를 보존했다. 공용 자산·실습 7·조사 자료·상태 문서는 수정하지 않았고 commit/push하지 않았다.

지정한 `scripts/notify.py`로 한국어 완료 보고를 전송했다. HTTP 200, 메시지 ID `1564575019936522241`을 확인했다. 토큰은 출력·저장하지 않았다.
