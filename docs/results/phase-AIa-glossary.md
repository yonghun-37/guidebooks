# AIa 신규 용어 후보

기존 용어집은 수정하지 않았다. 통합 시 필요한 항목만 기존 생성기에 합친다.

| 용어 | 제안 ID | 쉬운 설명 | 첫 등장 |
|---|---|---|---|
| AI 모델 | ai-model | 서비스 안에서 글·그림·소리를 생성하는 엔진. 같은 모델도 쓰는 앱에 따라 요금과 조건이 달라진다. | `chapters/05b-ai-tools.html#writing-tools` |
| 크레딧 | credit | 서비스가 사용량을 차감하는 내부 포인트. 다른 업체·앱·API의 포인트와 합칠 수 없다. | `ai-models.html#billing` |
| 토큰 | token | 모델이 글·소리를 나누어 세는 단위. 글자 수와 같지 않다. | `ai-models.html#start` |
| MTok | mtok | 100만 토큰. API 입력과 출력 단가를 읽는 단위. | `ai-models.html#start` |
| 번들 | bundle | 한 구독에 여러 제품의 이용량을 묶은 상품. 제품마다 잔액은 다를 수 있다. | `ai-models.html#billing` |
| C2PA | c2pa | 파일에 제작·편집 출처를 담는 메타데이터 체계. 업로드 때 AI 공개 판단을 대신하지 않는다. | `ai-models.html#disclosure` |
| SynthID | synthid | AI 생성 파일에 심는 비가시 출처 신호. 가시 로고·플랫폼 공개 설정과 구별한다. | `ai-models.html#disclosure` |

상업 이용·AI 공개는 `research/ai-production.md`와 `research/ai-models-pricing.md`의 연결 출처 범위에 맞춰 설명한다. 기존 API·TTS·지시문 항목은 재사용한다.
