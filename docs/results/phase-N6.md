## 출처·용어·실험실 구현

- `scripts/build_baby_appendices.py`는 현재 HTML·동적 각주에서 인용 N번호를 모으고 `research-baby/SOURCES.md` 원본의 기관·문서 제목·URL·날짜·확인 위치·상태·적용 한계를 옮긴다. **인용 101개만 등록하고 나머지 24개는 등록하지 않았다.** 연구 원본은 변경하지 않았다. 제작 도구 이름이 들어간 메타데이터 1곳은 ‘보조 조사’로 풀되 날짜·확인 상태는 유지했다.
- 장별 `.source-notes`·`.chapter-sources` 임시 목록을 제거했다. 정적 각주·달력·지원금 표·응급 상자는 모두 `credits.html#n###`를 연다. 장 끝 안내도 같은 문장·공용 링크로 통일했다.
- 용어 40개는 본문 설명 범위로 짧게 정의했다. 의료 용어는 근거 각주, 파일 형식·가족 계획 용어는 사용 본문에 연결했다. 검색·앵커 복원·첫 사용 링크 33개를 제공한다. 새 진단 기준·용량·발생률을 만들지 않았다.
- 실험실은 이론 도구 13개와 실습 8·9 도구 2개를 재사용한다. 연락처의 중복 사용처는 7장 원본 1개로 등록했다. 계산식·HTML 사본은 만들지 않았다. 위기 카드와 인쇄물은 부록 목차에서 연다.
- `check_site.py`에 선택적인 `track: 'practice'` 경로 처리를 추가했다. 기존 책의 경로 동작은 유지했고 회귀 테스트를 추가했다.
