## 구현 방향·소유 범위

1~4장 HTML과 새 전용 JS만 수정한다. 샘플 A의 반복 틀, B의 짧은 직답 FAQ, C의 단계표를 공통 부품으로 옮긴다. 질문과 연결되지 않는 가중치·장부·니치 점수 체험은 장에서 연결을 끊고 기존 JS 파일은 보존한다. 기존 절·실험실 진입 앵커는 유지한다. 연구·공통 파일·상태 문서는 수정하지 않으며 통합 요청은 `phase-9a-requests.md`에 기록한다.
