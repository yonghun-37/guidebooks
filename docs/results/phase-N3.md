- 은주는 두 아이를 키운 가상 선배 부모이며 **의료인이 아니다**. 의학 판단을 자신의 경험으로 내리지 않고 공식 안내·의료진으로 연결한다.
- 샘플 A는 생후 3주 봄이가 밤에 따뜻하게 느껴질 때다. 서윤은 연락하고 민재는 측정·수유 기록을 챙긴다.
- 샘플 B는 퇴원 5일째 신청하는 장면이다. 퇴원일을 출생일로 치환하지 않는다.

## 결정 사항·안전 경계

1. 모든 장 데이터는 `준비중`이다. 샘플이 있는 항목만 `sample` 표기로 실제 파일에 연결한다. 완성된 책으로 표시하지 않는다. 표지 실습 시작은 지금 할 수 있는 실습 7로 간다.
2. 응급 상자는 `119 / 즉시 진료 / 오늘 소아과에 묻기`다. 안전 판정·초록 칸·응급 점수 계산은 없다. 배꼽의 통일 문구는 계속 나는 피에 대한 즉시 행동을 포함하므로 전체 상자에서는 즉시 진료 쪽에 둔다. 축 설명에서는 붉어짐·고름과 지속 출혈의 행동을 구분한다.
3. 장·실습·인쇄·연락처 도구는 같은 `emergency-data.js`를 로드한다. 문자열을 HTML이나 다른 JS에 복사하지 않는다. 브라우저 검사에서 BRIEFING 원문과 일곱 문자열이 정확히 같은지, 실제 렌더링도 같은지 대조했다.
4. 지정한 진료 안내 문장은 표지·7장 각 1회만 있다. 3개월을 일수로 치환하지 않으며, 낮은 측정값으로 안전을 선언하지 않는다. 약 이름·용량, 진단용 변 색표·아기 사진·기관 로고·실제 앱 화면은 없다.
5. 실습 완료는 **제출 항목·접수내역 확인·다음 확인일**이다. 출생등록 수리·급여 결정·지급은 후속 상태다. 방문 전이라면 미제출·방문 예정으로 기록한다. 접수번호 원본은 개인 보관하고 책에는 항목·상태·날짜만 남긴다.
6. 연락처와 신청 기록은 `babybook:contacts:v1`, `babybook:applications:v1`에만 저장한다. 읽기·쓰기·삭제를 try/catch로 보호하며 외부 전송하지 않는다. 저장이 막히면 현재 화면에서 계속 쓰고 종이·인쇄로 남기도록 안내한다. 출생일 계산 입력은 저장하지 않는다.
7. 계산은 **2026-10-27 고정 조사일의 0~23개월 단면 예상액**이다. 미래 출생·범위 밖 월령·잘못된 날짜·선택값을 거절한다. 다음 해 정책을 자동 연장하지 않는다. 지역 모름은 `10만 원 이상, 지역 확인 필요`로 표시하고 확정 합계를 만들지 않는다.
8. 월 현금(부모급여·아동수당), 어린이집 보육료, 1회 첫만남 바우처를 분리한다. 지역 상품권 추가분은 현금 합계에서 제외하고 시행 여부를 주민센터에 묻게 한다. 실제 지급 조건은 결정 통지로 확인한다.
9. 10장은 계산기만 있는 준비중 원고다. `data-manuscript="pending"` 표식을 정적 검사에서 인식해 완성 이론 장으로 세지 않는다. 완성된 샘플 A의 9블록·퀴즈·그림·출처 검사는 그대로 수행한다. 신규 원고이므로 축약률 비교 기준선은 만들지 않았다.

## 근거 연결

건강·제도 주장은 기존 FACT-SHEET의 확인 사실과 N각주로 연결했다. 상충 항목을 확정 수치로 새로 도입하지 않았다. 미확인인 수첩 실수록·실시간 진료 가능 여부·인증 뒤 화면은 각각 실제 수첩 요청·기관 전화·본인 신청내역 확인 행동으로 안내한다.

| 샘플 내용 | 사실표 연결 | 원문 각주 |
|---|---|---|
| 발열·측정·호흡·탈수·야간·약 문의 | NB-SICK-01~06 | N001·N085·N090·N069 |
| 황달·구토·배꼽 | NB-JAUND-01·02·04·05, NB-BODY-01·02 | N003·N031·N060·N007 |
| 먹기·의료진에게 전할 기록 | NB-FEED-03, NB-RECORD-01 | N005·N019·N001·N073 |
| 고정 부모 위기 문구 | NB-PARENT-02·04 | N052·N054 |

N001·N037·N095·N098 공개 원문도 이번 단계에서 다시 열어 발열/측정, 보육료 차액, 지역 금액, 등록 처리 조건을 대조했다. 연구 문서·원응답은 수정하거나 사이트에 동봉하지 않았다.
