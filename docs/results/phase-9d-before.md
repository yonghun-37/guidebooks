# Phase 9d 개편 전 채점

2026-10-26. 본문 수정 전에 기록했다. 기준은 [확정 문체 기준](../STYLE-GUIDE.md) 5절이다. 점수는 기준별 통과 1·불통과 0이며, 부분 충족은 통과로 세지 않았다. ①은 다섯 질문 모두에 첫 문장 직답·숫자 또는 예·할 일이 있어야 1점이다. ⑤ 70% 분량은 실습편이므로 적용하지 않아 6점 만점이다. ④는 실습편의 지금/왜/따라 하기/성공/오류/OS 틀로 판정했다.

질문 원본 [learner-questions](../learner-questions.md)은 이론 1~14장만 수록한다. 아래 실습 질문은 그 문서의 1·4~12·14장 질문을 실제 조작 상황에 옮겼으며, 원문에 실습 질문이 있었던 것처럼 처리하지 않았다. E2E 질문은 ‘무엇부터/얼마나 남았나/선택 경로도 필수인가/어디서 재개/기록이 사라지면’이다.

실습 0~10 자동 검사: 금지어 29회·내부 용어 54회·상자 밖 단서 45회. 모든 실습이 문체 검사에 실패했다. 원본 파일과 해시는 `/tmp/phase9d-before/`, 공통 기준선은 `phase-9/baseline.json`에 보존했다. 기준선을 다시 만들지 않는다.

주요 불통과 사유: 0은 첫 행동 앞 시간 면책, 1은 계정 수·공개 효과를 모호하게 안내, 2~3은 작성자 검증 설명과 작업 용어, 4~5는 본문 사실 ID와 각주 없는 규격, 6~7은 확인된 메뉴 대신 후보 반복, 8은 권한·일반 공개 조건과 한도 충돌 설명의 긴 문장, 9는 재조사된 예약 한도·메뉴 미반영, 10은 실제 진입 대신 후보, E2E는 기본/선택/게시 완료의 구체적 종료점 부족이다. FAQ가 없어 질문별 답이 단계 사이에 흩어졌다.

아래 질문마다 개편 후 FAQ에 직답·예·행동·본문 링크를 넣고 재채점한다.

### 실습 0

- 오늘 무엇부터 하나요?
- 처음 한 번 올리는 데 API가 필요한가요?
- 돈을 내지 않고 연습할 수 있나요?
- 시간이 부족하면 어디까지 하나요?
- 막히면 무엇을 남기나요?

### 실습 1

- 연습 계정은 어떻게 만드나요?
- 계정은 몇 개까지 추가하나요?
- 프로페셔널로 바꾸면 비공개로 연습하나요?
- 계정을 잃지 않으려면 무엇을 하나요?
- 개발자 계정과 이메일 +별칭도 필요한가요?

### 실습 2

- 무엇을 설치하나요?
- 명령은 어디에 입력하나요?
- API 키 없이 실행할 수 있나요?
- 검수 대기에서 멈췄는데 실패인가요?
- 다시 실행하니 폴더가 있다고 해요.

### 실습 3

- AI에게 무엇을 넣나요?
- 무료 채팅을 못 쓰면 어떻게 하나요?
- AI가 지어낸 숫자는 어떻게 찾나요?
- 출처는 어디에 쓰나요?
- 실제 자료로 바꾸려면 무엇을 하나요?

### 실습 4

- 카드는 몇 장, 어떤 크기로 만드나요?
- 글은 어느 파일에서 고치나요?
- 색을 바꿨는데 왜 그대로인가요?
- PNG와 JPEG 중 무엇을 올리나요?
- 작은 글자가 안 읽히면 어떻게 하나요?

### 실습 5

- 목소리 없이도 만들 수 있나요?
- 내 목소리는 어떻게 넣나요?
- 영상 길이는 어떻게 정하나요?
- 자막과 음성이 안 맞으면 어떻게 하나요?
- 카드를 영상으로 만들면 수익화되나요?

### 실습 6

- 검수는 무엇을 확인하나요?
- AI 표시는 언제 켜나요?
- 제품만 받았어도 광고 표시를 하나요?
- 승인하면 바로 올라가나요?
- 승인 뒤 제목을 고쳐도 되나요?

### 실습 7

- 첫 게시에도 토큰이 필요한가요?
- 카드를 어떤 순서로 선택하나요?
- 릴스 표지는 어디서 바꾸나요?
- AI·협찬 버튼이 안 보이면 그냥 올리나요?
- 게시 완료는 어떻게 확인하나요?

### 실습 8

- 자동 게시에는 무엇이 필요한가요?
- 토큰은 어디에 두고 언제 갱신하나요?
- 내 컴퓨터의 파일을 바로 보내나요?
- 하루 게시 한도는 100개인가요, 50개인가요?
- 실패하면 다시 누르면 되나요?

### 실습 9

- 며칠 전부터 몇 개 예약하나요?
- 예약하면 컴퓨터를 꺼도 되나요?
- PC에서는 어디서 예약하나요?
- 예약을 고치거나 멈추려면요?
- 예약 버튼이 없거나 라벨이 빠지면요?

### 실습 10

- 인사이트는 어디서 보나요?
- 처음에는 어떤 숫자를 적나요?
- 언제, 어떤 기간으로 비교하나요?
- 빈칸이면 0으로 적나요?
- 조회가 낮으면 무엇부터 바꾸나요?
