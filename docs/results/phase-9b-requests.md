# Phase 9b — 공통 파일 통합 요청

담당 원고는 공통 부품 변경 없이 검증을 통과했다. 아래 파일은 소유 범위 밖이므로 수정하지 않았다. 통합 담당자가 다른 개편 결과와 함께 적용한다. `book.css`·`common.js`의 변경 요청은 없다.

## 상태·출처·진행 현황 인계

동시 편집 규칙에 따라 PROJECT_STATE·출처 부록·진행 현황·공통 생성 스크립트를 수정하지 않았다. 통합 시 이론 5~9장 개편·도구 축소·FAQ 25개와 [최종 결과](phase-9b.md)를 반영한다. 출처 부록이 링크하는 기존 각주 ID는 담당 HTML에서 모두 유지했다. 기존 원고 전체를 그대로 포함하거나 옛 JS를 새 DOM에 다시 연결하지 않는다.
