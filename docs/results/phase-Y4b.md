- [x] 6장 촬영·소재·AI 생성: 전체/가까운 구도와 가상 가림 영역 비교.
- [x] 7장 편집: 장면·자막·음성·음악 공통 시간축, 컷·자막·음성·음악 시간 수정, 재생 헤드·구간 반복·프레임 정지.

- [x] 문체·정적 검사와 브라우저·경계값·키보드 검사 완료 및 증거 보존.
- [x] 통합 요청 diff·용어·실제 결과 확정.

## 구현과 제한

네 장 모두 9블록, 설명 축 3개, FAQ 5개, 정리 3줄, 퀴즈 3개다. 동일한 자체 책상 장면을 SVG/Canvas로 그렸다. 플랫폼 로고·UI·외부 이미지/음원·CDN JS·신규 의존성이 없다.

- 6장: 물건 위치·전체/가까운 구도·가림 표시, 물건과 가림 영역 경계상자 교차 수, 프레임 밖 잘림을 텍스트로 알려 준다. 경계상자 검사는 정밀한 모양별 마스크 검사가 아니다.
- 7장: 가상 12초·30fps의 무음 시간표다. 중간 자막 시작·끝, 첫 컷, 음성 시작, 음악 끝과 반복 범위를 수정한다. 음성/음악은 실제 소리가 아닌 시간 구간 도식이다. 중간 자막 끝−중간 음성 끝을 결과로 표시한다.
- 8장: 공백 제외 글자 수÷초를 보여 준다. 자동 가독성 합격 판정이 없으며 실제 폰에서 읽도록 안내한다. 가상 말은 3초이며 자막 표시 시간이 짧으면 실제 재생 중 먼저 사라진다.
- 9장: 동일 합성 동작의 크기·fps·비트레이트 중 한 변수씩 바꾼다. 낮은 데이터에서는 블록 형태를 강조한다. 실제 코덱 인코딩이나 플랫폼 재압축의 품질을 모사하지 않는다. 예상 MB는 음성과 파일 정보를 제외한다.
- 조작은 네이티브 입력·버튼으로 제공한다. 자동 재생하지 않으며 화면 밖·탭 숨김·페이지 이탈·동작 줄이기 설정 전환 시 멈춘다. 동작 줄이기 환경에서도 명시적 재생과 프레임 이동을 사용할 수 있다. 입력은 저장하지 않는다.
- 공용 목차 데이터가 준비중인 상태는 유지했다. 담당 장은 직접 URL과 본문의 6~9장 이동 링크로 연결된다. 공용 목차·상태·문서 제목의 준비중 표시 해제는 통합 요청 diff에 있다.

## 발견·수정

- 초기 자막 상자의 가로 끝이 가상 오른쪽 가림 영역과 겹쳐 기본 예제부터 경고가 발생했다. 상자 폭을 줄여 기본 예와 극단 예가 구분되도록 수정한 뒤 전체 검사로 확인했다.
- 가림 영역을 숨겼는데 프레임 잘림 안내가 먼저 나오는 경우, 숨김 상태가 먼저 전달되도록 결과 우선순위를 정리했다.
- 재생 중 상태 문장을 매 프레임 다시 쓰지 않게 했다. 재생 헤드의 실시간 숫자는 `aria-live=off`로 두고, 결과와 재생/정지 상태만 안내한다.
- 공용 SVG 조판의 여백과 모바일 필드 그리드가 전용 도구에 적용되는 문제를 전용 CSS 범위 안에서 해소했다.
- 별도 서버 프로세스 종료로 최종 글꼴 검사 한 번이 연결 거부로 끝났다. 임시 HTTP 서버와 검사를 같은 Python 프로세스에서 관리해 최종 243개 검사를 통과했다.

## 통합에 남긴 것

[통합 요청 diff](phase-Y4b-requests.md)에 6~9장 상태·URL·배지·제목과 사실표 보충을 남겼다. 새 용어는 [용어 제안](phase-Y4b-glossary.md)에 있다. 공용 목차가 아직 준비중으로 가리키는 점은 통합 단계에서 해소한다. 이번 작업은 담당 장의 직접 URL·본문 연결로 검증했다. 프로젝트 상태·서가 진행표는 통합 담당자가 다른 묶음과 함께 갱신한다.

실제 Windows/macOS/휴대폰의 편집기 설치·출력·한국어 인식·AI 메뉴·업로드·기기별 플레이어 가림은 실행하지 않았다. 도구는 무음 도식/합성 그림이며 실제 인코딩 품질이나 플랫폼 가림 치수를 보장하지 않는다.
