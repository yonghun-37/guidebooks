# BlogBook 설계서 (블로그 수익화 편)

작성: 2026-10-26, Claude Code. 사용자 지시: 인스타·쇼츠 편과 비슷한 구성으로 **블로그 수익화** 교과서. 이론편/실습편 분리, 실습편은 오늘 기준 **실제 글 발행 완료**까지. 문체·구성은 docs/STYLE-GUIDE.md(확정)를 그대로 따르고, docs/DESIGN.md 12절(AI 제작 핵심 모듈)을 책의 중심에 둔다. 제작 순서는 .agents/skills/guidebook-pipeline을 따른다.

## 1. 목표와 성공 기준

초보자가 실습편을 끝내면 손에 남는 것:

1. 내 블로그 기획 메모(플랫폼 1개, 주제 1개, 독자, 수익 경로 1개)
2. 키워드 3개와 고른 이유(무료 도구의 실제 숫자)
3. **AI 서비스로 만들고 내 경험·사실 확인을 더한 글 1편**: 제목 → 개요 → 초안 → 사실 확인 → 내 경험·사진 → 이미지/썸네일 → 편집기 정리
4. **네이버 블로그 또는 티스토리(또는 워드프레스·블로거)에 실제로 발행한 글 1편과 그 주소(오늘 완료 목표)**
5. 검색 등록(서치어드바이저·Search Console) 완료, 수익 장치 신청 상태(애드포스트·애드센스·제휴 가입 중 해당하는 것)
6. (선택) blog-kit로 같은 글을 템플릿·검사·API 발행 드라이런으로 반복하는 방법

인스타·쇼츠 편과의 관계: 같은 AI 도구(ChatGPT·Gemini·Claude, Canva 등)를 쓰지만 이 책의 중심은 **검색으로 읽히는 글**이다. 다른 책을 읽지 않아도 따라 할 수 있게 쓴다.

## 2. 책의 핵심 메시지 (조사로 확인·수정)

- 블로그 수익은 크게 **광고(애드포스트·애드센스) / 제휴(쿠팡 파트너스·쇼핑커넥트 등) / 협찬·체험단 / 내 상품** 네 갈래다. "방문자 하루 ○명이면 한 달 얼마"를 근거 있는 참고치 + 계산식으로 직답한다.
- AI로 글을 "찍어내면" 검색에서 밀리고(구글 스팸 정책의 대량 생성 콘텐츠, 네이버의 품질 판단) 광고 승인도 어렵다. **AI는 조사·개요·초안·교정, 사람은 경험·사진·사실 확인**이라는 분업을 레시피로 가르친다.
- 플랫폼 선택이 수익 경로를 정한다(네이버=애드포스트·쇼핑커넥트 중심, 티스토리/워드프레스/블로거=애드센스 중심). 자동 발행 가능 여부도 플랫폼마다 다르다(조사로 확인).

## 3. 인물

- **수아**(초보, 회사원, 퇴근 후 하루 1시간): 질문하는 쪽.
- **태오**(블로그 6년 차 운영자, 멘토): 직답하는 쪽.
- 두 사람과 사례 블로그는 가상이다. 실제 사례는 출처를 달아 인용한다.

## 6. AI 제작 레시피(이론 6·7장, 실습 4·5의 본체)

결과물 예시 → 쓰는 서비스 → 단계별 입력·출력·복사용 프롬프트 → 좋은/나쁜 결과 → 흔한 실수 → 시간·비용.

- B1 **정보·해결 글**: 키워드 → AI로 검색 의도·질문 목록 → 개요 → 초안 → 출처 대조·숫자 확인 → 내 경험/스크린샷 → 제목 3안 → 요약·FAQ
- B2 **사용 후기·비교 글(제휴)**: 직접 사용한 제품 → 사진 촬영 → 장단점 메모 → AI로 구조화·비교표 → 대가성 문구(본문 첫머리) → 제휴 링크
- B3 **내 경험 기록 글**: 음성 메모/메모 → AI로 정리(받아쓰기 → 구조화) → 사진 고르기 → 다듬기
- 공통: 썸네일(Canva/미리캔버스 템플릿 또는 AI 이미지), 이미지 대체 텍스트, AI 사용 범위 기록

## 7. 인터랙션 후보 (책의 감각을 키우는 도구)

- 수익 계산기: 방문자 × 페이지/방문 × RPM 참고치 + 제휴 전환(가상·참고 표시, 내 값으로 바꿔 넣기) — 2장
- 플랫폼 고르기 분기(목표 수익 경로·자동화 필요·도메인 의사) — 4장
- 키워드 고르기 연습: 검색량·문서 수·경쟁 예시 표에서 고르고 이유 보기 — 5장
- AI 초안 → 사람 손질 전후 비교(사실 확인·경험 문장·중복 표현 하이라이트) — 6장
- 검색 결과 미리보기(제목 길이·설명 잘림, 모바일/PC) — 8장
- 발행 전 체크 분기(대가성 표기·이미지 권리·AI 사용·광고 위치) — 9·12장
- 숫자 해석(유입 키워드·클릭률 변화 읽기) — 11장

## 8. 스타터 키트(blog-kit)

`blog-kit/`(Python 3.10+, 표준 라이브러리 우선, 오프라인·무료):
- `brief.py`: 키워드·유형 → AI에 붙여 넣을 프롬프트 묶음(md) 생성
- `check.py`: 초안 md 검사 — 제목 길이, 소제목 구조, 글자 수, 이미지 대체 텍스트, 대가성 문구 유무(제휴 링크가 있을 때), 사실 확인 표시(숫자 문장에 출처 메모), 중복 문장
- `render.py`: md → 편집기에 붙여 넣을 HTML / 미리보기
- `publish.py`: 블로거 API·워드프레스 REST(조사로 가능한 것만) 발행 — **기본 드라이런**, `--live`는 사용자가 .env를 직접 넣었을 때만
- 테스트 pytest, 샘플 글 1편(가상 주제)

## 11. B2 조사 반영 (Claude 검수, 2026-10-26)

docs/results/phase-B2.md·research-blog/BRIEFING.md ⑧의 제안 1~7을 모두 채택한다.
- 실습 7 기본 플랫폼 = **네이버 블로그**(전체 공개·현재 발행·URL 저장), 티스토리는 애드센스 목표 대안 탭.

- 티스토리 AdFit 신규 연동 종료(2026-06-29) 반영, 쇼핑커넥트·조건부 신청·정산 상태 보강.
- API 자동 발행: 네이버 글쓰기 API·티스토리 Open API는 종료 → blog-kit 발행 대상 아님(로그인 매크로 금지). 실습 10 선택 API = Blogger(무료) 기본, 설치형 WordPress 심화, WordPress.com OAuth는 비교 표. 드라이런(쓰기 0회) → 초안 저장 → 공개 확인·중복 점검.
- 수익 계산기: UV/방문/PV·페이지 RPM·예상/확정/입금·취소를 구분하고 "한국 평균" 기본값을 넣지 않는다(개인 공개 사례는 사례로만, 계산식은 가상 표시).
- 처음엔 ChatGPT Free 하나, 무료 완주 조합 0원, 월 1~3만 원 조합(미리캔버스 Pro 14,900원).
- B1~B3 입력 차이와 사람 검수가 실습 4의 본체.

### 예시 (STYLE-GUIDE 7절)
수아의 가상 블로그 "퇴근 후 생활 정보" — 실제로 검색되고 읽히는 글로 장을 관통한다.
- B1 정보 글(대표): 공공 자료(공공누리 제1유형 등 이용 조건 확인)로 만드는 "청년·직장인 지원 제도 신청 방법 정리"류 글. 확인 안 되는 제도·금액은 지어내지 않는다.
- B2 사용 후기·비교 글: 실제로 한 달 써 본 생활 가전·앱 후기(예시에서는 브랜드 이름 없이 범주로), 대가성 문구·제휴 링크 위치 시연.
- B3 경험 기록 글: 주말 당일치기 여행·맛집 기록(직접 사진 + 메모 → AI 정리).
