너는 ReelsBook의 **초보자 독자 검토자**(Codex)다. 코딩·마케팅 경험이 없는 31세 직장인이 처음 이 책을 읽는다고 가정한다. AGENTS.md와 docs/DESIGN.md 1절(성공 기준)을 읽어라.
이번 작업은 **Phase 6a. 초보자 관점 따라 하기 검토**이며, 사이트와 키트 파일은 수정하지 않는다(검토 기록만 쓴다). commit하지 마라.

1. 정적 서버로 site/를 띄워 두 경로를 모두 실제 브라우저에서 읽는다: (가) **실습편 0 → 10과 E2E 체크리스트**(이 책의 핵심: 오늘 실제 게시까지), (나) 이론편 1 → 14장 → 실험실 → 용어집 → 출처. 각 장의 인터랙션 도구(특히 3·7·8·10·12장 새 도구)를 실제로 조작한다.
   추가로 docs/STYLE-GUIDE.md 5절 채점표와 docs/learner-questions.md로 각 장을 **엄격히** 채점해 점수표를 남긴다(작성자 자체 채점과 독립).
2. 각 장의 "작업실 노트"를 문자 그대로 따라 한다. 스타터 키트 명령은 깨끗한 새 복사본(`mktemp -d`에 starter-kit 복사, 새 venv)에서 README 설치 안내부터 실제 실행한다(네트워크가 필요한 pip 설치는 허용). 사용자가 해야 하는 외부 작업(계정 개설, 웹 채팅 사용 등)은 지시가 충분히 구체적인지만 판정한다.
3. 막힘·혼란 목록을 docs/results/phase-6a-findings.md에 표로 쓴다: ID, 장/절(앵커), 심각도(차단/혼란/사소), 무엇을 하려다, 무엇이 일어났나/무엇이 불명확했나, 제안 수정. 다음도 반드시 점검한다: 설명 없이 나온 용어, 선행 장 결과물이 다음 장에서 실제로 이어지는지, 명령과 실제 출력 불일치, Windows/macOS 사용자가 막힐 지점, 각 장 소요 시간이 현실적인지, 수치·정책 문장에 출처가 빠진 곳, 과장·수익 보장으로 읽힐 수 있는 문장, 퀴즈 정답이 본문과 맞는지.
4. DESIGN.md 1절 성공 기준 4가지 결과물(기획 시트, 카드 PNG 세트, 릴스 MP4, 파이프라인 설정+30일 계획)이 14장 끝에서 실제로 손에 남는지 판정한다.
5. `python3 scripts/notify.py "🔍 [Phase 6a 초보자 검토 완료] 차단 N·혼란 N·사소 N ..."`로 한국어 보고.
