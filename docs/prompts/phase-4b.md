검수 지적과 요구:
1. **카드 디자인이 실제 뉴스카드처럼 보이지 않는다.** 템플릿 3종 이상을 만든다: 표지(큰 헤드라인·핵심 숫자/키워드 강조색·계정 브랜딩), 본문(요점 1~3개, 번호), 마무리(출처·저장/공유 유도 문구·계정명). 강조 구문 마킹(예: `**강조**`)을 지원하고, 선택적 이미지 슬롯(사용자 제공 이미지, 없으면 패턴 배경)을 둔다. 테마 색 2~3개 프리셋. "합성 데이터" 표시는 샘플에서만 작고 눈에 덜 띄게 하되 유지한다.
2. **릴스가 정지 화면+무음이라 Meta 수익화 정책상 '정적 영상·슬라이드쇼' 제한(META-06)에 걸릴 수 있다.** 카드별 장면 전환, 느린 줌/팬, 자막 단어 단위 하이라이트 또는 등장 애니메이션, 진행 막대 등 움직임을 넣는다. 교과서가 이 한계를 설명할 수 있도록 README에 "이 예제는 연습용이며 수익화 적격을 보장하지 않는다, 직접 촬영·내레이션 같은 독창적 요소를 더하라"를 명시한다.
3. **음성 옵션**: 기본은 무음+자막 유지. 선택 옵션으로 ① 사용자가 녹음한 내레이션 파일(mp3/wav) 넣기(가장 권장, 권리 문제 없음) ② 사용자가 선택하는 TTS 백엔드 플러그 구조(라이선스 확인 책임을 README에 명시, 기본 비활성). 배경음악도 사용자 제공 파일만 받는다(라이선스 확인 체크박스를 REVIEW.md에 추가).
4. **LLM 연결(6장용)**: write_copy.py에 세 모드: `offline`(현행), `prompt`(무료 경로: LLM에 붙여 넣을 프롬프트 파일을 만들고, 사용자가 ChatGPT/Claude/Gemini 등 웹 채팅 답변 JSON을 `copy.json`에 붙여 넣으면 스키마 검증), `api`(OpenAI 호환 엔드포인트, 환경변수 키·모델명, 기본 비활성, 테스트는 모킹). 프롬프트 템플릿 3종(카드 문안, 릴스 대본, 캡션+해시태그)을 `prompts/`에 두고, 사실 추가 금지·출처 유지·과장 금지 규칙을 넣는다.
5. 테스트 확장 후 모두 통과, samples/ 재생성(10MB 이하), README·docs/results/phase-4b.md 갱신. 새 샘플 카드 3장과 릴스 중간 프레임 스크린샷을 docs/results/phase-4b/에 저장.
