검토 항목:
1. 근거 일치: 건강·제도 주장마다 인용한 N### 원문(SOURCES의 URL)과 맞는지 확인한다.
   - 숫자, 조건, 대상(월령·만삭/미숙아), 국내/국외 표시
   - 위험도가 높은 주장은 원문을 직접 열어 대조한다: 발열 기준, 응급 신호, 수면 안전, 분유 물 온도·보관, 모유 보관, 황달·변 색, 접종 일정·로타 마감, 검진 시기, 지원금 금액·기한, 휴가 일수
   - 열 수 없는 원문은 "대조 불가"로 표시한다.
2. 8절 위반 여부:
   - 약 이름·용량
   - 브랜드
   - 진단처럼 읽히는 판정, 특히 "괜찮다·지켜봐도 된다"로 읽히는 문장
   - 분유량 계산
   - 자체 색표
   - EPDS 점수
   - 100일 이유식·통잠 목표
   - 평균을 개인 목표처럼 쓴 곳
3. 응급 신호 일관성:
   - 응급 신호가 등장하는 모든 곳이 공통 문구와 같은지 확인한다.
   - 응급 신호를 넣어야 하는데 빠진 장(먹이기, 잠, 울음, 기저귀, 몸, 성장 등)이 없는지 확인한다.
   - 역명제("38℃ 미만이면 안전")나 3개월=90일 같은 치환이 없는지 확인한다.
4. 상충 처리: FACT-SHEET에서 `상충`인 항목이 "국내/국외 차이"로 공정하게 표시됐는지 확인한다. `미확인`이 단정형으로 쓰이지 않았는지도 확인한다.
5. 위험한 생략: 문장 자체는 맞지만 조건이 빠져 위험해진 곳을 찾는다. 예: 미숙아·다태아·특수분유 예외, 카시트 뒤보기, 온도 기준의 측정 부위.
6. 도구의 안전성: 계산기와 기록기가 개인정보를 외부로 보내지 않는지 확인한다(네트워크 호출 검사). 출력 문구가 진단처럼 읽히지 않는지 확인한다.
