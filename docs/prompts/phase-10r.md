너는 ai-insta 프로젝트의 작업자(Codex)다. AGENTS.md, docs/DESIGN.md, docs/STYLE-GUIDE.md, docs/reference-analysis.md(이전 ColorBook 분석)를 읽어라.
이번 작업은 **Phase 10r. books.euiyun.com 교과서 서가의 인터랙션 분석(REA)** 이다. 사용자가 "인터랙션 자료를 아주 잘 사용한 페이지"라며 다른 교과서들을 REA로 분석해 우리 책을 고도화할 방법을 찾으라고 했다. 사이트·키트 파일은 다른 작업자가 개편 중이니 **수정하지 마라**. commit하지 마라.

1. https://books.euiyun.com/ 의 서가에서 교과서 목록을 확인하고, ColorBook을 제외한 책들 중 인터랙션이 다른 유형인 책 3~5권을 고른다(선정 이유 기록). 각 책에서 표지, 대표 장 2개, 실험실/도구 페이지를 본다.
2. **REA MCP(`rea`)를 우선 사용**한다. 이번에는 승인 설정으로 REA 도구가 호출된다. 로컬 Chromium을 원격 디버깅 포트로 띄우고(임시 프로필, 저장소 밖 mktemp 디렉터리) REA의 웹 분석 도구(list_browser_targets, inspect_web_page, inspect_web_event_listeners, capture_browser_scenario, capture_web_screenshot, analyze_web_bundle, trace_web_module_imports 등)로 상호작용 구현을 분석한다. 쓴 REA 도구와 Evidence ID를 기록한다. REA로 안 되는 부분만 CDP/curl로 보완하고 이유를 적는다.
3. 분석 관점(우리 책 고도화용):
   - 인터랙션 유형 카탈로그: 무엇을 조작하게 하는가(드래그, 슬라이더, 단계 재생, 비교 토글, 직접 그리기, 시나리오 분기, 오류 유도 등), 학습 목적과의 연결 방식, 피드백 표현(즉시 수치/색/애니메이션/문장).
   - 설명 흐름: 상호작용 전후 문장 배치, 예측→조작→관찰→설명 같은 학습 순서, 한 화면에 보이는 정보량.
   - 시각 언어: 도식 스타일, 색 체계, 타이포 위계, 모션(지속 시간·이징), 모바일에서 조작 방식.
   - 기술 구현: 라이브러리/자체 구현, 상태 관리, 성능(파일 크기·지연 로딩), 접근성(키보드·대체 텍스트).
   - 책 전체 장치: 진행 표시, 복습/퀴즈, 용어, 장 사이 연결, 실험실.
4. 산출물 docs/reference-analysis-books.md:
   - 책별 요약(무엇이 뛰어난가, 근거 URL·선택자·REA Evidence).
   - **ReelsBook 고도화 제안 목록**: 제안마다 (패턴 / 참고 근거 / 우리 책의 어느 장·실습에 어떻게 / 학습 효과 / 구현 난이도 S·M·L / 우선순위). 최소 15개, 상위 5개는 구체 화면 스케치(텍스트 와이어프레임)와 상호작용 명세(입력→상태→출력).
   - 예: 3장 '돈의 네 갈래'를 조작형 흐름도로, 7장 카드 디자인을 실시간 미리보기 편집기로, 8장 릴스 타임라인 재생, 10장 API 게시 과정을 단계 재생 시뮬레이션으로, 12장 위험 판정을 시나리오 분기로 등 — 실제 분석 근거에 맞게 제안.
   - 유튜브 쇼츠 편(영상 제작 중심)에 특히 유용한 패턴 별도 절.
   - 따라 하지 않을 점과 저작권 주의(원 사이트 문장·코드·이미지 복사 금지, 패턴만 참고).
5. docs/results/phase-10r.md(사용한 도구, 성공/실패, 핵심 결론 10줄). 원본 코드·이미지는 저장소에 넣지 않는다.
