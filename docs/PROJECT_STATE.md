# 프로젝트 현황

갱신: 2026-10-26. 정책·자료조사는 **2026년 10월 조사 기준**(컷오프 2026-10-26)이다.

## 프로젝트 개요

AI로 Instagram 릴스·뉴스카드를 생성·검수·자동 게시하고 수익 구조를 이해하는 한국어 입문 교과서와 스타터 키트를 만든다. 설계·단계별 범위는 [DESIGN.md](DESIGN.md), [PLAN.md](PLAN.md)를 따른다.

## 현재 산출물

- **Phase 1 자료조사 산출물 완료, 검수·커밋 대기**: [결과](results/phase-1.md), [12개 주제의 통합 사실표](../research/FACT-SHEET.md), [출처 목록](../research/SOURCES.md). Hermes 초기12회·재시도1회·보충3회, 총16회/최대병렬4개. 명령15회 성공·1회 실패이며 웹 중계 오류로 내용 확보에 실패한 exit0도 구분했다.
- 사실·검증 공백100개, 출처·후보117개를 기록했다. Codex는 공식38개 출처의 관련 본문을 직접 확인했다. [검증 기록](../research/verification.json)과 [정합성 검사](../research/validation.json)에 확인 범위를 남겼다.
- **다른 작업자의 산출물**: [Phase 2 참고 사이트 분석](results/phase-2.md)과 [Phase 3 사이트 뼈대·디자인 시스템·1장](results/phase-3.md)이 저장소에 있다. 해당 결과 문서가 각 작업의 검증·제한을 설명한다. 이번 Phase1 작업에서는 관련 문서·사이트 코드를 수정하거나 다시 검증하지 않았다.
- Phase3 결과 기록상1장의 정책·실제 사례는 출처 확인 대기 표시다. 이번에 작성한 사실표와의 연결·검수는 아직 수행하지 않았다. 스타터 키트와 후속 장 구현은 이번 작업 범위가 아니다.

## 조사에서 확인한 주요 사항

- API 게시 한도100/50이 공식 문서 내부·레퍼런스에서 충돌한다. 계정 실효 한도는 미확인이다. API 캐러셀은 직접 읽은 가이드20개와 초기 검색 발췌10개를 구분했다.
- API 이미지는 JPEG 요건이며 학습용PNG와 게시 파일을 구분해야 한다. 현행 Overview는 새 통합에 Unified Login을 권장하고 기존 두 경로와 별도 요건을 둔다.
- Meta AI라벨·국내 AI서비스사업자 의무·경제적 이해관계·가상인물 광고 표시는 별도다. 공정위 지침은2026-06-01 시행 예규499호를 직접 확인했다.
- 공개 벤치마크의 표본·분모·기간을 검토했다. 미래까지의 분석기간을 적은 자료는 성과 수치를 채택하지 않았다. 성장 기간·단가·전환율을 보장할 한국 뉴스계정 자료는 확보하지 못했다.

## 남은 공백과 제약

- 현행 수익화 도움말의 독립 본문 대조, 한국 계정별 구매·지급·예약·음원·라벨·외부 커넥터 지원,2026 보너스/광고 운영 상태.
- 상업용 한국어TTS 출력·화자 권리, 쿠팡 최신 조건, 일부 소재 라이선스·무료량·가격, 국외 수익 세무 상세.
- 최신 AI요약 분쟁·개별 소재 이용조건, AI profile 한국 적용, 플랫폼 약관·스팸·복구 현행 절차와 실제 AI계정 실패 사례.
- 원응답은 외부 실행 디렉터리에 보존했고 경로·해시·실행 기록은 [provenance.json](../research/provenance.json)에 있다. 일부 Hermes 웹 중계가403으로 실패했다. 재시도 포함16회 한도를 소진했으며 미확인 내용을 추측으로 채우지 않았다.
- 유료 API·실계정 로그인/게시·Hermes 코드/config/runtime 수동 변경·컨테이너 재시작·push는 수행하지 않았다.

## Git 마무리 제한

이번 실행 환경에서 `.git`이 읽기 전용이어서 `git add`가 `index.lock` 생성에 실패했다(exit128). 요청된 `Phase 1: research notes` 커밋은 미완료이며 staging도 수행되지 않았다. 쓰기가 허용된 환경에서 Phase1 소유19개 파일만 커밋하는 후속 조치가 남았다. 다른 Phase 파일은 이번 커밋 대상이 아니다.
