# 프로젝트 현황

갱신: 2026-10-26. **2026년 10월 조사 기준**, 조사 컷오프 2026-10-26.

## 프로젝트 개요

AI로 Instagram 릴스·뉴스카드를 만들고 검수·게시·수익 구조를 배우는 한국어 입문 교과서와 오프라인 스타터 키트다. 설계·단계 범위는 [DESIGN.md](DESIGN.md), [PLAN.md](PLAN.md)를 따른다.

## 현재 구조와 구현

- `site/`: 빌드 도구 없는 정적 HTML/CSS/바닐라 JS. 1~14장 본문, 15장 실험실, 16장 용어집, 출처·크레딧과 표지를 갖춘다. `book.js`가 공통 장 메타·목차·이전/다음 이동을 담당한다. 하위 경로 `/reels/` 배포를 위해 내부 링크는 상대 경로를 사용한다.
- 본문 2~14장은 9블록·장별 퀴즈·그림과 입력 도구·실습 결과물 체크를 갖춘다. [5a](results/phase-5a.md)·[5b](results/phase-5b.md)·[5c](results/phase-5c.md)의 공통 요청은 Phase 5d에서 병합했다. 기본 집필은 Git `27ff7d6`에 있다.
- 원본 도구 28개와 실험실 전용 한 달 요약 1개, 총 29개다. 실험실은 선택한 원본 장의 해당 절을 iframe으로 표시해 모듈·HTML·가정 설명을 재사용한다. 3·4·14장 변경 입력과 원본 결과만 브라우저에 저장·복원하고 한 달 요약에 전달한다. 초기 예시값·빈칸·실제 0을 구별하며 삭제 기능이 있다.
- 용어집 31개와 본문 용어 링크 41개, 실제 인용한 연구 출처 126개를 연결했다. `scripts/build_appendices.py`가 원본 장·인계 용어·SOURCES에서 목록과 정적 부록을 갱신한다. 실행 시 장의 용어 링크도 정규화한다. 1장의 출처 대기 표시는 사실표의 확인 수준에 맞춰 대체했다.
- 표지에는 실제 장·도구 수, 독자별 추천 경로, 키트 샘플 PNG·MP4 미리보기가 있다. 복제 샘플·라이선스는 합계 약 1.58MB다.
- `starter-kit/`: Python 3.11+ 기반 합성 피드→문안→Pillow 카드→FFmpeg 릴스→사람 검수→게시 드라이런. 기본 키트·확장은 Git `3005fa0`·`b6e0155`, 검증 범위는 [Phase 4](results/phase-4.md)·[4b](results/phase-4b.md)·[5b](results/phase-5b.md)·[5c](results/phase-5c.md)를 따른다. Phase 5d는 키트 코드를 바꾸거나 전체 키트 시험을 재실행하지 않았다.

## 조사와 근거

- **Phase 7r 조사 기록 작성 완료, 앱 절차 근거는 일부 미확보:** [실습 1~10 절차 노트](../research/practice-instagram.md), [결과](results/phase-7r.md), PRAC-01~26을 추가했다. Hermes는 보충 포함 8/8회 모두 중계 403으로 근거 확보에 실패했고 Codex가 공식 문서 22개의 관련 본문을 직접 읽었다. Graph v26.0·발급 경로별 토큰 수명·공개 URL/동영상 재개 업로드 범위·전송/호스팅을 확인했다. 앱의 AI/협찬 토글·전환/2FA·예약·지표 클릭 순서는 미확인으로 남겼다. `site/`·`starter-kit/` 구현·실계정 로그인/게시·commit은 수행하지 않았다.
- [FACT-SHEET](../research/FACT-SHEET.md)·[브리핑](../research/BRIEFING.md)·[SOURCES](../research/SOURCES.md)에 초기·확장 조사를 보존했다. 전체 연구 출처는 Phase 7r 추가분을 포함해 195개다. 사이트가 노출하는 출처는 사이트 작업의 인용 범위를 따르며 이번 조사에서 사이트를 갱신하지 않았다. 모든 출처의 현행성·한국 적용을 검증했다는 뜻은 아니다.
- 초기 연구 Git `e22bd23`, 확장 연구 Git `97bca63`. [Phase 1](results/phase-1.md)·[1b](results/phase-1b.md)에 당시 Hermes 실행·웹 중계 실패·직접 보충 검증·원응답 보존 내역이 있다. 과거 결과의 커밋 불가 기록은 당시 상태이며 현재 Git 상태와 구별한다.
- 도구·폰트의 제작 크레딧은 [별도 라이선스 근거](../research/tool-licenses.md)에 있다. 확인 수준·날짜 미상·문서 상충을 사이트에서도 유지한다.

## 진행 중과 다음 단계

- Phase 7w는 7r 노트의 본문 확인과 미확인 탐색 후보를 구분해서 집필해야 한다. 본인 계정 Standard Access 검수 면제와 개발 모드 테스트 게시물의 일반 공개는 구분하며, 남은 앱 메뉴·공개 범위를 확인 완료로 표시하지 않는다. 실제 게시 검증은 사용자 테스트 계정 제공 시 Phase 7v에서만 수행한다.
- **Phase 5d 구현·통합 검증 완료, Claude Code 검수 대기:** [결과·재현 명령·검증 증거](results/phase-5d.md). 브라우저 검사 1,158개와 정적 링크/자산 872개 검사를 통과했다. HTML 19개의 1280/375px 가로 넘침·콘솔/페이지 오류는 0이다. 표지 첨부 Discord 보고는 HTTP 200으로 완료했다. commit·push는 하지 않았다.
- 이후 Phase 6의 독립 초보자 검토·품질 게이트를 수행한다. 이번 통합 검증은 독립 사용자의 실습 완주 검토를 대신하지 않는다.
- 작업 중 DESIGN 10·11절과 PLAN의 Phase 7/Y·후속 프롬프트·Phase 7r 연구 자료가 외부에서 추가된 것을 확인했다. 해당 변경은 보존했다. 이론/실습편 분리·현행 앱 게시 절차·ShortsBook은 설계/후속 단계이며 현재 사이트에 구현됐다고 표시하지 않는다. 해당 단계의 지시 전에는 진행하지 않는다.

## 알려진 공백과 제약

- 한국 Gifts·구독의 현행 개설/구매/지급, 보너스·광고·Live 배지, 예약·음원·표시·커넥터 전체 지원과 실계정 동작은 미확인이다.
- API 실효 한도·Unified 온보딩, TikTok 약관의 1만/5만 상충, 클립/이관 공지 전문, 쿠팡 현행 요율·정산·국외 제휴/세무는 추가 확인이 필요하다.
- 개별 TTS 화자·입출력·폰트/소재·RSS 재사용 권리, 일부 한국 가격/무료량·음성 품질, AI 기본법 후속 지침·최신 AI 요약 분쟁·개인정보·계정 복구 절차는 일괄 확정하지 않는다.
- 장부·성장·니치 점수·일정은 교육용 가정 모형이며 예측이 아니다. 회사 매출·다채널 독자를 개인 Instagram 자동수익으로 환산하지 않는다.
- 검증 환경은 Linux·Chromium이다. Windows/macOS·다른 브라우저·실제 보조기기·OS 예약 기동·실계정 로그인/게시·유료 API는 검증하지 않았다. 파일로 직접 열 때 프레임의 교차 문서 접근·저장은 브라우저 제한을 받을 수 있으며 원본 장 직접 링크가 있다.
- Hermes 원응답은 외부 허용 경로에 보존한다. 공개 저장소에 원응답 전문·개인 환경·토큰을 넣지 않는다. Hermes 저장소 코드/설정·DB를 수정하지 않는다.
