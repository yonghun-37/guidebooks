# 프로젝트 현황

갱신: 2026-10-26. **2026년 10월 조사 기준**, 조사 컷오프 2026-10-26.

## 프로젝트 개요

Instagram 릴스·뉴스카드의 기획·제작·검수·게시·운영을 배우는 한국어 입문 교과서와 오프라인 스타터 키트다. 설계·단계 범위는 [DESIGN.md](DESIGN.md), [PLAN.md](PLAN.md)를 따른다.

## 현재 구조와 구현

- `site/`: 빌드 도구 없는 정적 HTML/CSS/바닐라 JS. 기존 주소를 유지한 **(이론) 1~14장·15 실험실·16 용어집·출처**, **(실습) 0~10·E2E** 두 트랙이다. `book.js`가 공통 목차·메타·트랙별 이전/다음 이동을 그린다. 내부 링크는 `/reels/` 하위 배포를 지원하는 상대 경로다.
- 실습편 11개와 E2E는 **35단계**다. 지금 하는 일·이유·따라 하기·성공 기준·오류 대처·Windows/macOS 탭을 공통화했다. 체크와 본인이 입력한 게시물 주소는 브라우저에만 저장한다. 저장 차단·용량 부족에도 현재 페이지 조작이 가능하며 미저장임을 알린다. `scripts/build_practice.py`가 정적 원고·동일 단계 E2E·자체 SVG·7v 확인 목록을 생성한다.
- 표지에 실습 시작·E2E 진입점이 있다. 실습 1은 테스트 계정 두 경로·공개/보안/계정 수 확인 상자를 갖춘다. 실습 7 앱 게시가 기본 경로, 8 API·9 예약은 선택이다. 이론 5~10장의 중복 조작은 판단·기획 메모와 실습 링크로 정리했고 나머지 장에도 관련 실습을 연결했다.
- 이론 2~14장의 9블록·장별 퀴즈·모형은 유지했다. 원본 도구 28개+실험실 한 달 요약 1개, 총 **29개**다. 실험실은 선택한 원본 절을 iframe으로 재사용하며 3·4·14장의 변경 입력만 저장·전달한다. 초기 예시값·빈칸·실제 0을 구분한다.
- 용어집 **31개**, 현재 본문 용어 링크 **40개**, 이론·실습의 인용 출처 **147개**다. `scripts/build_appendices.py`가 목록·용어·출처를 생성한다. 샘플 PNG·MP4·JSON·라이선스는 약 1.58MB이며 모두 합성 자료다.
- `starter-kit/`: Python 3.11+, 로컬 RSS→규칙 기반/선택 웹 채팅 문안→Pillow 카드 PNG/JPEG→FFmpeg 릴스→사람 검수→승인→기본 드라이런이다. 실습 2~6은 같은 출력 폴더를 이어 쓴다. 직접 녹음 mp3/wav·사용자 음악·명시적 LLM/TTS 연결은 기존 선택 경로를 유지했다.
- 게시 키트는 **Instagram Login**이다. 기본 API 버전 **v26.0**을 `.env`/환경변수로 바꾸며 환경변수가 우선한다. `prepare_hosting.py`는 승인된 JPEG/MP4만 새 폴더에 복사하고 GitHub Pages 웹 업로드·URL 규칙을 안내한다. `publish.py --base-url`과 기존 `--public-base-url`을 지원한다. **이미지·동영상 모두 공개 URL**이 필요하다. 승인/변경 감지·합성 자료 live 거부·`LIVE_ATTEMPT.json` 중복 시도 방지를 유지한다. live는 캐러셀+릴스 2개 게시 시도이며 자동 토큰 갱신·예약·호스팅을 제공하지 않는다.

## 남은 작업과 제약

- 사용자 테스트 계정 제공 시 조건부 **7v**에서 앱 메뉴·라벨·예약·인사이트·일반 공개를 확인한다. 개발 모드 본인 계정의 검수 면제와 일반 독자 공개를 구분한다. 다음 품질 게이트 **Phase 6**의 독립 초보자 검토와 Claude Code 검수가 남아 있다. ShortsBook은 이번 구현 범위가 아니다.
- 실제 Instagram 로그인·게시·토큰 발급/갱신·휴대폰 전송·OS 예약 기동·Windows/macOS·다른 브라우저·실물 보조기기는 실증하지 않았다. 검증 환경은 Linux·Chromium이다. 실제 API/LLM 요청·결제·유료 키를 사용하지 않았다.
- 한국 Gifts·구독·보너스 등 개설/지급, API 실효 한도·Unified 온보딩, 교차 플랫폼 수익 요건·클립 공지 전문·쿠팡 요율/정산·개별 권리·세무/법 적용의 미확인은 유지한다. 모형은 교육용 가정이며 수익·성장 예측이 아니다.
- 저장 기록은 같은 브라우저/출처에 의존한다. 저장 불가 시 이동·새로고침 후 기록이 이어지지 않을 수 있다. file://의 저장·iframe 접근도 브라우저 정책을 따른다. 원본 장 링크를 제공한다.
- Hermes 원응답은 저장소 밖 허용 경로에만 있다. 공개 저장소에는 토큰·개인 환경·원응답 전문을 넣지 않는다. Hermes 코드·설정·DB를 수정하지 않는다. 커밋은 Claude Code 검수 후 담당한다.
