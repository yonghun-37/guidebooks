## 프로젝트 개요

AI로 Instagram 뉴스카드·릴스, YouTube 쇼츠, 검색으로 읽히는 블로그 글을 만드는 한국어 입문 교과서와 오프라인 스타터 키트다. 실제 서비스의 메뉴·입력·출력·복사용 프롬프트·결과 비교·시간·비용을 본문과 실습의 중심에 두며, 키트는 자동화·무료 대안이다. 생활 묶음의 BabyBook은 신생아~100일 부모를 위한 이론·실습·인쇄 부록을 만든다.

- **ReelsBook V-insta 시각자료 보강·로컬 게이트 완료, Claude Code 최종 검수 대기.** 개수 기준을 폐기하고 반복·의무 인물 그림을 정리했다. 화면 위치·크롭·차트·파일 구조를 보강하고 38 HTML의 3폭×2테마 검사를 통과했다. [시각자료 계획](results/phase-V-insta-plan.md)·[결과와 화면](results/phase-V-insta.md)을 따른다. AId에서 AIa/b/c의 공통 요청을 적용했다. [통합 결과](results/phase-AId.md), [도구·부록](results/phase-AIa.md), [레시피](results/phase-AIb.md), [실습](results/phase-AIc.md)을 함께 본다.
- **ShortsBook E-shorts 예시 전면 교체·로컬 게이트 완료, Claude Code 검수 대기.** 대표 예시는 가상 채널 「자취생 10분 생존법」의 월급날 네 칸 해설이며, 간장 계란밥 촬영·펭귄 택배기사 상상 이야기를 끝까지 연결한다. 새 AI 이미지 6장·36초 무음 샘플과 검증은 [E-shorts 결과](results/phase-E-shorts.md)를 따른다. 기존 통합 구조는 [Y5 결과](results/phase-Y5.md)에 있다.
- **BlogBook B8 독립 검토 11건 수정·로컬 최종 게이트 완료, Claude Code 검수 대기.** 논산시의 지난 모집 자료로 정보 글 완성 과정을 채우고 세 글의 제목·메모·사진 이름, 화면 위치 그림·RSS·수익 조합·CPC·배포 링크를 보완했다. [B8 결과](results/phase-B8.md)·[B7 발견](results/phase-B7-findings.md)·[블로그 설계](DESIGN-blog.md)를 따른다.

## 현재 구조와 구현

- `site/`: 빌드 없는 정적 HTML/CSS/바닐라 JS. **이론 1~15장**, 실험실(16)·용어집(17), 프롬프트·AI 모델/사용처/비용·출처 부록, 실습 0~10·E2E에 심화 A0~A9·E2E를 더한 세 트랙이다. `assets/book.js`가 번호·제목·목차·선행 장·이전/다음을 관리한다. URL slug는 기존 값이며 표시 번호와 다르다(예: `06-writing`은 7장). 상대 링크로 하위 경로 호스팅을 지원한다.
- 새 **6장 AI 도구 지도 → 7장 글쓰기 → 8장 뉴스카드 → 9장 릴스 레시피**가 연결된다. 무료 ChatGPT→Canva→Clipchamp, 실습의 CapCut/Vrew 및 무료 출력 차단 시 대안, 유료 조합·권리·AI 표시를 각주와 함께 안내한다. 부록의 복사용 프롬프트 6종과 모델/기능 274개 검색·비용 계산을 제공한다.
- 표지에 ‘AI로 무엇을 어떻게 만드나’와 부록 진입 링크가 있다. 기본 실습은 **0 유형 → 1 계정·보안 → 3 ChatGPT → 4 Canva → 선택 5 CapCut → 6 파일 검수 → 7 앱 게시 → 10 관찰**이다. 키트 2·API 8·매일 생성 9는 선택이다. 서비스 파일은 review.txt·권리/표시 메모로 검수하며 키트 APPROVED.json을 요구하지 않는다. 키트 묶음 승인 규칙은 유지한다. E2E는 기존 38키와 추가 5키, 총 **43키**를 본문과 공유한다.
- 기존 카드 편집기·릴스 재생 타임라인·가상 게시·증거 검수는 해당 실습에서도 재사용한다. 3·14장의 수입/비용/남는 돈 SVG와 무효 입력 처리, 큰 영상 미리보기·모바일 입력 접기, 15장의 시간 예산·날짜별 30일 표·주간 점검·복사 기능을 유지한다. 캘린더 완료 체크는 현재 화면에만 남는다.
- **실험실 31개·용어 39개·본문 인용 출처 329개**는 `scripts/build_appendices.py`가 현재 원고에서 생성한다. 번호는 `book.js`에서 읽고 실험실은 slug로 구분한다. 새 도구 지도 선택 도우미도 iframe으로 원본을 재사용한다. 15장 변경 입력만 한 달 요약으로 전달하며 저장 삭제·차단 안내를 유지한다. AI 사용량 토큰은 인증용 토큰과 구분한다. AI 삽화(109,058바이트)는 본문·크레딧에 생성 고지와 프롬프트를 함께 둔다.
- `starter-kit/`: Python 3.11+·로컬 RSS→규칙 기반/선택 웹 채팅 문안→Pillow PNG/JPEG→FFmpeg MP4→사람 검수·승인→기본 드라이런. 본인 녹음·음악·명시적 LLM/TTS 연결은 선택이다. 일일 생성은 날짜별 폴더·로그·중복 거절을 제공하고 OS 예약 도우미는 등록/확인/실행/해제 명령을 출력한다. 무인 승인·게시·자동 토큰 갱신·호스팅은 제공하지 않는다.
- Instagram 게시 API는 Instagram Login·v26.0이다. 환경변수가 `.env`보다 우선한다. 호스팅 준비는 승인 JPEG/MP4만 복사하며 둘 다 공개 URL이 필요하다. 변경 감지·합성 자료 live 거부·LIVE_ATTEMPT 중복 방지를 유지한다. token_check는 숨김 토큰으로 본인 ID·이름만 읽는 선택 도우미다.
- `site-shorts/`: 이론 1~15장(새 3장 AI 도구 지도)·실험실·용어집, 실습 0~10·E2E와 부록 프롬프트/모델·비용/출처를 실제 파일로 연결한다. 기존 slug를 유지하고 공통 목차·번호·이동을 통합했다. 실험실은 이론 15장의 원본 그림·도구 31개를 iframe으로 재사용한다. 용어 48개·첫 사용 링크 43개·실제 인용 Y출처 299개다. 부록 재생성 도구는 `scripts/build_appendices.py --site site-shorts`다. E-shorts의 새 크레딧·실험실 안내는 정적 HTML에 반영했으며, 재생성 전 scripts의 옛 예시 템플릿을 함께 갱신해야 한다. 테마·진행 저장 키는 ReelsBook과 분리한다. 표지 키트 샘플은 사이트 내부에 동봉했다.
- `shorts-kit/`: 독립 Python 키트. 오프라인 가상 대본→본인 녹음/무음·사진/클립/자체 도형→1080×1920 MP4·SRT→여섯 항목/아동용·AI 판단 검수·해시 승인→드라이런. 대본 기반 자막이며 음성 인식/강제 정렬 기능은 없다. 선택 OAuth·재개 업로드는 모킹으로 확인했고 실계정 전송은 하지 않았다. 세션/토큰 비공개 보관·중복 전송 방지를 제공한다. E-shorts에서 pytest 38개를 다시 통과했고 대표 샘플은 월급날 네 칸 해설 36초·무음이다.
- `site-blog/`: 이론 1~13·실험실(14)·용어집(15), 실습 0~10·E2E와 부록 3개가 모두 완성 상태다. 네이버 기본/티스토리 대안·PC/모바일 안내, 무료 AI 제작·사람 검수·공개 주소·검색/수익 신청 기록을 연결한다. 원본 도구 13개를 iframe으로 재사용하며 프롬프트 18개·용어 43개·첫 사용 링크 38개·실제 B 인용 출처 155개를 모았다. B8 재생성은 `python3 docs/results/phase-B8/rebuild.py`다(공유 생성기 단독 호출은 웹 README·TXT 동봉·CPC 보정을 덮어쓴다). 표지의 질문별 경로·AI 제작 진입과 동봉 blog-kit 미리보기·README·ZIP은 하위 경로에서 열린다. 저장 키는 `blogbook:`, 근거는 `research-blog/`다.
- `blog-kit/`: 표준 라이브러리 기반 자료/프롬프트→검사→HTML 미리보기→사람 검수·해시 승인→드라이런. 네이버·티스토리는 수동 편집기, 선택 API는 Blogger·설치형 WordPress의 초안 저장이다. 일일 자료 틀·재개·OS 예약 명령 안내를 제공하며 실제 예약 등록·무인 승인/게시·인증 발급/갱신은 하지 않는다. B8에서 Python 3.11.15 원본 복사본·동봉 ZIP 각각 pytest 97개와 샘플 명령 30회 확인을 통과했다. 대표 샘플은 논산시 2025년 청년내일저축계좌 공지를 정리한 학습용 글이며 접수 종료·확인일을 명시한다. [B3k 구현](results/phase-B3k.md)을 따른다.
- `site-baby/`: BlogBook의 빌드 없는 공통 구조를 재사용한다. 이론 1~15·실습 0~10/E2E 목차는 준비중이며 이론 7장·실습 7·10장 계산기·실험실 도구만 샘플로 연결한다. `assets/emergency-data.js` 한 곳의 응급 문구 7개를 장·실습·인쇄에서 재사용한다. `assets/benefits.js`는 2026-10-27 기준 0~23개월 월 현금/1회 바우처를 분리한다. 연락처·신청 상태는 `babybook:` localStorage에만 저장하고 차단을 처리한다. 공식 N출처를 `credits.html`에 연결한다. `print/emergency.html`은 흑백 A4 한 쪽이다.
- `auto-kit/`: 두 책 심화편 공통 Python 3.11+ 실행기. RSS/직접 원문·성과→LLM 스키마→카드/ffmpeg·TTS→관문→호스팅/게시→분석을 단계별 상태에 보존한다. 기본 mock 드라이런, 승인제/시작 기준 사후 확인/전자동을 명시적으로 고른다. Pages/R2 미디어와 암호화한 private 상태, 토큰 갱신·명시적 재인증 적용·한도 연기·예외 종결·메신저 알림/선택 수신·OS 예약 생성기를 제공한다. A6에서 결과 ID/flow 조회와 보유 소재 2~5개에 맞춘 생성 장면 수를 고정했다. `samples/editorial/`에 생활정보 카드 4장과 한국어 합성 낭독 38.667초 쇼츠가 있으며 기존 신호음 mock 견본과 목적을 구분한다. [실행/연결 안내](../auto-kit/README.md)·[구현 기록](../auto-kit/docs/plan.md).

## 남은 확인과 제약

- BabyBook은 N3 샘플 검수 후 N4 이후 작업을 진행한다. 전체 집필·독립 건강 안전 검토·실계정 지원 신청·기관 통화·실제 프린터 출력은 수행하지 않았다.

- Claude Code 최종 검수·커밋·배포와 쇼츠의 독립 초보자 검토가 남아 있다. BlogBook의 네이버 광고+제휴 개별 배치 허용은 공식 문의 답변으로 확인해야 하며, 지난 모집 학습 샘플을 현재 신청 안내로 쓰지 않는다. Y5는 `site/`·`shelf/`와 서가 진행표를 수정하지 않았다. 현재 원고·도구·키트 작성 완료와 실제 서비스 제작/게시 성공을 혼동하지 않는다.
- Windows/macOS 실기기·OS 예약 등록/다음 날 실행/잠자기·권한, 휴대폰 녹음/전송·앱 메뉴·가입/결제/생성·실계정 로그인/게시/예약·토큰 발급/갱신은 미실행이다. 검증은 Linux·Chromium·오프라인 실행·모킹 중심이다. 사용자 계정이 제공되면 [앱 확인 목록](results/phase-7w-verify-list.md)으로 별도 확인한다.
- 한국 Gifts/구독/보너스의 개별 지급, API 한도 100/50 충돌·Unified 온보딩, 라벨/음원/예약 조합·교차 플랫폼 권리·개별 저작권/법/세금 적용은 확인 공백이다. 계산·시간 도구는 수익/성장 예측이 아니다.
- 입문용 키트의 일일 생성은 로컬 피드 기준이다. 자료·권리 갱신과 파일별 사람 검수·승인은 계속 필요하다. 브라우저 진행·주소·시간은 같은 출처에만 저장되고 차단/file:// 환경에서는 이어지지 않을 수 있다.
- 공개 저장소에 토큰·키·개인 환경·Hermes 원응답 전문을 넣지 않는다. Hermes 저장소 코드/설정/DB는 읽기 전용이며 신규 유료 API·결제·실계정 로그인/게시를 하지 않는다.
