# 프로젝트 현황

갱신: 2026-10-26. **2026년 10월 조사 기준**, 조사 컷오프 2026-10-26.

## 프로젝트 개요

Instagram 릴스·뉴스카드의 기획·제작·검수·게시·운영을 배우는 한국어 입문 교과서와 오프라인 스타터 키트다. 설계는 [DESIGN.md](DESIGN.md)·[PLAN.md](PLAN.md), 확정 집필 기준은 [STYLE-GUIDE.md](STYLE-GUIDE.md)를 따른다.

## 현재 구조와 구현

- `site/`: 빌드 도구 없는 정적 HTML/CSS/바닐라 JS. 이론 1~14장·15 실험실·16 용어집·출처, 실습 0~10·E2E의 두 트랙이다. `book.js`가 장 제목·결과물·예상 시간, 공통 목차와 트랙별 이동을 관리한다. 상대 링크로 `/reels/`와 `/guidebooks/reels/` 배포를 지원한다.
- **문체 개편·통합 완료, Claude Code 검수 대기.** [9a](results/phase-9a.md)·[9b](results/phase-9b.md)·[9c](results/phase-9c.md)의 이론 14장과 [9d](results/phase-9d.md)의 실습 12페이지를 통합했다. 이론은 축별 반복 설명·FAQ 5개·정리 3줄·퀴즈를 유지하며 기준선의 70% 이하로 줄였다. 실습은 결과물 한 줄·FAQ 5개와 기존 35단계·저장 키를 유지한다. [통합 결과](results/phase-9-int.md)에 검증과 선택 이유를 기록한다.
- 실험실 **29개 항목**은 축 그림 14개·계산/점검 도구 12개·정적 연습 2개·한 달 요약 1개다. 원본 절을 iframe으로 재사용한다. 3·4장의 새 도구는 저장하지 않고 바로가기로 제공하며, 요약에는 14장의 변경한 시간 입력과 결과만 전달한다. 이전 판 입력은 유지하되 원본 장을 열 때 현재 결과로 갱신하고, 옛 일정 결과는 요약에서 숨긴다. 이전 3·4장 저장값은 표시하지 않으며 실험실 삭제 버튼으로 함께 지울 수 있다.
- 용어집 **24개**, 본문 `data-term` 링크 **24개**, 실제 본문 인용 출처 **98개**다. `scripts/build_appendices.py`가 현재 HTML의 학습 블록·용어 사용·각주 참조에서 재생성한다. 보존용 옛 각주는 본문에서 참조할 때만 출처 목록에 포함한다. 샘플 PNG·MP4·JSON·라이선스는 약 1.58MB이며 합성 자료다.
- 실습 7 앱 게시가 기본 경로, 8 API·9 예약은 선택이고 7에서 바로 10의 관찰로 이동할 수 있다. 체크와 본인이 입력한 게시물 주소는 브라우저에만 저장한다. 저장 차단에도 현재 페이지 조작을 유지하며 미저장임을 알린다. **현재 원고는 `site/practice/*.html`이다. 이전 `scripts/build_practice.py`는 원고·확인표를 덮어쓰지 않도록 실행을 차단했다.**
- [비교 샘플](../site/drafts/index.html)은 선택 완료 안내와 함께 보존한다. **A 뼈대 + B FAQ + C 단계표**를 3장과 전 장 개편에 반영했다. 진행 현황은 문체 개편 완료·인터랙션 고도화 예정으로 표시한다.
- `starter-kit/`: Python 3.11+, 로컬 RSS→규칙 기반/선택 웹 채팅 문안→Pillow 카드 PNG/JPEG→FFmpeg 릴스→사람 검수→승인→기본 드라이런. 실습 2~6은 같은 출력 폴더를 이어 쓴다. 본인 녹음 mp3/wav·사용자 음악·명시적 LLM/TTS 연결은 선택 경로다.
- 키트 게시 경로는 **Instagram Login**, 기본 API 버전 **v26.0**이다. `.env`보다 환경변수가 우선한다. `prepare_hosting.py`는 승인된 JPEG/MP4만 새 폴더에 복사하고 공개 URL 준비를 안내한다. `publish.py --base-url`과 기존 `--public-base-url`을 지원한다. 이미지·영상 모두 공개 URL이 필요하다. 승인/변경 감지·합성 자료 live 거부·`LIVE_ATTEMPT.json` 중복 시도 방지를 유지한다. 자동 토큰 갱신·예약·호스팅은 제공하지 않는다.

## 검증과 남은 작업

- Phase 9 통합 검증은 [결과와 재현 명령](results/phase-9-int.md)에 기록한다. 스타터 키트 **67개 테스트**, 문체 검사기 **10개 테스트** 통과. 문체 검사 사이트 35개·책장 2개 통과, 내부 참조 1,290개 오류 0. 브라우저 35페이지×1280/375/360px·2,022개 검사와 배포 하위 경로 469개 검사 통과, 가로 넘침·콘솔 오류 0. 부록 재생성 해시·기존 원고 앵커 1,146개·35단계 보존을 확인했다. 기존 기준선은 재생성하지 않는다.
- **다음은 인터랙션 고도화 예정**, Claude Code 통합 검수와 Phase 6 독립 초보자 검토도 남아 있다. 작성자 검증을 독립 학습자 검수로 간주하지 않는다. ShortsBook은 이번 작업 범위가 아니다.
- 사용자가 테스트 계정을 제공할 때 조건부 실제 계정 검증에서 앱 메뉴·라벨·예약·인사이트·일반 공개를 확인한다. 개발 모드 본인 계정과 일반 독자 공개를 구분한다.
- 실제 Instagram 로그인·가입·게시·토큰 발급/갱신·휴대폰 전송·예약 발행·Windows/macOS·다른 브라우저·실물 보조기기는 실증하지 않았다. 검증 환경은 Linux·Chromium이다. 실제 API/LLM 요청·결제·유료 키를 사용하지 않았다.
- 한국 Gifts·구독·보너스의 개별 개설/지급, API 실효 한도 100/50 충돌·Unified 온보딩, 라벨/음원/예약 조합, 교차 플랫폼 조건·클립 공지 전문·쿠팡 실시간 상품별 요율/정산·개별 권리·세무/법 적용은 남은 확인 사항이다. 모형은 수익·성장 예측이 아니다.
- 저장 기록은 같은 브라우저/출처에 의존한다. 저장 불가 시 이동 후 이어지지 않을 수 있다. `file://`의 저장·iframe 접근도 브라우저 정책을 따르며 원본 장 링크를 제공한다.
- 공개 저장소에 토큰·개인 환경·Hermes 원응답 전문을 넣지 않는다. Hermes 저장소 코드·설정·DB는 읽기 전용이다. 커밋·푸시·배포는 하지 않았으며 커밋은 Claude Code 검수 후 담당한다.
