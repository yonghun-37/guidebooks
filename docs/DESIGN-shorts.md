# ShortsBook 설계서 (유튜브 쇼츠 편)

작성: 2026-10-26, Claude Code. 사용자 지시: 인스타 편 다음 책, **영상 제작에 집중**, 이론편/실습편 분리, 실습편은 오늘 기준으로 **실제 업로드 완료**까지. 문체·구성은 docs/STYLE-GUIDE.md(확정)를 그대로 따른다. 제작 순서는 .agents/skills/guidebook-pipeline을 따른다(학습자 질문 → 조사 → 샘플 1장 → 사용자 선택 → 전체 집필).

## 1. 목표와 성공 기준

초보자가 실습편을 끝내면 손에 남는 것:

1. 내 쇼츠 채널 기획 메모(주제·독자·형식 1개)
2. 직접 만든 30~60초 쇼츠 MP4 1개: 대본 → 내레이션(본인 녹음 우선) → 장면(직접 촬영 클립 또는 권리 확인된 소재 또는 AI 생성) → 편집 → 자막 → 음악 → 9:16 출력
3. **YouTube Studio(또는 앱)로 실제 업로드한 쇼츠 1개**와 그 주소(오늘 완료 목표)
4. (선택) YouTube Data API 업로드 설정, 두 번째 영상을 더 빨리 만드는 템플릿

인스타 편과의 관계: 인스타 편에서 만든 뉴스카드·릴스를 재활용할 수 있지만, 이 책은 **영상 제작 기술**이 중심이다. 인스타 편을 읽지 않아도 따라 할 수 있게 쓴다.

## 2. 이론편 목차(초안)

축 구조(안 A)는 장마다 정한다.

| 장 | 제목(가제) | 학습자의 가장 큰 질문 |
|---|---|---|
| 1 | 쇼츠 한 편이 만들어지기까지 | 무엇부터 하면 오늘 한 편을 올릴 수 있나? |
| 2 | 쇼츠는 어떻게 보이고 무엇으로 돈이 되나 | 조회수 1만이면 얼마? 수익 창출 조건은? |
| 3 | 기획: 첫 3초와 한 편의 구조 | 사람들이 왜 넘기지 않고 보나? |
| 4 | 대본 쓰기와 AI 활용 | 60초에 몇 글자를 쓰나? AI 대본 그대로 써도 되나? |
| 5 | 소리: 내레이션·TTS·음악 | 내 목소리가 싫으면? 무료 음악은 어디서? 저작권 경고는? |
| 6 | 그림: 촬영·소재·AI 영상 생성 | 폰으로 어떻게 찍나? 무료 소재는? AI 영상(Veo 등) 써도 되나? |
| 7 | 편집: 컷·리듬·전환 | 무료 편집 프로그램은? 컷은 몇 초마다? |
| 8 | 자막과 화면 글자 | 자막 크기·위치·속도는? 자동 자막은? |
| 9 | 출력과 화질 | 해상도·프레임·비트레이트는 얼마로? 업로드하면 왜 화질이 떨어지나? |
| 10 | 자동화: 템플릿과 반복 제작 | 매일 올리려면 무엇을 자동화하나? |
| 11 | 업로드와 메타데이터 | 제목·설명·해시태그·썸네일은? 예약은? API는? |
| 12 | 분석: 숫자 읽기 | 조회수·시청 지속률·스와이프 비율은 무엇을 뜻하나? |
| 13 | 정책·저작권·AI 표시·세금 | 무엇을 하면 채널이 위험해지나? AI 표시는 언제? |
| 14 | 30일 운영 계획 | 하루 1시간으로 무엇을 할 수 있나? |
| 15 | 영상 실험실 | (도구 모음) |
| 16 | 용어집 | |

| 실습 | 내용 | 핵심/선택 |

## 4. 인터랙션(필수 후보, docs/reference-analysis-books.md 8절)

- 장면·자막·음성 공통 시간축 타임라인(재생 헤드, 구간 반복, 프레임 정지) — 7·8장, 실습 6
- 첫 3초 훅 비교(같은 영상, 첫 문장만 바꿔 보기) — 3장
- 내레이션/배경음 뮤트·솔로, 음량 균형 — 5장
- fps·해상도·비트레이트 비교 미리보기(자체 합성 예제) — 9장
- 제작 파이프라인 단계·실패 찾기 — 10장
- 업로드 체크 분기(아동용, AI 표시, 저작권) — 11·13장
- 지표 해석(시청 지속률 곡선 읽기) — 12장

## 5. 스타터 키트(shorts-kit)

starter-kit을 확장하거나 별도 폴더로 만든다(Phase Y3에서 결정). 오프라인·무료로 끝까지: 대본 JSON → (본인 녹음 또는 무음) → 장면 이미지/클립 → 자막 → 9:16 MP4. 업로드는 기본 드라이런, `--live`는 사용자 OAuth 설정 시에만.
