# 심화편 설계서: API로 완전 자동화 파이프라인 (인스타·쇼츠 공통)

작성: 2026-10-26, Claude Code. 사용자 지시: "인스타, 유튜브도 완전 자동화(API 사용해 파이프라인 구축) 내용도 있어야 한다. (심화)편으로 기획해서 실무에 도움이 되도록 보완." → ReelsBook·ShortsBook에 **세 번째 트랙 "심화편"** 을 추가한다. 이론편·실습편은 그대로 두고, 실습편을 끝낸 독자가 "매일 사람 손 거의 없이 돌아가는 파이프라인"을 직접 구축하게 한다. 문체는 docs/STYLE-GUIDE.md, AI 제작 중심 원칙은 docs/DESIGN.md 12절을 따른다.

## 1. 목표와 성공 기준 (사용자 지시: "거의 전자동화 수준")

심화편의 목표는 **사람이 매일 손대지 않아도 주제 선정부터 게시·분석·다음 주제 반영까지 도는 전자동 파이프라인**이다. 사람은 처음 설정, 주간 점검, 예외 처리만 한다.

심화편을 끝낸 독자 손에 남는 것:

1. 정해진 시간에 스스로 도는 파이프라인 1개(로컬 상시 실행 또는 GitHub Actions 등 클라우드 실행기)
   - 인스타: 주제 자동 선정(RSS·트렌드 + 지난 성과) → LLM API 요약·카드 문안(JSON) → 원문 대조 자동 검사 → (선택) 이미지 API → 코드 템플릿 렌더(카드/캐러셀/모션 릴스) → 공개 URL 호스팅 → **자동 품질 관문** → Instagram API 게시 → 인사이트 수집 → 다음 주제 점수에 반영
   - 쇼츠: 주제 자동 선정 → LLM API 대본·장면 목록(JSON) → TTS API → 장면(이미지/영상 생성 API 또는 소재 폴더) → ffmpeg 조립·자막·음량 정규화 → **자동 품질 관문** → YouTube Data API 업로드(예약 공개) → Analytics 수집 → 다음 주제 반영
2. **자동 품질 관문**: 사실 대조(요약 숫자·이름이 원문에 있나), 금지어·정책 검사, 중복·반복 콘텐츠 검사(최근 게시물과 유사도), 규격 검사(비율·길이·용량·음량), AI 표시 필드 설정, 비용 상한. 통과하면 자동 게시, 걸리면 **예외 대기열**로 보내 사람에게 알림.
3. 운영 자동화: 토큰 자동 갱신과 만료 경보, 재시도·백오프, 실패 단계부터 재시작, 중복 게시 방지, 한도·할당량 확인 후 자동 연기, 비용 상한 도달 시 자동 중단, 일일 실행 보고(디스코드/텔레그램)와 정적 HTML 대시보드
4. 키·토큰 보관(.env / GitHub Secrets)과 월 비용 상한
5. 자동화가 계정을 위험하게 만드는 경우(스팸·반복 콘텐츠·AI 표시 누락·한도 초과·토큰 유출)와 그것을 막는 자동 장치

운영 모드는 세 가지를 설정으로 고른다: **전자동(기본 목표)** — 품질 관문 통과 시 자동 게시 / **사후 확인** — 자동 예약 게시 후 공개 전 N시간 안에 거부하면 취소 / **승인제** — 승인 1번 후 게시(처음 1~2주 권장, 관문 기준을 맞추는 기간). 책은 승인제로 시작해 지표가 안정되면 전자동으로 넘어가는 순서로 안내한다.

### 1.2 시각자료 (심화편은 그림이 핵심)
코드와 시스템은 글로만 설명하면 이해가 어렵다. 심화편은 STYLE-GUIDE 6절 중에서도 다음을 적극적으로 쓴다:
- 전체 시스템 구성도(클릭하면 해당 장으로), 하루 실행 타임라인(몇 시에 무엇이 도나)
- API 호출 순서 시퀀스 그림(요청·응답·폴링·오류 분기, 토큰 가림)
- 상태 흐름 그림(대기→생성→검사→게시→분석, 실패·재시도·예외 대기열)
- 자동 품질 관문 판정 흐름(어떤 검사에서 무엇이 걸리면 어디로 가나)
- 폴더·파일·데이터 구조 그림, 설정 파일 주석 그림
- 비용 차트(편당·월, 공급자별), 할당량·한도 게이지
- 운영 대시보드 예시(실행 보고·지표), 승인/예외 알림 예시 그림
- 키·토큰 발급 경로는 직접 그린 화면 위치 그림(개발자 콘솔 캡처 금지)

## 1.1 범위: 심화편은 API와 코드만 다룬다

- Canva·미리캔버스·Clipchamp·CapCut·Vrew, ChatGPT/Gemini 웹·앱처럼 **사람이 화면에서 조작하는 웹 도구는 이론편·실습편의 영역**이다. 심화편 본문·코드에 넣지 않는다(비교가 필요하면 "실습편에서는 Canva로 하던 일을 여기서는 코드 템플릿으로 한다" 한 줄 연결만).
- 심화편에서 같은 일을 하는 방법: 카드 = 코드 템플릿(HTML/SVG 또는 Pillow) 렌더, 이미지 = 이미지 생성 API, 영상 = ffmpeg 조립 + TTS/영상 생성 API, 글·대본 = LLM API.
- n8n·Make 같은 노코드 자동화 도구는 API를 연결하는 실행기라서 장 하나로 다루지 않고 A7(스케줄링과 운영) 안의 "코드 없이 돌리는 선택지" 상자로 줄인다.

## 2. 심화편 목차 (두 책 각각, 플랫폼별 내용으로)

| 장 | 제목(가제) | 학습자의 가장 큰 질문 |
|---|---|---|
| A0 | 심화편 안내: 전자동 파이프라인의 전체 그림 | 사람 없이 어디까지 도나? 사람은 언제 개입하나? 한 달 비용은? |
| A1 | 파이프라인 설계 | 어떤 단계·파일·상태로 나누나? 실패하면 어디서 다시 시작하나? |
| A2 | API 키·토큰·비용 관리 | 키는 어디서 받고 어디에 두나? 요금 폭탄을 어떻게 막나? |
| A3 | 생성 API: 글·대본(LLM), 이미지, 음성, 영상 | 어떤 API를 얼마에? 결과를 JSON으로 안정적으로 받으려면? |
| A4 | 렌더링: 카드·영상 자동 조립 | 템플릿에 글을 넣어 이미지/MP4로 만드는 코드는? |
| A5 | 게시 API | (인스타) 계정 종류·앱 설정·권한·컨테이너→게시·한도·공개 URL / (쇼츠) OAuth·할당량·미검증 앱 비공개 잠금·감사·재개 업로드 |
| A6 | 자동 품질 관문과 예외 대기열 | 사람 승인 없이 올려도 안전하려면 무엇을 자동 검사하나? |
| A7 | 스케줄링과 운영 | 매일 몇 시에 어떻게 돌리나(작업 스케줄러·cron·GitHub Actions)? 승인 알림은? 재시도·중복 방지·로그는? (상자: 코드 없이 n8n 등으로 돌리는 선택지) |
| A8 | 분석 API와 자동 개선 루프 | 성과를 자동으로 모아 다음 주제·형식 선택에 반영하려면? |
| A9 | 자동화 정책·안전 | 자동 게시가 제재받는 경우는? AI 표시를 API로 하려면? |
| E2E | 심화 체크리스트 | A0→A9 순서대로 끝냈는지, 첫 자동 게시 기록 |

각 장은 STYLE-GUIDE 틀(먼저 답부터 → 한눈에 보기 → 축별 설명 → 해 보기 → 단계표 → FAQ → 정리)을 따르되, 심화편은 **실습형**이다: 장마다 "이 장에서 만드는 파일"과 복사해 실행하는 명령, "이렇게 보이면 성공", 흔한 오류 메시지와 해결 표를 넣는다.

## 3. 코드: auto-kit (두 책 공통)

`auto-kit/`(Python 3.10+). 기존 starter-kit/·shorts-kit의 렌더·게시 모듈을 재사용하되 독립 실행 가능하게 한다.

- `providers/`: LLM(OpenAI·Gemini·Anthropic), 이미지, TTS, 영상 생성 어댑터 — 같은 인터페이스, **구조화 출력(JSON 스키마)**, 비용 추정·상한, `mock` 공급자(키 없이 전체 흐름 테스트)
- `sources/`: RSS·직접 입력 주제 목록
- `pipeline.py`: 단계별 실행·상태 저장(SQLite 또는 JSON), 재시작, 중복 게시 방지(콘텐츠 해시)
- `gates/`: 자동 품질 관문(사실 대조·정책·중복 유사도·규격·AI 표시·비용) → 통과/예외 대기열
- `approve/`: 운영 모드(전자동·사후 확인·승인제), 디스코드/텔레그램 알림·승인·거부
- `ops/`: 토큰 자동 갱신·만료 경보, 한도·할당량 확인 후 자동 연기, 일일 실행 보고, 정적 HTML 대시보드
- `topics/`: 주제 자동 선정(소스 + 지난 성과 점수)
- `publish/`: Instagram API(이미지·캐러셀·릴스, 컨테이너 상태 폴링, 한도 확인), YouTube Data API(재개 업로드, AI 관련 필드) — **기본 드라이런**, `--live`는 사용자가 키·토큰을 직접 넣었을 때만
- `hosting/`: 인스타용 공개 URL(조사로 무료 선택지 확정: 예 GitHub Pages·클라우드 저장소 무료 등급)
- `schedule/`: Windows 작업 스케줄러·macOS launchd·cron·GitHub Actions 워크플로 예시
- `insights.py`: 지표 수집 → CSV
- `examples/n8n/`: (선택) 같은 흐름의 노코드 워크플로 JSON 1개
- 테스트: 모든 외부 호출은 모킹. 작업자는 유료 키를 쓰지 않는다.

## 4. 배포·사이트
