작성·질문 수집: 2026-10-27. 이론 1~13장, 실습 0~10의 **24묶음 × 5개 = 120개**. 설계서 8절 안전 규칙을 적용한다.

웹에서 공개 질문·FAQ·공식 안내의 질문 주제를 확인한 뒤 초보 부모의 말로 재구성했다. 설문이나 검색량 순위가 아니며, 각 장에서 우선 답할 질문 5개를 편집해 골랐다. 개인의 이름·아기 사진·답변 전문은 수집하지 않았다. 로그인 맘카페·지식iN 비공개 글·자동완성은 직접 확보하지 않아 수집했다고 쓰지 않는다. 아래 예시는 **질문 수집 전용**이며 의학·제도 답의 근거로 쓰지 않는다.
