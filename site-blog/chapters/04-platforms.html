플랫폼 고르기

수익 목표·공식 API·도메인을 함께 비교해 내 첫 블로그를 고릅니다.

2026년 10월 조사 기준

이 장의 흐름

먼저 답부터

초보자는 어디에 첫 글을 올릴까요?

오늘 첫 글은 네이버 블로그를 권합니다. 애드센스가 목표라면 티스토리, 무료 공식 API가 필요하면 Blogger, 서버까지 관리하려면 설치형 WordPress를 살펴보세요. [B001][B012][B010][B185]

수아 “생활 정보도 쓰고, 생활 가전 후기도 쓰려는데 어디가 좋을까요?”

태오 “오늘 직접 발행할 수 있는 곳부터 고르세요. 어떤 광고를 붙일지와 자동 발행이 꼭 필요한지도 함께 봅니다.”

API는 프로그램이 블로그에 글을 보내는 공식 통로입니다. 도메인은 사이트 주소이며, 호스팅은 글과 사진을 인터넷에 보관하는 서비스입니다.

수아는 첫 정보 글을 네이버에서 시작합니다. 같은 글의 자료 수집·AI 초안·사람 검수는 다른 플랫폼에서도 이어집니다. 달라지는 것은 편집기와 광고·자동 발행 경로입니다.

축별 설명

플랫폼마다 글·광고·주소의 조건이 다릅니다

좁은 화면에서는 표를 좌우로 밀어 읽으세요. 키보드에서는 표에 초점을 둔 뒤 방향키로 옮깁니다.

네이버 블로그 · 오늘 첫 공개가 우선일 때

한국어 공식 편집기로 글부터 공개하는 기본 경로입니다.

흐름
블로그 아이디 만들기 → 내 블로그 → 글쓰기 → 전체 공개·현재 발행입니다. [B001][B048]
기준·예
기본 개설·편집 추가 구독 0원. 광고는 애드포스트 검수 경로를 확인합니다. [B001][B023]
조건
제휴 활동은 프로그램 조건·표시 문구를 확인합니다. 공개 닉네임과 수익 서비스 본인확인을 구분합니다. [B093][B037][B018]
언제 쓰나
서버 설정 없이 내 경험·공식 자료로 글을 쓰고 싶을 때입니다.
지금 할 일
수아처럼 “퇴근 후 생활 정보”의 독자·주소 아이디를 정하고 발행 실습으로 갑니다.
확인할 점

네이버 글쓰기 API는 종료됐습니다. 개인 도메인 연결도 제한됩니다. 애드센스 코드를 붙이거나 로그인 매크로로 대신하는 경로를 택하지 마세요. API와 독립 주소가 필수라면 아래 플랫폼을 고릅니다. [B006][B070][B073][B158]

티스토리 · 애드센스와 직접 편집이 목표일 때

기본 호스팅을 이용하며 애드센스 신청을 준비할 수 있습니다.

흐름
카카오계정으로 시작 → 글쓰기 → 완료 → 공개 발행 → 애드센스 조건 확인입니다. [B167][B170][B185]
기준·예
기본 호스팅 0원, 유료 개인 도메인은 선택입니다. 수익형 블로그에는 플랫폼 자체 광고가 적용됩니다. [B008][B201]
조건
광고 승인과 사이트 심사는 따로 받습니다. 플랫폼 광고 정책을 지켜야 합니다. [B024][B008]
언제 쓰나
애드센스를 목표로 직접 편집하고 플랫폼의 광고 조건을 받아들일 때입니다.
지금 할 일
공식 자체 광고 공지를 읽고, 내 광고 자리와 서비스 광고를 구분해 메모하세요.
확인할 점

자체 광고는 내 광고 수입에서 일률 비율을 떼는 것으로 설명하지 않습니다. 앵커·오퍼월·모바일 전면광고 제한과 AdFit 신규 연동 종료를 확인하세요. 티스토리 Open API도 종료됐습니다. [B008][B009][B092][B082][B007]

Blogger · 무료 공식 API가 필요할 때

무료 기본 호스팅에서 공식 API를 배울 수 있습니다.

흐름
Blogger 글쓰기 → 검수·공개 → 필요할 때 API 초안 저장을 배우는 순서입니다. [B012][B069]
기준·예
기본 blogspot 주소·호스팅 0원. 산 도메인을 연결하려면 도메인 비용과 DNS 설정이 필요합니다. [B068][B069]
조건
애드센스는 이용 조건을 충족하고 검토를 받아야 합니다. API에는 본인 권한 인증이 필요합니다. [B182][B012]
언제 쓰나
나중에 검수한 글을 프로그램에서 초안으로 보내고 싶을 때입니다.
지금 할 일
처음에는 직접 발행하고 API는 선택 학습으로 남깁니다. 무료 기본 주소로 시작할지 적으세요.

WordPress · 설치형과 .com을 구분합니다

설치형은 무료 소프트웨어이며 서버·도메인은 따로 준비합니다.

흐름
호스팅 선택 → 설치 → 보안·백업 설정 → 직접 발행 → 필요하면 REST API입니다. [B017][B010]
기준·예
카페24 “워드프레스 블로그 스타트업”의 예: 월 500원 + 설치비 5,000원 = 첫 달 5,500원입니다. 독립 도메인 별도, VAT 포함입니다. [B017]
조건
설치형은 서버 업데이트·보안·백업을 관리합니다. WordPress.com은 호스팅을 포함한 별도 서비스이며 플랜별 기능을 확인합니다. [B015]
언제 쓰나
내 서버·광고 자리·주소를 직접 관리할 이유가 분명할 때입니다.
지금 할 일
첫 결제·갱신·도메인·백업 비용을 따로 적고 관리 시간을 확보하세요.
확인할 점

WordPress.com Free는 US$0이고, Personal은 월납 US$9 또는 연납 US$48 안내입니다. 연납의 월환산 US$4를 한 달만 내는 가격으로 읽지 마세요. 외부 광고 코드와 WordAds 조건은 현재 플랜 안내를 확인하세요. [B015][B016][B091]

플랫폼 고르기 분기

1개부터 검토

네이버 블로그: 오늘은 공식 편집기에서 첫 글을 공개하세요.

수익 보장 순위가 아닙니다. 세 조건을 함께 적용하며 맞지 않는 조합은 조건을 다시 고르도록 안내합니다.

실제 사례

공식 백업 기능과 주소 이전은 다릅니다

네이버는 콘텐츠 백업을, 티스토리는 데이터 백업을 안내합니다. Blogger도 백업과 가져오기 도움말을 제공합니다. 원고를 내려받는 일과 예전 주소·검색 순위를 이어받는 일을 나눠 준비해야 합니다. [B071][B200][B133]

배울 점: 처음부터 원고·사진·출처를 따로 보관합니다. 수아가 옮길 때는 생활 정보 글의 최신 신청 안내도 다시 확인합니다.

확인할 점

수아·태오와 예시 블로그는 가상입니다. 검색 순위가 그대로 따라온다고 약속하지 마세요. 글·사진·댓글의 가져오기 지원과 기존 주소 연결 가능 여부를 옮길 플랫폼의 공식 도움말에서 확인하세요. [B133][B200]

작업실 노트

고른 이유와 관리할 일을 남깁니다

내 독자와 글: 직장인의 지원 제도 신청 준비
우선 수익 경로: 애드포스트 / 애드센스 / 제휴 / 아직 미정
공식 API 필요: 지금은 아니오 / 반드시 필요
주소: 기본 주소 / 독립 도메인 / 서버까지 관리
고른 플랫폼과 이유:
첫 결제 / 갱신 / 도메인 비용:
원고·사진·출처 보관 위치:

개설은 실습 1 안내, 실제 공개는 실습 7로 이어갑니다.

자주 묻는 질문 5개

플랫폼을 고르기 전에

초보자는 네이버·티스토리·워드프레스·블로거 중 무엇을 고르나요?

오늘 첫 발행은 네이버 블로그부터 권합니다.

애드센스는 티스토리, 공식 API는 Blogger, 서버 관리는 설치형 WordPress를 비교하세요. 분기 도구에 조건을 넣으세요.

무료 블로그에도 광고와 제휴 링크를 넣을 수 있나요?

플랫폼이 지원하는 수익 경로와 심사 조건 안에서 가능합니다.

네이버는 애드포스트, 티스토리는 애드센스 경로입니다. 제휴 관계는 첫 부분에 밝히고 비교 표에서 내 경로를 적으세요. [B023][B185][B037]

티스토리 자체 광고가 붙으면 내 수익은 어떻게 되나요?

플랫폼 광고가 추가되며 내 수입 변화는 내 보고서로 확인합니다.

일률 공제율을 가정해 빼지 마세요. 자체 광고 안내에서 허용 형식을 확인하고 운영 중 같은 기간의 실적을 기록하세요. [B008]

워드프레스는 무료인데 왜 비용이 드나요?

설치형 소프트웨어와 서버·도메인 비용이 다르기 때문입니다.

카페24 해당 상품 예의 첫 달은 500 + 5,000 = 5,500원입니다. 도메인과 갱신비를 따로 적고 비용 예를 확인하세요. [B017]

나중에 바꾸면 글·주소·검색 순위도 옮길 수 있나요?

원고 백업과 주소·검색 이전을 따로 점검해야 합니다.

티스토리 백업을 내려받았어도 사진·링크·옛 주소 연결을 확인하세요. 이전 도식을 보고 원고부터 보관합니다. [B200]

핵심 정리

세 줄로 가져갑니다

  • 오늘 첫 발행은 네이버, 애드센스는 티스토리 경로부터 비교합니다.
  • 공식 API는 Blogger, 서버 통제는 설치형 WordPress를 검토합니다.
  • 원고 백업·주소·검색 이전과 첫 결제·갱신비를 따로 기록합니다.
