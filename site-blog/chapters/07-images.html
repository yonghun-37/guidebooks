이미지·썸네일

직접 사진과 AI 삽화의 역할을 나누고, 작은 화면에서도 읽히게 만듭니다.

2026년 10월 조사 기준

이 장의 흐름

먼저 답부터

사진이 없으면 무엇을 쓰나요?

설명용 이미지는 AI로 만들 수 있습니다. 실제 사용·방문을 보여 주는 사진은 직접 찍습니다. 수아의 지원 제도 글에는 준비물 삽화를, 제습기 후기에는 실제 물통 사진을 씁니다.[B037][B143]

수아 “사진이 없으면 AI로 제습기를 그려 넣을까요?”

태오 “설명용 삽화로는 쓰되, 써 본 증거로 보여 주면 안 됩니다.”

수아의 ‘퇴근 후 생활 정보’는 가상 블로그입니다. 아래 생성 이미지는 설명용 예시입니다.

세 글의 고정 제목·메모·사진 파일명을 이어 씁니다. 정보는 info-notes.txt·support-check.svg, 후기는 review-notes.txt·dehumidifier-tank.jpg와 dehumidifier-room.jpg, 여행은 trip-notes.txt·trip-river.jpg와 trip-shelter.jpg입니다. 원고 이름은 draft.txt로 유지하고 선택한 글의 제목을 제목칸에 넣으세요.

축별 설명

사진에서 썸네일까지

직접 사진 · 내가 본 것을 보여 줍니다

후기에는 글의 관찰을 뒷받침하는 사진을 붙입니다. 물통 손잡이가 편했다면 손잡이와 꺼내는 방향을 찍습니다.[B143]

흐름
관찰 메모 → 직접 촬영 → 개인정보 가리기 → 원본 보관 → 캡션입니다.
기준·비용
같은 물건의 비슷한 사진을 늘리기보다, 각 사진이 설명할 내용을 정합니다. 가지고 있는 휴대폰과 편집 기능으로 추가 구독 없이 시작합니다.
조건
남의 얼굴·차량 번호·주문 내역은 공개 전에 살핍니다. 인터넷 사진은 이용허락과 상업 이용 조건을 확인합니다.[B148]
언제 쓰나
실사용 후기, 여행 기록처럼 직접 겪은 장면을 보여 줄 때입니다.
사진나쁜 캡션좋은 캡션
물통 손잡이최고의 제습기dehumidifier-tank.jpg · 직접 촬영: 제가 잡기 편했던 물통 손잡이
여행 산책길인생 여행지trip-river.jpg · 직접 촬영: 비가 오기 전 먼저 걸은 강변 구간

지금 할 일: 후기 문장 옆에 필요한 사진 장면을 적으세요.

확인할 점

출처를 적는 것만으로 사진 이용이 허락되지는 않습니다. 사진 파일마다 권리자·허용 용도·원문 주소를 확인하세요. 허락을 찾지 못하면 내 사진이나 직접 만든 표로 바꿉니다.[B148]

AI 삽화 · 증명 대신 개념을 설명합니다

AI에는 글자 없는 배경을 만들게 하고, 제목은 편집기에서 넣습니다. ChatGPT의 새 채팅에서 이미지 생성/이미지 만들기처럼 쓰인 기능을 선택하거나, 입력창에 그림 요청을 넣습니다. Gemini의 이미지 생성 기능도 대안입니다.[B112][B111]

흐름
그림의 역할 정하기 → 장면·구도·제약 입력 → 생성 결과 검수 → 파일 저장 → 제목 추가입니다.
기준
사람·로고·공식 서류를 넣지 않고 실제 장소·제품으로 오해할 요소를 뺍니다. 저장 전에 글자·손·물체 모양을 확대해 봅니다.
비용
무료 앱의 생성 한도 안에서 시작합니다. 한도가 끝나면 내 사진과 무료 템플릿으로 완성합니다.[B097][B103]
언제 쓰나
지원 제도 준비처럼 추상적인 내용을 대표 이미지로 설명할 때입니다.

완성 예시 · 지원 제도 글의 준비물 삽화

Use case: illustration-story. Asset: landscape blog educational thumbnail background, no text. Editorial paper-cut illustration about preparing to apply for a public support program after work: a warm desk, an open blank checklist, plain unbranded folder, pen, small table lamp; no money or official seals, no logos, no readable documents, no UI. Sophisticated cream, muted plum and sage palette, soft paper texture, clear simple silhouettes. Composition wide with the objects on the right and calm empty cream space on left for title added later. This is a conceptual illustration, not documentary evidence. Save generated asset for workspace use if possible.

입력에서 배울 점: 소재는 준비물, 구도는 오른쪽 사물·왼쪽 여백, 금지는 로고·공식 서류·글자입니다. 결과에서 글자가 생겼다면 ‘글자를 모두 제거하고 나머지는 유지해 줘’라고 후속 요청합니다.

완성 예시 · 당일치기 글의 분위기 삽화

Use case: illustration-story. Asset: landscape blog thumbnail background. Primary request: clearly illustrated paper-cut conceptual image for a weekend day trip blog: winding riverside path, distant low green hills, a small plain commuter train crossing a bridge, no specific identifiable place. Warm cream paper, muted plum and sage palette, delicate cut-paper texture, balanced editorial composition with calm empty sky space at upper left for title added later. Not a documentary photograph. No people, no text, no labels, no logos, no brand, no watermark.

입력 → 출력: 산책길·열차·여백 요청 → 분위기 삽화입니다. ‘이곳에 다녀왔다’는 증거 사진 자리에는 넣지 않습니다.

흔한 실수: AI가 만든 여행지 풍경을 실제 전망으로 소개하거나 생성한 한글을 그대로 쓰는 일입니다. 장소는 직접 사진으로, 제목은 텍스트로 바꿉니다.

지금 할 일: 내 글에서 삽화가 설명할 내용을 한 문장으로 정하고 프롬프트 소재를 바꾸세요.

확인할 점

서비스의 상업 이용 조건과 타인 권리, 내 저작권 성립은 따로 확인합니다. 네이버의 AI 활용 설정은 표시 기능입니다. 미리캔버스 AI 결과를 게시할 때는 제작자 이름과 AI가 한 일을 명확히 표시합니다. 실제와 혼동될 그림에는 생성 설명을 붙이는 편집 원칙을 권합니다.[B003][B149][B186][B100]

썸네일 · 읽히는 제목은 따로 얹습니다

Canva나 미리캔버스에서 배경과 제목을 나눠 편집합니다. 무료 템플릿·요소만 골라도 대표 이미지를 만들 수 있습니다.[B107][B108][B109]

흐름
새 디자인 → 내 이미지 업로드 → 배경 배치 → 텍스트 추가 → 다운로드 → 모바일 확인입니다.
기준
‘지원 제도 신청 전 확인’처럼 내용이 먼저 보이는 짧은 제목을 권합니다. 가전 후기라면 ‘물통은 편할까?’처럼 실제 관찰을 예고합니다.
조건
무료 계정에서도 유료 요소가 섞일 수 있습니다. 다운로드 전 요소의 무료/유료 표시와 이용 조건을 확인합니다.[B108][B052]
언제 쓰나
블로그 대표 이미지와 본문 삽화를 완성할 때입니다.
서비스넣는 곳·행동나오는 것
Canva디자인 만들기/템플릿 → 업로드 → 내 파일 → 텍스트 → 다운로드 같은 메뉴내 배경 위에 수정 가능한 제목을 얹은 이미지
미리캔버스새 디자인 → 업로드 → 텍스트 → 다운로드 같은 메뉴무료 요소와 제목으로 만든 대표 이미지

대체 텍스트: 이미지를 못 보는 사람에게 내용과 기능을 전하는 설명입니다. ‘이미지’ 대신 ‘지원 제도 신청 전 확인할 대상·기간·준비물 표’처럼 씁니다. 입력 칸이 없는 편집기라면 주변 본문과 캡션에도 설명을 남깁니다.[B192]

시간·비용: 이 절의 편집 계획은 배경 고르기 10분 + 제목 배치 10분 + 모바일 확인 10분 = 30분입니다. 무료 요소로 추가 구독 0원, 반복 작업이 많을 때 미리캔버스 Pro 월 14,900원(VAT 포함 일반 가이드)을 비교합니다.[B052][B108]

지금 할 일: 제목이 사물과 겹치지 않게 옮기고 휴대폰에서 읽으세요.

확인할 점

시간은 수업용 계획입니다. 요금·소재 사용 범위는 현재 결제창과 약관을 확인하세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(Canva · 미리캔버스)을 확인하세요.[B052][B108]

자주 묻는 질문 5개

이미지를 넣기 전에

직접 사진이 없으면 AI로 대신해도 되나요?

설명용 삽화로 쓸 수 있습니다.

지원 제도 준비물은 삽화로, 후기의 실사용 장면은 직접 사진으로 보여 줍니다. 그림의 역할부터 적으세요.[B037]

인터넷 사진은 출처만 적으면 되나요?

아닙니다. 이용허락과 허용 용도도 확인합니다.

무료 다운로드 이미지도 광고 글 사용 조건을 봅니다. 사진별 권리 메모를 남기세요.[B148]

무료 Canva·미리캔버스로 광고 글 썸네일을 만들어도 되나요?

사용한 소재의 광고 이용 조건을 충족하면 가능합니다.

무료 템플릿에 유료 요소가 섞였는지 확인합니다. 다운로드 전 점검을 하세요.[B108][B052]

AI 제품 사진을 실사용 사진처럼 올려도 되나요?

실제 체험 증거로 속여 쓰면 안 됩니다.

제습기 후기에는 내 물통 사진을 씁니다. 관찰을 보여 주는 사진을 직접 찍으세요.[B037]

한글이 틀리거나 모바일에서 잘리면 어떻게 하나요?

제목을 텍스트로 다시 얹고 작은 화면에서 확인합니다.

배경만 생성하고 제목을 편집기에서 바꿉니다. 미리보기에서 길이를 줄여 보세요.

핵심 정리

세 줄로 가져갑니다

  • 실사용·방문은 직접 사진으로 보여 줍니다.
  • AI는 설명용 배경을 만들고 제목은 따로 편집합니다.
  • 소재 권리·생성 표시·모바일 잘림을 확인합니다.
