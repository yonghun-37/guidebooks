지금 하는 일

ChatGPT Free를 열고, 답변을 내 메모에 저장하는 연습을 해요.

이 실습이 끝나면 내 손에 있는 것: 무료 AI 대화·저장한 질문 목록·원고와 자료 파일.

왜 하나요? AI 답변을 내 자료와 함께 보관해야 다음 서비스로 옮길 수 있어요.

오늘 잡아 둘 시간: 10분

따라 하기 ① · 무료 AI 하나를 준비해요

처음에는 ChatGPT Free 하나로 시작하세요. 같은 대화에서 키워드 질문·개요·초안·교정을 나눠 요청해요.[B097] 공식 사용 안내[B210]

버튼 이름은 앱 버전에 따라 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(ChatGPT 웹 시작 안내)을 확인하세요.

  1. 브라우저에서 chatgpt.com을 열어요. 공식 사이트인지 주소를 확인하고 가입/로그인을 선택해요. 본인 이메일 또는 제공되는 로그인 방식으로 인증을 마쳐요.
  2. 무료 등급을 사용해요. 유료 업그레이드 제안은 건너뛰고 대화 화면으로 가요.
  3. 새 채팅/Chat과 같은 대화 메뉴를 열어요. 화면 아래쪽 메시지 입력칸에 아래 연습 문장을 붙이고 보내요.
  4. 답을 읽고 필요한 부분을 복사해 materials.txt 또는 휴대폰 메모에 저장해요. 대화 기록만 믿고 창을 닫지 않아요.
퇴근 후 생활 정보를 읽는 초보 직장인이 독자야.
나는 내 자료로 블로그 글을 쓰려고 해.
먼저 내가 답해야 할 질문만 적어 줘: 독자 질문, 직접 경험, 공식 출처, 사진, 제공 관계.
자료가 없으니 제도명·금액·사용 경험을 만들지 마.

같은 메모를 다른 AI에 넣어도 돼요

서비스가입·입력 위치다음에 남길 것
GeminiGoogle 계정으로 로그인 → 새 대화/질문 입력칸 → 무료 범위에서 같은 요청답변 복사 → 내 원고 파일
Claude공식 사이트 가입/로그인 → 새 채팅 → 메시지 입력칸 → 무료 범위답변 복사 → 내 원고 파일

무료 기능·한도는 서비스마다 달라요. 같은 글을 여러 서비스에 동시에 맡길 필요는 없어요.[B101][B103]

확인할 점

무료 한도가 끝나면 이미 받은 개요를 메모에 저장하고 직접 문장을 채워요. 이미지 한도는 직접 사진으로 대신해요. 앱 구독과 API 결제는 다르니 API 키를 만들지 않아도 돼요.[B097][B101][B103][B098]

따라 하기 ② · 이미지 도구는 하나만 골라요

미리캔버스 Free 또는 Canva Free 중 익숙한 곳을 준비해요. 직접 사진만 쓴다면 지금 가입을 건너뛰고 실습 5에서 해도 돼요.[B052][B107]

  1. 미리캔버스 또는 Canva 공식 사이트에서 본인 계정으로 가입해요. 무료 등급으로 시작해요.
  2. 템플릿 검색에 ‘블로그 썸네일’을 넣어요. Free/무료 표시와 요소별 이용 조건을 확인하고 유료 배지 요소를 빼요.
  3. 제목 한 줄을 바꿔 보는 데서 멈춰요. 실제 사진·글자를 넣고 저장하는 순서는 실습 5에서 진행해요.
[B107][B108][B052]

따라 하기 ③ · 자료를 지우고 파일을 나눠요

AI에 넣기 전에 개인정보를 지워요. 지원 제도 신청서의 주민번호, 후기 영수증의 주소, 여행 사진 속 다른 사람 얼굴을 먼저 확인해요. 공개할 필요가 없는 정보는 보내지 않아요.

기기저장하는 방법
Windows메모장 → 파일 → 다른 이름으로 저장 → draft.txt, UTF-8. 확장명 표시를 켜 이름이 draft.txt.txt가 아닌지 확인해요.
macOS텍스트 편집기 → 포맷 → 일반 텍스트 → draft.txt로 저장. 서식 문서 RTF 대신 일반 텍스트를 써요.
휴대폰메모 앱에 원고·출처·사진 메모를 구분해요. 사진은 파일/내 파일에서 찾을 수 있는 위치에 두세요.

draft.txt는 원고, materials.txt는 공식 URL·확인일·내 경험, images 폴더는 사진이에요. blog-kit는 지금 설치하지 않아도 돼요. 터미널은 선택 실습 10에서 처음 열어요.

이렇게 보이면 성공

AI가 만든 질문 목록이 내 메모에 저장돼 있어요. 입력칸을 찾았고, 무료 이미지 도구 또는 직접 사진 경로도 정했다면 준비가 끝났어요.

이렇게 보이면?

상황지금 할 일
결제 화면이 떠요닫기/무료로 계속 같은 항목을 찾아요. 결제 없이 대화나 템플릿을 사용할 수 있는 범위로 돌아가요.
개인정보를 넣었어요추가 전송을 멈추고 해당 서비스의 대화·데이터 관리 안내를 확인해요. 비밀번호를 넣었다면 공식 계정 화면에서 바꿔요.
다운로드한 사진을 못 찾아요브라우저 다운로드 목록과 파일/내 파일 앱의 다운로드 폴더를 열어요.

자주 묻는 질문 5개

무료 AI는 어디에 질문하나요?

ChatGPT의 새 대화 입력칸에 붙여요. 연습 요청을 보내고 답을 메모에 복사하세요. 공식 사용 안내

한도에 걸리면 결제해야 하나요?

받은 개요를 직접 채워도 완주할 수 있어요. 제목과 소제목을 메모에 옮겨 내 경험부터 쓰세요. 대안을 보세요.

무료 소재는 어떻게 고르나요?

Free/무료 표시와 요소의 이용 조건을 함께 봐요. 왕관/Pro 등 유료 배지가 있으면 사진·도형으로 바꾸세요. 템플릿 준비를 따라요.[B108][B052]

내 메모를 통째로 넣어도 되나요?

개인정보와 회사 비밀을 먼저 빼요. 신청서의 주민번호·영수증 주소처럼 필요 없는 부분을 지우고 자료 파일을 만드세요.

키트 설치를 건너뛰어도 되나요?

브라우저와 메모 앱으로 발행까지 가요. Python은 선택 자동화에서만 준비해요.

자동화·무료 대안

blog-kit brief.py는 프롬프트 파일을 만들 뿐 AI 서비스를 호출하지 않아요. 무료 대화창에 직접 붙이고 검수한 답을 저장하는 방식으로 진행해요. blog-kit 실행 순서에서 필요한 부분만 따라 하세요. 휴대폰만 있다면 메모 앱과 공식 편집기로 끝내도 돼요.

오늘 한 일을 남겨요

체크와 메모는 이 브라우저에 저장돼요. 중요한 결과는 개인 파일에도 남기세요.
