첫 글 실제로 발행하기

검수한 원고를 독자가 읽는 글로 바꾸고, 공개 주소를 남겨요.

2026년 10월 조사 기준

이 장의 흐름

지금 하는 일

검수한 글을 전체 공개하고, 휴대폰에서 읽어 본 주소를 남겨요. 오늘 끝낼 것은 공개 글과 주소예요.

이 실습이 끝나면 내 손에 있는 것: 첫 공개 글, 모바일 확인 기록, 저장한 글 주소.

왜 하나요? 편집기 안에서 보이는 글과 독자가 읽는 글을 직접 비교하려고 해요.

준비물은 내 블로그, 검수한 원고, 내가 쓸 수 있는 사진·그림이에요. 아직 원고가 없으면 실습 4 안내를 보고 먼저 준비하세요. 이 장은 네이버부터 안내해요. 티스토리를 골랐다면 아래 탭을 바꾸세요.

수아 “생활 정보 글에 제도 금액이 들어가는데 그대로 올려도 돼요?”

태오 “원문 날짜와 신청 대상을 다시 확인해요. 확인 못 한 금액은 빼고 올려요.”

두 사람과 블로그 ‘퇴근 후 생활 정보’는 가상이에요. 예시 글은 ‘2025 청년내일저축계좌, 대상과 신청 기간 정리’이에요. 실제 제도명·금액·대상은 본인이 확인한 공식 자료로 채워요.

세 글의 고정 제목·메모·사진 파일명을 이어 씁니다. 정보는 info-notes.txt·support-check.svg, 후기는 review-notes.txt·dehumidifier-tank.jpg와 dehumidifier-room.jpg, 여행은 trip-notes.txt·trip-river.jpg와 trip-shelter.jpg입니다. 원고 이름은 draft.txt로 유지하고 선택한 글의 제목을 제목칸에 넣으세요.

발행 전에 글 첫 부분을 보세요

표시가 필요한 내용은 발행 전에 고쳐요. 제공받은 것이 있다면 제목 또는 본문 첫 부분에 독자가 알아볼 수 있게 써요.[B037]

내 글에 있나요?지금 할 일
제휴 구매 링크제휴 관계를 첫 부분에 별도 문단으로 적어요. 프로그램 공식 표시 문구를 확인하고 링크를 열어 봐요.[B093][B076][B037]
무료 제품·원고료받은 내역을 적어요. 예: “업체로부터 제품과 원고료를 제공받아 작성했습니다.” 실제 받은 것에 맞게 바꿔요.[B037]
AI 이미지생성 서비스의 상업 이용·표시 조건을 확인해요. 실제 사진으로 오해할 삽화에는 “AI로 생성한 이미지”라는 캡션을 권해요. 네이버 AI 활용 설정도 확인해요.[B003][B186]
남의 사진파일별 사용 허락·이용 조건을 확인해요. 출처만 적으면 허락된다고 생각하지 마세요. 확인이 안 되면 내 사진·직접 만든 표로 바꿔요.[B148]

수아의 정보 글은 제휴·협찬이 없는 설정이에요. 공식 원문의 이용 조건을 확인한 뒤, 신청 준비 순서를 직접 만든 표로 설명해요. 생성 그림을 실제 신청 화면처럼 쓰지 않아요.

따라 하기 · 플랫폼과 기기를 고르세요

버튼 이름은 앱 버전에 따라 조금 다를 수 있어요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(네이버 발행 · 티스토리 발행)을 확인하세요.

네이버 블로그 · 기본

PC

오른쪽 위 ‘발행’으로 설정 창을 연 뒤, 아래 ‘발행’을 한 번 더 눌러요.[B048]

  1. 본인 계정의 내 블로그 → 글쓰기에서 검수한 제목·본문을 넣어요.
  2. 위쪽 발행을 눌러 카테고리와 주제를 골라요. 예시는 ‘생활 정보’ 카테고리예요.
  3. 전체 공개와 검색 허용을 확인해요. 이웃 공개나 비공개를 고르지 않아요.
  4. 태그에는 글에서 실제 다룬 주제를 요약해 넣어요. 예: ‘지원 제도’, ‘신청 준비’. 관련 없는 인기 태그는 넣지 않아요.[B206]
  5. 발행 시간 → 현재로 두고 아래 발행을 눌러요.[B048]

모바일

앱에서 보통 ‘글쓰기/연필 → 다음/발행 → 전체 공개 → 발행’과 같은 이름을 찾아요. 제목·본문을 넣고 다음 화면에서 공개 설정을 확인하세요.[B048]

  1. 내 블로그와 로그인 계정을 확인하고 글쓰기를 열어요.
  2. 검수한 글·이미지를 넣고 ‘다음’ 또는 ‘발행’처럼 쓰인 버튼을 찾아요.
  3. 카테고리·전체 공개·검색 허용·태그·현재 발행을 확인해요. 제휴·협찬 문구가 본문 첫 부분에 남아 있는지도 봐요.
  4. 최종 발행 후 글 화면으로 이동했는지 확인해요.

필수 설정을 못 찾으면 원고·사진을 따로 저장한 뒤 PC 탭으로 바꿔 공식 편집기에서 마쳐요.

티스토리

PC

‘임시저장’은 보관이고, ‘완료’ 뒤 ‘공개’로 발행해야 독자가 읽어요.[B170]

  1. 블로그 관리 → 글쓰기에서 제목과 원고를 열어요.[B168]
  2. 카테고리를 고르고, 글에서 다룬 단어를 태그로 넣어요. 예시는 ‘생활 정보’와 ‘신청 준비’예요.
  3. 완료를 눌러 공개 설정을 열어요. 공개를 고르고 대표 이미지를 확인해요. ‘보호’는 비밀번호가 필요한 글이에요.[B170]
  4. 발행 시각은 현재/즉시처럼 쓰인 항목을 확인해요. 최종 공개 발행과 같은 이름의 버튼을 눌러요.

모바일

앱에서 공개 설정을 못 찾으면 PC 관리 화면에서 마쳐요. 보통 ‘내 블로그 → 글쓰기/연필 → 제목·본문 → 완료/발행’ 같은 이름을 찾아요.[B168][B170]

  1. 내 블로그와 원고가 맞는지 확인해요.
  2. 카테고리·태그와 공개 범위를 확인해요. 비공개 저장으로 끝내지 않아요.
  3. 공개·현재 발행에 해당하는 설정을 고르고 최종 발행해요. 제휴·협찬 문구는 첫 부분에 유지해요.
  4. 필수 항목이 보이지 않으면 원고를 저장하고 PC에서 이어서 발행해요.
확인할 점

모바일 버튼·예약 기능은 현재 화면과 공식 도움말을 대조해요. 티스토리 발행 문서는 과거 기능 안내예요. 찾기 어려우면 원고를 보관하고 PC 관리 화면에서 진행하세요.[B048][B168][B170]

두 번 확인하는 지점을 그림으로 봐요

예약은 어디에서 바꾸나요?

오늘 첫 공개는 현재 발행으로 마쳐요. 다음 글을 나중에 올릴 때만 예약을 골라요.

  • 네이버 PC: 발행 설정에서 발행 시간 → 예약 → 날짜·시간 → 발행으로 진행해요. 예약 상태와 선택한 시각을 다시 확인하세요.[B002]
  • 티스토리: 완료 뒤 발행 시각/예약과 같은 이름의 항목에서 미래 시각을 골라요. 현재 항목 이름은 도움말과 화면을 대조해요.[B170]

예약해 두었다면 오늘 공개 과제는 아직 끝나지 않았어요. 실제 공개 후 주소를 열어 확인해요. 현재 발행으로 바꿀 때는 해당 글의 설정을 다시 열고 선택한 시각을 확인하세요.

이렇게 보이면 성공 · 모바일로 직접 읽어요

로그아웃한 휴대폰 브라우저에서도 본문이 읽히면 공개를 확인한 거예요. 글 화면의 공유/주소 복사 같은 메뉴로 URL을 복사하세요. PC 주소창을 이용해도 돼요.

  1. 휴대폰 브라우저의 비공개 창이나 로그인하지 않은 다른 브라우저에 글 주소를 붙여 넣어요.
  2. 제목·소제목·이미지를 끝까지 읽어요. 표가 잘리는지, 사진 글씨가 읽히는지, 제휴·협찬 문구가 첫 부분에 보이는지 확인해요.
  3. 출처·제휴 링크가 의도한 페이지로 이어지는지 열어 봐요. 내 광고를 눌러 시험하지 마세요.[B027]

주소·체크는 이 브라우저에만 저장돼요. 개인 메모에도 복사해 두세요. 주소 입력만으로 사이트가 실제 공개 여부를 확인하지는 않아요.

이렇게 보이면? · 수정과 삭제

보이는 상황지금 할 일
나에게만 글이 보임최종 발행 여부와 전체 공개/공개를 확인해요. 예약·보호·비공개 상태인지 살펴요.[B048][B170]
주소로는 읽히는데 검색이 안 됨공개와 검색 반영은 달라요. 네이버 검색 허용을 보고 다음 실습의 검색 확인으로 가요.[B048][B173][B178]
사진·표·표시 문구가 잘림본문을 수정하고 같은 공개 주소를 휴대폰에서 다시 열어요. 필요한 문구가 접힌 곳에만 있지 않게 옮겨요.[B037]

네이버 블로그

내 글의 ‘수정’ 또는 더보기 같은 메뉴부터 찾아요. 수정 화면에서 본문을 고친 뒤 발행과 공개 설정을 다시 확인해요. 메뉴가 보이지 않으면 작성자 계정인지 확인하고 PC로 전환하세요. PC에서 글을 내리려면 해당 카테고리 → 목록 열기 → 글 관리 열기 → 대상 글 선택 → 설정 변경/삭제를 이용해요.[B205]

티스토리

PC ‘블로그 관리 → 콘텐츠 → 글 관리 → 수정’으로 원고를 다시 열어요. 개별 글의 더보기 → 수정 경로도 살펴보세요.[B168] 삭제가 필요하면 글 관리에서 대상 글의 삭제와 같은 이름을 찾고 확인창을 읽어요.[B207]

확인할 점

삭제 전에는 원고·사진을 따로 보관해요. 티스토리 삭제 도움말은 오래된 안내라 현재 버튼 위치와 복구 가능 여부는 삭제 확인창·공식 지원에서 확인하세요. 잠시 숨기는 목적이면 공개 설정을 먼저 살펴요.[B207][B170]

발행하면서 자주 묻는 질문

PC 네이버는 어떤 버튼을 누르나요?

발행 → 전체 공개·현재 → 최종 발행 순서예요.

‘생활 정보’ 카테고리처럼 내 분류를 고르세요. PC 탭에서 설정을 확인해요.[B048]

네이버 앱은 어디서 시작하나요?

내 블로그에서 글쓰기/연필과 같은 이름을 찾아요.

다음/발행 화면에서 전체 공개를 확인해요. 못 찾으면 원고를 저장하고 PC 경로로 마쳐요.[B048]

티스토리 저장과 공개는 어떻게 다른가요?

임시저장은 보관이고 공개 발행은 누구나 읽는 상태예요.

완료 뒤 공개 설정까지 마치세요. 티스토리 탭에서 대표 이미지도 확인해요.[B170]

예약과 즉시 발행은 어디서 바꾸나요?

발행 설정의 시간 항목에서 골라요.

오늘은 현재 발행, 다음 글은 예약처럼 나눠요. 예약 안내를 보고 설정 시각을 기록하세요.[B002][B170]

주소는 어떻게 저장하고 확인하나요?

공유 주소를 복사하고 로그인하지 않은 휴대폰 브라우저에서 열어요.

예를 들어 내 글의 제목·이미지·출처가 보이는지 읽어요. 주소 칸과 개인 메모에 기록하세요.

오늘 한 일을 남겨요

공개 글과 모바일 확인을 끝냈다면 오늘 첫 발행을 마쳤어요. 다음은 내 플랫폼에 맞는 검색 확인이에요.

이 버튼은 실제 블로그 글을 지우지 않아요.
