이미지·썸네일 만들기

직접 사진이나 무료 템플릿으로 이미지를 만들고 설명·권리를 기록해요.

2026년 10월 조사 기준

실습 시작 · 0→10 전체 경로

이 장의 흐름

지금 하는 일

직접 사진이나 무료 템플릿으로 이미지를 만들고 설명·권리를 기록해요.

이 실습이 끝나면 내 손에 있는 것: 본문 이미지·썸네일 파일과 설명·권리 메모.

왜 하나요? 실제 경험을 보여 주는 사진과 설명용 삽화를 구분해 독자가 오해하지 않게 해요.

오늘 잡아 둘 시간: 정보·후기 15분 / 경험 10분

세 글의 고정 제목·메모·사진 파일명을 이어 씁니다. 정보는 info-notes.txt·support-check.svg, 후기는 review-notes.txt·dehumidifier-tank.jpg와 dehumidifier-room.jpg, 여행은 trip-notes.txt·trip-river.jpg와 trip-shelter.jpg입니다. 원고 이름은 draft.txt로 유지하고 선택한 글의 제목을 제목칸에 넣으세요.

따라 하기 ① · 증거는 사진, 설명은 삽화로 골라요

후기·여행의 실제 장면은 직접 사진을 써요. 정보 글은 신청 확인 순서를 직접 만든 표·그림으로 설명해도 돼요. AI 그림은 개념을 설명하는 배경으로 사용해요.[B143][B037]

글기본 이미지쓸 설명 예시
지원 제도 신청 방법직접 만든 대상 → 기간 → 제출 자료 순서도공식 공고에서 대상과 접수 기간을 먼저 확인하는 순서
생활 가전 한 달 후기직접 찍은 설치·사용·청소 사진dehumidifier-tank.jpg · 직접 찍은 물통 손잡이. 촬영일은 review-notes.txt에 기록
당일치기 여행직접 찍은 이동 지점·풍경trip-river.jpg · 강변 구간 / trip-shelter.jpg · 비를 피한 쉼터. 타인 얼굴 확인

사진을 images 폴더에 모아요. 원본을 보관하고 공개할 복사본에서 집 주소·차량번호·타인 얼굴처럼 불필요한 정보를 가려요. 남의 사진은 출처만 적어서 가져오지 않아요.[B148]

따라 하기 ② · 무료 템플릿에 내 사진과 제목을 넣어요

버튼 이름은 앱 버전에 따라 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(미리캔버스 도움말 · Canva 도움말)을 확인하세요.

실습 2에서 준비한 무료 계정을 사용해요. 아직 가입하지 않았다면 공식 사이트에서 무료 등급으로 가입하고 로그인하세요.[B052][B107]

미리캔버스

  1. 미리캔버스 → 디자인 만들기/바로 시작하기 같은 항목을 열어요. 템플릿 검색에 ‘블로그 썸네일’을 입력해요.
  2. 무료 템플릿을 선택해요. 유료 배지 요소가 보이면 삭제하고 무료 도형·사진으로 바꿔요.
  3. 업로드/내 파일 같은 메뉴에서 직접 사진 또는 아래 AI 배경 파일을 올려요. 템플릿 사진을 선택하고 내 이미지로 교체해요.
  4. 텍스트 메뉴에서 제목을 별도로 넣어요. 수아는 “지원 제도 / 신청 전 확인”을 써요. 작은 부제는 지우고 읽기 쉬운 크기로 조절해요.
  5. 다운로드에서 PNG 또는 JPG를 선택해요. 결제 없이 저장되는지 확인하고 images/thumbnail.png처럼 이름을 정해 저장해요.
[B052][B110]

Canva

  1. Canva → 디자인 만들기를 열고 템플릿 검색에 ‘블로그 썸네일’을 입력해요.
  2. 무료 요소만 남겨요. Pro 등 유료 배지나 워터마크가 있는 요소는 직접 사진·무료 도형으로 바꿔요.
  3. 업로드 → 파일 업로드 같은 메뉴에서 내 사진을 넣어요. 그림 영역에 배치하고 필요한 부분을 자르세요.
  4. 텍스트 → 제목 추가 같은 메뉴에서 한글 제목을 넣어요. 그림과 글자를 따로 움직일 수 있게 둬요.
  5. 공유 → 다운로드 같은 메뉴에서 PNG/JPG를 골라 저장해요. 브라우저 다운로드 폴더에서 파일을 확인해요.
[B107][B108]

선택 · AI 삽화를 배경으로 써요

ChatGPT의 같은 대화에서 이미지 생성을 요청해요. 무료 기능에서 사용할 수 있으면 아래 요청문을 붙이고 보내세요. 기능이 보이지 않거나 한도가 끝났다면 위 직접 사진·무료 템플릿 경로로 마쳐요.[B112][B097]

블로그 썸네일 배경용 삽화를 만들어 줘.
공식 공고를 확인하는 준비를 설명할 빈 체크리스트 종이와 닫힌 파일 폴더가 주제야.
연한 자주색과 크림색의 단순한 편집 삽화로.
가로형, 왼쪽은 제목을 나중에 넣을 수 있게 비우고 오른쪽에 사물을 배치해 줘.
글자·숫자·사람·브랜드·로고·돈·공식 도장·실제 신청서·앱 화면은 넣지 마.
실제 신청 증거 사진처럼 보이지 않게 해 줘.
  1. 생성된 이미지를 열고 다운로드/저장 같은 메뉴로 파일을 저장해요. Windows·macOS는 다운로드 폴더, 휴대폰은 사진 또는 파일/내 파일 앱에서 찾아요.
  2. 글자·가짜 로고·기관 문서처럼 보이는 부분이 없는지 확인해요. 마음에 들지 않으면 “글자와 도장을 빼고 배경만 다시 만들어 줘”처럼 고칠 곳만 요청해요.
  3. 미리캔버스/Canva의 업로드로 파일을 넘기고 제목을 텍스트로 얹어요. 최종 PNG/JPG를 따로 저장해요.

결과 예시 · 제목과 배경을 나눠요

후기는 “한 달 써 보니 / 청소에서 갈렸어요”, 여행은 “당일치기 / 돌아오는 교통 먼저”처럼 글의 실제 결론을 제목으로 써요. 과장된 효능·후기 문장을 만들지 않아요.

따라 하기 ③ · 설명과 권리 메모를 남겨요

대체 텍스트에는 이미지가 전하는 정보를 적어요. 대체 텍스트는 이미지를 볼 수 없을 때 내용을 전하는 설명이에요. “이미지입니다” 대신 “공고에서 대상과 기간을 확인하는 순서”처럼 쓰세요.[B192]

  1. 원고에서 이미지마다 파일명과 설명을 적어요. 편집기에 대체 텍스트/이미지 설명 항목이 있으면 넣어요.
  2. 입력칸이 없다면 이미지 바로 아래 캡션과 본문에도 같은 핵심을 써요. 중요한 절차를 그림 안에만 두지 않아요.
  3. info-notes.txt에 아래 권리 메모를 남겨요. 직접 사진은 촬영자·촬영일, 템플릿은 소재명·이용 조건 URL, AI 그림은 서비스·요청문·수정 범위를 적어요.
파일명:
역할: 직접 사진 / 템플릿 편집 / AI 삽화
내용 설명(대체 텍스트·캡션):
촬영자 또는 소재·서비스 이름:
촬영일 또는 생성·다운로드일:
이용 조건 URL / 확인일 / 허용 용도:
내가 넣은 제목·편집 내용:
AI 역할·제작자 표시 문구:
개인정보·타인 권리 확인:
확인할 점

무료 계정이어도 소재별 이용 조건을 확인해요. 미리캔버스 AI를 쓰면 게시 때 제작자 명의와 AI 역할을 분명히 밝혀요. 예: “제작: 생활기록자. 배경은 미리캔버스 AI로 만들고 제목·배치는 직접 편집했습니다.” 네이버 AI 활용 설정도 확인하세요.[B108][B186][B003]

이렇게 보이면 성공

저장한 이미지 파일, 읽히는 제목, 내용 설명과 권리 메모가 있어요. Windows는 탐색기, macOS는 Finder, 휴대폰은 파일/사진 앱에서 실제 파일을 열어 확인해요. 다음 실습에서 그 파일을 편집기에 직접 올려요.

이렇게 보이면?

상황지금 할 일
저장하려니 결제창이 떠요무료 범위 밖 요소를 제거해요. 직접 사진과 무료 도형으로 바꾼 뒤 다시 내려받아요.
한글이 깨져요AI 그림 속 글자를 지우고 디자인 도구의 텍스트로 입력해요.
실제 제품·여행 사진이 없어요경험을 보여 줄 사진은 나중에 직접 찍어요. 없는 장면은 생성해서 체험 증거로 쓰지 않아요.

자주 묻는 질문 5개

사진·AI·템플릿 중 무엇을 고르나요?

체험 증거는 직접 사진, 설명용 배경은 삽화예요. 가전 청소 사진과 여행 풍경은 내 사진을 골라요. 유형 표를 보세요.

AI 그림에 한글 제목은 어떻게 넣나요?

디자인 도구에서 별도 텍스트로 넣어요. “지원 제도 / 신청 전 확인”을 텍스트 메뉴에 입력하세요.

결제창이 뜨면 어떻게 하나요?

유료 요소를 지우고 무료 도형·내 사진으로 바꿔요. 다운로드 전 전체 요소를 확인하고 저장 오류 대응을 따라요.[B108][B052]

대체 텍스트 칸이 없으면요?

캡션과 본문에 핵심 설명을 남겨요. “대상 → 기간 → 자료 확인”처럼 절차를 글로도 쓰세요. 설명 기록을 따라요.[B192]

이미지 사용 기록은 무엇을 적나요?

파일명·만든 사람/서비스·날짜·이용 조건·AI 역할을 적어요. 권리 메모에 URL과 확인일을 남기세요.

자동화·무료 대안

blog-kit는 로컬 이미지를 미리보기 폴더로 복사하고 대체 텍스트를 점검해요. 썸네일을 만들거나 권리를 확인해 주지는 않아요. 이미지가 없어도 직접 만든 표로 내용을 설명할 수 있어요. blog-kit 실행 순서에서 필요한 부분만 따라 하세요. 휴대폰만 있다면 메모 앱과 공식 편집기로 끝내도 돼요.

오늘 한 일을 남겨요

체크와 메모는 이 브라우저에 저장돼요. 중요한 결과는 개인 파일에도 남기세요.
