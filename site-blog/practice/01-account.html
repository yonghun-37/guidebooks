계정과 블로그 만들기

내 블로그를 만들고, 비공개 연습 글과 계정 보안을 확인해요.

2026년 10월 조사 기준

실습 시작 · 0→10 전체 경로

이 장의 흐름

지금 하는 일

내 블로그를 만들고, 비공개 연습 글과 계정 보안을 확인해요.

이 실습이 끝나면 내 손에 있는 것: 내 블로그 주소·비공개 연습 글·보안 확인 메모.

왜 하나요? 주소와 계정을 먼저 정리하면 원고를 안전하게 이어 쓸 수 있어요.

오늘 잡아 둘 시간: 15분

따라 하기 ① · 내가 쓸 블로그를 열어요

버튼 이름은 앱 버전에 따라 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(네이버 개설 · 티스토리 가입)을 확인하세요.

네이버 블로그 · 기본

  1. 네이버 블로그에 본인 계정으로 로그인해요. 계정이 없으면 공식 회원가입 안내에 따라 만들어요.
  2. 내 블로그를 열어요. 처음이면 블로그 아이디 만들기에서 주소용 아이디를 정해요. 실명·전화번호·회사 이름은 피하세요.
  3. 블로그명은 ‘퇴근 후 생활 정보’, 별명은 ‘생활기록자’처럼 정해요. 예시를 그대로 쓰기보다 내 주제로 바꿔요.
  4. 내 블로그 주소를 자료 메모에 복사해요. 기존 블로그가 있다면 새로 만들지 않고 먼저 그 주소를 확인해요.
[B001]

이름·별명과 주소는 달라요. 이름은 블로그 관리의 기본 설정/블로그 정보 같은 항목에서 바꾸고, 주소는 개설 전에 다시 읽어요.[B165][B072]

티스토리

  1. 티스토리에서 시작하기 → 카카오계정으로 로그인해요. 카카오계정이 없다면 공식 가입 절차를 먼저 마쳐요.
  2. 추천 주소 또는 직접 입력한 주소를 확인해요. 주소에 개인정보를 넣지 말고 최종 확인 전에 철자를 읽어요.
  3. 개설 후 내 프로필에서 블로그 관리/톱니바퀴 같은 메뉴를 찾아요. 관리할 블로그가 맞는지 봐요.
  4. 블로그 이름·설명을 내 주제로 고치고 주소를 자료 메모에 남겨요.

개설한 티스토리 기본 주소는 바꿀 수 없어요. 블로그 이름 변경과 주소 변경을 혼동하지 마세요.[B167][B168]

따라 하기 ② · 계정을 잠그고 복구 방법을 확인해요

비밀번호·인증번호는 AI나 다른 사람에게 주지 마세요. 가입 대행이나 자동 발행 프로그램에 로그인 정보를 넘기지 않아요.

  1. 네이버는 네이버ID → 보안설정 → 2단계 인증을 열어요. 인증을 받을 기기의 네이버 앱에 같은 계정으로 로그인한 뒤 설정을 진행해요. 공식 사용 안내[B208]
  2. 티스토리는 연결한 카카오계정을 보호해요. 카카오톡의 설정 → 카카오계정 → 2단계 인증을 열어 안내를 따라요. 비상연락용 이메일도 확인해요. 공식 사용 안내[B209]
  3. 각 공식 화면에서 설정 완료 상태를 확인해요. 알림을 받을 기기가 내 기기인지 읽고, 복구 연락처를 최신 상태로 둬요.
확인할 점

인증이 막히면 네이버 보안 도움말 또는 카카오 보안 도움말에서 기기·복구 방법을 확인하세요. 모르는 로그인 알림은 승인하지 마세요.

따라 하기 ③ · 연습 글은 비공개로 저장해요

첫 연습은 같은 블로그의 비공개 글로 해요. 연습용으로 계정을 여러 개 만들 필요는 없어요.

  1. 내 블로그 → 글쓰기에서 제목 ‘연습 중’, 본문 ‘사진과 링크를 넣는 연습입니다’를 입력해요.
  2. 네이버는 발행 설정의 비공개, 티스토리는 완료 뒤 비공개를 골라 저장해요. 최종 확인창도 읽어요.[B048][B170]
  3. 관리 화면에서 해당 글의 비공개 상태를 확인해요. 오늘 완성할 본인 글은 실습 7에서 전체 공개해요.

휴대폰만 있다면: 네이버 블로그 앱 또는 티스토리 웹/앱에서 내 블로그·글쓰기/연필과 같은 메뉴를 찾아요. 긴 글은 메모 앱에 먼저 보관해요. 앱에 필요한 항목이 없으면 휴대폰 브라우저의 데스크톱 사이트 보기로 관리 화면을 열어 보세요. 조작이 어렵다면 원고를 저장하고 PC를 쓸 때 이어 가요.[B001][B168]

이렇게 보이면 성공

내 블로그 주소, 비공개 연습 글, 보안 설정 완료 상태가 있어요. 개인정보가 없는 메모에 “플랫폼 / 주소 / 2단계 인증 확인 / 연습 글 비공개”만 적어요. 비밀번호를 기록하는 칸은 만들지 않아요.

이렇게 보이면?

상황해결
아이디를 정했는데 원치 않는 주소예요확정 전에 멈추세요. 이미 확정했다면 공식 주소 변경 도움말에서 내 계정에 가능한지 확인해요.
인증 알림이 안 와요인증 기기의 계정·앱·알림 설정을 공식 도움말과 대조해요.
연습 글이 밖에서 보여요본인 계정의 글 관리에서 비공개로 바꾸고 다른 브라우저로 주소를 다시 열어요.

자주 묻는 질문 5개

네이버는 어디를 눌러 만드나요?

블로그홈에서 내 블로그 → 블로그 아이디 만들기로 시작해요. ‘생활기록자’ 같은 별명과 주소는 나눠 정하세요. 네이버 탭을 따라요.[B001]

티스토리는 카카오계정이 필요한가요?

카카오계정으로 로그인하고 블로그 주소를 정해요. 개설 뒤 기본 주소는 바꿀 수 없으니 철자를 읽으세요. 티스토리 탭에서 진행해요.[B167]

이름·별명·주소를 바꿀 수 있나요?

이름·별명과 주소는 다르게 관리해요. 이름은 정보 설정에서 고치고, 주소는 서비스별 변경 규칙을 확인하세요. 새 주소를 시험 삼아 확정하지 마세요.[B165][B072][B167]

휴대폰만 있어도 되나요?

메모 앱과 공식 블로그 앱/웹으로 시작해요. 글쓰기/연필 메뉴를 찾고 사진을 넣어요. 휴대폰 경로에서 원고를 따로 보관하세요.

공개 범위와 보안은 어디서 보나요?

공개 범위는 글 발행 설정, 보안은 계정 설정이에요. 연습 글은 비공개로, 2단계 인증은 공식 계정 메뉴에서 확인하세요.

자동화·무료 대안

blog-kit에는 네이버·카카오 로그인 비밀번호가 필요 없어요. 샘플 실행과 드라이런은 계정 없이 하고, 첫 글은 공식 편집기에서 직접 발행해요. blog-kit 실행 순서에서 필요한 부분만 따라 하세요. 휴대폰만 있다면 메모 앱과 공식 편집기로 끝내도 돼요.

오늘 한 일을 남겨요

체크와 메모는 이 브라우저에 저장돼요. 중요한 결과는 개인 파일에도 남기세요.
