오늘 쓸 글 한 가지와 발행할 플랫폼 하나를 정해요.

지금 하는 일

오늘 쓸 글 한 가지와 발행할 플랫폼 하나를 정해요.

이 실습이 끝나면 내 손에 있는 것: 유형·플랫폼·독자 질문·준비 자료 메모.

왜 하나요? 가지고 있는 경험과 자료에서 시작하면 AI에게 없는 내용을 만들게 하지 않아요.

오늘 잡아 둘 시간: 5분 · 아래 전체 시간표에서 내 경로를 확인하세요.

따라 하기 ① · 이미 가진 자료로 한 가지를 골라요

수아는 ‘퇴근 후 생활 정보’의 정보 글을 대표 예시로 유지해요. 내 자료가 아직 없고 여행 메모가 있다면 경험 글로 시작해도 좋아요. 공식 공고를 모았다면 정보 글, 한 달 쓴 생활 가전이 있다면 후기를 골라도 좋아요.

수아·태오와 예시 블로그는 가상이에요. 아래 소재를 본인의 자료로 바꿔요. 세 글을 모두 만들 필요는 없어요.

오늘 쓸 글먼저 챙길 입력필요 서비스·무료 경로제작 시간
정보·해결 글지원 제도 공식 공고, URL·확인일, 신청 전에 헷갈린 점ChatGPT Free → 직접 만든 표 또는 미리캔버스 Free → 네이버 블로그90분
사용 후기·비교 글한 달 쓴 생활 가전의 장단점, 직접 사진, 구매·제공 관계ChatGPT Free → 직접 사진/Canva Free → 네이버 또는 티스토리90분
내 경험 기록 글당일치기 여행 순서·실수·추천 이유, 직접 사진ChatGPT Free → 사진 고르기/미리캔버스 Free → 네이버 블로그60분

무료 AI와 무료 소재로 추가 구독비 0원 경로를 사용해요.[B097][B107][B052][B001]

시간은 대략이에요. 화면은 기기·버전마다 다를 수 있어요. 표는 키워드부터 편집까지 잡아 둔 실습 시간이에요. 기존 경험·사진을 사용하며 촬영·이동·제품 구매·인증·검색 반영·광고 심사 대기는 따로 잡아요. 계정 준비와 발행을 더한 전체 시간표도 보세요.

책 끝까지 이어 쓰는 세 글

이미 자료가 있는 독자는 앞서 고른 글을 유지해요. 자료가 없는 독자에게는 여행 메모가 있을 때 여행을 권할 뿐, 정보 글을 여행 글로 바꾸라는 뜻은 아니에요. 아래는 가상 블로그의 작성 예시예요. 신청·사용·방문 경험과 사진은 본인 것으로 바꾸세요.

경로·제목메모이미지 파일
정보 · 2025 청년내일저축계좌, 대상과 신청 기간 정리info-notes.txt · 논산시 지난 모집 공지, 일반·예외 대상과 기간 분리support-check.svg · 직접 그린 순서도, 사진 아님

그림은 동봉 순서도를 쓸 수 있어요. 후기·여행 사진은 동봉하지 않아요. 실제로 찍은 파일만 images 폴더에 넣으세요. 같은 메모·원고를 키트 샘플에서 읽기 →

따라 하기 ② · 첫 플랫폼은 하나만 골라요

고민되면 네이버 블로그를 고르세요. 오늘 공식 편집기로 첫 글을 발행하기 위한 수업 경로예요. 애드센스 운영이 목표면 티스토리를 골라요.[B001][B023][B185]

설치형 WordPress는 서버 관리가 준비된 독자의 심화 경로예요. 처음부터 호스팅이나 도메인을 결제할 필요는 없어요.[B010][B017]

따라 하기 ③ · 글과 자료를 같은 곳에 모아요

‘첫-블로그-글’ 폴더에 원고·출처·사진을 모아요. 오늘 결과는 글 한 편과 공개 주소예요. 마지막에 실습 7에서 휴대폰으로 열어 확인해요.

Windows

파일 탐색기 → 문서 → 새 폴더를 열어 ‘첫-블로그-글’을 만들어요. 메모장에 자료를 적고 파일 → 다른 이름으로 저장을 눌러요. 파일 이름은 info-notes.txt, 인코딩은 UTF-8로 두세요.

macOS

Finder → 문서에서 폴더를 만들어요. 텍스트 편집기 → 포맷 → 일반 텍스트 만들기를 고른 뒤 info-notes.txt로 저장해요. 사진은 같은 폴더의 images에 모아요.

휴대폰만 있어요

메모 앱에 ‘첫 블로그 글’을 만들고 원고·출처 URL·확인일을 적어요. 파일/내 파일 앱에 사진을 저장하세요. 앱을 오갈 때 원고를 복사해 메모에 남겨요. 터미널이나 Python 설치는 건너뛰어요.

이렇게 보이면 성공

유형·플랫폼·독자 질문이 적힌 메모와 자료 폴더가 있어요. 수아의 예: “정보 글 / 네이버 / 지원 제도 신청 전에 무엇을 확인할까 / 공식 공고와 내 확인 과정”. 휴대폰 독자는 같은 내용이 메모 앱에 있으면 돼요.

이렇게 보이면?

막힌 곳지금 할 일
후기를 쓰고 싶은데 아직 안 썼어요공식 사양을 비교하는 정보 글로 바꾸거나 이미 다녀온 여행을 골라요.
사진이 없어요정보 글에 직접 만든 신청 순서 표를 써요. 생성 이미지를 체험 증거로 만들지 않아요.
오늘 한 시간이 전부예요오늘은 자료·개요를 만들고 다음 날 초안·발행을 마쳐요. 저장할 파일명을 메모하세요.

자주 묻는 질문 5개

오늘 가장 쉽게 끝낼 글은 무엇인가요?

이미 메모와 사진이 있는 경험 글이에요. 예: 당일치기 여행에서 돌아오는 버스를 놓친 이유. 유형 표에서 자료가 있는 행을 고르세요.

메모·사진은 얼마나 필요한가요?

독자의 질문에 답할 자료부터 챙기세요. 정보 글은 공식 공고, 후기는 사용 조건과 장단점, 여행 글은 이동 순서와 직접 사진이에요. 자료 양식을 채워요.

첫 플랫폼은 무엇이 좋나요?

이 수업의 기본은 네이버예요. 애드센스가 목표면 티스토리를 고르세요. 선택 그림에서 한 곳을 적어요.

결제·설치가 필요한가요?

무료 서비스와 브라우저로 진행해요. ChatGPT Free와 직접 사진으로 시작하세요. blog-kit 설치는 선택 실습이에요.[B097]

무엇이 남으면 오늘 끝낸 건가요?

공개 글과 휴대폰에서 읽은 주소가 남으면 돼요. “원고 저장”에서 끝내지 말고 주소 기록까지 확인하세요.

자동화·무료 대안

blog-kit의 brief.py는 유형·키워드로 복사용 프롬프트를 만들어요. 오늘은 아래 자료 양식을 메모에 복사해도 같은 순서로 시작할 수 있어요. blog-kit 실행 순서에서 필요한 부분만 따라 하세요. 휴대폰만 있다면 메모 앱과 공식 편집기로 끝내도 돼요.

오늘 한 일을 남겨요

체크와 메모는 이 브라우저에 저장돼요. 중요한 결과는 개인 파일에도 남기세요.
