구독·크레딧·API는 어떻게 다른가요?

구독
월·연 요금을 내고 앱의 정해진 한도를 씁니다. 무제한을 뜻하지 않습니다. 연간 월 환산가는 선납 총액도 확인하세요.
크레딧
생성할 때 내부 포인트를 차감합니다. 한 요청에서 여러 결과를 만들거나 다시 생성하면 더 씁니다. 도구마다 차감·만료·이월 규칙이 다릅니다.
API 종량제
프로그램이 요청한 입력·출력의 사용량에 따라 청구합니다. AI 사용량 토큰은 글을 처리할 때 나누는 조각이며, 로그인 비밀값인 인증 토큰과 다릅니다. 글자 수와 토큰 수는 같지 않습니다.
다른 도구에 내장
편집기에서 외부 모델을 골라도 그 편집기의 요금과 권리 조건을 읽습니다. 모델 회사의 무료량이 그대로 따라오지 않습니다.

글 1편에 얼마가 드나요?

아래 편수·토큰량·시도 횟수는 가상 계산 조건입니다. 제목·개요·초안·교정을 합친 사용량으로 계산합니다. 한국어 글 한 편의 고정 평균이나 품질 순위가 아닙니다.

API 예는 직접 사진을 쓰고 이미지 생성·검색 도구·캐시·장문 할증을 쓰지 않는 조건입니다. 같은 양으로 두 번 생성하면 Luna US$0.0084, Sol US$0.168입니다. 사고 토큰·추가 원문·검색 호출을 쓰면 사용량과 비용을 더하세요. 최소 충전액·세금·환전/카드 수수료는 실제 청구에서 확인합니다.

이번 달 현금 지출은 새 구독료 + 실제 API/크레딧 충전 결제 + 소재·취재비 + 세금·수수료입니다. 내 시간을 기록해야 남는 돈도 판단할 수 있습니다. 11장 기록 방법 →
