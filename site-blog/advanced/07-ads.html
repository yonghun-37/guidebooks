가치가 낮다는 거절을 받으면 기존 사이트의 거절 사유부터 읽어요. 보통 애드센스의 사이트 목록·정책센터와 심사 메일에서 확인해요. 예를 들어 그림책 표지만 나열한 글에 선정 이유·대상 독자·출처를 더하고 목차에서 접근되게 고쳐요. 중복 계정을 새로 만들며 재신청하지 마세요.[BX022]

③ 광고는 본문과 버튼이 헷갈리지 않게 놓아요

안전한 광고 개수 하나가 정해져 있지는 않아요. 콘텐츠를 읽기 어렵게 하거나 클릭을 잘못 유도하는 배치를 피하세요. 이 실습은 두 번째 소제목 뒤의 자리 하나만 보여 줘요. 공식 허용 개수라는 뜻은 아니에요.[BX024]

실제 설치는 승인 후 본인 애드센스에서 발급받은 코드를 써요. 보통 이런 이름의 광고 → 사이트 기준/광고 단위 기준에서 코드 종류를 먼저 고르고, WordPress의 해당 코드 삽입 기능에 넣어요. 자동 광고와 수동 광고 단위 코드를 섞어 복제하지 마세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

④ ads.txt는 내 판매자 정보로 준비해요

ads.txt는 권장 사항이에요. 광고 판매가 허용된 판매자를 적는 텍스트 파일이에요. 생성 파일의 pub-REPLACE_ME는 가짜 자리표시예요. 승인 후 계정이 제공하는 행을 복사하고 내 도메인의 /ads.txt에서 공개되는지 확인해요. 파일 이름을 ads.txt.txt로 저장하지 마세요.[BX025]

⑤ 부모 독자·광고 종류·방문 지역을 확인해요

부모가 읽는 육아 글이라는 이유만으로 아동 대상 사이트가 되지는 않아요. 실제 이용자·내용·정보 수집을 보세요. 아이가 직접 하는 활동 페이지라면 아동 대상 여부부터 다시 판단해요. 미국 아동 대상이나 해당 아동 정보 수집을 아는 경우에는 한국 운영자도 미국 COPPA 적용을 검토해요.[BX028]

광고 요청의 아동·연령 처리 설정은 코드 유형별 공식 안내를 따라요. 다른 광고 제품의 예제 코드를 애드센스 자동 광고에 그대로 넣지 마세요. TFAT는 미성년자 관련 광고 처리 설정이고, TFCD는 아동 대상 처리, TFUA는 동의 연령 미만 처리에 쓰던 이름이에요. 적용 연령·기능은 코드 유형별 현재 안내에서 대조해요. 세 이름을 같은 설정값으로 바꾸어 쓰지 마세요.[BX098] EEA·영국·스위스 방문자에게 맞춤 광고를 제공할 때는 Google 인증 동의 관리 도구(CMP) 요건을 확인해요. 아동 처리 설정이 개인정보 고지나 동의를 대신하지 않아요.[BX029]

보통 이런 이름의 브랜드 안전성 → 차단 관리 → 민감한 카테고리에서 내 독자에게 맞지 않는 광고를 검토해요. 차단 뒤에도 실제 노출을 확인하세요.[BX026] AdFit은 먼저 사이트를 제시해 제휴 문의를 하고 사전승인·초대와 매체 심사를 확인해요. 즉시 가입 가능한 광고망으로 안내하지 않아요.[BX123]

def build_ads(root, config, today):
    """수동 점검표, ads.txt, 광고 위치, 모의 보고서를 생성한다."""
    base = Path(root) / 'output' / 'ads'
    base.mkdir(parents=True, exist_ok=True)
    n = int(config.get('ad_after_h2', 2))
    if n < 1: raise ValueError('광고 위치는 1 이상이어야 합니다')
    article = str(config.get('article_html', '<h2>첫째</h2><p>본문</p><h2>둘째</h2><p>본문</p>'))
    matches = list(re.finditer(r'</h2\s*>', article, re.I))
    if len(matches) >= n:
        pos = matches[n - 1].end()
        article = article[:pos] + '<aside>광고 위치 예시 (실제 광고 없음)</aside>' + article[pos:]
    publisher = config.get('publisher_id', 'pub-REPLACE_ME')

확인할 점

한국어 자격 안내와 연령 전용 도움말은 모두 만19세 이상으로 안내해요. 신청 시 본인에게 적용되는 약관도 확인하세요.[BX020][BX021] 실제 광고 코드를 넣기 전에는 방문 지역·아동 대상 여부·수집 도구에 맞춰 개인정보 고지와 설정을 다시 확인하세요.

정리

  • 광고 신청은 글 수 대신 콘텐츠·탐색·정책 준비로 판단해요.
  • ads.txt는 권장, 개인정보처리방침은 실제 처리에 맞춰 준비할 의무예요.
  • 광고 위치와 예상·확정·입금액은 각각 확인해요.
글 수·방문자·운영일·도메인에 공식 최소 조건이 있나요?

공통 숫자로 정해진 글 수·방문자·운영일 조건은 없어요. 자체 콘텐츠와 HTML 관리권이 핵심이에요. 예를 들어 내 놀이 글을 휴대폰에서 끝까지 읽어 보세요. 신청 준비 표의 각 항목을 확인하세요.[BX020]

가치가 낮은 콘텐츠로 거절되면 무엇부터 고치나요?

거절 메일과 사이트·정책센터에 적힌 사유부터 고쳐요. 표지만 나열한 그림책 글에는 독자별 고르는 이유를 더해요. 고친 글과 탐색 링크를 확인한 뒤 재검토를 요청하세요.[BX022]

소개·문의 페이지도 공식 필수인가요?

개인정보 고지 의무와 운영 권장 페이지를 구별해요. 소개·문의·광고 정책을 갖추는 것은 권장해요. 문의 이메일을 수집한다면 처리방침도 실제 흐름과 맞춰요. A2 페이지를 다시 읽고 가상 주소를 바꾸세요.[BX023]

광고는 몇 개, 어디에 넣나요?

고정 개수 합격 공식 대신 읽기와 오클릭을 점검해요. 이 실습의 자리 하나는 배치 연습이에요. 소제목 번호를 바꾸고 본문과 버튼을 가리지 않는지 보세요.[BX024]

부모 대상 글과 아동 대상 글은 다른가요?

실제 독자와 이용 방식을 보고 구분해요. 부모에게 읽어 주기 방법을 설명하는 글과 아이가 직접 쓰는 활동 페이지는 이용 방식이 달라요. 광고 코드의 아동 처리와 방문 지역별 동의 요건을 따로 확인하세요.[BX028][BX029]

ads.txt·차단·보고 API·AdFit도 쓸 수 있나요?

각각 준비와 확인 경로가 있어요. ads.txt는 내 계정 행, 민감 광고는 차단 관리, 보고 API는 OAuth 권한을 확인해요. AdFit은 사이트 URL을 준비해 사전 제휴 문의부터 하세요. 오늘은 가상 자료로 차이를 구별하면 돼요.[BX025][BX026][BX063][BX123]
