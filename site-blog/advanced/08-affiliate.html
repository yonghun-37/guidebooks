③ 독자용 표시와 검색용 속성을 각각 확인해요

블로그의 관계 표시는 제목 또는 첫 부분에서 쉽게 보여야 해요. 글하단·댓글·더보기 뒤에만 숨기지 않아요. 이 과정은 첫 문단을 기본으로 삼아요. 사진만 따로 추천글로 재사용한다면 사진의 표시와 연결 본문 인식도 다시 확인해요.[BX037]

실제 쿠팡 활동 글에는 가이드의 문구를 사용하세요.

이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

위 문구의 근거는 쿠팡 공식 가이드예요.[BX032] 제품 제공·원고료도 받았다면 그 관계를 추가로 밝혀요. 예를 들어 “제품을 제공받았고, 이 글의 제휴 링크를 통한 구매가 발생하면 수수료를 받습니다”처럼 실제 받은 것을 구체적으로 적어요.[BX037]

기본 원고와 등록부의 프로그램명은 모두 쿠팡(모의)이에요. 첫 문장은 이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.예요. 실제 글에서는 현재 프로그램 안내와 내 관계를 대조하세요. output/drafts/affiliate.html을 열고 첫 문단과 링크를 확인해요. 텍스트 편집기에서는 링크의 rel="sponsored"도 찾아요. 이 속성은 검색 서비스에 유료 관계를 알리는 것이며 독자용 문구를 대신하지 않아요.[BX064]

Tab으로 위치 선택에 들어가고 방향키로 바꿔 보세요. 링크 옆만 선택한 뒤 첫머리로 되돌려 차이를 확인해요. 제목은 이 작은 미리보기에서 보이더라도 실제 목록·앱에서 잘릴 수 있어요.

④ 영유아 제품은 품목별로 나눠요

KC 번호 하나로 모든 아기 제품을 검사하지 않아요. 먼저 product_type(품목), intended_use(용도), model·maker(모델·업체)를 적어요. 다음으로 certification_scheme(해당 안전 절차), recall_check(리콜 확인), ad_review_scope(광고 자료와 허용 표현)를 확인해요. 어린이제품법은 식품용 기구·용기, 화장품, 의료기기 등을 같은 어린이제품 절차로 다루지 않아요.[BX041]

법적 금지·프로젝트 거절·자료 보류를 구별해요
품목·예판정과 이유지금 할 일
조제유류 제휴·협찬법적 금지에 해당하는 인터넷 광고·판매촉진을 차단해요.유형을 먼저 확인하고 판매촉진을 거절해요. 일반 부모의 비대가성 양육기록 전체를 금지로 확대하지 않아요.[BX082]
의료기기 체온계 등 사용자 체험담 광고법적 금지: 사용자의 체험담 등을 이용한 광고를 차단해요.허가·인증·신고 및 매체·내용별 심의 범위를 따로 확인해요. 작은 블로그라 무조건 면제라고 보지 않아요.[BX131][BX044]
영아 수면용 베개·느슨한 이불·범퍼프로젝트 거절: 안전 수면 원칙과 충돌하는 홍보를 받지 않아요.KC가 있어도 거절해요. 놀이·그림책 소재로 바꿔요. 모든 제품의 국내 판매 자체가 금지라는 뜻은 아니에요.[BX078]
일반 완구·어린이제품자료 보류: 적용되는 인증·안전확인·공급자적합성 자료가 없어요.모델·업체와 라벨을 맞추고 리콜을 확인해요. 검색 결과가 없다는 이유만으로 불법이라고 정하지 않아요.[BX041][BX040]
젖병·젖꼭지자료 보류: 제품 유형·식품용 기구 규격·표시 등을 확인해요.조제유류 금지를 전품목에 그대로 적용하지 말고 해당 제품 자료를 요청해요.[BX041]
영유아 화장품치료·의약품 오인 표현은 법적 금지, 안전 자료 부족은 자료 보류예요.책임판매업자의 안전 자료와 허용 표현을 확인해요. 아기용이라는 말만 믿고 효능을 더하지 않아요.[BX104][BX043]
건강기능식품·영양제질병 치료 표현은 법적 금지, 품목·기능·심의·대상 연령 부족은 자료 보류예요.건강기능식품 해당 여부와 허용 기능·심의 내용을 확인해요. 영양제라는 이름만으로 아기에게 맞다고 추천하지 않아요.[BX106][BX084]

표시·광고주 확인·안전 자료는 서로 대신하지 않아요. 법적 금지 내용은 사람 승인으로 풀지 않아요. 프로젝트 거절은 우리 운영 기준에 따른 거절이에요. 자료 보류는 모델·허용 표현·심의 자료를 받아 다시 검사해요.

⑥ 다른 제휴와 가격은 확인 뒤에 더해요

실제 가격은 기본 글에 표시하지 않아요. 가격 갱신·보관 조건은 현재 약관에서 확인한 뒤 추가해요. 가격을 임의로 오래 저장하거나 가상 가격을 실제 판매가처럼 쓰지 마세요. AI는 확인한 자료를 정리하는 데 쓰고 사용 경험을 만들어 후기라고 부르지 않아요.[BX032][BX037]

네이버 쇼핑커넥트·브랜드커넥트는 등록 채널·활동 제한 매체·캠페인의 지정 채널을 각각 확인해요. 약관에 웹 매체가 있다는 이유로 WordPress 단독 가입이나 모든 캠페인 게시가 허용된다고 판단하지 마세요. 크리에이터 약관과 링크 발급 화면에서 내 외부 블로그 주소의 사용 가능 여부를 확인해요. 네이버 쇼핑 검색 API는 제휴 링크 발급 API가 아니에요.[BX034][BX102]

가입·최종 승인·API 키 발급은 같은 조건인가요?

각기 다른 단계예요. 누적 판매 15만 원은 채널 최종 검토 시작 기준이고 API 자동 발급 조건이 아니에요. 단계표를 보며 계정의 최종승인과 현재 API 자격을 각각 확인하세요.[BX032]

API 조건이나 한도를 못 채우면 어떻게 하나요?

수동 링크와 mock으로 계속 연습해요. 기본 nail 주소는 가상 링크예요. 실제 수동 링크는 활동 프로그램의 생성 화면에서 만들고, API 조건 확인 전 live 연결을 켜지 마세요.[BX032]

쿠팡 문구는 어디에 넣나요?

가이드 문구를 제목 또는 첫 부분에 분명하게 넣어요. 이 장의 기본은 첫 문단이에요. 문구와 모바일 미리보기에서 제목 잘림과 링크 옆만 표시의 문제를 비교하고 내 휴대폰에서 확인하세요.[BX032][BX037]

API 가격을 계속 보여 주거나 AI 후기를 만들 수 있나요?

가격은 조건 확인 전 미표시, 사용 경험은 사람이 적어요. 오늘 샘플은 사용 후기 대신 날·손잡이·소리 같은 선택 기준을 비교해요. 현재 데이터 이용 조건과 AI 작성 허용을 확인하고, 쓰지 않은 경험은 빈칸으로 남기세요.[BX032][BX037]

분유·젖병·화장품·체온계·영양제는 무엇이 다른가요?

적용 품목과 광고 규칙이 달라요. 조제유류 판매촉진과 의료기기 체험담 광고는 차단하고, 젖병·화장품·건강기능식품 등은 해당 분류와 자료를 확인해요. 제품 표에서 내 모델의 판정·다음 행동을 찾으세요.[BX082][BX131]

네이버 제휴 링크를 설치형 블로그에도 쓸 수 있나요?

내 등록 매체와 캠페인의 외부 게시 허용부터 확인해요. 웹 매체 정의만으로 모든 WordPress 게시가 허용되지는 않아요. 크리에이터 약관과 지정 채널을 읽고 내 주소를 사용할 수 있는지 확인하세요.[BX034][BX102]
