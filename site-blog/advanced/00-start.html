코드는 자료 정리·초안·검사·발행 요청을 맡고, 사람은 경험·사진·건강·계약과 최종 승인을 맡아요. 낮잠 시간에는 한 글의 다음 단계까지만 마쳐도 돼요.

서윤광고까지 붙이려면 처음부터 서버를 사야 하나요?

태오아니요. 로컬 실습으로 광고·제휴·협찬 흐름을 배우고 실제 연결은 준비 뒤에 해요.

시작 상태 확인

시작 상태 확인

계정·키·Docker 없이 계획부터 세울 수 있어요. 새 텍스트 파일을 만들고 이름을 운영계획.txt로 저장하세요. 실제 연락처·아이 이름·비밀키는 적지 않아요.

심화편은 가상 블로그 「봄이랑 크는 집」을 이어 가요. 등장인물·제품·광고주는 가상이에요. 화면은 기기·버전마다 다를 수 있고 실습 시간은 대략이에요. 이 책은 진료를 대신하지 않아요. 이상하다 싶으면 소아과에 묻는 게 언제나 맞아요.

단계 ① · 글마다 자동화 수준을 정해요

단계 ① · 글마다 자동화 수준을 정해요

건강 글과 그림책 목록은 같은 방식으로 자동 발행하지 않아요. 여러 주제가 섞이면 높은 위험 등급을 적용해요. 아래 표는 이 프로젝트의 운영 규칙이에요.

글 유형별 자동화 수준 · 운영계획에 하나를 고르세요
글 유형사람이 확인할 일운영 방식
건강·안전: 발열·수면·수유·접종공식 근거·월령·문맥항상 사람 승인. 자동 발행 금지
협찬·제휴계약·제품·표시·실제 경험항상 사람 승인 + 적용되는 광고주 확인
아이 사진·경험식별 정보·배경·공개 범위항상 사람 승인
제도·지원금시행일·지역·원문기본은 사람 승인. 아래 자동 예약 조건을 모두 충족할 때만 선택 가능
놀이·교육·그림책질문·추가 가치·안전 관련 여부기본은 사람 승인. 건강·사진·경험이 없는 신규 글만 아래 조건으로 선택 가능
기존 글 갱신바뀐 금액·날짜·원고자동 탐지 + 사람 승인

사후 확인 모드는 현재 키트에 없어요. 터미타임처럼 안전과 관련된 놀이는 항상 사람이 확인해요.

자동 예약의 조건

자동 예약은 아래 조건을 모두 만족할 때만 가능해요. 설정이 mode="auto"이고 auto_allowed_types에 허용된 info 또는 play여야 해요. 관문 항목이 전부 pass이고, 제목·설명·본문·HTML·관련 자료 전체에 건강·아이 정보·상업 관계·사진·경험·갱신 신호가 없어야 해요. 미디어는 아이 사진이 아니며 직접 제작한 삽화라고 명시된 파일만 허용해요. 서버 조회로 신규 글임을 확인해야 해요. 하나라도 해당하지 않거나 분류가 불명확하면 사람 승인으로 가요. 건강 글과 기존 서버 글의 갱신은 항상 사람이 승인해요.

작업 시간은 자동화 비율보다 내가 검토할 범위로 정하세요. “다음 낮잠 시간에는 공식 원문 하나와 초안 한 편을 읽는다”처럼 끝점을 적어요. 사람이 답하지 않았다고 건강·협찬 글을 자동 공개하지 않아요.

단계 ② · 수입은 내 숫자로 계산해요

단계 ② · 수입은 내 숫자로 계산해요

조회수가 적어도 계산할 수 있고, 모르는 값은 빈칸으로 남겨도 돼요. 계산하려면 해당 칸을 직접 채우세요. 수입이 없다는 것을 확인한 항목은 0을 입력해요. 평균 단가·기대 수익 기본값은 없어요.

광고는 광고 페이지뷰 ÷ 1,000 × 페이지 RPM, 제휴는 확정 구매 건수 × 수수료 대상 평균 구매액 × 수수료율 ÷ 100, 협찬은 현금 약정 합계로 계산해요. 서로 다른 기간·통화를 섞지 않아요. 세금·비용·지급 지연 전의 계산이며 실입금과 다를 수 있어요. 현물 가격은 현금 수입에 더하지 않아요.[BX050]

교육용 가정 모형 · 같은 월·원화 기준

값을 입력하면 세 수입을 합산해요. 빈칸은 모르는 값이에요.

광고 신청에 공통으로 정해진 최소 글 수·방문자 기준은 없어요. 독창적·유용한 콘텐츠, 정책 준수, 사이트 관리권과 실제 준비 상태를 확인하세요. 이 책의 광고 → 제휴 → 협찬은 배우는 순서예요. 각 프로그램·계약 조건을 확인해 독립적으로 준비하세요.[BX020][BX022]

광고 준비는 A7, 제휴 링크·표시는 A8, 실제 지표와 대표글을 정리하는 미디어킷은 A9에서 만들어요.

단계 ③ · 월 비용과 갱신비를 따로 봐요

단계 ③ · 월 비용과 갱신비를 따로 봐요

mock는 외부 서비스 추가요금 0으로 완주할 수 있어요. 기존 기기·전기·통신비는 제외해요. LLM은 초안을 쓰는 AI 언어 모델이고, 토큰은 모델이 글을 나누어 처리하는 단위예요. 호스팅·도메인은 실제 서버를 운영할 때, LLM 요금은 실제 API를 쓸 때 따로 들어요.

가격표에서 읽을 항목 · 업체 추천 순위가 아니에요
항목조사 당시 예운영계획에 적을 것
호스팅카페24 해당 상품 월 500원·설치 5,000원(VAT 포함), 코드 삽입·플러그인·REST·복구 지원은 구매 전 확인[BX015]갱신 월 비용·최초 설치비·REST/복구 지원
장기 선납Hostinger Premium 공개 USD 예: 48개월 $119.52 선납, 갱신 $10.99/월 표시[BX016]월환산 광고가와 실제 선납 총액 구별. 세금·갱신기간 확인
도메인 갱신가비아 .com 10월 정가 연 24,000원(VAT 별도), 11월부터 25,000원[BX019]첫해 할인과 갱신 연 총액을 따로 기록
AI API모델별 입력·출력 토큰 요금[BX071]현재 단가·사용량·재시도·환율·세금

예를 들어 10월 .com 정가에 VAT를 더하면 24,000×1.1÷12=2,200원/월이에요. 갱신 가격이 바뀌면 입력도 바꾸세요. 첫해 할인을 갱신비 칸에 넣지 않아요.[BX019]

계산식은 호스팅 월 총액 + 도메인 갱신 연 총액÷12 + LLM 월 달러×내 환율이에요. LLM은 호출당 입력·출력 토큰과 각 단가를 계산하고 재시도를 포함한 월 호출 수를 곱해요. 서로 다른 모델은 먼저 각각 계산해 합산하세요. 설치비·백업·추가 용량·이미지·최소 결제·세금은 별도 지출 메모에 남겨요.

교육용 가정 모형 · 토큰 비용과 갱신비의 월환산

견적과 사용량을 직접 넣으세요. 단가·환율 기본값은 없어요.

지금 할 일: 예상 사용량은 가정이라고 표시하고, 받은 견적은 조회 날짜와 함께 적어요. 기능 진단은 A2, 호출 전 비용 예약은 A4에서 확인해요.

코드 읽기

설정에서 기본 승인제와 하루 상한을 정해요. 아래 숫자는 키트 설정이며 플랫폼이 정한 발행 안전선이 아니에요.

config.example.toml:10의 실제 발췌예요.

auto_allowed_types = ["info", "play"] # 자동 모드에서도 신규·모든 관문 pass·위험 신호 없음만 허용
daily_limit = 2 # A6 키트 운영 상한이며 검색엔진의 안전선이 아닙니다.

확인할 점

호스팅·도메인·모델 가격은 구매 직전 공식 견적과 갱신 총액을 확인해요. 광고·제휴 자격은 해당 프로그램에서, 협찬은 계약에서 확인해요. 육아휴직급여를 받는 동안 소득 활동은 세금과 별도로 고용센터·1350에 실제 계약·시간·소득 자료를 제시해 신고 여부를 확인하세요.[BX019][BX071][BX108]

정리

정리
