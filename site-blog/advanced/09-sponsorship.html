  • 제품 유형·용도·모델·제조사와 안전 자료는 무엇인가요? 리콜은 확인했나요?
  • 제공품과 현금은 각각 무엇인가요? 반납·배송비·현물 가액 자료는 어떻게 받나요?
  • 어디에 언제 쓰나요? 체험 기간·광고주 확인 기한·게시 유지 기간은 언제까지인가요?
  • 사실관계 수정은 어디까지인가요? 횟수·추가 비용·중단·취소 조건은 무엇인가요?
  • AI 원고·문장 다듬기·합성사진을 각각 허용하나요? 허용 범위와 지정 매체를 적어 주세요.
  • 첫머리 광고 표시와 솔직한 아쉬운 점을 유지해도 되나요? 아이 얼굴·이름 없이 진행하나요?
  • 2차 사용은 어느 매체·기간·편집 범위인가요? 별도 동의와 비용을 정하나요? 지급일·증빙은 무엇인가요?

서울형 1인미디어 표준계약서는 질문을 빠뜨리지 않게 돕는 참고 서식이에요. 모든 블로그에 같은 계약을 강제하는 서식은 아니에요.[BX124]

거절 사례 · 「포근담요」 낮잠 이불

영아가 자는 자리에 느슨한 이불을 두도록 홍보하는 제안은 거절해요. 잠자리를 비우는 안전 수면 원칙과 충돌해요.[BX078][BX086] 이 사례는 프로젝트 거절이에요. 이불 판매 전체를 법적 금지라고 판정하는 사례가 아니에요.

대장에 declined, 사유 영아 수면 안전 충돌, 회신 기록을 남겨요. 대안은 수면용 홍보를 이어 받는 대신, 별도로 안전 검토한 그림책 정리 소재를 고르는 거예요.

제안해 주셔서 감사합니다. 「봄이랑 크는 집」은 영아 잠자리를 비우는 원칙을 지키고 있어요. 보내 주신 낮잠 이불의 수면용 홍보는 진행하기 어려워 이번 제안은 정중히 사양합니다.

위 문장은 거절 회신 예시예요. 키트와 이 페이지는 외부에 회신을 보내지 않아요.

수락 사례 · 「도담」 그림책 꽂이

그림책 꽂이도 제품 자료와 권리를 확인한 뒤 수락해요. 모델·업체·용도를 적고 적용되는 안전 절차를 찾으세요. 안전인증·안전확인·공급자적합성확인은 서로 달라요.[BX041][BX126] SafetyKorea에서 라벨의 모델·업체와 리콜을 대조해요. 검색에 없다는 이유만으로 불법이나 안전을 확정하지 않아요.[BX125]

이번 샘플의 제품 자료와 계약은 모두 가상이에요. 계약의 ai_allowed=false를 먼저 확인하고 사람 작성 경로를 골라요. 사람이 실제로 사용한 메모·허락된 사진만 넣어요. 허용 여부가 unknown이면 답을 받을 때까지 보류해요. AI 사용을 허용해도 사용 경험을 지어내면 안 돼요.[BX037]

def transition(store, id, target, records, today):
    """허용된 전이와 필수 기록을 확인하고 이력을 보존한다."""
    row = store.get('sponsors', id)
    if not row or target not in STATES:
        raise ValueError('문의 또는 상태가 없습니다')
    current = row['state']
    if current == 'on_hold':
        allowed = [row['history'][-1]['records']['return_state']]
    else:
        allowed = STATES[current][1]
    if target not in allowed:
        raise ValueError('허용되지 않은 전이입니다')
    _validate(target, records)
    if target == 'on_hold' and records['return_state'] != current:
        raise ValueError('복귀 상태는 보류 전 상태여야 합니다')
    if target == 'approved':
        approved = row['history'][-1]['records']['content_hash']
        if records['approval_hash'] != approved:
            raise ValueError('승인 해시가 일치하지 않습니다')
    row = dict(row, state=target, history=row['history'] + [{'state': target, 'date': today, 'records': dict(records)}])
    store.put('sponsors', id, row)
    return row

python blog.py draft --sample sponsor --human-notes
