⑤ 실제 수집을 준비한다면 인증과 권한을 나눠 확인해요

먼저 화면에서 같은 기간의 보고서를 읽은 뒤 API 수집을 붙이세요. API는 프로그램이 서비스에 자료를 요청하는 창구예요. analytics/adapters.py는 요청 형식과 응답 상태를 처리해요. 로그인·토큰 갱신·정기 수집을 완성한 명령은 아니에요.

인증은 누구인지, 권한은 무엇을 읽어도 되는지예요
경로선택 기준준비할 것
서비스 계정내 소유 자료를 서버가 반복해서 읽는 자동 작업전용 계정 이메일에 GA4 속성 읽기 권한을 추가. GSC에서도 해당 사이트 권한을 부여
사용자 OAuth내 계정으로 동의하거나 다른 운영자의 자료를 읽을 때사용자 동의·읽기 scope·갱신 토큰 보관. 로그인한 사용자에게도 해당 속성/사이트 권한 필요
AdSense 개인 보고서사용자 계정으로 수입 보고서 읽기사용자 OAuth와 adsense.readonly. 서비스 계정 키로 대체하지 않기

서비스 계정은 사람 대신 쓰는 프로그램 전용 신원이고, OAuth는 사용자가 읽기 권한에 동의하는 방식이에요. API 사용 설정만으로 사이트 접근권한이 생기지 않아요.[BX062][BX059][BX063]

보통 이런 이름으로 찾아요: Google Cloud의 API 사용 설정 → GA4 관리의 속성 액세스 관리 → Search Console 설정의 사용자 및 권한. 서비스 계정 이메일 또는 OAuth 사용자의 권한을 확인하세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

실제 수집 기록에는 속성 ID·사이트 주소·기간·시간대·조회 시각·응답 상태·남은 할당량을 남겨요. 서비스 계정 키·OAuth 토큰·검색어 원자료를 공개 저장소에 올리지 마세요. 동의·개인정보 처리 흐름은 A12에서 확인해요.

⑥ 시간대·빈 행·한도를 읽어요

어제 데이터가 비었다면 지연부터 확인하세요. GA4는 속성 시간대, GSC 날짜는 태평양 시간 기준이에요. GSC는 보통 2~3일 뒤 자료가 제공돼요. dataState="final"은 최종 자료를 요청해요.[BX059][BX116]

숫자 0과 자료 없음은 다르게 보관해요
결과판단다음 행동
ready · 행 있음자료를 읽었어요. 기간·시간대 확인같은 조건의 이전 기간과 비교
empty · 빈 행지연·필터·기간·실제 자료 없음 중 확인할 차례필터 없이 날짜별 조회 → 최근 날짜는 나중에 재조회

기본 GSC 요청은 date·page, rowLimit=1000, startRow=0이에요. 한 요청은 최대 25,000행이며, 페이지 순회에도 일별·검색 유형별 최대 50,000개 상위 행이라는 한계가 있어요. 이 예제 어댑터는 첫 페이지를 읽어요. 전체 검색어 수집기로 쓰지 마세요.[BX059][BX116]

    """GA4 행과 속성 시간대를 반환한다."""
    check_period(start, end)
    ident = str(property_id).removeprefix('properties/')
    body = {'dateRanges': [{'startDate': start, 'endDate': end}],
            'dimensions': [{'name': 'date'}, {'name': 'pagePath'}],
            'metrics': [{'name': name} for name in (
                'activeUsers', 'sessions', 'screenPageViews', 'engagementRate')],
            'returnPropertyQuota': True}

실제 수집은 내 속성·사이트의 읽기 권한, 측정·동의 설정, 보고 기간과 시간대를 확인한 뒤 연결해요. 데이터가 없으면 보류로 기록하세요. 통계 플러그인만으로 시작해도 돼요. Google Site Kit은 WordPress에서 Google 지표를 연결하는 대안이에요. Jetpack은 본인 상업 사이트의 현재 요금 조건을 확인하세요.[BX109][BX110]

GA4 방문과 Search Console 클릭이 왜 다른가요?

측정하는 곳과 단위가 달라요. 가상 검색 클릭 20과 방문 120을 맞출 필요는 없어요. 지표 표에서 내 열 이름을 먼저 확인하세요.

무료 할당량과 지표 이름은 무엇인가요?

표준 GA4 Core의 속성당 하루 한도는 200,000토큰이에요. activeUsers·sessions·screenPageViews·engagementRate를 써요. 토큰 잔여량을 응답에서 확인하세요.[BX057][BX058]

어제 검색 데이터가 비면 실패인가요?

최근 날짜는 지연일 수 있어요. GSC는 보통 2~3일 뒤 제공돼요. 빈 행 확인 순서로 기간·시간대·필터를 살펴요.[BX116]

서비스 계정이면 사이트 권한이 필요 없나요?

권한을 따로 줘야 해요. GA4 속성과 GSC 사이트 양쪽에 읽을 신원의 권한을 확인하세요. AdSense 개인 보고서는 사용자 OAuth를 준비해요.[BX062][BX059][BX063]

예상 수익과 실제 입금은 어떻게 모으나요?

같은 거래의 세 칸으로 모으고 합산하지 않아요. 가상 예상 10,000원 → 확정 9,000원 → 입금 8,700원처럼 기록해요. 입금 증빙과 차이 이유를 채우세요.

WordPress 통계 플러그인만 써도 되나요?

네. 이번 주 고칠 글을 고를 수 있으면 시작할 수 있어요. 먼저 오래된 지원 제도 글 하나를 골라 출처·기준일을 확인하세요. API는 반복 수집이 필요할 때 연결해요.
