output/drafts/info.json을 편집기로 여세요. title은 제목, markdown은 원고, html은 브라우저용 원고예요. 같은 이름의 HTML 파일도 생겨요. experience·experience_by는 빈 문자열, photos는 빈 배열이어야 해요.

일반 답변과 JSON 초안의 차이는 검사할 칸이 정해져 있다는 점이에요. 실제 OpenAI의 기능 이름은 Structured Outputs예요. Responses의 text.format에 type="json_schema"·strict=true와 스키마를 지정해요. 구조가 맞아도 사실은 원문과 대조해야 해요.[BX072]

키트의 providers/openai_adapter.py는 실제 연결용 어댑터예요. 이번 draft 명령은 고정 mock 경로이며 설정의 모델 이름만 바꾼다고 실제 API 호출로 전환되지 않아요. 거절·잘린 응답·JSON 해석 실패를 성공한 초안으로 저장하지 마세요.

단계 ③ · 경험과 비용을 확인해요

단계 ③ · 경험과 비용을 확인해요

“직접 써 봤다”는 문장은 사람이 겪은 내용을 직접 넣어야 해요. 실제 후기라면 날짜·사용 조건·좋았던 점·불편했던 점을 사람이 쓰고 experience_by="human"을 기록해요. 그 표시만 바꾸고 AI 문장을 남겨 두면 안 돼요. 직접 사용하지 않은 비교는 자료 비교라고 밝히고 후기처럼 쓰지 않아요.[BX037]

한 편의 토큰 비용은 입력 비용과 출력 비용을 더해요. 토큰은 모델이 텍스트를 나누어 처리하는 단위예요. 계산식은 (입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가) ÷ 1,000,000이에요. 월 계산은 재시도를 포함한 호출 횟수를 곱해요.[BX071]

가상 계산: 입력 3,000·출력 1,000토큰, 100만 토큰당 입력 $0.10·출력 $0.50이면 (3,000×0.10+1,000×0.50)/1,000,000 = $0.0008이에요. 같은 호출 30회면 $0.024예요. 이 단가는 조사 당시 gpt-6-luna Standard 단문·캐시 없음 조건이며 예상 수익이나 실제 결제액이 아니에요.[BX071]

재시도·사고/도구 토큰·이미지·세금·최소 충전·환전 비용은 따로 봐요. 월 비용 계산기에는 본인이 선택한 현재 단가와 사용량을 넣으세요. API 키를 새로 만들거나 결제할 필요는 없어요.

mock 초안도 비용 0을 기록해요. private/state.sqlite3의 costs에 실행 이름·날짜·micro_usd=0·status="settled"가 남아요. SQLite는 한 파일에 데이터를 저장하는 방식이에요. 같은 샘플·날짜의 mock 재실행을 새로운 유료 호출처럼 기록하지 않아요.

모델 이름이 없거나 종료 오류가 나면 공급자의 모델 목록·지원 종료 안내에서 현재 ID와 종료일을 확인하세요. 이름을 추측해 넣지 말고 가격·구조화 출력 지원도 대조하세요.[BX074]

지출 알림과 강제 한도를 함께 확인하세요. 공급자 계정의 지출 한도와 키트의 호출 전 비용 예약을 함께 써요. monthly_cap_usd는 키트 예약 예산이에요. 실패·재시도를 비용 기록에 포함하고 무한 재시도를 하지 마세요.[BX073]
