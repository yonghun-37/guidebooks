선택 · Docker로 로컬 WordPress 준비하기

Docker 없이도 mock으로 모든 장을 마칠 수 있어요. 실제 WordPress의 화면과 인증을 연습할 때만 선택해요. 키트의 ops/README.md를 열어 절차를 따라요.

키트가 고정한 이미지는 wordpress:7.1.3-php8.3-apache예요.[BX001][BX002] DB는 mariadb:11.4.13-noble예요. ops/.env에 본인이 정한 DB 비밀번호 두 개를 넣고 Compose로 실행해요. 브라우저에서 로컬 주소 http://127.0.0.1:8877의 설치를 완료해요. 이 상자는 준비 안내예요. A1의 mock 통과가 Docker 설치 성공을 뜻하지 않아요.

로컬 성공은 관리자 글 목록과 REST 응답을 함께 확인해요. 실제 호스팅은 본인 HTTPS 주소·권한·공개 상태를 다시 확인해요. 운영 서버의 DB와 미디어를 새 환경으로 복구하는 과제는 A11에서 이어져요.
