자동 예약의 조건

자동 발행은 내가 승인한 틀에 정해진 데이터만 채운 글뿐이에요. AI나 사람이 쓴 문장이 들어간 글은 전부 내가 읽고 승인해요. 틀의 고정 문장은 한 번 읽고 승인해요. 새로 쓴 자유 문장이 하나라도 들어가면 글 전체를 다시 읽고 승인해요.

제목·설명·본문·HTML까지 다시 대조해요. 틀이나 데이터 규칙을 바꾸면 옛 승인은 무효예요. 경험·사진·상업 관계·기존 글 갱신은 사람이 승인해요. 본문·HTML의 링크를 모두 모아 제휴·쇼핑 링크는 표시 관문과 사람 승인으로 보내요. 허용 도메인 밖의 URL도 사람이 확인해요.

단계 ② · 금지·거절·보류를 구별해요

법적 금지, 프로젝트 거절, 자료 보류는 해결 방법이 달라요. 제품 이름 하나나 KC 번호 유무 하나로 모두 같은 판정을 내리지 않아요.

세 판정과 조치
구분예다음 행동
법적 금지조제유류 판매촉진, 의료기기 사용자 체험담 광고[BX082][BX131]해당 광고를 거절하거나 금지 내용 자체를 제거해요. 사람 승인으로 예외 통과시키지 않아요.
프로젝트 거절가상 포근담요의 영아 잠자리용 낮잠 이불 협찬안전 수면 원칙과 충돌하므로 거절해요. 모든 이불의 판매가 법으로 금지됐다는 뜻은 아니에요.[BX086][BX136]
자료 보류제품 유형·용도·모델·업체·적용 안전자료·리콜·광고 심의 범위가 불명확자료를 받아 해당 모델·용도와 대조해요. 검색 결과 없음만으로 불법이라고 하지 않아요.[BX041][BX126]

product_records는 product_type·intended_use·model·maker·certification_scheme·recall_check·ad_review_scope로 나눠요. 리콜을 확인한 자료는 recall_check에, 결과는 recall_status에 적어요. none_found는 확인 결과 없음, recalled는 회수 대상, unchecked는 확인 전이에요. classification_basis에는 품목 분류 근거를 적고, 분류가 불명이면 자료 보류로 멈춰요. “리콜 확인 결과 없음”을 리콜 대상으로 읽지 않아요. “자료 비교”라고 표시해도 실제 사용자 체험담이 있으면 의료기기 광고 제한을 피해 갈 수 없어요. 어린이제품도 안전인증·안전확인·공급자적합성확인 대상이 달라요. 의료기기·화장품을 같은 KC 번호 관문으로 처리하지 마세요.[BX041][BX126]

단계 ③ · 코드가 놓치는 것을 사람이 봐요

단계 ③ · 코드가 놓치는 것을 사람이 봐요

얼굴을 가렸어도 실명·정확한 생일·어린이집·병원·생활 위치와 사진 메타데이터를 확인해요. EXIF는 사진에 붙은 위치·기기 같은 부가 정보예요. 파일 이름만 믿지 말고 공개할 파일의 실제 형식을 확인하세요. EXIF와 XMP 등 위치 메타데이터를 제거한 공개용 사본을 다시 검사해요. 검사하지 못한 형식은 보류해요. 정상 JPEG 원본·제거본이 모두 열리고 가짜 기기·GPS 정보가 제거됐는지도 확인하세요. 명찰·간판·동선은 사람이 화면을 봐야 해요.[BX049][BX085]

약 이름·용량과 “집에서 지켜봐도 된다”는 판정은 원고에서 제외하고, 건강 글은 항상 사람이 승인해요. 약 이름·용량을 찾는 검사는 보조 장치예요. 건강으로 분류된 글은 사람이 읽고 승인해야만 발행돼요. 단어가 안 잡혀도 자동 발행 허가가 되지 않아요. 제목·설명뿐 아니라 본문 전체에서 건강·응급 주제를 확인하고 공식 근거·월령·기준일을 대조하세요. 필요한 공통 응급 문구와 출처를 그대로 넣고, 차단 문장은 고친 뒤 다시 검사해요.

협찬 표시를 글 끝이나 더보기 안에만 두면 첫부분에서 관계를 알아볼 수 없어 막혀요. 현행 추천·보증 심사지침은 문자형 게시물의 제목 또는 첫 부분에 쉽게 알아볼 표시를 두도록 해요. 키트는 실제 받은 물품·현금·수수료 관계를 각각 첫 문단에서 확인해요. 등록부에 없는 본문 제휴·쇼핑 링크도 추출해 관계 표시와 사람 검토를 요구해요. “제휴 활동 안내”만으로 수수료를 설명하지 않아요. 숨김 스타일·작은 글자·접힌 영역이 없는지 모바일에서 직접 확인하세요.[BX037]

중복·효능 표현 검사를 통과해도 원문 사실과 사진 맥락은 사람이 확인해요. 제목만 바꾼 유사문서, 원문과 다른 숫자, 허가 범위 밖 효능, 사용하지 않은 경험을 다시 읽으세요. 키트의 유사도·발행 상한은 운영 설정이며 검색엔진의 안전선이 아니에요.[BX064][BX065]
