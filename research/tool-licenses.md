# Phase 5d 제작 크레딧의 라이선스 근거

2026년 10월 조사 기준. 확인일 2026-10-26. 정책·수치용 SOURCES 항목과 구별하는 제작 크레딧 기록이다. 원문 라이선스가 우선하며 프로그램·래퍼·폰트·출력 파일의 적용 범위를 섞지 않는다.

| Noto Sans KR | starter-kit/assets/fonts/README.md·OFL.txt | 저장소에 보존한 상류 저작권·SIL OFL 1.1 전문 확인. 사이트에는 폰트 바이너리를 추가 복제하지 않고 샘플과 전문 고지를 제공한다. |

추가 유료 도구·키·모델·서체를 사용하지 않았다. 크레딧에는 연구의 인용 출처 126개와 별도인 제작 라이선스 절로 표시한다. 인용 수량은 scripts/build_appendices.py로 실제 각주에서 재계산된다.
