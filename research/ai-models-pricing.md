## 1. 표를 읽는 법

- 각 모델 행의 **B1~B24**은 바로 아래 구독표의 가격·포함량을 함께 뜻한다. API 단가는 행에 따로 적는다. 같은 크레딧이라는 이름이어도 업체·앱·API 간 교환할 수 없다.
- `$`는 USD, `MTok`는 100만 토큰. LLM의 `$입력/$출력`은 각각 100만 토큰 기준이며 사고 토큰·검색 원문·이미지 입력 등이 추가될 수 있다. 글자·토큰·음성 초를 같은 단위로 취급하지 않는다.
- **한국 가능**은 공식 지원국/국내 판매 근거가 있을 때만 확정한다. “국제 웹 접근·계정 확인”은 한국 결제·최신 모델 해금까지 검증했다는 뜻이 아니다. 한국어 지원과 한국 거주자의 사용 가능성도 별개다.
- **미확인**은 0원·무제한·불가가 아니다. 로그인 가격표, 앱의 생성 직전 차감량, API 모델 카드, 약관을 확인할 위치까지 남긴다. 프리뷰/가중치의 “무료”는 GPU·전력·호스팅 비용까지 무료라는 뜻이 아니다.
- **상업 이용**은 서비스의 계약상 허락이다. 제 3자 저작권·초상·상표권, 생성물의 저작권 성립, 플랫폼 수익화 승인을 보장하지 않는다. 플랫폼 AI 공개 의무와 생성기의 워터마크는 별개다. [S303](SOURCES.md#s303) [S363](SOURCES.md#s363)
- SynthID는 주로 비가시 신호, C2PA/Content Credentials는 출처 메타데이터 체계다. 가시 로고가 없어도 AI 표시 의무는 남을 수 있고, 메타데이터가 사라져도 사람이 만든 자료로 바뀌지 않는다. 경로별로 적용 범위가 다른 경우 “미확인”을 유지한다. [S376](SOURCES.md#s376) [S389](SOURCES.md#s389)
- 최신 주력 모델과 요청된 주요 이전 버전을 망라했다. 모든 날짜 고정 스냅샷·튜닝 파생·임베딩·보안/생명과학 전용 모델까지의 전체 API 카탈로그는 범위 밖이다. 서비스 이름밖에 공개되지 않은 기능에는 가상의 모델명을 붙이지 않았다.

## 4. 비용 체계 해설

**구독형**은 월·연 요금을 내고 앱의 사용 한도를 받는 방식이다. ChatGPT/Claude의 메시지는 대화 길이·추론 강도·도구 사용에 따라 소모가 달라진다. “월정액”을 “모든 모델 무제한”이나 “API 사용권 포함”으로 읽지 않는다. 다만 Claude Max의 명시된 API 크레딧처럼 실제로 포함되는 예외는 구독표에 따로 적었다.

**크레딧형**은 사용량을 내부 포인트로 차감한다. 구독으로 받는 크레딧과 별도 구매 크레딧은 만료·이월·사용처가 다를 수 있다. Pika 웹 팩과 API/iOS, Runway 앱과 Dev API가 대표적이다. Luma Plus의 `월 $30÷10,000=$0.003/크레딧`은 **전량 썼을 때의 배분 단가**다. 이 가격으로 낱개 크레딧을 살 수 있다는 뜻은 아니다. [S433](SOURCES.md#s433) [S434](SOURCES.md#s434) [S428](SOURCES.md#s428)

**종량형 API**는 프로그램이 사용한 토큰·문자·영상 초·성공 출력물에 따라 청구한다. `입력토큰/1,000,000×입력단가 + 출력토큰/1,000,000×출력단가 + 도구비`가 LLM의 기본 계산이다. 이미지의 해상도·품질·참조 입력, 영상의 출력뿐 아니라 입력 영상·최소 길이, TTS의 문자·오디오 토큰을 추가한다. 일괄 Batch 할인은 즉시 응답과 다른 처리 방식이다. [S400](SOURCES.md#s400) [S408](SOURCES.md#s408) [S428](SOURCES.md#s428)

**번들형**은 다른 구독에 모델 사용권이 들어가는 방식이다. Google AI에는 Gemini 앱·Flow·저장공간 등이, Adobe에는 앱별 Firefly 크레딧이 들어간다. 같은 회사의 상품이어도 사용량 풀이 서로 다르다. Google AI Pro의 Flow 1,000크레딧, Flow Music 10,000크레딧, Gemini 앱의 컴퓨팅 한도, Cloud 크레딧을 한 잔액으로 합산하지 않는다. [S409](SOURCES.md#s409) [S419](SOURCES.md#s419)

같은 모델의 가격이 다른 이유는 **판매처가 묶어 제공하는 기능과 과금 단위가 다르기 때문**이다. 예를 들어 Veo3.1은 Flow에서 영상 한 개당 크레딧, Runway Dev에서는 영상 초당 달러로 계산한다. Seedance2.5는 BytePlus에서 토큰, Runway에서 출력 초+입력 영상초, Pika에서 설정별 크레딧으로 보인다. 저장·편집·업스케일·대기열·상업 라이선스·고객지원 비용과 판매처 마진이 다르다. 다른 모델/버전, 다른 해상도, 다른 지역·할인·세금을 같은 조건인 것처럼 비교하면 안 된다. ## 5. 실전 비용 시나리오: 3가지 결과물 × 3가지 조합

**비교를 위한 가정이며 품질 순위·평균 성공률 실측이 아니다.** 저비용·고품질은 아래에서 선택한 제작 설정의 이름이다. 뉴스카드는 표지 1+본문 5, 해설 릴스는 30초, 영상 쇼츠는최종 8초×4=32초·9:16을 만든다. 직접 소재·무료 편집·직접 녹음을 쓰면 별도 생성비는 0원이다. 쇼츠 음악은 권리 확인한 YouTube 보관함을 쓰고, 인스타 릴스는 음악을 생략한다. 배경 이미지는 원본을 세로 프레임에 배치·크롭하므로 모든 원본이 9:16일 필요는 없다. 카드 조판/한글/자막은 편집기에서 사람이 검수한다.

공통 계산 입력:

- LLM 저비용: GPT-6 Luna 입력 2,000+출력 1,000토큰: `2,000/1M×$0.10 + 1,000/1M×$0.50 = $0.0007`.
- LLM 고품질 설정: GPT-6 Astra 같은 토큰량: `2,000/1M×$10 + 1,000/1M×$50 = $0.07`. 사고 토큰·검색 호출·원문 토큰은 가정량 밖이면 추가한다.

- 고품질 이미지 5장: GPT Image2 high 1024×1536: `5×$0.165 = $0.825` **출력비만**. 매장 텍스트 입력 100토큰·참조없음 가정: `5×100/1M×$5=$0.0025`; 이미지 합계 `$0.8275`.

### 실패·재생성과 월정액까지 포함한 예산

위 표는 성공본만의 하한이다. **생성 2번 중 1번만 채택하는 것으로 예산**을 잡으면 유료 API 사용분은 대체로 2배: 카드저비용약 ₩190.89/고품질약 ₩2,423.25, 해설저비용약 ₩203.31, AI영상저비용약 ₩5,553.09/고품질약 ₩34,749다. 이 2배는 관측 실패율이 아니라 사용자가 바꿀 수 있는 예산 가정이다. TTS 다운로드를다시하지않는고품질해설은 `2×₩1,211.625+₩82.5=약 ₩2,505.75`배분, 신규현금 `2×₩1,211.625+₩9,900=약 ₩12,323.25`다.

Flow 무료의 8초영상 8개=96크레딧은하루 50을초과한다. 같은조건의 4개씩이틀이면 48+48로충당가능하나, 일 잔액 이월은없고대기시간/생성접근이보장되지않는다. Google AI Plus를새로산다면영상 4개를만들든월 ₩7,500을낸다. 월 200크레딧중 48을소비했다는비례배분은 `₩7,500×48/200=₩1,800`이지만 **편당현금 결제 ₩1,800이라고쓰면안된다**. 무료일지급까지겹치므로이비례배분은구독의가격대비사용량설명에불과하다. [S425](SOURCES.md#s425) [S495](SOURCES.md#s495)

**재사용 가능한 계산식:** `월현금지출 = 신규구독료 + 실제 API/크레딧충전결제 + 별도소재비 + 세금/수수료`, `편당사용분 = 생성시도별과금량합계 + 구독료의배분액`. 이미보유한구독/무료량은추가현금 0일수있지만유료 구독의경제적원가까지 0은아니다. API에서오류가나도항상무료라고가정하지말고각업체의실패청구규칙을확인한다.
