## 전환 절차와 확인 수준

프로필 → 더 보기 → 설정 및 활동 → ‘프로페셔널’ 아래 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 카테고리 선택 → 프로페셔널 계정으로 전환 → 크리에이터 → 다음. **이 중간 경로와 카테고리→유형 순서는 공식 한국어 검색 발췌만 확보**했다. 페이지 전체를 열었다는 이유로 이 경로를 본문 확인으로 올리지 않는다. 공개 전환의 효과는 본문 근거지만 동의 팝업 위치·버튼은 미확인이다. [S180](SOURCES.md#s180)

## 수치·한국 가용성

10개는 2026-10-26 읽은 한국어 도움말의 문서상 상한이다. 한국 실계정에서 10개를 실제 추가한 결과가 아니다. 5→10 변경일, 앱 OS/버전별 적용 완료는 미확인이다. 25개는 영문 계정 센터 설명에 한정한다. [S180](SOURCES.md#s180) [계정 센터](https://www.facebook.com/help/173102953236749)

## 불확실·상충

- 새 계정 만들기 이후 가입 6~9단계, 계정 센터에 추가하지 않는 비밀번호 분기는 한국어 공식 검색 발췌 수준이다. 문서에 없는 필수 전화번호/이메일·인증 순서를 만들지 않는다.
- 로그아웃 시작 화면 가입 버튼과 정확한 순서는 미확인. [새 프로필 공식 문서](https://help.instagram.com/155940534568753/?locale=ko_KR&cms_platform=android-app)는 앱/웹 생성 가능의 근거만 확보했다.
- `+이메일 별칭`의 가입 수락·독립 주소 처리·우회 가능성은 미확인이다. 이메일 입력 지원으로 별칭 수락을 추론하지 않는다.
- 계정에 따라 계정 센터/Meta 계정 설정의 전환 안내가 있다. OS별 경로 동일성은 입증되지 않았다.
- Codex 직접 HTTP 요청은 S180의 본문을 반환하지 않았다. 메뉴·10개 상한은 Hermes 근거로만 올린다.
