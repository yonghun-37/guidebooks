먼저 답부터

API 키와 채널 토큰을 나눠 보관하고, 공급자 상한과 키트 상한을 함께 설정하세요.

API 키는 생성 서비스의 사용료를 내 계정에 연결해요. access token은 허용한 채널 작업을 수행하고, refresh token은 새 access token을 받는 비밀 값이에요.

도윤매주 자동화가 끊기면 갱신 코드를 더 쓰나요?

서진Testing의 refresh token이 끝났다면 새 동의가 필요해요. 정상 토큰 갱신과 구분하세요.

한눈에 보기

만드는 순서

7일 만료부터 해결해요

External Testing의 업로드용 refresh token은 7일 뒤 만료될 수 있어요.[A018]

Google Cloud 프로젝트에서 YouTube Data API v3와 YouTube Analytics API를 켜세요. Google Auth Platform에서 보통 이런 이름의 Branding → Audience → Data Access → Clients를 찾아요. 개인 실습은 External, Testing에는 본인 테스트 사용자를 추가해요. Clients에서 Desktop app을 만들고 받은 파일을 private/client_secret.json에 저장해요.[A017][A024]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

장기 운영 전 Production 전환·개인 사용 예외·요청 scope의 검증 조건을 확인한 뒤 다시 동의하세요. scope는 프로그램에 허용한 기능 목록이에요. Production으로 바꿨다고 API 감사까지 끝나는 것은 아니에요. access token 자동 갱신으로 만료된 refresh token을 되살릴 수는 없어요.[A018][A015]

지금 할 일 A5에서 브라우저 동의를 하고, A7의 만료 경보를 시험하세요.

알림은 상한과 달라요

Cloud budget 이메일만으로 과금이 멈추지 않아요.[A031]

OpenAI는 보통 Organization/Project Limits의 Spend → Enforce a hard limit에서 강제 상한을 켜요. Gemini는 AI Studio Spend의 project spend cap, Anthropic은 조직·별도 workspace의 Spend limits를 확인하세요. 각 범위와 지연 조건을 공식 안내에서 확인해요.[A081][A030][A115]

버전에 따라 메뉴가 다를 수 있어요. 공급자 공식 상한 안내와 계정 Billing 화면을 대조하세요. Google TTS에는 Cloud budget 알림 외에 앱의 문자 수·호출 수 제한을 함께 둬요.

"budget": {
  "daily_usd": 1.0,
  "monthly_usd": 10.0,
  "max_attempts": 2,
  "max_output_tokens": 2000,
  "max_source_chars": 12000,
  "provider_hard_cap_confirmed": false
}

위는 전체 JSON 안의 budget 부분이에요. 키트 기본 상한 예시이며 가격 약속이 아니에요. false는 확인 전 표시예요. 실제 공급자 제어를 설정·확인한 뒤 true로 바꾸세요. JSON은 이름과 값을 큰따옴표·쉼표로 저장하는 텍스트예요.

지금 할 일 요청 전 최대비 예약·실제 usage·공급자 청구를 대조하세요.

키를 파일에서만 읽어요

로컬은 .env와 private, Actions는 Secrets와 암호화 상태에 보관해요.

파일을 공개 저장소에 올린 뒤 지우는 것으로 토큰을 회수할 수 없어요. 노출됐다면 먼저 예약 중지 → 키 폐기·재발급 → 사용·청구·게시 확인 → 새 값 교체 순서로 처리하세요.[A075][A107]

지금 할 일 토큰이 들어 있는 화면·로그를 채팅이나 공개 이슈에 붙이지 마세요.

내 한 달 생성비

교육용 가정 모형

가상 입력 3,000·출력 1,000토큰, 음성 600자/편. 무료량 소진 후, 세금·충전·전기·실행기 제외예요.

이미지 단가: 1K 출력 $0.0336 + 입력 100토큰 $0.00015 = $0.03375/장. 영상은 $0.05/초예요. 추가 추론·참조 입력·검색 비용은 따로 더하세요.

기본 저비용: 여유 포함 월 $0.11520 · 월 상한 안이에요.

단가 기준: 2026년 10월 조사. LLM·이미지·음성·영상의 기본 종량 단가를 썼어요. Haiku는 입력 10만 토큰 이하 조건이에요. 고급 음성 선택은 가격 비교이며 현 키트의 단가표·모델도 별도로 맞춰야 해요.[A025][A028][A032][A038][A037]

해 보기 · 명령 실행

지금 하는 일: 비공개 설정 파일과 월 생성 예산을 확인해요.

왜 하는지: 앞 단계의 실제 파일과 상태를 읽어 다음 작업을 이어 가기 위해서예요.

아래 명령은 auto-kit 폴더에서 실행하세요. A0에서 가상환경을 먼저 준비해요. RUN_ID가 있으면 앞 명령이 출력한 실제 12자리 ID로 바꿔요. Windows와 macOS는 같은 Python 명령을 써요.

Copy-Item config.example.json config.json
Copy-Item .env.example .env
python doctor.py --config config.json
cp config.example.json config.json
cp .env.example .env
python doctor.py --config config.json

이렇게 보이면 성공

config.json·.env가 생기고 doctor는 기본 검사에서 mock 준비 완료를 출력해요. 키가 없어도 정상이에요. 비밀 값 없이 설정 복사까지만 끝낸 상태예요.

비용과 확인할 점

비용 · 편당과 한 달

2026년 10월 조사 · 가상 월 30편. mock 생성 API $0/편·$0/월. 권장 저비용 조합은 무료 음성량 소진 후 $0.0032/편 × 30편 = $0.096/월이에요. 입력 3,000·출력 1,000토큰, 음성 600자, 보유 소재 가정이에요. 무료 음성량이 남으면 월 $0.024예요. 전기·실행기·저장소·세금·환율·최소충전·재생성은 따로 더하세요.[A025][A038] 내 편수로 계산 →

확인할 점

공급자 cap에는 적용 범위·전파 지연이 있어요. 동시에 돌리는 다른 앱과 사용량을 합산하세요. 월 상한은 UTC 기준, YouTube insert의 일별 카운터는 Pacific 기준이에요. 공급자 가격·무료량·최소충전·자동충전은 본인 계정에서 확인하세요.[A030][A013]
