먼저 답부터

처음엔 GPT-6 Luna + 보유 소재 + Google WaveNet + ffmpeg로 시작하세요. 목표는 주제 선정부터 다음 주제 반영까지 전자동이에요. 음성 무료량 소진 후 가상 월 30편 생성비는 $0.096이에요.[A025][A038]

도윤의 가상 채널 「자취생 10분 생존법」을 이어 만들어요. 이번 영상은 「월급날 10분, 돈을 네 칸으로 나누기」예요. 투자 비율을 추천하지 않고 내 지출을 정리하는 생활 메모예요.

도윤매일 제가 눌러야 전자동인가요?

서진처음에는 관문 기준을 맞추려고 승인해요. 기준이 안정되면 승인 없이 통과한 영상만 올려요.

먼저 키 없이 한 바퀴 돌려요

mock은 돈을 내거나 계정에 연결하지 않는 연습 공급자예요.

터미널은 명령을 입력하는 창이에요. 저장소를 내려받아 압축을 풀고, 그 안의 auto-kit 폴더에서 터미널을 여세요. 파일 탐색기의 경로가 auto-kit으로 끝나는지 확인하세요. Windows는 주소창에 powershell을 입력해 열 수 있어요. macOS는 터미널에서 cd 를 입력하고 그 폴더를 끌어 놓은 뒤 Enter를 누르세요.

키트 README·다운로드 위치에서 Python 3.11 이상 설치를 먼저 확인하세요. 화면은 기기·버전마다 다를 수 있어요. 시간은 내 속도로 진행해요.

지금 할 일 아래 설치 명령 뒤 doctor의 준비 완료 문구를 확인하세요.

처음엔 이 조합

가상 월 30편 생성비는 $0.096이에요. 무료 음성량이 남으면 $0.024예요.[A025][A038]

입력 3,000·출력 1,000토큰, 음성 600자, 보유 소재, 음성 무료량 소진 후라는 견적이에요. 편당 $0.0008 + $0.0024 = $0.0032, 월 30편 × $0.0032 = $0.096이에요. 세금·환율·최소충전·전기·실행기·저장소는 더해야 해요. 신호음 연습의 실제 생성비는 $0이에요.

이미지 6장과 고급 음성을 쓰는 비교안은 편당 $0.2365, 월 $7.095예요. 생성 영상 10초를 더하면 $0.50/편, 월 $15가 추가돼요. 모두 가상 사용량 계산이에요.[A025][A028][A038][A037]

지금 할 일 내 편수와 공급자 단가로 다시 계산하세요.

승인제에서 전자동으로 옮겨요

첫 1~2주는 승인제로 시작하고, 관문 통과율과 미해결 예외를 보고 모드를 바꾸세요.

아래는 이 책이 제안하는 가상 운영 기준이에요. 플랫폼 규정이나 안전 보장 수치가 아니에요. 통과율 = 자동 관문을 처음에 모두 통과한 고유 실행 수 ÷ 생성·렌더를 마친 고유 실행 수 × 100이에요. 재시도로 분모를 늘리지 않아요.

단계전환 조건 · 직접 집계사람이 할 일
승인제 approval처음 1~2주. 최근 10편 중 9편 이상 통과(90% 이상), 미해결 예외 0건이면 다음 단계파일·권리·발음·AI 표시를 매번 보고 approve
사후 확인 post_review최근 20편 중 19편 이상 통과(95% 이상), 미해결 예외·잘못 공개한 영상 0건이면 전자동미래 예약 공개 전 거부·삭제를 실제 시험
전자동 auto기준 유지. 예외는 게시하지 않고 분리. 잘못 공개 1건이면 승인제로 복귀일일 보고 확인·주간 표본 점검·예외 처리

가상 예: 9÷10×100=90%, 19÷20×100=95%예요. 달력이 지났다는 이유만으로 전환하지 마세요. 설정의 mode를 직접 바꿔야 해요. auto도 공개 범위가 private면 비공개로만 올라가요.

지금 할 일 private 시험·예약 취소·복구를 마친 뒤 전환하세요.
