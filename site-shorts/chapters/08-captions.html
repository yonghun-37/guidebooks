제작 레시피 · 자동 자막을 완성 자막으로

Clipchamp에서 한국어를 선택하고 원음을 들으며 고칩니다

숫자·이름·부정어를 먼저 고친 뒤 자막과 MP4를 각각 저장합니다. 자동 자막은 완성품의 초안입니다. 직접 촬영·해설·생성 영상 모두 말과 장면 편집을 마친 뒤 같은 순서를 따릅니다.[Y385]

  1. 한국어 음성을 전사합니다

    입력 · 확정 음성이 있는 Clipchamp 타임라인

    메뉴·행동 · 속성 패널의 Captions/자막 → 자동 자막 켜기 → 언어 한국어 → Transcribe media/전사에 해당하는 버튼을 누릅니다.

    출력 → 다음 · 시간이 붙은 한국어 자동 자막 초안

  2. 원음과 대본을 대조합니다

    입력 · 자막 초안·script.txt·음성

    메뉴·행동 · 자막 패널의 단어를 눌러 수정하고 해당 구간을 다시 듣습니다. 숫자·단위·이름·부정어부터 봅니다. 소리가 불분명하면 원녹음이나 TTS 발음을 고친 뒤 자막을 다시 맞춥니다.

    출력 → 다음 · 뜻과 시간이 맞는 교정 자막

  3. 폰 크기에서 읽습니다

    입력 · 교정 자막·장면

    메뉴·행동 · 글꼴·색·배경·위치를 조정하고 긴 문장은 뜻 단위로 나눕니다. 아래 검사 도구로 가림·시간을 비교하고 실제 영상에서도 재생합니다.

    출력 → 다음 · 말끝까지 읽히고 동작을 가리지 않는 자막

  4. 자막과 영상을 따로 보관합니다

    입력 · 확정 자막·타임라인

    메뉴·행동 · Captions의 자막 다운로드에서 SRT를 저장합니다. 화면 자막 표시를 확인하고 내보내기 → 1080p로 MP4를 저장합니다.

    출력 → 다음 · captions.srt + short.mp4 → 끝까지 재생 → 10장 / 실습 7

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(열기)을 확인하세요.

확인할 점

SRT는 글자·시간 파일이고 MP4는 재생 영상입니다. SRT를 수정해도 이미 출력한 화면 자막은 바뀌지 않습니다. 프로젝트 자막을 고치고 MP4도 다시 출력하세요. 앱이 바뀌면 다운로드와 화면 자막 표시 위치는 공식 도움말을 확인합니다.[Y385]

지금 할 일 · 교정 SRT와 MP4를 같은 이름 묶음으로 저장하고 출력 실습으로 이어 갑니다.

① 자동 생성과 교정

한국어 자동 자막은 초안으로 만들고, 말과 대조해 고칩니다.

어떻게 되나
음성 가져오기 → 한국어 선택 → 자막 생성 → 고유명사·숫자·끊기는 위치 교정 순서입니다.
기준과 예
Clipchamp 무료에는 자동 자막이 있고 한국어 지원 근거가 있습니다. Create는 60초가 넘는 클립의 자막 생성을 지원하지 않는다고 안내합니다.[Y021][Y077][Y064]
조건
Create 자막 생성 클립 한도와 쇼츠 전체 길이는 다릅니다.
언제 쓰나
녹음 편집을 마친 뒤 자동 자막을 만듭니다.
지금 할 일
예를 들어 ‘비상금’을 잘못 알아들었다면, 원음을 듣고 그 단어와 시간을 고칩니다.

② 크기·위치·속도

실제 폰 크기에서 끝까지 읽히고, 말이 끝날 때까지 남게 만듭니다.

어떻게 되나
짧은 뜻 단위로 나누기 → 배경과 대비 주기 → 가림 피하기 → 말과 함께 재생합니다.
기준과 예
가상 예: ‘월세와 생활비를 적고 비상금과 목표도 나눠요’ 대신 ‘월세·생활비’와 ‘비상금·목표’로 나눕니다.
조건
공식 고정 자막 px·컷 간격은 없습니다. 버튼·설명에 겹치는 곳은 현재 앱의 시각 가이드로 확인합니다.[Y002][Y080]
언제 쓰나
작은 화면에서 읽기 어렵거나 자막이 먼저 사라질 때 씁니다.
지금 할 일
아래에서 크기·위치·표시 시간을 바꾸고, 멈추지 않고 소리 내 읽어 봅니다.

③ 화면 자막과 선택 자막

화면에 구운 자막은 영상 그림의 일부이고, 선택 자막은 따로 켜고 끄는 글자입니다.

어떻게 되나
편집기의 글자 레이어 → MP4에 함께 출력하면 화면 자막입니다. 글자·시간을 담은 SRT는 선택 자막을 준비하는 파일입니다.
기준과 예
가상 도윤은 화면에 핵심 문장을 넣고, 전체 말은 별도 자막 파일로 보관합니다. 같은 말이 겹쳐 보이지 않는지 재생합니다.
조건
Clipchamp는 자막 수정과 SRT 다운로드를 안내합니다.[Y066]
언제 쓰나
글자 모양을 영상에 고정하려면 화면 자막, 따로 교정·활용하려면 자막 파일을 남깁니다.
지금 할 일
최종 MP4와 자막 파일을 각각 열고, 오타와 시간표가 같은지 확인합니다.

한국어 자동 자막을 무료로 만들 수 있나요?

네, Clipchamp 무료 자동 자막부터 확인할 수 있습니다.[Y021][Y077]

예를 들어 본인 녹음을 한국어로 인식시킨 뒤 오타를 듣고 고칩니다. 생성과 교정 순서로 진행하세요.

휴대폰에서 잘 읽히는 자막 크기와 줄 수는 얼마인가요?

고정 숫자 대신 실제 폰에서 읽히도록 짧게 나누세요.

가상 도구의 64px는 출발점이며 공식 기준이 아닙니다. 크기 검사에서 긴 문장을 줄이고 전체를 한 번에 읽어 보세요.

자막을 어디에 놓아야 버튼에 가리지 않나요?

중앙 쪽 여유 공간에 두고 현재 앱의 가이드로 확인하세요.[Y080]

화면 아래 설명과 오른쪽 버튼을 떠올려 보세요. 가림 예에서 자막을 아래로 옮겨 보고 실제 앱에서도 대조하세요.

자막이 말보다 먼저 사라지면 어떻게 맞추나요?

자막 끝을 말의 마지막 단어까지 늘리거나 문장을 나누세요.

가상 말 3초·자막 1초라면 3 − 1 = 2초가 빕니다. 공통 시간축에서 끝을 맞추세요.

화면에 구운 자막과 유튜브 자막은 무엇이 다른가요?

화면 자막은 영상의 일부, 선택 자막은 따로 켜고 끄는 글자입니다.

예를 들어 MP4에는 핵심 문장, SRT에는 전체 말을 남깁니다. 두 형태를 읽고 자막이 겹치지 않는지 확인하세요.
