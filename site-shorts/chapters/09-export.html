올리면 왜 흐려지나요?

출력 MP4가 선명한지 먼저 봅니다. 업로드 직후에는 HD 처리가 끝나지 않았을 수 있으니, 처리 상태와 재생 화질을 확인하세요.[Y032]

도윤숫자를 전부 크게 하면 더 선명해지나요?

서진먼저 원본을 봐요. 찍지 않은 세부나 동작을 출력 숫자만으로 되살릴 수는 없어요.

도윤·서진은 가상 인물입니다. 이 장의 책상 그림과 도구는 직접 만든 연습 예제입니다.

화면 크기모양과 점의 수를 구분합니다.움직임촬영과 출력의 fps를 구분합니다.파일과 압축숫자와 실제 프레임을 함께 봅니다.

축별 설명

같은 순서로 준비하고 확인합니다

① 비율과 해상도

비율은 화면 모양, 해상도는 그 화면을 채우는 점의 수입니다.

어떻게 되나
세로 작업 화면 설정 → 원본을 잘리지 않게 배치 → 출력 크기 확인 순서입니다.
기준과 예
가상 제작 선택: 1080×1920은 1080 ÷ 120 : 1920 ÷ 120 = 9:16입니다. 비교용 540×960도 같은 비율이며 가로·세로 점 수는 각각 절반입니다.
조건
일반 채널은 2024년 10월 15일부터 올린 최대 3분의 정사각형·세로 영상을 쇼츠로 분류합니다. 9:16만 허용하는 것은 아닙니다.[Y001]
언제 쓰나
편집을 시작할 때 비율을 정하고, 내보내기 뒤 실제 파일의 크기를 확인합니다.
지금 할 일
검은 여백까지 포함한 파일 전체의 가로·세로를 확인합니다. 가로 화면 안에 세로 장면만 넣은 파일과 구분하세요.

② fps와 움직임

fps는 1초에 담는 화면 수입니다. 원본의 움직임부터 확인합니다.

어떻게 되나
촬영 파일의 fps 확인 → 편집 시간축 설정 확인 → 출력 fps 확인 순서입니다.
기준과 예
가상 계산: 1초 × 30fps = 30프레임, 1초 × 60fps = 60프레임입니다. 30fps 원본을 60fps로 저장해도 찍지 않은 중간 동작이 새로 생기지는 않습니다.
조건
이 장은 같은 합성 동작을 30/60fps로 나누어 비교합니다. 실제 원본을 더 부드럽게 만드는 기능은 포함하지 않습니다.
언제 쓰나
빠른 손동작의 끊김을 볼 때는 움직이는 동안 비교합니다.
지금 할 일
첫 영상에서는 원본 fps와 같은 값으로 연습하고, 움직임과 파일 정보를 함께 확인합니다.

③ 파일과 압축

MP4는 담는 파일 형식, 코덱은 영상을 압축하는 방식입니다. 비트레이트는 초당 데이터 양입니다.

어떻게 되나
이 책의 출력 연습은 MP4에 H.264 영상을 담습니다. 내보내기 화면의 파일 형식·코덱·크기·fps를 차례로 확인합니다.
기준과 예
가상 계산: 영상 8Mbps × 12초 ÷ 8 = 약 12MB입니다. 음성과 파일 정보는 뺀 계산입니다. 같은 길이에서 비트레이트를 줄이면 파일은 작아지지만 세부가 뭉개질 수 있습니다.
조건
8Mbps는 이 장의 계산 예입니다. 정해진 쇼츠 합격값으로 쓰지 않습니다. 실제 편집기의 출력 옵션과 완성 파일을 대조합니다.
언제 쓰나
글자 가장자리나 손 주변이 뭉개지면 원본과 출력 파일을 같은 위치에서 멈춰 비교합니다.
지금 할 일
출력 MP4를 먼저 재생하고, 업로드 뒤에는 HD 처리가 끝났는지 확인합니다.[Y032]
확인할 점

HD 처리는 시간이 걸릴 수 있습니다. Studio에서 처리 상태를 확인하고, 플레이어의 화질을 올려 다시 보세요. 출력 권장값은 편집기의 현재 안내와 공식 인코딩 도움말을 대조합니다.[Y032]

해상도·fps·비트레이트 비교

교육용 가정 모형 · 가상 예제

가상 12초 영상이며, 기준 동작은 60fps로 그립니다. 같은 동작의 크기·fps·데이터 양 중 하나만 바꾸세요. 비교 그림은 글자 가장자리와 블록 뭉침을 강조한 도식입니다. 실제 코덱이나 YouTube 압축 결과를 재현하지 않습니다. 예상 영상 크기(MB) = Mbps × 12 ÷ 8, 음성·파일 정보 제외입니다.

막히는 곳부터 다시 봅니다

9:16과 1080×1920은 무엇이고 꼭 지켜야 하나요?

9:16은 비율, 1080×1920은 해상도입니다. 쇼츠가 이 값만 허용하는 것은 아닙니다.[Y001]

가상 제작에서는 두 값을 함께 씁니다. 비율 계산을 보고 파일 전체가 세로인지 확인하세요.

30fps와 60fps 중 무엇으로 내보내나요?

먼저 원본 fps에 맞춰 연습하세요.

가상 30fps 원본에는 초당 30장의 동작만 있습니다. 움직임 비교에서 fps만 바꾸고 내 파일 정보도 확인하세요.

MP4·코덱·비트레이트는 어떤 값으로 고르나요?

이 책의 연습은 MP4·H.264를 쓰고, 비트레이트는 출력 프레임을 보고 비교합니다.

가상 8Mbps·12초의 영상 데이터는 약 12MB입니다. 파일과 압축을 보고 편집기 설정을 메모하세요.

컴퓨터에서는 선명한데 업로드하면 왜 흐려지나요?

HD 처리 상태와 재생 화질을 먼저 확인하세요.[Y032]

출력 파일도 같은 장면에서 멈춰 비교합니다. 화질 확인 순서대로 점검하고, 바로 재업로드부터 하지 마세요.

3분 이내인데 일반 동영상으로 올라가는 이유는 무엇인가요?

길이뿐 아니라 파일 비율과 업로드 시점도 확인해야 합니다.[Y001]

가로 파일 안의 세로 장면은 파일 자체가 세로가 아닙니다. 전체 파일 크기를 확인하고 Studio의 Shorts 구분을 대조하세요.
