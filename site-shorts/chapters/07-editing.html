제작 레시피 · 편집과 파일 전달

Clipchamp에서 세 제작 경로를 같은 타임라인으로 모읍니다

확정 음성을 먼저 놓고 그 말에 장면·자막·음악을 맞춥니다. 타임라인은 재료를 재생 순서대로 놓는 시간표입니다. Clipchamp 개인 무료판은 자동 자막·1080p 무워터마크 출력을 안내합니다.[Y334][Y385]

선택가져올 파일 → 완성 결과전체 시간·추가 지출
직접 촬영+AI 편집script.txt + 촬영 MP4 + 본인 녹음 → short.mp4약 60분 = 대본 10+촬영·녹음 15+편집 15+자막 10+음악·출력 10. 보유 기기·무료 기능이면 0원
얼굴 없는 해설script.txt + voice.wav/mp3 + 장면 PNG → faceless-short.mp4약 65분 = 대본 10+음성 10+장면 20+편집·자막 15+출력 10. 녹음·무료 장면이면 0원, 타입캐스트 신규 Basic은 ₩9,900/월[Y336]
AI 영상 생성storyboard.txt + reference.png + 짧은 샷 MP4 4개 + 본인 해설 → ai-short.mp4약 80분 = 샷 계획 10+기준 그림·소리 15+생성 25+편집·자막 20+출력 10. 생성 대기·재시도 및 크레딧 별도

시간은 책의 작업 계획용입니다. 가입·설치·생성 대기·재시도는 더 잡고 첫 편에서 실제 시간을 적습니다. 각 레시피의 단계는 아래와 AI 도구 지도에서 이어집니다.

  1. 프로젝트와 재료를 엽니다

    입력 · 음성·촬영/생성 MP4·장면 PNG·선택 음악

    메뉴·행동 · Clipchamp → 새 동영상 만들기 → 미디어 가져오기. 화면 비율에서 9:16을 고르고 파일을 넣습니다.

    출력 → 다음 · 세로 프로젝트 + 미디어 목록

  2. 말에 장면을 맞춥니다

    입력 · voice.wav/mp3와 장면 파일

    메뉴·행동 · 음성을 타임라인에 먼저 끌어놓습니다. 문장 시작·끝에서 멈추고 장면을 위 트랙에 놓습니다. 재생 헤드를 옮겨 분할 도구로 대기만 자르고 남은 클립을 붙입니다.

    출력 → 다음 · 끊기지 않는 말 + 설명과 맞는 장면

  3. 생성 클립의 연결을 정리합니다

    입력 · shot-01~04.mp4

    메뉴·행동 · 앞 샷 끝 자세와 다음 샷 시작을 비교해 자릅니다. 음성 파일을 쓰면 불필요한 생성 대사는 음소거합니다. 빈 구간은 직접 만든 설명 카드로 채웁니다.

    출력 → 다음 · 내용이 이어지는 30~45초 생성 영상 / 해설은 실제 음성 길이에 맞춤

  4. 그림 카드에 움직임을 줍니다

    입력 · 정지 PNG/JPG

    메뉴·행동 · 이미지 클립 길이를 말 길이에 맞추고 느린 확대·위치 이동 기능을 시험합니다. 손끝·화분·자막 자리가 잘리지 않게 재생합니다.

    출력 → 다음 · 정지 그림을 움직여 보여 주는 편집 구간

  5. 자막·음악·출력을 마칩니다

    입력 · 편집 타임라인·music.mp3·표시문

    메뉴·행동 · 8장에서 자동 자막을 만들고 고칩니다. 음악은 별도 트랙에서 낮춥니다. 내보내기 → 1080p → MP4 저장 → 전체 재생합니다.

    출력 → 다음 · short.mp4 + 교정 SRT + 프로젝트 + 권리·표시문 메모 → 9장 출력 확인

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(열기)을 확인하세요.

복사 · 장면 배치표를 먼저 만들기

입력: [장면 파일명·내용·길이], [확정 음성의 문장별 시작·끝]
음성 순서를 유지하며 장면 배치표를 제안해 주세요.
출력: 구간 | 음성 문장 | 장면 파일 | 자를 대기 | 남길 핵심 동작.
없는 장면은 촬영할 목록으로 남기고 실제 편집 완료처럼 답하지 마세요.
말끝·부정어·중요한 손동작은 삭제하지 마세요.
CapCut·Vrew를 이미 쓰고 있다면?

CapCut · 새 프로젝트 → 가져오기 → 타임라인에 음성·장면 배치 → 분할·트림 → 텍스트/자동 캡션 → 한국어 → 생성·교정 → 내보내기 순으로 진행합니다. PC와 모바일의 템플릿 메뉴는 다릅니다. 짧은 시험 파일로 유료 요소·워터마크·자막 제한부터 확인합니다.[Y327][Y380]

Vrew · 새로 만들기 → 텍스트로 비디오 만들기에 해당하는 메뉴에서 대본을 넣고 AI 목소리·장면을 고릅니다. 또는 영상·음성을 가져와 분석합니다. 글자를 지우듯 잘라도 “하지 마세요”의 “마세요”가 빠지지 않았는지 원음과 다시 듣습니다. 장면·소재 사용권·자막을 고친 뒤 내보내기를 합니다.[Y366][Y391]

케이블을 끼우는 손동작은 남고, 말·그림·자막이 같은 행동을 설명합니다.

자동 컷이 손동작이나 “아니요”를 삭제합니다. 삭제 전후를 이어 듣고 중요한 구간을 복구합니다.

이번 편집 단계 · 직접 촬영 약 15분, 얼굴 없는 해설은 자막 포함 약 15분, 생성 영상은 자막 포함 약 20분을 잡습니다. Clipchamp 무료 기능·본인 소재면 추가 0원입니다. 생성 크레딧과 TTS 월 구독료는 앞 단계 비용입니다.[Y334]

확인할 점

CapCut의 무료 자동 자막 횟수·한국 Pro 가격은 계정의 구독/출력 화면에서 확인합니다. Commercial Sounds의 허용 플랫폼에 YouTube가 자동 포함되지는 않습니다. 음악은 보관함이나 따로 허락받은 파일을 씁니다. 720p 생성 클립을 1080p로 내보내도 원본 세부가 새로 생기지는 않습니다.[Y328][Y380]

지금 할 일 · 편집 실습에서 먼저 짧게 시험 출력한 뒤 전체 영상을 완성합니다.

① 편집기 고르기

PC에서는 Clipchamp, 휴대폰에서는 Create부터 살펴봅니다.

어떻게 되나
내 촬영 파일 가져오기 → 자르기 → 자막 → 시험 출력 순서로 확인합니다.
기준과 예
Clipchamp 무료는 1080p 무워터마크 출력을 안내합니다. Create는 한국 제공 목록에 있는 무료 편집 앱입니다.[Y021][Y022][Y052]
조건
Resolve 무료판도 있습니다. Studio 전용 기능을 무료 기능으로 섞지 마세요. CapCut의 내장 음악 권리는 YouTube 사용까지 자동으로 이어지지 않습니다.[Y020][Y023]
언제 쓰나
처음 고를 때는 내 기기에서 시험 출력이 되는지 봅니다.
지금 할 일
본인 촬영 클립으로 시험 파일을 내보내고, 결제 안내와 워터마크를 확인합니다.

② 컷과 전환

설명할 정보나 동작이 바뀌는 곳에서 장면을 바꿉니다.

어떻게 되나
빈 동작 줄이기 → 의미가 바뀌는 곳 자르기 → 앞뒤를 이어 보기 순서입니다. 전환은 장면 사이에 넣는 연결 효과입니다.
기준과 예
가상 예제는 정리 전·묶는 손·정리 후입니다. 전환 없이 바로 잇고, 손동작을 알아보기 어려운 구간만 늘립니다.
조건
공식 추천 안내에는 고정 컷 간격이 없습니다. 효과 수보다 실제로 내용을 이해할 수 있는지 확인합니다.[Y002]
언제 쓰나
주제가 바뀔 때는 컷, 시간이나 장소가 크게 바뀌었음을 알려야 할 때는 연결 효과를 시험합니다.
지금 할 일
같은 구간을 반복하며, 변화가 없는 대기 부분만 먼저 덜어 냅니다.

③ 화면·소리 맞추기

음성의 시작과 끝에 화면·자막을 맞춥니다.

어떻게 되나
음성 놓기 → 문장 경계 찾기 → 장면 놓기 → 자막 시간을 맞추기 → 음악 끝 정리 순서입니다. 트랙은 종류별 재료를 놓는 줄입니다.
기준과 예
가상 예: 말이 8초까지 이어지는데 자막이 6초에 끝나면 8 − 6 = 2초 동안 글자가 없습니다.
조건
음성·음악이 없는 아래 도식은 타이밍만 비교합니다. 실제 편집에서는 녹음 파일도 함께 듣습니다.
언제 쓰나
컷 뒤 단어가 잘리거나 자막이 먼저 사라질 때 씁니다.
지금 할 일
말의 마지막 단어가 끝나는 위치에서 프레임을 멈추고, 자막·장면 끝을 대조합니다.
확인할 점

CapCut·Create·Resolve의 모든 템플릿과 효과를 같은 무료 조건으로 보지 마세요. 앱의 현재 출력 화면에서 결제 요구·워터마크를 확인하세요. CapCut Commercial Sounds의 외부 사용권도 따로 읽습니다.[Y023]
