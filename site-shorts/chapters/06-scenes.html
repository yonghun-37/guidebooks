Flow의 Veo로 기준 그림을 움직입니다

  1. 참조와 생성 조건을 넣습니다

    입력 · reference.png·아래 영문 동작 프롬프트

    메뉴·행동 · Flow → 새 프로젝트 → Frames to Video 또는 Ingredients to Video를 고릅니다. 기준 이미지를 넣고 프롬프트 입력창에 붙입니다. 설정에서 사용 가능한 Veo 모델·9:16·6초·출력 수를 확인합니다.

    출력 → 다음 · 생성 전 크레딧 표시 → 예산 메모

  2. 샷 하나를 생성하고 검사합니다

    입력 · 승인된 참조·한 동작

    메뉴·행동 · 생성 → 미리 보기에서 눈·팔·화분·카메라·불필요한 대사를 확인 → 다운로드합니다. 실패한 요소 하나만 고쳐 다시 만듭니다.

    출력 → 다음 · shot-01.mp4 → 같은 참조로 다음 샷 → shot-02.mp4 등

  3. 같은 스타일로 연결합니다

    입력 · 승인 참조·이전 샷 끝 자세·같은 모델 설정

    메뉴·행동 · 다음 샷에도 참조를 넣습니다. 색·소품·조명을 유지하고 한 동작만 바꿉니다. 마지막 프레임을 참조할 수 있으면 연결 자세를 맞춥니다.

    출력 → 다음 · 검수한 짧은 MP4 4개 + 프롬프트·모델·비용 기록 → 7장

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(열기)을 확인하세요.

Runway로 대체하려면?

생성 화면의 Image to Video → 기준 이미지 업로드 → 같은 동작 문장 → 모델·길이·9:16 → Generate → Download 순으로 진행합니다. Gen-4.5의 이미지→영상은 세로를 지원하지만 텍스트→영상은 문서상 16:9입니다. Gen-4.5는 Standard 이상, 2~10초·720p·초당 12크레딧입니다.[Y349][Y384]

Free는 최초 125크레딧이며 월 갱신이 아닙니다. Standard는 US$15/월·625크레딧입니다. 무료 모델 목록과 한국 계정 접근은 선택 화면에서 확인합니다.[Y347][Y383]

좋은 결과

두 장면의 민트색·눈·화분·빛이 이어지고 로봇은 한 번 고개만 기울입니다.

나쁜 결과 → 고치기

같은 프롬프트에서 걷기·물주기·꽃피우기·카메라 회전을 모두 요구합니다. 동작을 나눠 생성하고 외형이 바뀐 샷은 승인 참조로 다시 만듭니다.

시간·비용 · AI 영상 전체 레시피는 약 80분+생성 대기·재시도입니다. Flow 비Ultra Veo 3.1 Fast 기준 4샷×1출력×20=80크레딧, 2안씩이면 160입니다. 무료 일 50크레딧보다 큽니다. Google AI Plus 표시가는 ₩7,500/월·추가 월 200, Pro는 ₩29,000/월·추가 월 1,000입니다.[Y343][Y375] 생성 샷을 8초로 골라도 4×8=32초입니다. 해설 길이에 맞춰 설명 카드를 더해 30~45초로 완성합니다. 시간은 작업 계획용입니다.

확인할 점

Flow는 한국·한국어 지원 목록에 있지만 무료 가입 조건 안내가 서로 다릅니다. 생성 직전 계정의 접근·모델·차감·세로 지원을 확인하세요. 한국 가시 워터마크 조건과 SynthID를 보존합니다. 무료 완성이 필요하면 기준 그림에 느린 확대를 주는 편집으로 전환합니다. 이는 정지 그림의 모션 편집입니다.[Y342][Y343][Y382]

지금 할 일 · 기준 그림 또는 클립을 저장하고 장면 실습의 파일 목록과 대조합니다.

③ AI 생성

AI 장면은 선택으로 두고, 사실처럼 보이는 합성은 공개합니다.

어떻게 되나
필요한 장면 설명 → 생성 기능·이용권 확인 → 손·글자·사실 검수 → 공개 여부 판단 순서입니다.
기준과 예
가상 예: 실제 정리한 책상은 촬영합니다. 존재하지 않는 방을 사실처럼 만든 장면은 AI 공개 대상으로 판단합니다.[Y013]
조건
대본·아이디어 보조나 자막 보조는 공식 공개 예외에 있습니다. 사실적 생성 장면과 구분합니다.[Y013]
언제 쓰나
촬영으로 얻기 어려운 표현이 꼭 필요하고 사용 조건을 확인했을 때 씁니다.
지금 할 일
장면 메모에 직접 촬영/소재/생성을 표시하고, 사실적 합성이 있으면 업로드의 AI 사용 안내를 확인합니다.
확인할 점

Create의 한국 지원과 AI 생성 지원국은 다릅니다. 앱의 생성 기능 안내와 현재 계정 메뉴를 대조하세요. Veo·Omni라는 이름만으로 무료 사용·한국 제공을 판단하지 마세요. 메뉴가 없으면 직접 촬영이나 권리 확인 소재로 진행합니다.[Y022][Y072]

얼굴 없이 손이나 물건만 찍어도 되나요?

네, 손동작과 물건의 변화로 내용을 전달할 수 있습니다.

가상 도윤은 정리 전후와 손만 찍습니다. 촬영 축을 보고 내 대본의 동작을 적으세요.

Pexels·Pixabay의 무료 영상을 수익 영상에 써도 되나요?

가능한 사용 범위와 추가 권리를 확인한 소재를 쓰세요.[Y018][Y019]

예를 들어 상표가 크게 보이는 파일은 추가 확인이 필요합니다. 권리 메모에 원문과 조건을 저장하세요.

Veo 같은 AI 영상 도구를 한국에서 무료로 쓸 수 있나요?

한국의 모든 계정에서 무료 생성이 된다고 보고 시작하지 마세요.

Create 일반 편집은 한국을 지원하지만 Omni 영상 생성 도움말의 국가 목록에는 한국이 없습니다.[Y022][Y072] 기능 확인 안내를 읽고, 메뉴가 없으면 직접 촬영으로 완성하세요.

AI 장면을 쓰면 어떤 때 시청자에게 표시해야 하나요?

실제로 보이는 인물·사건·장소를 사실처럼 합성·생성했다면 공개합니다.[Y013]

가상 방을 실재하는 방처럼 보여 주는 경우를 생각해 보세요. AI 축에서 판단하고 실제 업로드 설정에 옮기세요.
