세로로 찍기만 하면 되나요?

세로 촬영에 더해, 보여 줄 동작·가려짐·소재 권리를 확인해야 합니다. 오늘은 손과 물건으로 책상 정리 전후를 찍어 봅니다.

도윤얼굴을 꼭 보여 줘야 하나요?

서진손이 무엇을 바꾸는지 보이면 설명할 수 있어요. 먼저 결과부터 찍어 봐요.

한눈에 보기

책상 정리 영상으로 이어 갑니다

도윤·서진은 가상 인물입니다. 이 장의 책상 그림과 도구는 직접 만든 연습 예제입니다.

직접 촬영손·물건·결과를 보여 줍니다.권리 확인 소재무료 표시 옆 조건을 읽습니다.AI 생성쓰는 목적과 공개 여부를 정합니다.

축별 설명

같은 순서로 준비하고 확인합니다

① 직접 촬영

세로 화면 안에서 손동작과 결과가 함께 보이게 찍습니다.

어떻게 되나
결과를 먼저 놓고 → 손이 움직일 자리 확보 → 시험 촬영 → 화면 가장자리 확인 순서로 합니다.
기준과 예
가상 예: 정리 전 책상 → 케이블을 묶는 손 → 정리 후 책상을 찍습니다. 얼굴 대신 손과 물건으로 설명합니다.
조건
공식 시작 가이드는 9:16을 권합니다. 버튼·설명에 가리는 위치는 앱의 시각 가이드로 확인합니다.[Y079][Y080]
언제 쓰나
내가 보여 줄 실제 동작이나 물건이 있을 때 씁니다.
지금 할 일
렌즈를 닦고 폰을 고정한 뒤, 손끝이 잘리지 않는지 시험 영상을 재생합니다.

② 권리 확인 소재

무료 영상도 파일별 사용 조건을 확인한 뒤 씁니다.

어떻게 되나
필요한 장면 찾기 → 원문 이용 조건 읽기 → 권리 메모 저장 → 내 설명과 연결해 편집합니다.
기준과 예
가상 예: 서랍 전체 모습은 직접 찍고, 설명에 필요한 배경만 소재 영상으로 보충합니다.
조건
Pexels·Pixabay는 무료 사용·수정을 허용하지만 원본 재판매·단독 재배포·오인추천·인물과 상표 등에 제한이 있습니다.[Y018][Y019]
언제 쓰나
직접 찍기 어려운 보조 장면이 필요할 때 씁니다.
지금 할 일
파일명·원작자·원문 주소·사용 범위·표시문구·확인일·증빙을 메모합니다.

③ AI 생성

AI 장면은 선택으로 두고, 사실처럼 보이는 합성은 공개합니다.

어떻게 되나
필요한 장면 설명 → 생성 기능·이용권 확인 → 손·글자·사실 검수 → 공개 여부 판단 순서입니다.
기준과 예
가상 예: 실제 정리한 책상은 촬영합니다. 존재하지 않는 방을 사실처럼 만든 장면은 AI 공개 대상으로 판단합니다.[Y013]
조건
대본·아이디어 보조나 자막 보조는 공식 공개 예외에 있습니다. 사실적 생성 장면과 구분합니다.[Y013]
언제 쓰나
촬영으로 얻기 어려운 표현이 꼭 필요하고 사용 조건을 확인했을 때 씁니다.
지금 할 일
장면 메모에 직접 촬영/소재/생성을 표시하고, 사실적 합성이 있으면 업로드의 AI 사용 안내를 확인합니다.
확인할 점

Create의 한국 지원과 AI 생성 지원국은 다릅니다. 앱의 생성 기능 안내와 현재 계정 메뉴를 대조하세요. Veo·Omni라는 이름만으로 무료 사용·한국 제공을 판단하지 마세요. 메뉴가 없으면 직접 촬영이나 권리 확인 소재로 진행합니다.[Y022][Y072]

막히는 곳부터 다시 봅니다

휴대폰을 세로로만 찍으면 충분한가요?

아니요. 동작과 결과가 잘리고 가려지지 않는지도 봅니다.

예를 들어 케이블을 묶는 손끝을 확인합니다. 가림 미리보기 뒤 실제 폰에서 시험 영상을 재생하세요.

얼굴 없이 손이나 물건만 찍어도 되나요?

네, 손동작과 물건의 변화로 내용을 전달할 수 있습니다.

가상 도윤은 정리 전후와 손만 찍습니다. 촬영 축을 보고 내 대본의 동작을 적으세요.

Pexels·Pixabay의 무료 영상을 수익 영상에 써도 되나요?

가능한 사용 범위와 추가 권리를 확인한 소재를 쓰세요.[Y018][Y019]

예를 들어 상표가 크게 보이는 파일은 추가 확인이 필요합니다. 권리 메모에 원문과 조건을 저장하세요.

Veo 같은 AI 영상 도구를 한국에서 무료로 쓸 수 있나요?

한국의 모든 계정에서 무료 생성이 된다고 보고 시작하지 마세요.

Create 일반 편집은 한국을 지원하지만 Omni 영상 생성 도움말의 국가 목록에는 한국이 없습니다.[Y022][Y072] 기능 확인 안내를 읽고, 메뉴가 없으면 직접 촬영으로 완성하세요.

AI 장면을 쓰면 어떤 때 시청자에게 표시해야 하나요?

실제로 보이는 인물·사건·장소를 사실처럼 합성·생성했다면 공개합니다.[Y013]

가상 방을 실재하는 방처럼 보여 주는 경우를 생각해 보세요. AI 축에서 판단하고 실제 업로드 설정에 옮기세요.

핵심 정리

  • AI 장면은 선택입니다. 사실적 생성은 공개 여부를 확인합니다.
