이 장의 흐름
AI 도구 지도프롬프트 모음모델·비용 총정리이 장의 제작 레시피

먼저 답부터

내 목소리가 싫으면 무료 TTS를 써도 되나요?

한국어 TTS로 만들 수 있습니다. 수익용 영상에는 선택한 음성과 요금제의 상업 이용권부터 확인합니다. TTS는 글자를 음성으로 바꾸는 기능입니다. 무료 한국어 기능의 예는 Clipchamp이며, Vrew는 제공 AI 음성의 상업 이용을 안내합니다.[Y078][Y095]

우선 같은 짧은 대본을 본인 녹음과 TTS로 들어 보고 발음·강조가 자연스러운 쪽을 고릅니다. 결제 없이 시작하려면 보유 휴대폰의 본인 녹음으로 진행하세요.

도윤음악을 넣으니 목소리가 묻혀요.

서진음악을 잠깐 꺼 보고 말부터 들어요. 말이 또렷하면 음악을 낮춰 다시 합쳐 들어 봐요.

내레이션은 장면을 설명하는 말입니다. 배경음은 그 뒤에서 분위기를 더하는 소리입니다. 서로 다른 트랙, 즉 따로 조절하는 소리 줄에 두면 문제를 찾기 쉽습니다.

제작 레시피 · 목소리와 음악

대본을 녹음하거나 타입캐스트에서 음성 파일로 만듭니다

말을 먼저 확정하고 voice.wav 또는 voice.mp3를 편집기에 넘깁니다. 직접 촬영 레시피는 본인 녹음, 얼굴 없는 해설은 본인 녹음 또는 타입캐스트를 씁니다. TTS는 글자를 읽어 음성으로 만드는 기능입니다.

  1. 무료로 만들면 본인 녹음을 고릅니다

    입력 · 5장의 script.txt

    메뉴·행동 · 휴대폰 녹음 앱에서 녹음 → 정지 → 저장합니다. 짧은 시험 문장을 먼저 듣고 팬 소리·숨소리가 적은 자리에서 본 녹음을 합니다.

    출력 → 다음 · 원본 녹음 파일 → PC로 복사 → 편집기 가져오기

  2. 타입캐스트를 쓰면 화자부터 시험합니다

    입력 · 같은 대본·시험 문장

    메뉴·행동 · 타입캐스트 스튜디오의 새 프로젝트/음성 제작에 해당하는 메뉴를 찾습니다. 대본 입력 → 화자 선택 → 미리 듣기 → 발음이 틀린 줄 수정 순서입니다.

    출력 → 다음 · 발음을 고친 음성 → 다운로드 전에 요금제 확인

  3. 사용권을 확인하고 저장합니다

    입력 · 음성 초안·개인/기업 사용 목적

    메뉴·행동 · 타입캐스트 요금표에서 상업 사용 표시와 남은 다운로드 크레딧을 읽습니다. 다운로드에서 제공하는 WAV/MP3를 골라 저장하고 전체를 듣습니다.

    출력 → 다음 · voice.wav/mp3 + 화자·요금제·다운로드 날짜 메모 → 8장 편집

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(열기)을 확인하세요.

위 문장은 직접 만든 발음 시험 예입니다. 고유명사·숫자·약어·문장 끝을 듣습니다. 대본 길이는 생성된 음성 파일을 재생해 다시 잽니다.

YouTube 오디오 보관함에서 배경음 가져오기

  1. 곡과 표시문을 함께 받습니다

    입력 · 음악을 넣을 완성 음성

    메뉴·행동 · YouTube Studio → 오디오 보관함에서 곡을 미리 듣습니다. 라이선스·저작자 표시 필요 여부를 열고 MP3를 다운로드합니다. Creative Commons 곡은 표시문을 복사합니다.

    출력 → 다음 · music.mp3 + 표시문 → 편집기 음악 트랙 / 업로드 설명 메모

  2. 음악을 낮추고 말을 다시 듣습니다

    입력 · voice.wav와 music.mp3

    메뉴·행동 · 음악을 끄고 말을 듣습니다. 말이 또렷하면 음악을 낮춰 두 트랙을 함께 재생합니다.

    출력 → 다음 · 문장 끝까지 들리는 두 트랙 → 다음 장 편집

보관함은 무료이며 YouTube 수익 영상에 사용할 수 있습니다. 곡별 표시 조건을 따릅니다.[Y360]

시간·비용 · 음성 약 10분, 음악 확인·출력 약 10분을 잡습니다. 본인 녹음+보관함은 추가 0원, 타입캐스트를 새로 구독하면 ₩9,900/월입니다. 시간은 작업 계획용이며 녹음·다운로드 재시도는 더 잡습니다.

확인할 점

한국어 지원은 음질 보장이 아닙니다. 같은 문장으로 들어 고르세요. 일반 TTS와 타인 목소리 복제를 구분하고, 사실적 합성·AI 음악은 공개 기준을 확인합니다. 보관함의 YouTube 사용권을 다른 플랫폼에 그대로 옮기지 마세요.[Y363][Y360]

지금 할 일 · 음성 실습에서 파일을 저장하고 화자·곡·필수 표시를 메모합니다.

① 본인 녹음을 먼저 시험합니다

휴대폰 녹음으로 시작하고 발음과 잡음을 직접 듣습니다.

어떻게 되나
조용한 자리 찾기 → 짧게 읽어 녹음 → 처음부터 재생 → 잡음 원인 바꾸기 → 본 녹음 순서입니다.
기준·예
가상 시험 문장: “월세부터 따로 적습니다”. 바람·팬 소리를 줄이고, 폰에 숨이 직접 닿지 않게 방향을 바꿔 비교합니다.
조건
갤럭시는 음성 녹음 앱에서 녹음·정지 후 파일 이름을 정해 저장합니다. 기기별 녹음 앱으로 파일을 저장하고 전체 재생을 확인하세요.[Y097]
언제 쓰나
대본을 줄인 다음, 장면을 편집하기 전에 씁니다. 말이 찢어지면 입력 음량·폰 위치를 바꿔 다시 녹음합니다.
지금 할 일
같은 문장을 서로 다른 자리·방향으로 녹음해, 발음이 잘 들리고 잡음이 적은 파일을 고릅니다.

② 음악을 낮추기 전에 말을 따로 듣습니다

말만 들어도 안 들리면 녹음부터 고치고, 말이 또렷하면 음악을 낮춥니다.

어떻게 되나
음악 뮤트 → 말만 확인 → 음악 솔로 → 함께 재생 → 음악 낮추기 순서입니다. 뮤트는 끄기, 솔로는 선택한 트랙만 듣기입니다.
기준·예
아래 가상 비교는 내레이션 막대 70, 음악 막대 20에서 시작합니다. 설정 차이 70 − 20 = 50이며 실제 음량의 배수나 표준 비율이 아닙니다.
조건
휴대폰에서도 말의 끝부분까지 들리는지 확인합니다. 장면 설명이 중요하면 음악을 빼는 선택도 가능합니다.
언제 쓰나
편집 중과 완성 파일 재생 때 씁니다. 자막을 읽어야만 말을 알아듣는다면 소리도 다시 확인합니다.
지금 할 일
아래 도구로 겹침을 듣고, 내 편집기에서도 음악을 끈 상태와 켠 상태를 번갈아 비교합니다.

③ 음악은 사용권이 확인된 곳에서 고릅니다

유튜브에서 찾은 노래를 내려받아 임의로 넣지 않습니다.

어떻게 되나
Studio 오디오 보관함 → 트랙 선택 → 이용 조건·저작자 표시 확인 → 설명에 필요한 문구 기록 순서로 진행합니다.[Y016]
기준·예
앱에서 고르는 음악은 곡마다 허용 길이가 다릅니다. 3분 쇼츠에서 대부분 90초, 일부는 60초 또는 30초입니다. 선택한 곡의 표시를 읽으세요.[Y001]
조건
Studio 오디오 보관함 음악은 YPP 영상에도 쓸 수 있으며 Creative Commons 트랙은 설명란 저작자 표시가 필요합니다. 앱 음악의 개인·비상업 사용 안내를 협찬 사용 허락으로 확대하지 마세요.[Y016][Y080]
언제 쓰나
음악을 편집에 넣기 전에 확인합니다. 찾기 어려우면 음악 없이 본인 녹음으로 첫 편을 마칩니다.
지금 할 일
곡 이름·원작자·원문 주소·허용 범위·필요 표시·확인 날짜를 내 메모에 남깁니다.
확인할 점

1분 초과 쇼츠의 Content ID 차단 설명은 공식 문서 사이에 차이가 있습니다. 새 1분 초과·3분 미만 영상의 변경 안내를 모든 영상에 넓히지 마세요. 권리 확인 음악으로 만들고 게시 전 Studio 제한사항을 읽으세요.[Y001][Y006][Y068]

내레이션·배경음 균형

교육용 가정 모형 · 자체 합성 소리

브라우저에서 직접 만든 소리입니다. 내레이션 트랙은 말소리의 끊김을 흉내 낸 합성 신호이며 실제 문장을 읽지 않습니다. 배경음도 자체 합성입니다. 겹침을 듣는 연습 뒤 본인 녹음으로 발음까지 확인하세요.

가상 막대는 0~100, 기본은 말 70·음악 20입니다. 두 소리의 파형 최고 크기를 같은 기준으로 맞춘 뒤 막대 값을 곱합니다. 막대 차이는 체감 음량·배수·권장 dB가 아닙니다. 기기 음량을 낮춘 상태에서 재생하세요.

그림은 리듬을 설명하는 도식입니다. 아래 막대는 현재 재생에 반영되는 설정입니다.

내레이션 역할 신호

배경음

솔로가 있으면 그 트랙만 선택됩니다. 뮤트는 솔로보다 우선합니다. 둘 다 솔로면 두 트랙을 듣습니다. 재생 버튼으로 멈출 수 있고, 화면 밖이나 다른 탭으로 가면 정지합니다.

무료 제공량·음성별 조건은 현재 요금·약관 화면에서 확인하세요. Vrew 상업 이용 안내를 무료 무제한 제공으로 읽지 마세요. Clipchamp도 무료 기능 소개만으로 상업 이용권을 판단하지 않습니다.[Y027][Y078][Y095]

주장과 경고는 다릅니다

Content ID 소유권 주장은 곧 저작권 위반 경고가 아닙니다. 일치한 음악에 대해 권리자가 차단·수익화·추적을 설정할 수 있습니다. 경고는 유효한 법적 삭제 요청으로 콘텐츠가 삭제되는 경우입니다.[Y015][Y068][Y069]

가상 예: 음악 구간에 주장이 뜨면 Studio의 제한사항에서 대상 구간·권리자·영향을 읽습니다. 허락이 없다면 음악을 바꾸거나 빼고 다시 출력합니다.[Y068]

자주 묻는 질문 5개

소리를 넣기 전에 묻는 질문

내 목소리가 싫으면 무료 한국어 TTS를 써도 되나요?

네, 한국어 기능을 쓰되 수익용 영상은 상업 이용권부터 확인합니다.

예를 들어 Clipchamp는 무료 한국어 TTS를 안내합니다.[Y078] 도구별 선택표에서 조건을 보고 같은 문장을 만들어 발음을 들어 보세요.

휴대폰으로 잡음 없이 목소리를 녹음하려면 어떻게 하나요?

조용한 자리를 고르고 시험 녹음을 들어 잡음 원인부터 줄입니다.

예를 들어 팬 소리와 숨소리를 확인하고 폰 방향·녹음 장소를 바꿉니다. 본인 녹음대로 비교한 뒤 본 녹음을 하세요.

배경음악 때문에 말이 안 들리면 무엇부터 바꾸나요?

음악을 끄고 말부터 확인한 뒤 음악을 낮춥니다.

가상 도구에서 말 솔로와 함께 듣기를 비교하세요. 음량 도구 후 실제 영상에서도 문장 끝까지 들리는지 확인하세요.

유튜브에서 찾은 음악을 다운받아 넣어도 되나요?

일반 영상의 노래를 임의로 내려받아 쓰지 말고, 사용권이 있는 음악을 고릅니다.

예를 들어 Studio 오디오 보관함의 트랙 조건과 필요한 저작자 표시를 확인합니다.[Y016] 음악 권리를 보고 출처·조건을 기록하세요.

저작권 주장과 경고는 무엇이 다르고 음악은 몇 초까지 쓸 수 있나요?

소유권 주장과 삭제 요청에 따른 경고는 다르며, 모든 곡에 통하는 허용 시간은 없습니다.

예를 들어 앱 음악도 곡마다 허용 길이가 다릅니다.[Y001][Y068][Y069] 주장·경고를 읽고 선택한 곡의 이용 조건과 Studio 제한사항을 확인하세요.

핵심 정리

세 줄로 가져갑니다

  • 같은 대본으로 본인 녹음과 이용권을 확인한 TTS를 비교합니다.
  • 말만 먼저 확인하고 음악을 낮춰 함께 듣습니다.
  • 음악은 곡별 사용권과 필요한 표시를 기록합니다.
