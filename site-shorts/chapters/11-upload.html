제목이 약속한 장면을 확인하고, 시청자층·AI·권리·공개 범위를 각각 정합니다.

2026년 10월 조사 기준 · 도윤·서진은 가상 인물입니다.

이 장의 흐름

먼저 답부터

완성 MP4가 있으면 어디서 올리나요?

PC에서 편집했다면 Studio, 휴대폰에 파일이 있다면 YouTube 앱에서 시작하세요. 제목·설명은 영상에 맞게 쓰고, 공개 전에는 전체 재생과 설정을 확인합니다.[Y031][Y033]

도윤영상은 다 만들었는데 해시태그부터 찾게 됩니다.

서진첫 장면과 제목이 맞는지부터 봐요. 표지·공개 범위도 정하고 파일을 올리면 됩니다.

축별 설명

업로드와 메타데이터

① 제목과 설명

메타데이터는 영상을 소개하는 제목·설명 같은 정보입니다.

어떻게 되나
첫 화면의 변화 확인 → 제목 → 영상 요약 → 필요한 소재 표시 순으로 적습니다.
어떤 기준
가상 제목: “책상 밑 케이블, 집게로 한곳에 모으기”. 해시태그를 붙여도 내용과 맞는지부터 봅니다.
조건
공식 안내의 제목·설명 상한은 영문 기준 100자·5,000자입니다. 숨은 태그의 역할은 철자 오류 등을 제외하면 제한적입니다.[Y032]
언제 쓰나
제작한 파일을 고른 뒤 씁니다. #Shorts는 필수 분류 스위치가 아닙니다.[Y001][Y031]
지금 할 일
첫 장면을 멈추고 제목이 약속한 것을 실제로 보여 주는지 대조하세요.

② 시청자층과 AI 사용

시청자층과 AI 사용은 서로 다른 질문입니다.

어떻게 되나
의도한 시청자 확인 → 아동 대상 표현 대조 → AI가 만든 부분 확인 → 각 설정에 답합니다.
어떤 기준
가상 예: 일반 성인 대상 정리 영상에 AI로 대본만 다듬었다면, 사실적인 합성 장면과 AI 음악이 추가됐는지 확인합니다.
조건
아동용은 의도·주제·표현을 종합 판단합니다. 대본 보조는 공개 예외 예시지만 사실적 합성·AI 음악은 공개 예시에 있습니다.[Y014][Y013]
언제 쓰나
업로드 때 답하고, 영상을 수정하면 다시 확인합니다.
지금 할 일
아래 설정 연습에 답한 뒤 실습 8의 실제 입력 순서를 따르세요.
확인할 점

AI 전용 도움말은 속성 → AI 사용, 일반 업로드 문서는 더보기 → 변경된 콘텐츠를 안내합니다. 보이는 메뉴를 공식 예시와 대조하세요.[Y013][Y032]

③ 표지와 마지막 재생

표지는 선택할 장면이며, 검토는 공개 전 확인할 과정입니다.

어떻게 되나
영상의 핵심 프레임 선택 → 표지 확인 → HD 처리·제한사항 확인 → 처음부터 끝까지 재생합니다.
어떤 기준
가상 예: 집게로 정리한 결과가 보이는 프레임을 표지로 고릅니다. 과장한 완성 이미지는 피합니다.
조건
앱은 업로드 전후 영상 프레임 선택을 안내합니다. PC Studio의 맞춤 이미지 업로드는 인증 계정 조건을 확인합니다.[Y070][Y035]
언제 쓰나
프레임 선택과 외부 이미지 업로드를 구분해 원하는 작업을 고릅니다.
지금 할 일
음악 사용권 증거와 필요한 저작자 표시를 대조하세요. 검토 통과가 최종 권리 보증은 아닙니다.[Y016][Y032]

④ 공개 범위·예약·API

공개 범위는 누가 볼지를 정합니다.

어떻게 되나
확인용 저장 → 재생 확인 → 공개 또는 예약 → 실제 상태·주소 기록입니다.
어떤 기준
비공개는 본인·지정한 사람, 일부 공개는 주소를 아는 사람, 공개는 누구나 볼 수 있습니다. 예약은 정한 때 공개하는 방식입니다.[Y032][Y036]
조건
예약은 날짜·시간·시간대를 함께 정합니다. 일부 공개 주소는 비밀 보관 수단이 아닙니다.[Y032][Y036]
언제 쓰나
처음에는 공식 경로로 완료하고, 반복 업로드가 필요할 때 API를 검토합니다.
지금 할 일
실습 8에서 공개 범위를 고르고 저장 후 상태를 다시 확인하세요.
확인할 점

API의 일반 비공개 설정과 비공개 잠금은 다릅니다. 현행 API 문서와 잠금 도움말의 설명이 다릅니다. 잠겼다면 제한사항을 읽고 공식 앱 재업로드 또는 API 감사를 확인하세요. OAuth 앱 검증과 API 감사는 다른 절차입니다.[Y037][Y086][Y040][Y041]

    자주 묻는 질문 5개

    궁금한 것부터 다시 찾습니다

    PC와 휴대폰 중 어디서 올리는 것이 쉬운가요?

    완성 파일이 있는 기기에서 시작하는 편이 간단합니다.

    PC 편집본은 Studio의 파일 선택, 휴대폰 파일은 앱의 만들기 → 동영상으로 고릅니다.[Y031][Y033] 실습 8에서 내 경로를 고르세요.

    제목·설명에 무엇을 쓰고 #Shorts는 꼭 넣어야 하나요?

    제목은 보여 줄 변화, 설명은 요약·필요한 표시를 적습니다. #Shorts는 필수가 아닙니다.[Y001][Y031]

    “케이블을 집게로 모으기”처럼 장면과 맞춰 씁니다. 제목 점검에서 과장한 약속을 빼세요.

    쇼츠의 표지 이미지를 직접 고르거나 바꿀 수 있나요?

    앱에서는 영상 프레임을 고르고, PC 맞춤 이미지는 계정 조건을 확인합니다.[Y070][Y035]

    정리가 끝난 프레임을 고르는 것이 연습 예입니다. 표지 설명을 보고 내 계정의 메뉴를 확인하세요.

    비공개·일부 공개·공개·예약은 어떻게 다른가요?

    볼 수 있는 대상과 공개하는 시간이 다릅니다.[Y032][Y036]

    일부 공개는 주소를 아는 사람이 볼 수 있습니다. 민감한 초안은 비공개를 고르고 공개 범위를 저장 후 확인하세요.

    API로 올린 영상이 비공개에서 풀리지 않는 이유는 무엇인가요?

    일반 비공개 설정인지, 미검증 API의 비공개 잠금인지 먼저 구분합니다.[Y086]

    잠금이라면 public으로 바꾸기만 해서는 해결되지 않습니다. 확인할 점의 공식 경로·감사 안내를 확인하세요.
