AI 준비

처음 가입할 AI는 ChatGPT 무료예요

지금 하는 일

대본과 장면 요청을 넣을 채팅을 준비해요.

왜 하는지

같은 대화에서 대본·장면·제목을 이어서 고칠 수 있어요.

따라 하기

ChatGPT 공식 사이트에서 본인 계정을 만들거나 로그인하세요. 무료 등급으로 시작하고 유료 체험·결제 창은 건너뛰세요. 새 채팅 입력창에 「책상 정리 쇼츠의 첫 문장 후보를 제안해 줘」라고 적고 보내요.[Y300]

답이 오면 이 대화에 다음 실습 프롬프트를 붙여 넣을 준비가 된 거예요. 이미지 기능에는 별도 한도가 있어요. 무료 생성 장수를 고정해서 계획하지 마세요.[Y300][Y374]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

이렇게 보이면 성공

새 채팅에서 내 질문과 답변이 보여요.

이렇게 보이면?

무료 이미지 한도 안내가 떠도 대본을 먼저 만들 수 있어요. 개인정보나 비공개 계정 자료는 넣지 마세요.

편집기 준비

내 기기에서 편집기 하나를 열어요

지금 하는 일

PC는 Clipchamp, 휴대폰은 Create로 시작해요.

왜 하는지

편집기에서 파일을 이어 붙이고 자동 자막을 만들어요.

따라 하기

Clipchamp 공식 사이트의 Windows 앱 안내에서 Microsoft Store로 이동해 설치하세요. 개인 Microsoft 계정으로 열고 새 빈 프로젝트를 만들어요. 기본 설치 앱이 있으면 그대로 열어요.[Y334]

Clipchamp는 이 경로에서 브라우저 편집기를 사용해요. Chrome/Edge에서 공식 웹 편집기를 열어요. 설치형 무료 프로그램이 필요하면 Resolve 무료판을 설치할 수 있지만, 여기의 자동 자막 단계는 Clipchamp 웹에서 따라가세요.[Y333][Y334]

Create 공식 제공 지역·스토어 안내에서 설치해요. 새 프로젝트를 만들고 본인 클립을 고르세요. Create의 자동 자막은 60초가 넘는 클립에서 만들 수 없어요.[Y022][Y332]

PC에서 무료 편집 프로그램 설치를 마치고 싶다면 Windows는 Clipchamp 앱, macOS는 Resolve 무료판을 설치해요. 본문 제작 순서는 PC Clipchamp와 모바일 Create로 설명해요.

사진 한 장으로 시험 MP4 만들기

프로젝트 저장은 편집 상태를 남기는 일, MP4 저장은 재생 파일을 만드는 일이에요. 아래 출력까지 마친 뒤 준비 완료를 체크하세요.

  1. PC: 새 빈 동영상 → 9:16 → 미디어 가져오기에서 본인 사진 한 장을 골라요. 사진을 아래 타임라인으로 끌어 놓고 재생해요. 가져오기 자세히
  2. PC: 내보내기 / Export → 1080p를 골라 exports/test.mp4로 저장해요. 파일을 열어 사진이 보이는지 확인하세요. Clipchamp는 무료 1080p·무워터마크 출력을 안내해요. 왕관·다이아·Premium 소재는 빼고 시험해요.[Y334]
  3. 휴대폰: Create의 + → 갤러리 → 본인 사진 → 가져오기로 프로젝트를 만들어요. 더보기 / ⋮ → 내보내기 → 품질 선택 → 내보내기로 폰에 저장하고 사진 앱에서 재생하세요. 사진 가져오기 · 저장 화면 순서

이렇게 보이면 성공

편집기 밖에서 test.mp4를 열어 사진이 보이고, 유료 결제 없이 출력했어요.

이렇게 보이면?

한국어 메뉴가 없으면 Captions·Import media·Export 같은 기능 이름을 찾아요. 자막 언어에 한국어가 없으면 수동 텍스트로 시작하거나 다른 기기에서 열어요.

자동화·무료 대안: shorts-kit

키트는 명령으로 대본·자막·MP4를 만드는 PC 대안이에요. AI 채팅이나 편집기를 사용하려면 설치하지 않아도 돼요. 저장소에서 Code → Download ZIP을 받아 압축을 풀고 shorts-kit 폴더를 찾으세요. 실행 전에 Python 공식 설치 파일로 준비해요. 여기서는 Python 3.11로 확인했어요.

터미널은 명령을 글로 입력하는 창이에요. 경로는 파일 위치이고, 가상환경은 이 키트의 도구를 따로 넣는 폴더예요. 아래는 OS별 같은 절차예요. 활성화 명령은 필요 없어요.

탐색기로 shorts-kit를 열고 주소창에 powershell을 입력하세요. Python 설치 때 PATH 추가를 선택해요. 버전이 다르면 설치한 버전으로 실행하세요.

py -3.11 --version
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_pipeline.py run --output output/first

터미널에서 cd와 공백을 입력하고 Finder의 shorts-kit 폴더를 끌어 놓은 뒤 Enter를 눌러요. python3가 다른 버전이면 설치한 실행 파일을 직접 골라요.

python3.11 --version
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_pipeline.py run --output output/first

이렇게 보이면 성공: 끝에 영상 생성 완료, 검수 대기, 미리보기와 파일 경로가 나와요. output/first/preview.html을 열고 재생하세요. 이 첫 파일은 가상 대본·무음·도형 예제예요. 내 녹음이 들어갔다고 생각하지 마세요.

이후 키트 코드의 python은 Windows에서는 .\.venv\Scripts\python.exe, macOS에서는 .venv/bin/python으로 바꾸세요. 명령은 shorts-kit 폴더에서 실행해요. 이미 있는 결과 폴더에는 다시 run하지 말고 다른 이름을 쓰세요.

자주 묻는 질문 5개

어떤 무료 편집기를 설치하나요?

Windows는 Clipchamp 앱, 휴대폰은 Create를 설치해요.

macOS는 Clipchamp 웹으로 본문을 따라가고 설치형은 Resolve 무료판이 있어요. 기기 탭을 여세요.

가짜 다운로드 사이트는 어떻게 피하나요?

공식 사이트가 연결하는 스토어나 설치 파일만 써요.

예: 검색 광고의 다운로드 버튼은 누르지 않아요. 공식 링크로 들어가세요.

무료 기능과 유료 소재는 어떻게 구분하나요?

Premium·왕관 표시와 내보내기 경고를 봐요.

시험 파일에 유료 스톡이 들어갔다면 빼세요. 무료 시험 출력을 먼저 해요.

한국어 메뉴·자막이 없으면요?

같은 기능의 영문명을 찾고, 자막 언어를 따로 선택해요.

예: Captions에서 Korean을 찾아요. 없으면 수동 자막 대안으로 가세요.

키트와 편집기는 무엇이 다른가요?

키트는 정해진 파일을 명령으로 만들고, 편집기는 눈으로 보며 조정해요.

키트 자막은 음성을 인식하지 않아요. 선택 설치 후에도 직접 검수하세요.
