먼저 답부터

MP4를 편집기 밖에서 끝까지 보고, AI 사용 메모를 만든 뒤 업로드하세요.

도윤 편집기에서 잘 보이면 바로 올려도 되나요?

서진 저장한 MP4를 따로 열고 끝까지 봐요. AI 사용 기록도 함께 가져가세요.

MP4 출력

세로 완성 파일을 저장해요

지금 하는 일

편집 프로젝트를 재생 가능한 MP4로 내보내요.

왜 하는지

프로젝트 파일은 완성 영상 파일과 달라요.

따라 하기

Clipchamp에서 비율이 9:16인지 확인한 뒤 내보내기 / Export → 1080p를 선택하세요. 다운로드한 MP4를 exports/short.mp4로 옮겨요. 1080p 세로의 학습 목표는 1080×1920이에요. 무료 출력 범위의 본인/무료 소재를 써요.[Y334][Y394]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

fps는 1초의 화면 수예요. 출력 fps를 고를 수 있으면 원본과 같은 값을 사용하세요. Clipchamp에 선택 항목이 없으면 저장된 파일 정보의 실제 값을 확인해요. MP4·H.264는 공식 인코딩 안내에도 나오는 조합이에요.[Y003]

휴대폰: Create에서 MP4 저장·품질 선택

  1. 편집 프로젝트를 열고 재생해 자막·음성을 확인해요. 오른쪽 위 더보기 / ⋮ → 내보내기 / Export를 눌러요.
  2. 품질 옆 화살표를 눌러 제공되는 해상도 중 1080p를 골라요. 이 항목이 없다면 제공되는 가장 높은 품질을 고르고 저장 뒤 실제 치수를 확인해요.
  3. 내보내기를 눌러 기기 저장이 끝날 때까지 기다려요. 오늘은 파일부터 검수하므로 이 화면의 YouTube 업로드 버튼은 아직 누르지 않아요. 저장·품질 선택 공식 도움말
  4. 갤러리·사진 앱의 최근 항목에서 출력 영상을 열어요. 파일 앱에서 찾아 my-short/exports/short.mp4로 복사·이름 변경해요. 사진 앱 안에만 있으면 공유 → 파일에 저장처럼 파일 앱으로 옮기는 기능을 써요. 확장자를 바꾸는 것만으로 MP4 변환이 되지는 않아요.

이렇게 보이면 성공: 편집기를 닫아도 파일 앱에서 MP4가 열리고 처음부터 끝까지 자막·소리가 나와요. 다음: 파일 정보와 화질을 확인하세요. 프로젝트는 Create의 최근 프로젝트에 남겨 두고 원본도 보관해요. SRT를 따로 저장하는 메뉴가 없으면 자막 내용을 script.txt에 보관하세요.

이렇게 보이면 성공

exports 폴더에 MP4가 있고 편집기 밖에서도 재생돼요.

이렇게 보이면?

유료 결제 창이 뜨면 프로젝트의 Premium 스톡·효과·해상도를 확인해요. 유료 요소를 빼고 무료 출력으로 돌아가요. 워터마크를 덮거나 잘라 숨기지 마세요.

파일 검사

파일 자체의 화질·소리·자막을 확인해요

지금 하는 일

처음·중간·마지막을 보고 끝까지 재생해요.

왜 하는지

미리보기에서 괜찮아도 저장 파일의 누락은 다시 확인해야 해요.

따라 하기

① 플레이어에서 처음부터 끝까지 들어요. 말이 잘리거나 뜻밖의 생성 소리가 섞였는지 봐요. ② 음소거하고 자막을 읽어요. 숫자·부정문·줄 끝과 화면 아래 가림을 봐요. ③ 검은 여백·가운데 크롭·워터마크를 확인해요. ④ 파일 정보를 열어 길이·치수·fps를 적어요.

탐색기 → 파일 우클릭 → 속성 → 자세히에서 프레임 너비·높이·길이·프레임 속도를 확인해요.

Finder 정보 가져오기에서 치수를 보고, QuickTime Player → 윈도우 → 동영상 속성 보기에서 세부 정보를 확인해요.

갤러리/사진의 파일 정보에서 치수와 길이를 확인해요. 전체 화면과 실제 앱의 확인용 재생으로 글자 가림도 봐요.

첫 과제는 30~45초를 목표로 했어요. 실제 쇼츠 분류는 일반 채널의 최대 3분·정사각형 또는 세로 조건으로 확인해요. 제목의 #Shorts만으로 판정되지 않아요. 최종 분류는 실습 8에서 Shorts 목록으로 확인해요.[Y001][Y031]

폰으로 옮길 때는 USB·AirDrop·본인 클라우드의 원본 파일을 써요. 메신저의 압축 영상 대신 파일 첨부/원본 전송을 고르세요. 받은 파일의 길이·치수와 끝 재생을 다시 확인해요.

이렇게 보이면 성공

저장 파일이 세로로 재생되고 말·자막·장면이 끝까지 맞아요.

이렇게 보이면?

원본도 흐리면 촬영·생성 파일부터 확인해요. 원본이 작은데 출력 치수만 키워도 새 세부 정보가 생기지는 않아요. 업로드 뒤만 흐리면 HD 처리 상태를 확인해요.[Y032]

AI 사용 기록

AI 사용 부분을 기록하고 표시를 판단해요

지금 하는 일

대본·음성·이미지·영상·음악 사용을 나눠 메모해요.

왜 하는지

업로드의 AI 사용 질문에 완성 영상 전체를 보고 답할 수 있어요.

따라 하기

파일명·영상 구간:
사용한 AI 서비스·모델·생성 날짜:
사용 부분: 대본 / 음성 / 이미지 / 영상 / 음악
원본·프롬프트 저장 위치:
현실 장면·인물·발언처럼 오해할 요소:
내가 고른 AI 공개 판단과 이유:
이용 조건·워터마크·필요 출처 표시:
사용 예업로드 판단
대본·제목 보조, 자동 자막·사소한 보정공개 불필요 예시예요. 최종 장면·음성도 따로 보세요.[Y363]
사실처럼 보이는 사건·장소 합성, 타인의 하지 않은 말·행동의미 있는 사실적 합성이면 공개해요.[Y363]
만화 종이 로봇, 일반 TTS비현실 만화 예시와 오인 가능한 합성 음성을 구분해요. 일반 TTS를 전부 면제로 보지 마세요.[Y363]
AI 생성 음악공개 필요 예시에 있어요. 사용권도 기록해요.[Y363]

이 기록을 ai-log.txt로 저장하고 실습 8의 AI 사용 항목에 옮겨요. 출처 정보나 워터마크가 남았다는 사실과 내 공개 판단은 따로 확인해요.[Y363][Y376]

이렇게 보이면 성공

사용 부분·권리·표시 판단이 메모에 있고 업로드 화면에 답할 준비가 됐어요.

이렇게 보이면?

대본 보조만 썼다고 적었는데 사실적 생성 영상도 있다면 기록을 고치세요. 모르겠으면 공식 예시와 대조한 뒤 진행해요.

자동화·무료 대안: shorts-kit

키트는 1080×1920·30fps·H.264/AAC MP4로 출력해요. 이는 키트의 선택 규격이에요. video-info.json에서 실제 size·fps·duration·audio·warnings를 봐요. silent: true는 녹음 없이 만든 무음 상태예요. 내 녹음을 넣었다면 이 상태와 실제 재생을 함께 확인하세요.

python run_pipeline.py render output/my-script

설정 경로를 바꿨으면 실습 6의 --config config.yaml을 다시 써요. 그대로 재출력할 때는 결과 폴더의 config.yaml 사본을 사용해요. output/my-script/REVIEW.md 여섯 칸을 실제로 확인하고 체크해요. 승인 뒤 파일을 고치면 재검수·재승인이 필요해요. 승인·드라이런은 선택 실습 9, 오늘 실제 게시는 실습 8이에요.

자주 묻는 질문 5개

어떤 해상도·fps·형식으로 내보내나요?

세로 1080p MP4를 목표로 하고 fps는 원본과 맞춰요.[Y003][Y394]

Clipchamp에 fps 메뉴가 없으면 파일 정보로 확인해요. 출력 후 재생하세요.

워터마크·결제 창이 나오면요?

Premium 소재·효과·출력 옵션과 생성 원본 조건을 확인해요.

예: 유료 스톡을 본인 사진으로 바꿔요. 무료 출력으로 돌아가세요.

소리·잘린 자막·검은 여백은 어떻게 보나요?

소리 켜기·끄기를 나눠 끝까지 재생해요.

예: 폰 크기에서 자막 줄 끝을 읽어요. 파일 검사를 하세요.

폰으로 옮길 때 화질은 어떻게 지키나요?

원본 파일로 전송하고 받은 파일의 정보도 대조해요.

예: USB나 원본 클라우드 다운로드를 써요. 길이·치수를 보세요.

쇼츠 조건에 맞는지 어디서 보나요?

파일 정보로 길이·비율을 보고 게시 후 Studio Shorts 목록을 봐요.[Y001][Y031]

예: 내 MP4가 최대 3분 이내의 세로인지 확인해요. 실제 분류도 보세요.
