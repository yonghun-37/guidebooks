먼저 답부터

Clipchamp에서 컷을 정리하고 음성에 장면을 맞춘 뒤, AI 자동 자막을 고치세요.

도윤 자동 자막을 만들면 편집이 끝난 건가요?

서진 원음과 맞는지 읽고 들어야 해요. 뜻을 바꾸는 오타와 가려진 글자부터 고쳐요.

세로 프로젝트

Clipchamp에 세로 프로젝트를 만들어요

지금 하는 일

대본·음성·장면 파일을 편집기에 가져와요.

왜 하는지

파일을 같은 시간축에 놓아야 말과 그림을 맞출 수 있어요.

따라 하기

Clipchamp에서 새 동영상 만들기 → 화면 비율 → 9:16을 골라요. 미디어 가져오기 / Import media에서 voice의 녹음과 scenes의 PNG·MP4를 선택하세요. 프로젝트 이름은 내 주제로 바꿔요.[Y394]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

타임라인은 시간 순서대로 파일을 놓는 줄이에요. 음성을 아래 줄, 장면을 위 줄에 끌어 놓아요. 음성이 들어 있는 촬영 클립은 소리를 다시 겹치지 않게 해요. 별도 녹음을 쓰면 촬영/생성 클립의 원래 소리는 음소거하세요.

휴대폰: Create에서 장면과 별도 음성 넣기

scenes의 사진·MP4와 voice/voice-original.m4a 또는 voice/voice.mp3를 폰에 다운로드해 두세요. 생성형 예는 네 샷 장면표를 순서대로 써요.

  1. Create 홈의 + → 새 프로젝트 → 갤러리에서 장면을 순서대로 고르고 가져오기 / Import를 눌러요. 다른 앱의 파일은 갤러리 옆 화살표에서 찾아요. 화면 비율 메뉴(보통 ⋮ → 가로세로 비율)에서 9:16 세로를 골라요. 프로젝트 공식 도움말
  2. 클립 선택을 풀고 아래 툴바의 사운드 / Sound → 기기 / 내 음악처럼 기기에 저장된 소리를 여는 탭을 찾아요. 내 녹음 파일을 미리 듣고 + / 추가로 넣어요. 음악 검색 결과와 혼동하지 말고 파일명을 대조하세요.
  3. 녹음 파일이 목록에 없으면 폰의 파일 앱에서 다운로드 위치·오디오 형식을 확인해요. 계속 안 보이면 음성 해설 / Voiceover → 녹음 버튼 길게 누르기 → 완료로 같은 script.txt를 직접 읽어요. 영상 길이를 먼저 확보한 뒤 녹음하세요. 오디오 공식 도움말

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 위 공식 도움말을 확인하세요.

이렇게 보이면 성공: 세로 미리보기 아래 장면 줄과 별도 녹음 줄이 보이고 재생하면 내 목소리가 들려요. 다음: 자르기·배치로 가세요.

이렇게 보이면 성공

세로 미리보기와 영상·음성의 서로 다른 줄이 보여요.

이렇게 보이면?

클라우드에만 있고 기기에서 못 읽는 파일이면 원본을 먼저 다운로드해요. 파일을 옮긴 뒤 누락 표시가 나면 새 위치로 다시 연결해요.

컷과 음성

컷 → 음성 → 장면 순서로 맞춰요

지금 하는 일

틀린 구간과 침묵을 자르고 장면 길이를 조정해요.

왜 하는지

전환 효과보다 말과 행동이 맞는 것이 먼저예요.

따라 하기

① 장면 클립을 선택하고 양끝 손잡이를 안쪽으로 끌어 불필요한 앞뒤를 잘라요. 중간을 빼려면 재생 막대를 시작점에 두고 분할 / Split, 끝점에서도 분할한 뒤 가운데 조각을 삭제해요. 남은 클립을 붙여 빈틈을 없애요.

② 녹음의 틀린 문장과 긴 침묵도 같은 방식으로 잘라요. 남길 음성의 첫 문장을 맨 앞에 맞춰요. ③ 「분류해요」라는 말이 나올 때 분류 장면이 보이도록 장면 경계를 끌어 맞춰요. 정지 이미지는 끝 손잡이를 늘려요.[Y394]

장면을 옮길 때 음성까지 같이 움직였는지 들어 보세요. 소리가 갑자기 사라지면 음소거·줄의 시작·빈틈을 따로 확인해요. 전환은 장면 의미가 이어지기 어려울 때만 시험하세요.

휴대폰: 장면과 녹음을 각각 자르기

  1. 장면 클립을 탭하고 양끝 손잡이를 끌어 앞뒤를 줄여요. 중간 실수는 재생 막대를 시작점에 놓고 분할 / Split, 끝점에서도 분할한 뒤 가운데 조각을 선택해 삭제해요.
  2. 장면 클립을 길게 눌러 순서를 바꾸고 빈틈 없이 붙여요. 녹음 줄을 따로 탭하고 같은 분할·삭제로 틀린 말과 침묵을 덜어내요. 녹음만 옮길 때는 해당 오디오 조각을 길게 눌러 원하는 시작 위치로 끌어요. 화면을 확대해 경계를 맞춰요.
  3. 첫 음성의 시작을 첫 장면과 맞추세요. 장면 손잡이로 길이를 조절하고 다시 들어요. 예: 생성형의 「고개를 기울이니」에서 shot-02.mp4가 보여야 해요. 오디오는 전체 영상보다 길게 둘 수 없으니, 뒤가 잘리면 장면·설명 카드를 먼저 늘린 뒤 음성을 넣어요. 오디오 길이·분할 공식 안내

이렇게 보이면 성공: 첫말·행동·마지막 말에 맞는 장면이 나오고 소리가 겹치거나 잘리지 않아요. 다음: 음량을 맞추고 자막을 교정하세요.

이렇게 보이면 성공

내레이션이 시작할 때 첫 화면이 있고, 행동을 말할 때 같은 장면이 나와요.

이렇게 보이면?

자막을 아직 만들지 않았다면 음성부터 확정하세요. 나중에 음성을 크게 바꾸면 자막 시점도 다시 맞춰야 해요.

AI 자동 자막

AI 자동 자막을 만들고 원음과 대조해요

지금 하는 일

한국어 전사 결과의 글자·시간·가림을 고쳐요.

왜 하는지

자동 자막은 시작점이에요. 이름·숫자·부정문 오독은 뜻을 바꿔요.

따라 하기

Clipchamp의 자막 / Captions → 한국어 → 미디어 전사 / Transcribe media로 생성해요. 전사할 때 클라우드 처리 안내를 읽고 동의 여부를 정하세요. 결과의 문장을 선택해 오타를 고치고 텍스트·자막 스타일에서 크기·위치를 조절해요.[Y385]

예: 「버리지 않아요」를 「버려요」로 읽었다면 원음에 맞춰 고치세요. 말이 끝나기 전에 자막이 사라지면 구간 끝을 늘려요. 휴대폰 크기로 읽어 보고 아래·오른쪽의 버튼 자리와 겹치지 않는 위치로 옮겨요.[Y080]

편집기에서 자막 구간을 직접 늘릴 수 없으면 음성을 다시 나누거나, 해당 줄을 숨기고 텍스트 클립으로 직접 넣어 길이를 맞춰요. 한국어 전사가 없으면 같은 수동 텍스트 경로로 완성하세요. 가능하면 교정한 SRT 다운로드도 해요. SRT는 글과 표시 시간이 들어 있는 자막 파일이에요.[Y385]

모바일 Create: 프로젝트 → 자막 → 모든 동영상/음성 해설 → 언어 → 생성. 자막 레이어의 수정/스타일에서 고쳐요. 60초 초과 클립은 자막 생성 대상이 아니에요.[Y332]

교육용 가상 연습 · 아래는 편집 순서를 이해하는 시간 도식이에요. 실제 음성 파일은 재생하지 않아요.

가상 발화: 「지금 쓸 것만 남겨요」 · 끝 위치 6초

지금 쓸 것만

프레임은 한 장의 화면이에요. 이 연습은 초당 30장으로 이동해요. 숫자는 모두 가상 설정이에요.

이렇게 보이면 성공

원음과 자막이 같은 뜻이고 말이 끝날 때까지 읽을 수 있어요.

이렇게 보이면?

자동 자막을 만들었다는 이유만으로 체크하지 마세요. 영상을 음소거하고 읽은 뒤 다시 소리를 켜 비교하세요.

음악과 음량

음성·음악을 따로 듣고 섞어요

지금 하는 일

필요한 때만 권리를 확인한 음악을 더해요.

왜 하는지

말을 가리는 배경음보다 조용한 영상이 나아요.

따라 하기

음악 없이 완성해도 돼요. 넣으려면 Studio → 오디오 보관함에서 곡별 이용 조건과 저작자 표시문을 읽고 MP3를 받아요. Creative Commons 표시가 필요한 곡은 문구를 설명란에도 넣어요.[Y016][Y360]

음악은 음성과 다른 줄에 넣어요. 음악을 음소거해 말만 듣고, 반대로 말소리를 꺼 음악만 들어요. 둘을 켜서 폰 스피커로 다시 듣고 말이 묻히면 음악 음량을 낮추세요. 끝에서 음악이 갑자기 끊기면 제공되는 페이드 기능으로 줄이거나 빼요.

확인할 점

무료 편집기·스톡·음악의 사용권은 각각 확인해요. 인기 음악을 짧게 쓰거나 출처만 적는 것으로 허락이 생기지 않아요. AI 생성 음악은 공개 판단에도 기록하세요.[Y016][Y363]

휴대폰: 원본 소리·음성·음악을 따로 조절하기

  1. 촬영·생성 클립을 탭해 볼륨 / Volume 슬라이더를 내려요. 별도 내레이션을 쓸 때는 원본 소리를 0으로 두고 완료해요. 원본 목소리를 쓰는 촬영형은 그 소리를 남기고 중복 녹음을 빼세요.
  2. 녹음 줄을 탭해 볼륨 → 슬라이더 → 완료로 말소리를 맞춰요. 음악은 생략해도 돼요. 넣으려면 사운드 → 기기에서 사용권을 확인한 MP3를 추가하고, 음악 줄의 볼륨을 말소리보다 낮춰요.
  3. 음악 볼륨을 0으로 해 말만, 음성 볼륨을 0으로 해 음악만 들어요. 마지막에 필요한 볼륨을 복원하고 함께 재생해요. 끝이 거칠면 음악 줄의 페이드 → 끝 위치 → 완료를 시험해요. 볼륨·페이드 공식 안내

이 실습은 기기에 MP4를 저장하므로 인기곡 탭 대신 음악 없음 또는 권리를 확인한 기기 음원을 써요. 이렇게 보이면 성공: 폰 스피커에서도 말이 들리고 불필요한 원본 소리가 없어요. 다음: 폰에 MP4 저장으로 가세요.

이렇게 보이면 성공

말만·음악만·함께 듣기를 마쳤고 설명란에 필요한 표시문이 있어요.

이렇게 보이면?

오디오 보관함과 비슷한 이름의 외부 음악 채널을 혼동하지 마세요. 권리 기록이 없으면 음악을 빼고 진행해요.

자동화·무료 대안: shorts-kit

키트는 음성 인식 대신 script.json의 subtitle과 duration으로 자막을 만들어요. 각 장면의 duration은 그 장면의 초예요. narration은 읽을 말, subtitle은 짧은 화면 글이에요. 내 말과 맞도록 장면을 나누고 시간을 고치세요. JSON의 큰따옴표·쉼표를 유지해요.

실습 4·5에서 config.yaml의 녹음·장면 경로와 rights를 고쳤다면 아래 명령을 써요. 동봉 예제는 first, 내 대본은 my-script예요. 여기서는 내 대본 폴더를 계속 써요.

python run_pipeline.py validate output/my-script
python run_pipeline.py render output/my-script --config config.yaml

이렇게 보이면 성공: 대본 형식 확인 완료 뒤 영상 생성 완료와 미리보기 경로가 나와요. output/my-script/preview.html에서 재생·장면·반복·프레임·안전 영역과 음원 따로 듣기를 확인하세요. 클립 소리는 빠지고 지정한 녹음·음악만 들어가요.

subtitles.srt만 수정하면 화면 자막은 바뀌지 않아요. script.json의 subtitle을 고치고 재출력하세요. 녹음보다 영상이 짧으면 duration 합을 늘려요. 실제 생성된 장면 수만큼 파일을 준비하고 고정된 예제 장수에 맞추지 마세요. 음악을 넣는 추가 설정은 키트 README의 권리 증빙 항목을 따라요.

자주 묻는 질문 5개

9:16 프로젝트와 가져오기는 어디서 하나요?

새 동영상의 비율을 고르고 미디어 가져오기를 눌러요.

예: voice와 scenes의 파일을 선택해요. 프로젝트를 준비하세요.

자르기와 순서 바꾸기는요?

손잡이로 앞뒤를 줄이고, 분할·삭제 후 끌어 순서를 바꿔요.

예: 틀린 문장 사이 조각을 지워요. 빈틈도 없애세요.

녹음과 장면 시작은 어떻게 맞추나요?

음성 첫 문장을 기준으로 장면 경계를 맞춰요.

예: 「분류」를 말할 때 분류 장면이에요. 시간축을 보며 재생하세요.

자막 오타·크기·위치는 어디서 고치나요?

Captions의 문장과 자막 스타일에서 고쳐요.

예: 부정문 오독과 아래 가림을 수정해요. 끝 위치 연습도 해 보세요.

음악과 말을 따로 어떻게 듣나요?

트랙별 음소거로 각각 듣고, 함께 켜서 음악을 낮춰요.
