시작 전에: 오늘 만들 쇼츠 고르기

이 실습이 끝나면 내 손에 있는 것: 내 영상 유형·파일 폴더·오늘의 일정

2026년 10월 조사 기준 · 도윤·서진과 사례는 가상이에요.

먼저 답부터

세 가지 유형 중 하나만 고르고, AI 대본부터 완성 MP4와 공개 주소까지 이어 가세요.

도윤 어떤 AI로 무엇부터 만들죠?

서진 무료 ChatGPT로 대본을 만들고 Clipchamp에서 편집해요. 오늘은 한 유형만 골라요.

유형 선택

오늘 만들 영상 유형을 골라요

지금 하는 일

결과물에 맞춰 필요한 도구만 골라요.

왜 하는지

도구를 전부 가입하지 않고 한 편을 끝낼 수 있어요.

따라 하기

시간은 대략이에요. 화면은 기기·버전마다 다를 수 있어요. 아래 시간은 연구 노트의 학습 일정이에요. 가입·설치·생성 대기·재시도·파일 전송은 더 걸려요.

유형도구와 무료 가능 여부제작 시간
① 직접 촬영 + AI 편집ChatGPT 무료 → 내 폰 촬영·녹음 → Clipchamp 무료 자동 자막. 보유 기기 기준 새 구독료 없이 가능해요.[Y300][Y334][Y385]약 60분[Y394]
② 얼굴 없는 해설ChatGPT 무료 → 본인 녹음 또는 Vrew TTS → 권리 확인 스톡/AI 이미지 → Clipchamp. 녹음·스톡이면 무료, 이미지·TTS 한도는 확인해요.[Y329][Y330][Y374]약 65분[Y391]
③ AI 영상 생성ChatGPT/Gemini 기준 이미지 → Flow/Runway → Clipchamp. 무료 잔여량·생성 접근·다운로드 권한이 있어야 해요.[Y342][Y343][Y347]약 80분 + 생성 대기[Y367]

제작 시간은 기획부터 출력까지예요. 전체 일정은 준비 A분 + 제작 60/65/80분 + 업로드 약 20분 = A+80/A+85/A+100분으로 잡아요. 준비 A에는 내 가입·설치 시간을 적으세요. 업로드도 연습용 일정이며 처리 대기는 더해요. 제작 일정 근거는 AI 제작 레시피예요.[Y394][Y391][Y367]

오늘의 선택

휴대폰만 있으면 ChatGPT 웹과 YouTube Create 일반 편집으로 이어 가세요. PC가 있으면 Clipchamp를 기본으로 따라가요. 키트는 PC 선택 경로예요.[Y022][Y334]

이렇게 보이면 성공

선택한 유형과 도구, 오늘 쓸 시간을 메모했어요.

이렇게 보이면?

무료 영상 생성이 막히면 ②의 사진 모션으로 전환하세요. 생성 대기 때문에 다른 단계를 멈출 필요는 없어요.

폴더 준비

내 파일을 모을 폴더를 만들어요

지금 하는 일

원본과 완성본을 나누어 보관해요.

왜 하는지

나중에 자막·권리·화질을 고칠 원본이 남아요.

따라 하기

휴대폰·PC의 문서 폴더에 my-short를 만들고 아래처럼 나누세요. 이 폴더는 편집기 경로예요. 키트의 input/과는 달라요.

my-short/
  script.txt
  originals/
  voice/
  scenes/
  rights/
  exports/
  ai-log.txt

탐색기 → 문서 → 새로 만들기 → 폴더에서 만들어요. 보기 → 표시 → 파일 확장명을 켜세요.

Finder → 문서 → 새 폴더에서 만들어요. Finder 설정 → 고급의 모든 파일 확장자 표시를 켜세요.

파일 관리 앱에서 같은 이름의 폴더를 만들어요. 편집 앱이 파일 접근 권한을 물으면 필요한 폴더를 허용하세요.

이렇게 보이면 성공

내 폴더에 대본·원본·권리 메모·완성본을 구분해 넣을 자리가 있어요.

이렇게 보이면?

다운로드 폴더에만 두면 정리 중 지울 수 있어요. 편집 프로젝트가 읽는 원본은 완성 전까지 옮기지 마세요.

게시 목표

연습과 오늘 게시할 영상을 구분해요

지금 하는 일

내가 설명하고 사용할 수 있는 소재로 만들어요.

왜 하는지

예제 재생과 내 채널의 게시 완료를 혼동하지 않아요.

따라 하기

도윤은 직접 해 본 책상 정리를 골랐어요. 내 주제·시청자·보여 줄 행동을 script.txt에 적으세요. 파일이 이미 있으면 출력 확인부터 가도 돼요. 키트 예제로만 연습했다면 실습 3에서 내 대본으로 바꿔 다시 출력하세요.

첫 확인은 비공개 또는 일부 공개로 해요. 일부 공개는 주소를 아는 사람이 볼 수 있어요. 확인이 끝난 뒤 공개하고 주소를 남겨요.[Y032]

오늘의 결과는 내 MP4와 공개 주소예요. 게시 다음 날과 그다음 주의 숫자 확인은 이후 일정이에요.

이렇게 보이면 성공

내 주제와 공개 전 확인 순서를 정했어요.

이렇게 보이면?

연습 파일만 있으면 아직 내 첫 게시물은 없어요. 실제 자료로 돌아가 대본·녹음·장면을 바꾸세요.

자주 묻는 질문 5개

오늘 끝나면 무엇이 남나요?

내가 만든 MP4와 공개 주소가 남아요.

예: 책상 정리 영상과 그 주소예요. 내 주제를 먼저 적으세요.

휴대폰만 있으면 어디서 갈라지나요?

실습 2에서 Create를 골라요.

PC는 Clipchamp, 휴대폰은 Create예요. 내 기기 경로로 가세요.

무료로 끝내려면 무엇이 필요한가요?

보유 폰·인터넷·무료 AI와 편집 계정이 필요해요.

예: 본인 녹음·촬영이면 생성 크레딧이 없어도 돼요. ① 경로를 고르세요.

원본과 완성 파일은 어디에 모으나요?

my-short 폴더 안에서 나눠요.

원본은 originals, 최종 MP4는 exports예요. 폴더를 만드세요.

실수로 공개하지 않고 확인할 수 있나요?

비공개로 먼저 올려 확인할 수 있어요.[Y032]

민감한 영상은 일부 공개 대신 비공개를 골라요. 공개 범위를 확인하세요.
