선택: Data API 업로드

이 실습이 끝나면 내 손에 있는 것: 선택한 API 설정과 비공개 시험·전송 결과

먼저 답부터

첫 게시에는 API가 필요 없어요. 반복 제작이 익숙해진 뒤 비공개 시험부터 하세요.

도윤 토큰을 복사해서 AI에게 설정을 맡겨도 되나요?

서진 토큰은 비밀 파일이에요. 본인 브라우저에서 권한을 확인하고 비공개로 보관해요.

오늘 처음 올린다면 실습 8이면 돼요

API는 프로그램이 내 채널에 업로드 요청을 보내는 연결이에요. 완성 MP4가 있고 첫 게시를 마쳤다면 선택하세요. 먼저 공식 업로드로 한 편을 끝내도 좋아요. API 연습 때문에 같은 영상을 중복 공개하지 마세요.

API 준비

프로젝트·동의 화면·데스크톱 인증을 준비해요

지금 하는 일

내 채널에 업로드할 프로그램의 권한을 정해요.

왜 하는지

API 키만으로 내 채널 업로드 권한을 대신할 수 없어요.

따라 하기

Google Cloud 콘솔에서 프로젝트 선택/만들기 → API 및 서비스 → 라이브러리 → YouTube Data API v3 → 사용으로 가세요.[Y037][Y038]

Google Auth Platform → Branding·Audience·Data Access를 설정해요. 개인 외부 테스트는 External + Testing을 골라요. Audience → Test users → Add users → 내 계정 → Save로 추가하고 Data Access의 필요한 권한을 확인하세요. 업로드 권한 이름은 youtube.upload예요.[Y041][Y099]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

Clients / 사용자 인증 정보 → OAuth 클라이언트 ID → 데스크톱 앱을 만들고 키트에 private 폴더를 만들고 받은 JSON을 private/client_secret.json에 저장하세요. OAuth는 비밀번호를 프로그램에 맡기지 않고 내가 정한 작업을 허용하는 로그인 방식이에요.[Y101]

현재 업로드 요청 비용은 전용 묶음에서 1 unit/호출·기본 하루 100호출이에요. 내 프로젝트의 API 할당량 화면을 직접 확인하세요. 이 수치가 내 채널의 게시 가능량을 보장하지는 않아요.[Y037][Y038][Y088]

이렇게 보이면 성공

내 프로젝트에 API 사용 상태·본인 테스트 사용자·데스크톱 JSON이 준비돼요.

이렇게 보이면?

Internal은 조직 내부용이에요. 혼자 쓰는 개인 계정이라는 뜻으로 고르지 마세요.[Y099]

비공개 인증

토큰은 브라우저 인증으로 만들어요

지금 하는 일

비밀번호·토큰을 터미널에 붙이지 않고 인증해요.

왜 하는지

토큰은 허용한 권한을 증명하는 비밀 파일이에요.

따라 하기

실습 2에서 키트를 설치했다면 같은 터미널·폴더에서 아래를 실행하세요. 선택 의존성을 설치하고 인증 도구가 브라우저를 열어요.

python -m pip install -r requirements-live.txt
python oauth_setup.py

본인이 연 브라우저에서 프로젝트·앱·계정·채널·요청 권한이 맞는지 읽고 허용하세요. 다른 앱이거나 채널이 다르면 취소해요. 받은 JSON과 생성 토큰은 private/에 두고 키트 README의 저장 위치 안내를 따라요. 토큰 문자열을 셸 명령·AI 채팅·스크린샷에 붙이지 마세요.[Y101][Y102]

비밀 토큰을 직접 입력할 단계가 없어요. 로그인·권한 승인은 본인 브라우저에서 하고 파일로 저장해요. .gitignore는 private·input·output을 제외하지만 다른 위치에 복사한 파일까지 보호하지는 않아요.[Y102]

이렇게 보이면 성공

인증 도구가 알려 준 비공개 위치에 토큰 파일이 생기고 선택한 계정을 확인했어요.

이렇게 보이면?

외부 Testing의 refresh token은 보통 7일에 만료돼요. 만료되면 예전 토큰을 안전한 곳으로 옮기고 본인 테스트 계정으로 재인증하세요.[Y042]

승인과 드라이런

먼저 검수·승인·드라이런을 해요

지금 하는 일

전송할 파일과 설정을 확인하되 아직 보내지 않아요.

왜 하는지

승인한 내용이 무엇인지 남겨야 자동화 실수를 줄일 수 있어요.

따라 하기

이 절은 키트가 만든 output/my-script가 필요해요. 편집기 MP4만 있는 사람은 실습 8을 쓰거나 키트 README대로 내 자료를 먼저 렌더하세요. 완성 MP4를 그냥 이 폴더에 덮어써서 승인하지 마세요.

script.json에서 privacyStatus는 첫 시험에 private로 정해요. selfDeclaredMadeForKids는 아동용이면 true, 아니면 false예요. containsSyntheticMedia도 실습 7의 판단으로 true/false를 정하세요. null은 미결정이라 승인되지 않아요. JSON의 true/false는 예/아니요예요.[Y014][Y037][Y363]

python run_pipeline.py render output/my-script

새 REVIEW.md 여섯 칸을 직접 확인하고 [ ]를 [x]로 고쳐 저장하세요. 그다음 아래를 실행해요.

python run_pipeline.py approve output/my-script
python upload.py output/my-script

이렇게 보이면 성공: APPROVED.json과 dry-run.json이 생겨요. 드라이런은 요청 내용만 확인하는 예행연습이에요. network_calls: 0이면 전송하지 않았어요. API 요청에는 isShorts라는 판정 스위치를 보내지 않아요. 파일 조건으로 분류해요.[Y037][Y001]

이렇게 보이면 성공

승인 파일과 전송 없는 dry-run.json을 확인했어요.

이렇게 보이면?

승인 뒤 대본·설정·MP4·검수표를 바꿨다면 다시 출력·검수·승인하세요. 단순 파일 복사로 우회하지 마세요.

선택 전송

선택: 내 계정으로 실제 전송해요

지금 하는 일

비공개 시험을 본인이 명시적으로 실행해요.

왜 하는지

기본 명령은 보내지 않으므로 실제 전송을 구분해요.

따라 하기

실습 8로 이미 공개했다면 여기서 같은 영상을 또 올리지 마세요. 별도 비공개 시험을 하려면 인증 파일·토큰·승인 폴더를 확인한 뒤 직접 실행해요.

python upload.py output/my-script --live

이 명령은 본인 채널로 실제 업로드해요. 완료 응답의 id·주소와 upload-result.json이 남으면 전송 결과를 확인하세요. 그다음 Studio에서 실제 공개 상태·처리·제한사항·Shorts 분류를 봐요.[Y032][Y037]

연결이 끊기면 같은 명령을 다시 실행해요. 키트가 저장된 세션으로 받은 위치를 조회하고 남은 부분을 보내요. 완료 기록이 있으면 새 전송을 시작하지 않아요. 세션이 만료되면 Studio에 이미 파일이 올라갔는지 먼저 확인해요. 전송 기록이 있는 폴더를 재출력하지 마세요.

확인할 점

공식 insert는 미검증 프로젝트 비공개 제한이 없다고 하지만 잠금 도움말은 제한을 설명해요. 먼저 비공개 시험으로 내 Studio 상태를 확인하세요. 잠긴 영상은 public으로 바꾸기만 해서 풀리지 않아요. 공식 업로드 또는 API 감사 안내를 따르세요. API 감사·할당량 증설은 OAuth 앱 검증과 다른 절차예요. 감사는 사용 목적·프로젝트·시연과 정책 준수 자료를 공식 양식에 제출하는 과정이에요.[Y037][Y086][Y040][Y087][Y041]

이렇게 보이면 성공

전송 응답과 Studio의 실제 상태가 모두 확인돼요. 공개 완료는 실제 공개 주소까지 확인해요.

이렇게 보이면?

인증·잠금·권리 문제를 해결하지 못했다면 실습 8 공식 경로로 돌아가요. 오류 로그를 공유할 때 토큰·세션 URL·개인 파일 경로를 가리세요.

자주 묻는 질문 5개

프로젝트와 API는 어디서 켜나요?

Cloud 콘솔의 프로젝트와 API 라이브러리에서 켜요.[Y038]

예: 내 연습 프로젝트를 선택해요. 사용 상태를 확인하세요.

동의 화면과 테스트 사용자는 어디서요?

Google Auth Platform의 Branding·Audience·Data Access예요.[Y041]

Audience의 Test users에 내 계정을 넣어요. 외부 테스트를 확인하세요.

인증 파일·토큰을 공개하지 않으려면요?

private 폴더와 Git 제외를 확인하고 비밀 값을 공유하지 마세요.[Y102]

예: client_secret.json을 공개 샘플에 두지 않아요. 브라우저 인증을 쓰세요.

업로드 한 번의 할당량과 하루 기본량은요?

전용 묶음에서 1 unit/호출·기본 하루 100호출이에요.[Y037][Y088]

실제 프로젝트는 Cloud 할당량 화면에서 보세요. 현재 값을 적어 두세요.

비공개 제한과 감사는 어떻게 다른가요?

잠금은 영상 제한, 감사는 API 서비스 정책 확인 절차예요.[Y086][Y040]

OAuth 검증도 다른 절차예요. 비공개 시험 후 Studio에서 판단하세요.
