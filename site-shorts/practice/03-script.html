AI로 기획·대본 만들기

이 실습이 끝나면 내 손에 있는 것: 검수한 내 대본·장면표·제목·설명

2026년 10월 조사 기준 · 도윤·서진과 사례는 가상이에요.

먼저 답부터

ChatGPT에 확인한 사실과 원하는 출력 틀을 주고, 읽어 본 뒤 내 대본으로 저장하세요.

도윤 AI가 써 준 대본을 바로 읽으면 되나요?

서진 원문과 내 경험을 대조한 뒤 읽어 봐요. 틀린 정보는 대본에서 먼저 고쳐요.

복사 프롬프트

ChatGPT에 복사해 대본과 장면표를 받아요

지금 하는 일

첫 문장·대본·장면·제목을 한 대화에서 만들어요.

왜 하는지

무슨 말을 어떤 화면으로 보여 줄지 함께 정해야 제작으로 이어져요.

따라 하기

실습 2의 ChatGPT 새 채팅 입력창에 아래 글을 붙여 넣으세요. 내 주제와 직접 확인한 사실, 고른 영상 유형으로 바꾸고 전송해요.[Y300][Y302]

직접 촬영·해설형은 아래 프롬프트를 써요. AI 영상 생성형은 로봇 네 샷 프롬프트·확정 예를 복사하세요. 생성형은 종이 분류 주제 대신 같은 로봇 이야기를 끝까지 써요. 실습 0의 선택은 채팅창에 자동 입력되지 않으니 유형을 직접 적어 주세요.

선택한 유형: [직접 촬영 / 얼굴 없는 해설 중 하나로 바꾸기]
독자: 처음 책상 정리를 해 보는 사람.
주제: 책상 위 종이를 지금 쓸 것 / 보관할 것 / 버릴 것으로 나누기.
내가 직접 해 본 사실: 종이를 나눈 뒤 지금 쓸 것만 책상에 남겼다.
근거 없는 효과·통계·전문가 발언은 만들지 말아 줘.
30~45초 쇼츠 초안을 써 줘. 길이는 내가 소리 내 읽고 다시 잴 거야.
1. 첫 문장(훅) 3안: 질문형 / 결과 먼저 / 행동 제안형.
2. 한 안을 골라 시작 → 직접 만든 예 → 시범 → 오늘 할 일로 대본.
3. 표: 장면 번호 / 읽을 말 / 보여 줄 장면 / 짧은 자막 / 확인할 근거.
4. 위에 적은 선택한 유형에 맞춰 줘.
5. 과장 없는 제목과 설명 초안. 사용 소재·음악 출처를 적을 자리도 남겨 줘.
없는 사실은 추측하지 말고 확인 질문으로 모아 줘.

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

답변을 읽고 훅 하나를 고르세요. 「질문형으로 하고 인사말을 빼 줘」처럼 수정 요청을 보내요. 결과는 my-short/script.txt로 옮겨요. 목표 30~45초는 이 책의 연습 길이예요.

이렇게 보이면 성공

대본 옆에 보여 줄 장면·짧은 자막·제목·설명이 있어요.

이렇게 보이면?

AI가 가격·효과·인용을 새로 만들면 지우고 내가 확인한 사실만 다시 넣으세요. 실제 뉴스라면 원문을 먼저 모으세요.

사실 확인

좋은 결과와 나쁜 결과를 가려요

지금 하는 일

내 예시와 원문을 보며 사실을 검수해요.

왜 하는지

AI가 링크를 붙여도 내가 읽은 근거와 맞는지 봐야 해요.

따라 하기

구분가상 대본 예지금 고칠 것
나쁜 결과「이 방법이면 생산성이 반드시 올라요. 전문가도 추천해요.」근거 없는 효과·전문가 말을 지워요.
좋은 결과「지금 쓸 종이만 남겨 볼까요? 저는 세 갈래로 나눴어요.」직접 찍은 분류 장면으로 보여 줘요.

사실 주장이 있으면 원출처를 직접 열고 이름·날짜·숫자·단위·대상·예외를 대조하세요. 링크가 없거나 원문을 못 찾으면 그 문장을 빼고 직접 해 본 사례로 바꿔요. 확인한 URL과 해당 부분은 rights/facts.txt에 남겨요.[Y302]

실제 뉴스·정보를 만들 독자는 예제 책상 문장을 그대로 게시하지 마세요. 내 원문 → 확인한 사실 → 내 설명의 순서로 대본을 다시 만들어요.

이렇게 보이면 성공

대본의 모든 사실이 내가 본 원문 또는 직접 한 행동으로 설명돼요.

이렇게 보이면?

「출처: 인터넷」은 확인 가능한 근거가 아니에요. 원문 주소를 저장하거나 주장을 삭제하세요.

읽고 저장

읽어 보고 저장해요

지금 하는 일

실제 읽는 시간에 맞춰 설명을 줄여요.

왜 하는지

글자 수보다 내 낭독 길이가 편집에 바로 쓰여요.

따라 하기

초시계로 끝까지 읽어 보세요. 길면 인사말·반복 설명·두 번째 예부터 빼요. 예: 「오늘은 제가 정리에 관해 알려 드리려고」를 지우고 바로 행동을 보여 줘요. 발음을 빨리 돌리는 대신 말할 내용을 줄이세요.

메모장에 붙이고 다른 이름으로 저장 → UTF-8을 골라요. 일반 대본은 script.txt예요. 키트 JSON은 파일 형식을 모든 파일로 바꾸고 script.json으로 저장해요. 확장자 표시를 켜서 .json.txt가 아닌지 확인하세요.

텍스트 편집기 → 포맷 → 일반 텍스트로 만들기 후 저장해요. script.txt로 저장하고, 키트 JSON은 .txt 자동 추가를 끄고 script.json인지 확인하세요.

장면표에는 읽을 말과 화면 자막을 따로 둬요. 예: 읽을 말 「지금 필요한 종이만 남겼어요」 / 자막 「지금 쓸 것만」 / 장면 「정리된 책상」이에요.

이렇게 보이면 성공

내가 읽은 길이와 장면표가 script.txt에 저장됐어요.

이렇게 보이면?

시간이 넘으면 끝 문장을 잘라 버리지 말고 대본을 줄인 뒤 다시 읽어요. 서식 문서라면 일반 텍스트로 다시 저장하세요.

자동화·무료 대안: shorts-kit

선택 키트는 내 대본을 JSON으로 받아요. JSON은 이름과 값을 짝지은 텍스트예요. 키트가 만든 형식을 유지하려면 아래 명령으로 프롬프트와 예제를 먼저 만들어요.

python run_pipeline.py run --mode prompt --output output/my-script

output/my-script/prompt.md를 열어 내 주제로 바꾸고 ChatGPT에 붙여 넣어요. 답변 중 JSON만 output/my-script/script.json에 저장하세요. 위 일반 표를 그대로 이 파일에 붙이지 마세요. hooks 후보만 고치면 실제 첫 장면은 안 바뀌어요. 선택한 말을 첫 scene의 title·narration·subtitle에도 옮기세요.

python run_pipeline.py validate output/my-script
python run_pipeline.py render output/my-script

이렇게 보이면 성공: 대본 형식 확인 완료가 나오고 새 MP4와 미리보기가 생겨요. 형식 검사는 사실 확인이 아니에요. 다음부터 이 경로를 골랐다면 계속 output/my-script를 쓰세요. 동봉 연습은 output/first예요.

자주 묻는 질문 5개

AI 채팅에 처음 무엇을 붙이나요?

독자·주제·직접 확인한 사실과 출력 틀을 붙여요.

예: 책상 정리의 세 갈래예요. 복사 프롬프트를 내 주제로 바꾸세요.

짧게 줄일 때 어느 문장을 지우나요?

인사말·반복·두 번째 예부터 지워요.

「오늘은 알려 드리려고」를 지우고 행동으로 시작해요. 다시 읽어 시간을 재세요.

모르는 사실은 어떻게 확인하나요?

기관 발표나 원문을 직접 열어 대조해요.

예: 숫자의 단위·적용 대상을 비교해요. 근거가 없는 문장은 빼세요.

장면·자막 메모는 어디에 적나요?

대본 옆 장면표의 별도 칸에 적어요.

읽을 말과 「지금 쓸 것만」 자막을 나눠요. 장면 예를 따라 적으세요.

읽어 보니 시간이 넘으면요?

말을 빨리 하지 말고 설명을 줄여 다시 읽어요.

예: 두 번째 사례를 빼세요. 낭독 길이를 메모해요.
