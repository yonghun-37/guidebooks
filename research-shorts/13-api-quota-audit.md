## 핵심 사실

- **YT-067** 현행 videos.insert는 업로드 전용 버킷 1unit/호출·기본 100호출/일이다. search.list도 별도 100호출이며 나머지 엔드포인트는 합계 10000units/일이다. [Y037](SOURCES.md#y037) [Y038](SOURCES.md#y038) [Y088](SOURCES.md#y088) — 현재 본문 확인.
- **YT-068** 변경 이력은 2025-12-04 업로드 비용 1600→약100units, 2026-06-01 업로드·검색의 별도 버킷 전환을 기록한다. 과거 비용으로 현행 업로드 횟수를 계산하지 않는다. [Y039](SOURCES.md#y039) — 이력확인.
- **YT-069** 2020-07-28 뒤 생성된 미검증 프로젝트의 비공개 잠금·감사 해제 정책은 변경 이력에 있다. 현재 insert 본문은 비공개 제한이 없다고 하지만 한국어 잠금 도움말은 제한을 계속 설명한다. [Y039](SOURCES.md#y039) [Y037](SOURCES.md#y037) [Y085](SOURCES.md#y085) [Y086](SOURCES.md#y086) — 상충·해제 시행일 미확인.
- **YT-070** API 감사·할당량 증설과 OAuth 동의 화면 검증은 다른 절차다. 감사 안내는 API 사용 목적·정책 준수 정보와 증설 양식으로 연결된다. [Y040](SOURCES.md#y040) [Y041](SOURCES.md#y041) — 확인.
- **YT-071** insert는 privacyStatus·publishAt·selfDeclaredMadeForKids·containsSyntheticMedia를 지원한다. 쇼츠 판정은 파일의 비율·길이에 따르며 isShorts 필드를 보내는 방식이 아니다. [Y037](SOURCES.md#y037) [Y001](SOURCES.md#y001) — 지원필드·판정확인.
- **YT-072** 비공개 잠금 도움말은 미검증 API로 잠긴 영상의 항소를 허용하지 않고 검증된 서비스/공식 앱 재업로드 또는 API 감사를 안내한다. 단순 private 설정을 public으로 바꾸는 것과 다르다. [Y086](SOURCES.md#y086) — 직접 본문 확인.
- **YT-073** 감사 양식은 요청 유형, 조직·연락처, API 클라이언트, 사용 사례와 증빙을 요구한다. 추가 할당량 감사/재감사 항목을 확인했으며 실제 제출은 하지 않았다. [Y087](SOURCES.md#y087) — 직접 본문 확인.

## 수치·비교 표

| 시점/영역 | 업로드 비용·기본량 |
|---|---|
| 과거 | 1600units/건 |
| 2025-12-04이력 | 약100units/건 |

## 한국 가용성

한국 학습자가 본인 Google 프로젝트와 OAuth로 설정하는 선택 실습이다. 이번에는 프로젝트 생성·인증·실업로드를 하지 않았다.

## 불확실·상충과 권장 결론

비공개 잠금은 현재 공식 문서끼리 상충한다. Hermes가 ?hl=en에서 잠금 문구를 받았지만 Codex가 나중에 열자 기본 URL과 같은 제한 없음 문구였다. 언어만으로 해결되는 차이가 아니다. 해제 시행일은 찾지 못했다. 실습은 명시적 private+드라이런, 실제 공개 완료는 공식 UI로 안내한다. 이미 잠긴 영상은 단순 공개 전환으로 해제된다고 쓰지 않는다. API 100호출도 채널의 실효 게시 한도를 보장하지 않는다.

## 교과서 반영 포인트

실습9는 선택이다. 프로젝트 준비→OAuth 테스트 사용자→범위 승인→메타데이터/파일 확인→드라이런→사용자 실행을 분리한다. API 감사의 실제 순서는 Y040의 안내와 Y087 양식에서 프로젝트 정보·사용 목적·시연 자료·정책 준수 설명을 준비한 뒤 사용자가 제출하는 것이다. OAuth 앱 검증 통과를 API 감사 통과로 쓰지 않는다. 공개 URL 확보가 목표라면 공식 Studio 업로드를 먼저 마친다.
