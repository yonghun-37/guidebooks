## 핵심 사실

- **YT-080** 2025-03-31부터 쇼츠 공개 조회수는 최소 시간 없이 재생/재재생 시작을 센다. 기존 기준은 engaged views이며 한국어 도움말에서는 유효 조회수로 안내한다. [Y034](SOURCES.md#y034) — 확인.
- **YT-081** 2026-08-27 API 이력은 모든 형식의 공개 조회수 집계 정렬과 engaged 지표 유지를 설명한다. 가입·수익 기준의 qualified/engaged 지표를 확인해야 한다. [Y039](SOURCES.md#y039) [Y056](SOURCES.md#y056) — 변경확인.
- **YT-082** 피드에 표시된 횟수는 쇼츠 피드 노출 횟수다. 일반 썸네일 노출/클릭률과 같은 분모로 취급하지 않는다. [Y045](SOURCES.md#y045) — 확인.
- **YT-083** 계속 시청/스와이프는 머물거나 넘긴 비율이다. 평균 시청 시간은 머문 시청의 시간, 평균 조회율은 영상 길이에 대한 평균 비율로 함께 읽는다. [Y056](SOURCES.md#y056) — 정의확인.
- **YT-084** 지속시간 곡선은 재시청 구간의 상승·건너뛴 구간의 하락을 보여 준다. 보통 처리에 1~2일이 걸리며 급상승은 이해가 안 돼 다시 본 경우일 수도 있다. [Y046](SOURCES.md#y046) — 확인.
- **YT-085** 전 형식 재생 시작 조회수 통일의 시행일은 2026-08-24다. 공식 블로그는 08-19, API 변경 이력은 08-27로 발표/기록일이 다르며 수익·가입의 유효 지표는 유지한다. [Y089](SOURCES.md#y089) [Y090](SOURCES.md#y090) [Y039](SOURCES.md#y039) — 직접 본문 확인.

## 수치·비교 표

| 기록할 지표 | 목적 |
|---|---|
| 공개 조회수·유효 조회수 | 시작재생과머문재생구분 |
| 피드에표시된횟수 | 노출기회관찰 |
| 계속시청/스와이프 | 첫화면선택관찰 |
| 평균 시청시간·평균 조회율 | 머문뒤길이/비율관찰 |
| 수익탭RPM | 수익자격후기간/분모맞춤 |

가상읽기예: 30초영상의평균 시청시간24초면80%(24÷30×100). 높은비율하나로노출보장을예측하지않는다.

## 불확실·상충과 권장 결론

유효 조회수(engaged views, 참여 조회수)와 YPP가 인정하는 qualified Shorts views는 화면·용도가 다를 수 있다. 가입 진척은 수익 창출에서 확인한다. 2026-08-24는 참여도 도움말이 명시한 시행일이고 08-27은 API 이력 날짜다. 시청 선택 비율을 유효 조회수÷공개 조회수로 계산하지 않는다. 짧은 첫 영상에는 모든 곡선 카드가 나타나지 않을 수 있다.
