# 직접 만든 무음 쇼츠 예제

`preview.html`을 열고 장면 버튼으로 첫 화면·자막·끝 장면을 확인하세요. 자체 타이틀과 가상 책상 정리 대본으로 만든 무음 영상이에요. 도윤·서진은 가상 인물이에요.

- `short.mp4`: 36초·1080×1920·30fps·H.264/AAC. 이 키트의 기본 출력값이에요.
- `subtitles.srt`: 대본에서 만든 시간·자막. 같은 글자가 MP4에도 구워져 있어요.
- `script.json`: 대본과 메타데이터 예제. 아동용·AI 공개 판단은 비워 두었어요.
- `video-info.json`: 실제 파일 규격·장면 시간·무음 상태예요.

이 샘플 폴더 전체는 10MB보다 작아요. 승인·인증 기록은 들어 있지 않아요. 직접 검수하려면 상위 [README](../README.md)를 따라 새 결과 폴더를 만드세요. 샘플 대본을 재사용하려면 새 결과 폴더의 script.json에 복사하고 render 명령으로 출력해요.

직접 그린 도형·직접 쓴 가상 대본이며 타인의 영상·음악이나 플랫폼 로고·UI를 사용하지 않았어요. 자체 생성 샘플은 [MIT](../LICENSE), 렌더링한 글꼴은 [OFL](../assets/fonts/OFL.txt)이에요.
