# BlogBook 출처 목록

접근일: **2026-10-26 · 2026년 10월 조사 기준**. B번호는 이 책 전용이며 기존 릴스·쇼츠 출처번호와 다르다. 출처의 공식성·실제 확인 수준·적용 범위를 함께 읽는다.

- **A**: 해당 정책·기능·가격을 정하는 기관/사업자의 원문. 공식 문서끼리 상충할 수도 있다.
- **B**: 독립 조사·신뢰할 만한 튜토리얼. 국가·표본·방법·날짜에 따른 한계를 보존한다.
- **C**: 개인 실적·커뮤니티 질문. 실제 고민/개인 관측의 자료이며 공식 정책·대표 평균의 근거로 쓰지 않는다.
- **직접 본문 확인**: Codex가 웹 도구 또는 다운로드·텍스트 추출로 해당 설명을 확인했다. **Hermes**: 원응답에서 원문/검색을 구분한 근거를 확보했으나 Codex의 추가 직접 확인 수에는 넣지 않는다.
- **기존 조사 재사용**: `research/ai-production.md`·`ai-models-pricing.md`·`SOURCES.md`의 확인 결과를 읽어 활용했다. 이번 새 직접 확인 건수에서 제외한다. **확인 대기·실패·검색 본문**을 검증 완료로 취급하지 않는다.

날짜 미표기는 2026년 갱신이라는 뜻이 아니다. 파일명에 날짜가 있어도 공표된 개정일과 구별한다. 로그인·실제 결제·게시/API 호출은 하지 않았다. [공식 출처 직접 확인표](../docs/results/phase-B2-source-checks.md)와 [질의 품질표](../docs/results/phase-B2.md)를 함께 본다.
