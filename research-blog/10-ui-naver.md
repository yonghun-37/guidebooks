## 모바일 경로

개설은 공식 앱의 ‘블로그 아이디 만들기’까지 확인된다. 글쓰기는 보통 **연필/글쓰기 → 제목·본문 → 사진 → 다음/발행 → 공개 범위·발행**과 같은 이름이지만 **현재 앱의 정확한 버튼 위치·최종 문구·예약 설정은 미확인**이다. 모바일과 PC가 같은 레이아웃이라고 쓰지 않는다. 사진 접근 권한이 필요하면 필요한 사진에만 허용하고, 발행 후 공유 주소와 전체 공개 상태를 확인한다. 공식 기능 도움말 [B001](SOURCES.md#b001) [B048](SOURCES.md#b048) [B163](SOURCES.md#b163).

막히면 앱 업데이트·권한·로그인 계정을 확인하고 PC 공식 편집기로 전환한다. ‘미리보기’라는 단일 기능을 전제로 만들지 않는다. ONE 미지원 도움말은 전체 미리보기·장문 맞춤법·HTML 기능의 제한을 설명하며, 모바일 보기 관련 UI와 범위를 구분해야 한다. [B047](SOURCES.md#b047)

## 애드포스트: 가입 → 미디어 검수 → 광고 설정 → 지급

1. **PC** 애드포스트에서 시작한다. 개인 가입은 만19세 이상 등 조건을 확인하고 실명·본인확인과 약관 절차를 진행한다. 가입 완료가 블로그 광고 승인 완료는 아니다. [B018](SOURCES.md#b018) [B022](SOURCES.md#b022)
2. `미디어 관리 → 미디어 등록 → 네이버 미디어 → 블로그 → 주제` 순서로 검수 신청한다. 결과 상태와 사유를 확인한다. 블로그 검수 안내는 최대5영업일이며 ‘90일·50글·일100명 보장’으로 쓰지 않는다. [B023](SOURCES.md#b023)
3. 승인되면 `내 블로그 관리 → 메뉴·글·동영상 관리 → 애드포스트 설정 → 사용`을 확인한다. 공식 도움말의 메뉴 경로이며 계정별 현재 화면 검증은 아니다. [B022](SOURCES.md#b022)
4. 지급 설정에서 본인 계좌 인증·자동 지급·최소 지급액·세금 상태를 확인한다. 개인 정기 지급 설정 범위는5만~1천만원, 보통25일 지급이다. **Npay 머니 전환은 별도 경로**로100원 단위·1회 최대5만원·다음달12일 조건을 확인한다. 포인트와 머니를 혼용하지 않는다. [B019](SOURCES.md#b019) [B020](SOURCES.md#b020) [B085](SOURCES.md#b085)

## 오류 대응·한국 가용성·집필 반영

공개 주소가 타인에게 안 보이면 비공개/이웃 공개와 실제 발행 여부를 먼저 본다. 검색이 안 되면 즉시 저품질로 단정하지 말고 검색 허용·처리 시간·공식 제한 기준을 확인한다. 계좌명 불일치·지급 보류는 실제 정산 도움말과 문의로 해결하고 광고를 직접 눌러 시험하지 않는다.

실습1 개설, 실습6 편집, 실습7 **오늘 전체 공개**, 실습9 조건부 애드포스트 순으로 연결한다. 계정2단계 인증은 네이버ID 보안 설정의 공식 안내를 찾아 적용하도록 권장하되, 이번에 잘못 리디렉트된 도움말을 검증된 상세 경로로 싣지 않는다.
