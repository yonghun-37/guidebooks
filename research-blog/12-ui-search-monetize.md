## 먼저 플랫폼 분기

**네이버 블로그에는 서치어드바이저 등록 과제를 주지 않는다.** 네이버 서비스는 별도 웹마스터도구 연동이 필요 없으며 `blog.naver.com/내아이디`는 독립 호스트가 아니다. 자동 수집 대상이어도 모든 글의 노출이 보장되는 것은 아니다. 외부 사이트의 연관 채널로 네이버 블로그를 연결하는 것은 별개다. [B173](SOURCES.md#b173) [B174](SOURCES.md#b174)

아래 메뉴는 공식 한국어 도움말 기반이다. 실제 로그인·가입·소유확인·심사 요청을 실행하지 않았다. 버튼 배치나 접힌 항목이 확인되지 않으면 **보통 이런 이름**으로 안내하고 해당 공식 문서를 함께 연다.

## 외부 사이트: 네이버 서치어드바이저

1. `서치어드바이저 → 웹마스터 도구 → 사이트 관리/사이트 등록 → 주소 입력 → 추가`와 같은 흐름으로 이동한다. 호스트 주소를 입력한다. 사이트 관리·추가 명칭 일부는 공식 검색본문 확인 수준이다.
2. **HTML 태그** 방식을 선택해 계정에 발급된 메타태그를 첫 페이지의 `<head>` 안에 넣는다. 글 본문에 붙이지 않는다. HTML을 편집할 권한이 필요하다.
3. **소유확인**을 눌러 결과를 확인한다. 대안은 HTML 확인 파일을 사이트 루트에 올리는 방식이며, 티스토리 본문 첨부와 다르다.
4. 소유확인한 사이트에서 **요청 → RSS 제출 / 사이트맵 제출**을 연다. 실제 서비스가 제공하는 주소를 입력한다. 티스토리는 `/sitemap.xml` 자동 생성 경로를 먼저 확인한다.
5. 제출 목록·수집/색인 현황을 확인한다. 제출 성공과 검색 노출은 별개다. 태그·피드가 외부에서 열리는지, 등록한 프로토콜·호스트가 맞는지 확인한다.

[B174](SOURCES.md#b174) [B175](SOURCES.md#b175) [B176](SOURCES.md#b176) [B184](SOURCES.md#b184)

소유확인은 JS가 뒤늦게 삽입하는 태그에 의존하지 않는다. HTML 원문에서 실제 태그를 확인한다. 네이버 도움말의 리디렉션301 안내와 FAQ의301/302 안내가 달라 최종 서비스 주소를 등록하는 경로를 기본으로 권한다. 등록은 외부 사이트가 검색에 반영되는 절대 필수조건도 아니다. [B175](SOURCES.md#b175)

## Google Search Console

| 단계 | 입력·행동 | 학습자 확인 기준 |
|---|---|---|
| Google 계정 로그인 → 속성 선택기 → **+ 속성 추가** | 독립 도메인 관리 권한이 있으면 도메인, 티스토리 기본 주소 등은 **URL 접두사 속성** | 범위·프로토콜·주소가 내 블로그와 일치 |
| 도메인 속성 | `example.com` 형태, DNS 레코드로 확인 | DNS 제공업체 화면은 업체별로 다름 |
| URL 접두사 속성 | `https://내블로그.tistory.com/` 형태, HTML 태그 등 지원 방식 | 등록한 페이지의 `<head>`에서 확인 태그 검출 |
| **사이트맵** | 실제 사이트맵 URL 제출 | 제출 상태·오류 확인 |
| 상단 **URL 검사** | 내가 발행한 글의 전체 URL | 색인·수집 상태 확인, 필요하면 **색인 생성 요청** |

[B177](SOURCES.md#b177) [B035](SOURCES.md#b035) [B178](SOURCES.md#b178)

티스토리에서는 `블로그 관리 → 플러그인 → Google Search Console → 계정 연결하기 → Google 권한 → 적용`의 공식 경로가 있다. 자동 사이트맵 제출을 안내했던2020 공지이며 현재 로그인 화면 배치는 미확인이다. 계정 연결과 애드센스 심사는 서로 다른 기능이다. [B183](SOURCES.md#b183)

Blogger는 동일 관리 Google 계정에서 속성이 이미 있는지 먼저 확인한다. 자동 추가·소유확인 관련 공식 접힘 문구는 검색본문으로 보완했으며 모든 오래된 블로그·맞춤 도메인에 무조건 적용된다고 하지 않는다. [B035](SOURCES.md#b035)

`URL이 Google에 등록되어 있음`도 실제 검색 노출을 보장하지 않는다. 요청의 고정 일일 횟수나 ‘24시간 내 검색’은 이번 근거로 확정하지 않는다. [B178](SOURCES.md#b178)

## 일반 사이트 애드센스 가입·연결

1. 애드센스 공식 **시작하기**→Google 로그인→사이트 URL 또는 **아직 사이트가 없습니다**→도움말 수신 여부→수취 국가·지역→약관→**애드센스 사용 시작**. 수취 국가·지역은 나중에 변경할 수 없다는 공식 안내를 확인한다. [B179](SOURCES.md#b179)
2. 실제 지급받을 주소·연락처 등 결제 정보를 입력한다. 개인/사업자 유형과 실제 수익자 정보가 일치해야 한다. 구체 입력 카드의 현재 배치는 미확인이다.
3. **사이트 추가 → URL → 저장 → 애드센스에 사이트 연결 → 시작**과 같은 경로에서 안내된 확인 방법을 선택한다. 코드 스니펫/메타태그는 `<head>`, ads.txt는 루트 경로다. 세 가지를 전부 해야 한다는 뜻은 아니다. [B180](SOURCES.md#b180)
4. 완료 확인→**검토 요청**, 사이트 카드의 상태를 기록한다. 코드 설치·신청·승인·광고 게재는 다른 상태다. 며칠에서2~4주가 걸릴 수 있다는 안내를 승인 보장 기한으로 바꾸지 않는다. [B180](SOURCES.md#b180)
5. 거절되면 원본 가치·탐색·정책·크롤러 접근·코드·중복 계정 중 실제 사유를 확인하고 고친 뒤 재검토한다. 글수만 늘리거나 새 계정을 반복 생성하지 않는다. [B181](SOURCES.md#b181) [B027](SOURCES.md#b027)

Blogger는 `관리 → 수입 → 애드센스 계정 만들기`의 호스트 경로를 우선한다. 티스토리는 공식 과거 공지의 `블로그 관리 → 수익 → Google AdSense → 연동하기 → Google 로그인 → 허용`을 참고하되, 연동 버튼만으로 사이트 심사가 자동 합격한다고 쓰지 않는다. [B182](SOURCES.md#b182) [B185](SOURCES.md#b185)

한국어 연령 안내18/19세 상충, USD100달러 지급 기준, 계좌·인증·세금 보류는 [광고 노트](02-ads-revenue.md)에서 확인한다.

## 쿠팡 파트너스 가입·활동 페이지·승인

공식 최신 발견 PDF 표지는2024.12, 파일명에는20260917이 들어 있다. 파일명만으로 정책 개정일을 확정하지 않는다. 아래는 PDF 절차를 확인한 것이며 실제 가입한 결과가 아니다. [B093](SOURCES.md#b093)

1. 공식 사이트 **회원가입**→사업자 유형 선택. 개인·개인사업자/세금계산서 여부를 실제 상태대로 고른다.
2. 연락받을 전화번호·이메일, 링크를 게시할 **활동 페이지 URL**을 등록한다. 본인 글을 확인할 수 있는 정확한 주소를 쓴다.
3. 사용할 매체에 제휴 링크와 공식 대가성 문구를 올리고, 요구되는 활동 화면·관련 자료를 준비한다. 공정위 기준에 맞춰 제목 또는 첫 부분에 분명히 표시한다.
4. 가이드상 **판매금액15만원**은 최종승인 검토 기준이며 수익15만원이나 자동 합격이 아니다. 본인 구매 등 제외 실적을 합격 수단으로 쓰지 않는다.
5. 최종승인·지급정보·필요 서류와 정산 상태를 확인한다. 월1만원 이상 지급 조건과 다다음달15일 일정은 발생월·확정·휴일 조건을 함께 읽는다.

## 실패 대응·교과서 반영

외부에서 글을 못 읽으면 공개 범위·로그인 제한부터, 태그를 못 찾으면 `<head>`와 실제 HTML부터, 광고가 안 보이면 승인·정책·차단 프로그램부터 확인한다. 빈 RSS는 공개글을 먼저 발행한다. 네이버 학습자는 실습8에서 ‘별도 등록 불필요’를 확인하고 검색 허용·공개 주소 점검으로 끝내며, 외부 사이트 학습자만 소유확인·사이트맵을 수행한다. 실습9는 미승인 상태에서 유료 대행이나 허위 정보를 요구하지 않는 조건부 과제로 만든다.
