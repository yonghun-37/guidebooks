## Meta: 공식 API로 올려도 콘텐츠 규칙은 적용

Meta 플랫폼 약관(2026-02-03 수정 표시)은 허용된 API·권한·문서 요구 준수, 타인 권리 보호, 사용자 데이터 보안과 토큰/앱 시크릿 보호, 위반 시 앱·계정 접근 제한을 설명한다. 공식 API를 써도 권한을 우회하거나 데이터·콘텐츠를 무제한 재사용할 수 있다는 허가가 아니다. [A068](SOURCES.md#a068)

자동화 운영에서 피할 것: 허위 참여·가짜 계정/사칭, 같은 게시물·댓글·홍보의 무차별 반복, 권한 없는 수집, 출처를 숨긴 재게시, 제한을 피하려는 계정/토큰 순환. 공식 데이터 접근 문서는 별도 서면 허가가 없으면 Platform API를 통해 접근하도록 설명한다. 이는 데이터 접근 근거이며 모든 예약 게시 금지로 확대하지 않는다. [A159](SOURCES.md#a159). 위 항목은 ‘하루 몇 개면 안전’한 임계값을 뜻하지 않는다. 실제 게시 오류에도 스팸 의심 활동·제한 계정 코드가 있다. [A009](SOURCES.md#a009)

> 확인할 점: Instagram Community Guidelines·Spam·Inauthentic Behavior의 이번 직접 HTTP 응답 일부는 제목뿐이었다. 조항 전체를 직접 검증했다고 표시하지 않는다. 기존 `research/r2-failures.md`의 약관 부분 근거와 보충 Hermes의 확인 범위를 구분한다. 보충 Hermes는 Community Guidelines 부분 본문/발췌, Spam 금지 항목 본문, Inauthentic Behavior 부분 본문을 보고했다. 인위적 참여·반복 상업 연락·수동/자동의 극고빈도 활동과 기만적 네트워크를 다룬다는 근거로 한정한다. [A158](SOURCES.md#a158). 공식 API **사용 자체**가 유기적 도달을 높이거나 낮춘다는 비교 근거는 확보하지 못했다. 수치·차별 없음 보장 모두 쓰지 않는다. [A069](SOURCES.md#a069) [A138](SOURCES.md#a138) [A139](SOURCES.md#a139)

## YouTube 2025~2026

- 2025-07-15: `repetitious content`를 `inauthentic content`로 바꾸고 반복·대량생산 포함을 명확히 한 변경이다. 새로 AI 전체를 수익화 금지한 날이 아니다.
- `reused content`는 기존 온라인 소재를 실질적 해설·변형·교육/오락 가치 없이 재사용하는 문제이며 위 변경과 별도다. 저작권 허락이 있어도 수익화의 독창성 요건을 자동 충족하지 않는다.
- 현행 예시에는 설명/교육 가치가 적은 슬라이드쇼·스크롤 텍스트, 거의 같은 이야기 템플릿, 독창적 관점 없는 AI 대량 템플릿이 포함된다. **이미지+TTS라는 형식 자체**와 가치 없는 반복을 동일시하지 않는다. [A070](SOURCES.md#a070)
- 스팸·기만·사기 정책은 무차별 반복·오해를 부르는 메타데이터 등에도 적용된다. ‘daily upload’와 스팸 판정은 같은 단어가 아니다. [A103](SOURCES.md#a103)
- 2026-01-21 CEO 공식 글은 저품질 AI·반복·클릭베이트 확산을 줄이는 기존 시스템의 강화와 사실적 AI 공개·유해 합성물 제거 방침을 설명한다. 이를 모든 AI 채널 삭제 발표로 쓰지 않는다. [A105](SOURCES.md#a105)

## 실제 제재 사례

**Screen Culture·KH Studio**: 2025-12-18 TheWrap은 YouTube가 두 채널의 반복 정책 위반에 따른 종료를 확인했다고 보도했다. AI 가짜 영화 예고편·오인 가능 표시 문제의 사례다. 조회수·매출 추정은 비용표에 쓰지 않는다. 이 사례를 2026년 새 AI 전면금지나 ‘AI 사용만으로 삭제’의 증거로 바꾸지 않는다. [A128](SOURCES.md#a128)

이 사건은 플랫폼 관계자 확인을 인용한 언론 보도(B)이며 조사자가 원래 채널/수익 계정을 감사한 것은 아니다. 2026-01-28 The Verge는 Kapwing이 지목한 채널 중 11개가 스팸·기만·사기 정책 위반으로 제거됐다는 YouTube 대변인 확인을 보도했다. 별도1개는 YPP 정지이며 나머지 비공개/이름 변경/운영자 삭제와 구분한다. 연구 목록 전체가 YouTube 제재 목록이라는 뜻은 아니다. [A161](SOURCES.md#a161)

## AI 표시와 API 필드

| 최종 콘텐츠 | 권장 판단 | API 처리 |
|---|---|---|
| LLM로 아이디어/문안/자막만 보조 | 도구 사용만으로 사실적 합성 영상과 같은 의무로 묶지 않음 | 최종 영상/음성의 사실성 판단을 승인에 저장 |
| 실제같은 사건·장소·인물 행동/타인 음성을 생성·변형 | 플랫폼 공개 요구 확인·표시 | Instagram `is_ai_generated`, YouTube `status.containsSyntheticMedia` |
| 비현실 일러스트·경미한 보정 | YouTube의 불필요 예시와 사실적 합성 구별 | 무조건 모든 AI필드 false라는 규칙도 만들지 않음 |
| AI 생성 음악·일반 TTS | 서비스 약관의 음성 고지와 플랫폼 공개 요건을 각각 판단 | YouTube 음악 공개 예시 적용·Instagram 음악/공개 필드 경로 확인 |

Instagram API 필드는 A006·A011, Meta 표시 정책은 기존 AI 제작 노트와 A154, YouTube 공개 범위는 A071, status 이름은 A020, OpenAI TTS 고지는 A040을 따른다. 캐러셀은 부모 컨테이너에 AI 필드를 넣는다. 협찬은 AI 표시로 대신할 수 없으며 별도 경제적 이해관계·파트너십 표시를 확인한다.

YouTube 공식 도움말은 **AI 공개 자체로 시청자 도달을 제한하거나 수익화 자격을 떨어뜨리지 않는다고 설명**한다. 이것은 콘텐츠가 다른 정책을 위반해도 면제된다는 뜻이 아니다. [A071](SOURCES.md#a071). Instagram에 같은 문장을 옮길 공식 비교 근거는 확보하지 못했다.

## 위험을 줄이는 운영안

원문 링크·팩트체크 → 권리 있는 소재 → 승인된 문안/파일 해시 → AI·협찬·아동용·공개범위 판단 → 계정별 한도 → 발행 ID 저장 → 게시 상태와 분석 확인을 둔다. 뉴스·건강·금융·실제 인물/재난 소재는 모델이 만든 사실/사진을 실제 증거로 쓰지 않는다. 같은 템플릿에도 매 편 독자에게 줄 정보·해설·원본 검증을 추가한다. 실패 때 중복 발행·토큰 순환으로 제한을 우회하지 않는다. 유출 대응은 [승인·보안](approval-security.md)을 따른다.

한국 정책 적용·라벨의 실제 표시·수익화 승인은 로그인해 시험하지 않았다. A0/A1/A5/A9에 반영한다.
