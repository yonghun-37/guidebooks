STEP 01 · 예약 가능한 화면 찾기

예약 가능한 화면 찾기

지금 하는 일

필요한 표시를 유지하며 예약할 수 있는지 확인해요.

왜 하는지

예약 기능이 보인다는 이유만으로 모든 콘텐츠를 처리한다고 가정하지 않아요.

따라 하기

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. 현재 앱 도움말은 공개 계정·최대 30일 전·하루 25개를 안내해요. 먼저 게시물 하나를 예약해 보세요.[S037]
  2. 앱에서 파일·캡션을 준비한 뒤 옵션 더 보기 → 이 게시물 예약 / 이 릴스 예약 → 날짜·시간 → 완료 → 돌아가기 → 예약을 눌러요.[S037]
  3. PC에서는 Business Suite의 게시물 만들기 → 게시할 위치에서 Instagram → 예약 옵션 → 날짜·시간 → 예약을 사용해요.[S040]
  4. 대상 계정·현지 날짜·시각·필수 표시를 확인하고 저장하세요. 앱이나 Suite에 저장된 예약은 PC를 꺼도 실행돼요. 예약 뒤에는 목록에서 저장된 항목을 다시 확인해요.[S037][S040]

공식 한국어 도움말 · 옵션 더 보기 → 이 게시물 예약 / 이 릴스 예약에서 시작해요.[S037]

공식 데스크톱 도움말 · 게시물 만들기 → 게시할 위치: Instagram → 예약 옵션 → 예약. 페이지 미연결 프로페셔널 계정으로 접근하는 경로도 있어요.[S038][S040]

확인할 점

75일은 과거·검색 자료에 남은 값이에요. 현재 본문값 30일을 기준으로 삼고 내 화면을 확인하세요. 시간대와 AI·협찬·음원 조합이 맞지 않으면 수동으로 게시하세요. 앱 한도를 Suite 한도로 옮기지 마세요.[S037]

이렇게 보이면 성공

선택한 계정의 예약 목록에 의도한 파일과 날짜·시각이 보여요. 필수 표시도 유지돼요.

이렇게 보이면?

  • 필수 라벨·음원 지원이 불명확하면 예약하지 말고 실습 7로 돌아가세요.
  • 저장됐는지 모를 때 새 예약을 반복하지 말고 목록부터 확인하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 02 · 예약 목록과 취소 경로 확인

예약 목록과 취소 경로 확인

지금 하는 일

예약한 항목을 다시 찾아 수정·취소 가능 여부를 확인해요.

왜 하는지

잘못된 시간이나 중복 예약을 발견할 수 있게 해요.

따라 하기

  1. 앱은 만들기 → 게시물/릴스 → 예약됨에서 목록을 열어요. 대상 콘텐츠의 옵션 → 게시물 수정 / 일정 조정 / 삭제 / 지금 공유하기 중 필요한 항목을 고르세요.[S037]
  2. Suite는 대상 Instagram 계정을 고른 뒤 플래너 → 예약 콘텐츠 → 옵션 → 일정 변경 / 삭제로 관리해요.[S257]
  3. 변경 뒤 목록에서 시각·상태를 다시 확인하세요. 예약 시각이 지나면 실제 게시물의 내용·표시를 확인하고 주소를 기록해요.

공식 한국어 도움말 · 예약됨 → 옵션 → 일정 조정 / 삭제예요. Suite는 플래너에서 관리해요.[S037]

확인할 점

삭제 후 초안이 남는다고 가정하지 마세요. 원본 파일과 캡션을 보관한 뒤 삭제하세요.

이렇게 보이면 성공

변경·삭제한 예약의 목록 상태를 확인했어요. 예약 시각 뒤에는 실제 게시 여부도 기록해요.

이렇게 보이면?

  • 목록이 안 보이면 예약 도구·대상 계정·날짜 필터를 확인하세요.
  • 예약 시각이 지나도 게시물이 없으면 실패 상태부터 확인하고 중복 업로드를 피하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 03 · 자동 실행의 경계 정하기

자동 실행의 경계 정하기

지금 하는 일

생성·검수·게시·갱신을 별도 작업으로 구분해요.

왜 하는지

검수와 토큰 만료를 건너뛴 자동화를 만들지 않기 위해서예요.

따라 하기

  1. 키트는 예약 서비스·호스팅·토큰 자동 갱신을 제공하지 않아요. PC가 꺼져 있으면 로컬 프로그램도 실행되지 않아요.
  2. 자동화를 계획할 때는 생성 → 사람 검수 대기 → 승인한 자료만 전송으로 나누세요. 승인 명령은 드라이런이에요.
  3. 미발행 컨테이너는 24시간 뒤 만료돼요.[S004] 먼 미래 예약을 위해 미리 생성하지 마세요. 예약은 앱이나 Suite에 저장하세요.

이렇게 보이면 성공

예약 기록에 검수·시간대·취소·게시 확인이 포함되고, 키트가 제공하지 않는 기능을 구분했어요.

이렇게 보이면?

  • 승인 없이 전송하는 자동화를 만들지 마세요.
  • 발행 응답 유실 뒤 전체 파이프라인을 다시 돌리기 전에 기존 게시 상태를 확인하세요.
