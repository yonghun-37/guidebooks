STEP 01 · 연습용 테스트 계정 만들기

연습용 테스트 계정 만들기

지금 하는 일

기존 계정을 쓸지 연습용 새 계정을 만들지 결정해요.

왜 하는지

실수한 게시물이 본계정에 올라가지 않게 대상부터 구분해요.

따라 하기

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. 사용자 이름과 소개를 정하세요. 예: 소개에 “콘텐츠 제작 연습 계정”이라고 적어요.
  2. 방법 A · 기존 계정에서 추가: 프로필 → 상단 프로필 이름 → Instagram 계정 추가 → 새 계정 만들기를 누르세요.[S203]
  3. 앱의 가입 안내에 따라 연락처를 인증하세요. 방법 B · 로그아웃 상태: 시작 화면에서 보통 새 계정 만들기 / 가입이라는 항목을 찾아 시작할 수 있어요.[S206]
  4. 가입 뒤 프로필 사용자 이름을 메모하고, 게시할 때마다 이 이름을 확인하세요.

공식 한국어 도움말 · 앱 동시 로그인은 최대 10개예요. 계정 센터의 Instagram 25개는 연결 한도예요.[S205][S180]

확인할 점

+이메일 별칭의 가입 수락은 공식 안내에서 아직 확인되지 않았어요. 본인이 관리하는 별도 주소를 쓰세요. 로그아웃 뒤 가입 화면이 다르면 공식 도움말을 확인하세요.

이렇게 보이면 성공

가입·인증을 마쳤고, 프로필에 의도한 연습 계정의 사용자 이름이 보여요.

이렇게 보이면?

  • 인증이 막히면 반복 생성하지 말고 본인 연락처·앱 도움말을 확인하세요.
  • + 별칭이 거부되면 지원된다고 가정하지 말고 본인 별도 주소로 확인하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 02 · 계정 유형과 공개 범위 확인

계정 유형과 공개 범위 확인

지금 하는 일

필요하면 연습 계정을 크리에이터 또는 비즈니스로 전환해요.

왜 하는지

API는 프로페셔널 계정을 대상으로 하므로 경로를 미리 구분해요.

따라 하기

  1. 공개해도 되는 계정인지 먼저 결정하세요. 비공개 개인 계정을 프로로 바꾸면 공개되고 대기 중 팔로우 요청도 수락돼요.[S204]
  2. 아래 경로를 찾아 카테고리와 크리에이터 또는 비즈니스를 고르세요.
  3. 전환 뒤 계정 유형과 공개 상태를 개인 메모에 적으세요. Instagram Login API에는 Facebook 페이지 연결이 필요 없어요.[S002]

공식 검색에 나온 경로 · 보통 설정 및 활동 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 카테고리 → 크리에이터라는 이름이에요.[S180]

확인할 점

중간 버튼은 최신 화면의 안내를 따르세요. 전환 도움말은 공식 도움말에 있어요.

공식 한국어 도움말 · 테스트 게시물은 게시물 → 옵션 → 보관으로 숨길 수 있어요.[S228] 삭제는 옵션 → 삭제 → 삭제예요.[S229][S228]

복원이 필요하면 내 활동 → 최근 삭제 항목에서 찾아요. 일반 복원 대상은 30일 동안 남아요. 보관함에 없는 스토리는 최대 24시간이에요.[S230][S231]

확인할 점

릴스 보관이나 카드 일부 삭제는 해당 콘텐츠의 옵션을 직접 확인하세요. 외부에 복사된 파일은 내 게시물을 지워도 남을 수 있어요.

이렇게 보이면 성공

선택한 계정 유형과 공개 상태를 확인했어요. 공개 전환을 원하지 않으면 개인 계정으로 계속해요.

이렇게 보이면?

  • 이미 전환한 계정인지 먼저 확인하세요. 메뉴 부재만으로 한국 전체 비지원이라고 판단하지 않아요.
  • 전환 과정에 유료 구독 화면이 나오면 필수 단계라고 생각하지 말고 도움말로 돌아가세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

기획 시트의 이름·소개는 앱에서 보통 프로필 → 프로필 편집이라는 이름의 화면을 찾아 이름·소개 칸에 옮기고 저장하세요. 계정 사용자 이름도 확인해요. 카드에 보이는 계정 이름은 config.yaml의 account_name에 따로 입력해야 해요. 앱 화면이 다르면 공식 프로필 수정 도움말을 확인하세요.

STEP 03 · 2단계 인증과 복구 수단

2단계 인증과 복구 수단

지금 하는 일

인증앱과 백업 수단을 준비해요.

왜 하는지

비밀번호 하나만 유출되어 계정을 잃는 위험을 줄이기 위해서예요.

따라 하기

  1. 2단계 인증은 비밀번호와 인증 코드를 함께 확인하는 로그인 보호예요. 아래 경로에서 대상 계정을 고르세요.
  2. 계정 센터 → 비밀번호 및 보안 → 2단계 인증 → 계정 → 인증 앱 → 다음을 따라가요. 앱을 연결하고 생성된 코드를 입력하세요.[S181]
  3. 백업 코드는 인증 앱을 잃었을 때 쓰는 복구용 코드예요. 2단계 인증 → 계정 → 추가 방법 → 백업 코드에서 받아 본인만 접근할 곳에 보관하세요.[S182]

Android 도움말 경로 · 인증 앱이 만든 코드를 입력하고 설정 완료를 확인하세요.[S181]

Android 도움말 경로 · 새 코드 받기는 이전 목록을 취소해요. 새 목록으로 보관본도 바꾸세요.[S182]

확인할 점

iPhone이나 연결 중간 화면은 앱 안내를 따르세요. QR·설정 키·코드를 다른 사람에게 보내지 마세요.

이렇게 보이면 성공

대상 계정에서 2단계 인증을 켰고, 복구 연락처와 백업 코드를 안전하게 보관했어요.

이렇게 보이면?

  • 코드가 틀리면 인증앱의 대상 계정과 기기 시간을 점검하고 앱 도움말을 따르세요.
  • 백업 코드 화면을 찾지 못했다면 완료로 체크하지 말고 도움말로 확인하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

STEP 04 · API 실습 준비물만 구분

API 실습 준비물만 구분

지금 하는 일

API를 선택할 때 필요한 준비물을 적어요.

왜 하는지

오늘 앱 첫 게시를 개발자 설정 때문에 미루지 않기 위해서예요.

따라 하기

  1. 앱으로 첫 게시할 때는 개발자 계정이 필요 없어요. 기본 경로는 실습 3 · AI 문안으로 가세요. 키트 자동화를 고른 사람만 실습 2 · 설치를 먼저 해요.
  2. API는 프로그램이 서비스에 요청하는 통로예요. 선택 실습 8에서는 공개 프로페셔널 계정·개발자 앱·역할·권한을 준비해요.[S002][S031]
  3. 토큰은 API 접근 권한을 담은 비밀 문자열이에요. 선택 실습에서 본인 컴퓨터의 비공개 .env에 보관해요.

이렇게 보이면 성공

오늘의 기본 경로와 선택 API 경로의 준비물 목록을 구분했어요.

이렇게 보이면?

  • 개발자 계정이 없어도 실습 2~7을 할 수 있어요.
  • 인증·개발자 등록에 결제 요구가 보이면 이 실습의 필수 조건이라고 단정하지 말고 공식 안내를 확인하세요.
