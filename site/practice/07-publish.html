7. 앱으로 첫 게시하기

진행 기록은 이 브라우저에 저장해요.

이 실습의 흐름

Canva·CapCut 결과는 서비스 검수표를 마친 파일로 시작해요. 키트 승인 명령은 필요 없어요.

첫 게시에는 앱만 있으면 돼요. 검수한 카드나 릴스 하나를 올리고 주소를 남기세요.

합성 연습 파일을 실제 뉴스처럼 올리지 마세요. 본인 자료로 바꾸기와 검수를 마친 파일을 사용해요.

STEP 01 · PC 파일을 휴대폰에 원본으로 저장

PC 파일을 휴대폰에 원본으로 저장

지금 하는 일

검수한 카드와 MP4를 휴대폰에 옮겨요.

왜 하는지

앱에서 원본 파일을 선택할 수 있어야 하기 때문이에요.

따라 하기

  1. Canva 카드 PNG/JPG 묶음 또는 CapCut의 reel.mp4 중 오늘 올릴 파일을 준비해요. 키트는 cards/card-01.jpg부터 실제 생성된 마지막 JPEG 또는 reel.mp4를 골라요. 파일 순서·크기·재생을 전송 전후 비교해요. 앱 게시용 파일을 인터넷 전체에 공개할 필요는 없어요.
  2. Windows→Android USB: 잠금 해제 → 데이터 전송 케이블 연결 → 휴대폰 USB로 이 기기 충전 중 / Charging this device via USB 알림 → USB 사용 / Use USB for → 파일 전송 / File Transfer → PC에서 복사 → 꺼내기. 일부 단계는 Android 14 이상 문서 기준이에요.
  3. Drive→iPhone: PC에서 본인 Drive에 올린 파일을 휴대폰 Drive에서 찾아 더보기 / More → 사본 보내기 / Send a copy → 이미지 저장 / Save image 또는 동영상 저장 / Save video로 저장해요. Open in → Save to Files는 사진 보관함 저장과 달라요.
  4. Mac→iPhone: Wi-Fi·Bluetooth·수신 허용 확인 → 파일의 공유 / Share → AirDrop → 본인 기기 → 필요하면 수락 / Accept. Finder AirDrop에 끌어놓기도 가능해요. 사진/파일 앱 중 실제 저장 위치를 확인해요.
확인할 점

전송 뒤 파일을 열어 해상도·작은 글자·영상 재생을 원본과 비교하세요. 메신저를 쓴다면 원본 전송 여부도 확인하세요.

이렇게 보이면 성공

휴대폰에서 카드의 작은 글자까지 읽히고 영상이 끝까지 재생돼요. PC와 순서·해상도·화질을 비교했어요.

이렇게 보이면?

  • 충전만 되면 데이터 케이블과 파일 전송 모드를 확인하세요.
  • Drive에서 파일 앱에만 보이면 사진 보관함 저장 경로를 다시 확인하세요.
  • AirDrop에 안 보이면 Wi-Fi·Bluetooth·수신 대상을 확인하고 최신 공식 코드 안내가 나오면 따르세요.

Windows

Windows→Android는 USB, Windows→iPhone은 위 Drive 저장 경로를 선택할 수 있어요. 기기 제조사·앱 UI는 다를 수 있어요.

macOS

Mac→iPhone은 AirDrop을 먼저 확인해요. 다른 조합은 본인 Drive로 파일을 옮긴 뒤 해당 기기의 원본 저장 기능을 확인하세요.

STEP 02 · 카드 묶음 선택과 미리보기

카드 묶음 선택과 미리보기

지금 하는 일

의도한 계정에서 캐러셀 카드 순서를 확인해요.

왜 하는지

다른 계정·뒤섞인 순서·잘린 카드로 게시하지 않게 해요.

따라 하기

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. 프로필에서 게시할 사용자 이름을 확인하세요.
  2. 만들기 → 게시 → 여러 항목 선택에서 card-01.jpg부터 고르세요. 앱 도움말의 상한은 사진·동영상 합계 20개예요.[S068]
  3. 프레임을 조정하고 다음을 누르세요. 길게 눌러 끌어 순서를 맞춘 뒤 다시 다음으로 가요.
  4. 생성된 모든 카드(동봉 예제 5장, 자료 1건이면 3장)를 넘겨 출처와 잘린 글자가 없는지 확인하세요.

공식 한국어 도움말 · 여러 항목 선택 → 프레임 조정 → 다음 → 끌어 재정렬 → 다음 순서예요.[S068]

이렇게 보이면 성공

게시할 계정과 카드 순서·크롭을 확인했어요. 캡션과 표시를 확인할 때까지 공유는 누르지 마세요.

이렇게 보이면?

  • 파일이 안 보이면 사진 접근 권한과 저장 위치를 앱 도움말로 확인하세요.
  • 화면이 다르면 아래 공식 도움말의 기능명을 검색하고 추정한 버튼을 반복 누르지 마세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 03 · 릴스 파일 선택과 미리보기

릴스 파일 선택과 미리보기

지금 하는 일

독립 릴스로 MP4를 가져와 봐요.

왜 하는지

파일 재생과 앱에서 보이는 자막·소리가 같은지 확인해요.

따라 하기

  1. 카드와 릴스 중 오늘 올릴 포맷을 고르세요. 릴스를 선택했다면 reel.mp4를 가져와요.
  2. Android: 프로필 → 새로 만들기 → 릴스로 들어가요. iPhone: 만들기 → 릴스를 누르고 왼쪽 아래 카메라 롤에서 파일을 가져와요.[S242]
  3. iPhone 도움말 순서는 다음 → 편집 → 다음 → 커버 수정이에요. 질문이 읽히는 표지를 고르고 캡션 단계로 가세요.[S242]
  4. 시작·끝·자막·소리를 확인하세요. 이미 영상에 새긴 자막은 그대로 보여요. 자동 인식 자막을 추가한다면 겹치거나 틀린 부분을 확인하세요.

공식 한국어 도움말 · iPhone 자동 인식 자막: 옵션 더 보기 → 선택 캡션 활성화.[S243] Android 직접 녹음: 동영상 수정 → 보이스오버 → 녹화 → 완료.[S244][S242]

확인할 점

휴대폰별 후반 편집 화면은 앱 안내를 따르세요. 표지와 프로필 그리드에 보이는 모양을 각각 확인하세요.

이렇게 보이면 성공

앱 미리보기에서 선택한 MP4의 내용·자막·음성·표지를 본인이 확인했어요. 카드만 먼저 게시한다면 이 단계는 나중에 해도 돼요.

이렇게 보이면?

  • 기본 무음 영상은 소리가 없는 상태로 올릴 수 있어요. 녹음을 넣었다면 원본과 앱 음량을 비교하세요.
  • 글자나 소리가 바뀌었다면 실습 6의 검수를 다시 하고 공유하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 04 · 캡션과 AI·협찬 표시 확인

캡션과 AI·협찬 표시 확인

지금 하는 일

출처와 필요한 표시를 게시 전에 확인해요.

왜 하는지

게시 뒤 수정이 가능하다고 가정하지 않기 위해서예요.

따라 하기

  1. 서비스에서 메모한 게시 설명문 또는 키트 copy.json의 caption을 붙여 넣고 원출처·줄바꿈·관계 표시를 읽으세요. 판단 기준은 실습 6에 있어요.
  2. 필요한 AI·협찬 표시를 아래 메뉴에서 설정하세요. 브랜드를 광고에 쓰도록 허가하는 설정은 별도 항목이에요.[S241]
  3. 필수 표시를 설정할 수 없으면 공유를 보류하세요.

공식 한국어 도움말 · AI 레이블 추가를 켜요. 도움말에서 설명하는 표시 이름은 AI 콘텐츠예요.[S183]

공식 한국어 도움말 · 파트너십 레이블 및 광고 → 협찬 광고 레이블 추가에서 브랜드를 고르세요.[S237]

확인할 점

AI 토글의 정확한 위치는 화면에서 찾아요. 협찬 브랜드명은 승인 전후에 다르게 표시돼요. 공식 도움말에서 승인 상태를 확인하세요.

이렇게 보이면 성공

캡션·출처·필요한 라벨을 확인했어요. 필수 표시가 모두 갖춰졌으면 공유로 진행하세요.

이렇게 보이면?

  • 필수 토글이 없으면 OS·앱 버전·계정 유형을 기록해 공식 도움말로 확인하고 게시를 보류하세요.
  • 광고 허락 버튼과 파트너십 표시를 같은 동작으로 판단하지 마세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

STEP 05 · 공유 후 실제 게시물 확인

공유 후 실제 게시물 확인

지금 하는 일

본인이 공유를 실행하고 결과를 확인해요.

왜 하는지

업로드 시작과 게시 완료를 구분해요.

따라 하기

  1. 계정·파일·캡션·표시를 마지막으로 확인하고 공유하기를 누르세요.[S068][S242]
  2. 업로드 중 다시 누르지 마세요. 프로필에서 게시물을 열고 카드 마지막 장이나 영상 끝까지 확인해요.
  3. 게시물은 보내기 → 링크 복사를 눌러요. iPhone 릴스는 공유 옵션 → 링크 복사예요.[S245][S246]
  4. 아래 기록 칸에 주소를 붙여 넣으세요. 일반 공개가 목적이면 로그인하지 않은 창에서 공개 범위도 확인해요.

공식 한국어 도움말 · 게시물을 다시 열어 계정·내용·순서·소리·표시를 확인하고 주소를 복사하세요.[S245]

공식 한국어 도움말 · 게시 후 AI·협찬 표시 변경 경로는 공식 도움말에서 확인하세요. 필수 표시가 빠지면 공개를 유지하지 말고 보관·삭제 경로를 확인하세요.[S183]

확인할 점

게시 후 라벨을 고칠 수 있다고 가정하지 말고 공유 전에 설정하세요. 비공개 게시물은 URL을 복사해도 팔로워에게만 보일 수 있어요.[S245]

이렇게 보이면 성공

실제 게시물을 열어 내용·표시를 확인했고 게시물 주소를 기록했어요.

이렇게 보이면?

  • 멈춘 것 같아도 재공유 전 프로필에서 이미 올라갔는지 확인하세요.
  • 필수 표시가 빠졌다면 공개를 그대로 두지 말고 공식 도움말로 수정/보관/삭제 가능 여부를 확인하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

첫 게시물 주소를 남기세요

직접 열어 내용과 표시를 확인했다면 첫 게시를 마쳤어요. 주소를 보관하고 다음 관찰로 이어가세요.
