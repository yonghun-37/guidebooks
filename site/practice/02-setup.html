STEP 01 · 터미널에서 폴더 찾기

터미널에서 폴더 찾기

지금 하는 일

키트 폴더를 열고 명령 입력을 연습해요.

왜 하는지

명령을 엉뚱한 폴더에서 실행하는 실수를 줄여요.

따라 하기

  1. 저장소에서 Code → Download ZIP을 눌러 내려받고 압축 풀기를 해요. Git은 필요 없어요.
  2. 터미널은 글자로 명령을 입력하는 창이고, 명령어는 컴퓨터에 시킬 한 줄 작업이에요. Windows는 시작에서 PowerShell, macOS는 Spotlight에서 터미널을 열어요.
  3. 폴더 경로는 파일이 있는 위치예요. 아래 내이름과 Downloads 위치를 실제 경로로 바꾸세요. cd는 폴더 이동이에요. 목록에 run_pipeline.py가 보이면 맞아요.
  4. 명령은 한 줄씩 붙여 넣고 Enter를 눌러요. Windows는 Ctrl+V, macOS는 ⌘+V로 붙여 넣어요. Ctrl+C는 실행 중인 명령을 멈춰요. 중단 후에는 파일이 일부만 생겼을 수 있으니 새 출력 폴더를 쓰세요.

이렇게 보이면 성공

목록에 README.md·requirements.txt·run_pipeline.py가 보여요. 현재 폴더가 starter-kit이면 준비됐어요.

이렇게 보이면?

  • ZIP 안에서 바로 실행하지 말고 압축을 푼 폴더로 이동하세요.
  • 공백이 있는 경로는 큰따옴표로 감싸세요.

Windows

cd "C:\Users\내이름\Downloads\guidebooks-main\starter-kit"
dir

macOS

cd "/Users/내이름/Downloads/guidebooks-main/starter-kit"
ls

STEP 02 · Python 확인과 설치

Python 확인과 설치

지금 하는 일

Python 3.11 이상을 준비해요.

왜 하는지

키트의 Python 파일을 실행할 도구가 필요해요.

따라 하기

  1. Python은 이 키트의 프로그램을 실행하는 언어와 실행 도구예요. 아래 OS 탭의 확인 명령을 실행해요.
  2. 없거나 3.11보다 낮으면 Python 공식 다운로드에서 설치해요. Windows 설치 화면에 Add python.exe to PATH가 있으면 선택해요. PATH는 실행 파일을 찾을 위치 목록이에요.
  3. 설치 뒤 터미널을 다시 열어 키트로 이동하고 확인 명령을 다시 실행해요. Windows에서 다른 버전을 설치했다면 이후 py -3.11을 해당 설치 버전으로 바꿔요. macOS에서 python3가 여전히 낮으면 python3.11 --version처럼 설치한 버전 이름으로 확인해요. 3.12를 설치했다면 python3.12예요. 3.11 이상이 확인된 명령을 다음 가상환경 생성에도 그대로 써요.

이렇게 보이면 성공

Python 3.11.x 또는 그보다 높은 버전이 출력돼요. x는 설치된 세부 버전이라 달라도 돼요.

이렇게 보이면?

  • 명령 대신 Microsoft Store가 열리면 설치 경로·실행 별칭을 점검하고 py 명령으로 다시 확인하세요.
  • 명령을 찾지 못하면 설치 여부와 PATH를 확인하고 창을 다시 여세요.

Windows

py -3.11 --version

macOS

python3 --version

STEP 03 · 가상환경과 라이브러리 설치

가상환경과 라이브러리 설치

지금 하는 일

키트 전용 실행 환경에 필요한 패키지를 설치해요.

왜 하는지

다른 프로젝트의 Python 설정과 섞이지 않게 해요.

따라 하기

  1. 가상환경 .venv는 이 폴더용 Python과 패키지를 모으는 상자예요. pip는 패키지 설치 도구예요.
  2. 아래 OS 명령을 한 줄씩 실행해요. Windows는 활성화 정책을 바꾸지 않고 .venv\Scripts\python.exe를 직접 사용해요. 이후 모든 python 명령도 이 경로로 바꿔요.
  3. macOS 아래 첫 줄은 python3.11 --version으로 확인한 경우예요. 설치한 버전 이름으로 바꿔 생성하세요. 기존 .venv가 낮은 버전이면 지우지 말고 .venv-old로 이름을 바꾼 뒤 새로 만들어요. 활성화 뒤 python을 사용해요. 새 창에서는 다시 폴더 이동·활성화하세요. FFmpeg는 영상 도구이며 키트가 설치 패키지의 바이너리를 사용할 수 있어 별도 설치가 기본 필수는 아니에요.

이렇게 보이면 성공

설치 명령이 오류 없이 끝나고 전용 Python의 버전이 3.11 이상이에요. 설치 로그의 세부 버전·줄 수는 달라도 돼요.

이렇게 보이면?

  • PIL/yaml/imageio_ffmpeg가 없으면 이 가상환경의 Python으로 pip 명령을 다시 실행하세요.
  • 지원 FFmpeg 바이너리가 없는 OS/CPU에서는 README의 오류 표를 확인하세요.

Windows

py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install --cache-dir .cache/pip -r requirements.txt
.venv\Scripts\python.exe --version

macOS

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --cache-dir .cache/pip -r requirements.txt
python --version

STEP 04 · 첫 생성은 합성 자료로

첫 생성은 합성 자료로

지금 하는 일

오프라인 샘플을 별도 출력 폴더에 만들어요.

왜 하는지

계정·키 없이 생성부터 검수 대기까지 익혀요.

따라 하기

  1. 아래 명령의 output/first-post는 새 결과 폴더예요. 첫 실행만 이 명령을 사용하고 이후 단계에서는 이어 써요.
  2. 완료 후 폴더를 열어 카드와 영상을 확인해요. 확장자는 파일 이름 끝의 종류 표시로, .png/.jpg는 이미지, .mp4는 영상이에요.
  3. REVIEW.md는 사람이 읽는 검수표이에요. 검수 대기에서 멈추는 것이 정상이에요. 합성 자료는 실제 뉴스가 아니며 live 게시를 거부해요.

이렇게 보이면 성공

검수 대기: …/output/first-post/REVIEW.md가 나와요. 기본 예제의 카드 5장(PNG/JPEG)과 reel.mp4를 열어 보세요. APPROVED.json은 아직 없어요.

이렇게 보이면?

  • File exists면 기존 결과를 지우지 말고 새 이름으로 바꾸고 이후 모든 경로도 맞추세요.
  • 영상이 무음인 것은 기본 설정이에요. 실습 5에서 녹음을 선택할 수 있어요.

Windows

.venv\Scripts\python.exe run_pipeline.py --offline --output output/first-post

macOS

python run_pipeline.py --offline --output output/first-post
