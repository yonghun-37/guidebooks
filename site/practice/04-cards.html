STEP 01 · 카드 다시 만들기

카드 다시 만들기

지금 하는 일

검증한 문안을 이미지에 반영해요.

왜 하는지

JSON을 고쳐도 이미지가 자동으로 바뀌지 않기 때문이에요.

따라 하기

  1. 렌더링은 문안·설정을 실제 이미지와 영상 파일로 만드는 작업이에요. 아래 명령은 카드와 릴스를 함께 다시 만들어요.
  2. cards/card-01.png부터 표지 → 본문 → 마무리 순서로 열어요. PNG와 같은 내용의 JPEG(.jpg)도 있어요.
  3. 문안은 copy.json, 현재 출력물의 색·음성 설정은 output/first-post/config.json을 수정해요. config.yaml 변경은 새 실행부터 반영돼요.

이렇게 보이면 성공

검수 대기: …/output/first-post/REVIEW.md가 출력돼요. cards/에 card-01부터 card-05까지 PNG와 JPEG가 있어요.

이렇게 보이면?

  • 변경이 안 보이면 현재 폴더의 copy.json·config.json을 수정했는지 확인하세요.
  • 렌더링은 기존 승인을 지워요. 실패 후에도 새 검수 없이는 게시할 수 없어요.

Windows

.venv\Scripts\python.exe run_pipeline.py render output/first-post

macOS

python run_pipeline.py render output/first-post

STEP 02 · 휴대폰 크기로 모든 장 확인

휴대폰 크기로 모든 장 확인

지금 하는 일

글자·크롭·출처를 카드마다 확인해요.

왜 하는지

첫 장만 좋아 보이고 나머지가 잘리는 문제를 막아요.

따라 하기

  1. 모든 PNG/JPEG에서 제목·요점·출처·합성 고지를 읽으세요. 길면 조건과 출처를 남기며 줄이고 다시 render하세요.
  2. 기본 카드 1080×1350·5장은 키트 예제 설정이에요. 앱 게시에는 이 파일을 그대로 사용할 수 있어요.
  3. API 입력은 JPEG·최대 8MB·비율 4:5~1.91:1·너비 320~1440px예요.[S004] 실제 앱 선택·미리보기는 실습 7에서 확인하세요.

이렇게 보이면 성공

작은 화면에서도 다섯 카드의 글자·출처가 읽히고 순서가 맞아요. 실제 앱 선택은 실습 7에서 확인해요.

이렇게 보이면?

  • 제목이 잘리면 글을 줄여 재생성하고 전체를 다시 확인하세요.
  • 앱 미리보기 크롭이 달라지면 실습 7에서 각 장을 점검하고 게시를 보류해 수정하세요.

Windows

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.

macOS

PC 명령은 없어요. 위 순서를 휴대폰 앱이나 웹에서 따라 하세요.
