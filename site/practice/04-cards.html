이 실습의 흐름

Canva Free에서 카드뉴스 또는 해설용 세로 장면을 만드세요. 카드는 실습 3 문안을 4:5로, 해설은 장면표를 9:16으로 배치해 PNG 또는 JPG로 내려받아요. 이미지 생성은 선택이에요. 도형과 본인 사진만으로도 끝낼 수 있어요.[S318][S320][S365]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

따라 하기 · 무료 가입 → 카드·해설 장면 크기 고르기

무료 가입 → 카드·해설 장면 크기 고르기

지금 하는 일

Canva에서 세로 카드 작업 공간을 만들어요.

왜 하는지

처음부터 크기를 정해야 글자와 출처가 잘리지 않아요.

따라 하기

뉴스카드·모션의 원본 카드: 아래 4:5·5장 순서로 만들어요. 해설: 먼저 실습 5에서 장면표·낭독문을 만들고 이곳으로 돌아오세요. 아래 1번으로 가입한 뒤, 2~3번의 카드 템플릿·크기 대신 사용자 지정 1080×1920px(9:16) 새 디자인과 무료 세로 템플릿 또는 빈 페이지를 고르세요. 4번의 무료 요소 확인은 함께 해요. 모션용 4:5 카드와 섞지 않아요.

  1. Canva 공식 웹 또는 공식 앱에서 본인 계정으로 가입·로그인하세요. Free로 시작하고 Pro 체험 결제는 넘겨요.[S318]
  2. 홈의 검색에서 카드뉴스를 찾아요. 무료 템플릿 중 단순한 제목·본문·출처 자리가 있는 것을 고르세요.
  3. 이 책의 연습 크기는 4:5 = 1080×1350px예요. 다른 크기면 기존 디자인의 유료 크기 변경 대신, 홈의 디자인 만들기/만들기 → 사용자 지정 크기와 비슷한 메뉴에서 너비 1080·높이 1350·단위 px로 새 디자인을 만들어요. 편집기의 디자인/템플릿에서 무료 카드 템플릿을 적용하세요.
  4. 템플릿의 왕관·Pro 요소는 무료 요소로 바꾸세요. 빈 페이지에 배경색과 텍스트만 넣어도 좋아요. 제목은 “오늘소식 카드”처럼 저장해요.[S320]

이렇게 보이면 성공

뉴스카드는 1080×1350, 해설 장면은 1080×1920 디자인에 글·그림 자리가 있어요.

이렇게 보이면?

템플릿이 유료면 뒤로 가서 다른 무료 디자인을 고르세요. 크기 변경 결제가 나오면 새 사용자 지정 디자인을 만들어요.

Windows·macOS 브라우저에서 만들기 → 사용자 지정 크기를 찾아요. 왼쪽 디자인/템플릿 목록에서 골라 적용하고 원래 크기를 확인해요.

앱 홈의 +/만들기 → 사용자 지정 크기와 비슷한 메뉴를 찾아요. 편집 화면 아래의 디자인/템플릿을 열어요. 항목이 없으면 Canva 모바일 웹에서 같은 크기의 새 디자인을 만들어요.

카드 5장 또는 해설 장면에 배치하기

지금 하는 일

실습 3의 문안을 텍스트 상자에 넣어요.

왜 하는지

글자를 이미지로 생성하지 않고 직접 넣으면 날짜와 숫자를 고칠 수 있어요.

따라 하기

해설 선택자: storyboard.txt 한 행당 한 페이지를 만들어요. 예: 장면 1의 질문→1페이지, 장면 2의 설명→2페이지. 각 행의 그림 지시에 맞게 본인 사진·도형·검수한 삽화를 넣고, 말과 다른 새 사실은 더하지 마세요. 장면 수만큼 복제한 뒤 아래 카드 문안 배치 대신 다음 이미지·저장 단계로 가요.

  1. cards.txt의 표지 제목을 복사해 템플릿 제목을 선택하고 붙여 넣으세요. 본문 자리도 내 문장으로 교체해요.
  2. 페이지의 복제 메뉴로 5장 구성을 만들어요. 1 표지 질문 / 2 핵심 사실 / 3 대상·조건 / 4 할 일 / 5 출처·확인일 순서로 문안을 바꿔요. 장수는 이번 연습 구성이에요.
  3. 각 페이지 아래에 짧은 출처를 넣고 마지막 장에 원출처·제목·날짜를 적어요. 긴 URL과 게시 설명문은 caption.txt에도 남겨요.
  4. 넘치면 글자부터 줄이지 말고 문장을 줄여요. 예외·단위·출처는 남기고 제목이 본문보다 강한 주장을 하지 않는지 확인하세요.
같은 지원 신청 예시의 디자인 비교
좋은 카드나쁜 카드바로 고칠 것
“신청 전 3가지” 아래 대상·기간·서류와 출처가 읽혀요.제목만 크게 “매일 개방!”이고 조건·출처가 없어요.제목을 사실에 맞추고 조건을 본문으로 복원하세요.

이렇게 보이면 성공

카드 5장 또는 장면표의 행 수만큼 내 내용이 있고 템플릿 예시가 남지 않아요.

이렇게 보이면?

붙여 넣은 글이 사라지면 텍스트 상자를 다시 선택하세요. 뒤에 숨으면 위치/정렬 메뉴에서 앞으로 가져와요.

텍스트 상자를 두 번 클릭해 기존 글만 선택한 뒤 붙여 넣어요. 페이지 목록에서 복제·순서 변경을 하고 1~5장을 열어 확인해요.

글자를 두 번 탭해 편집하고 키보드를 닫은 뒤 카드 전체를 보세요. 페이지 보기에서 복제와 순서를 확인해요.

따라 하기 · 선택 · AI 삽화 만들고 표시하기

선택 · AI 삽화 만들고 표시하기

지금 하는 일

필요한 장에만 글자 없는 삽화를 넣어요.

왜 하는지

현장 사진처럼 보이는 가짜 증거를 만들지 않고 내용을 설명해요.

따라 하기

해설용 삽화는 아래 요청 첫 줄의 “카드뉴스·세로 4:5”를 “해설 장면·세로 9:16”으로 바꾸세요. 저장 치수가 달라도 Canva의 1080×1920 페이지에서 배치·자르기를 확인해요.

  1. 삽화가 필요 없으면 본인 사진 또는 무료 도형 사용이라고 메모하고 다음 단계로 가세요.
  2. 필요하면 실습 3의 ChatGPT 대화 입력창에 아래 지시문을 넣어 이미지를 요청해요. 이미지 만들기 메뉴가 보이면 선택해도 돼요. 한도가 끝나면 도형으로 마쳐요.[S300][S374]
  3. 생성된 이미지를 열어 저장/다운로드를 누르세요. 원본·사용 프롬프트·생성일을 보관해요. 손·물체·글자 오류를 보고 사용할 삽화만 골라요.
  4. Canva 업로드 → 파일 업로드에서 이미지를 넣고, 해당 카드 아래에 AI 생성 삽화 · 실제 현장 아님을 직접 적어요. 제목·날짜는 텍스트 상자에 넣어요. 선택한 삽화가 가리키는 내용이 뉴스의 실제 증거가 아닌지 확인해요.
생활 뉴스 카드용 세로 4:5 배경. 아침빛이 드는 익명의 도시 버스 정류장과 유리 업무 건물. 남색·회청색·크림색, 위쪽 절반은 제목을 따로 넣을 여백. 사람·실제 명소·간판·글자·숫자·로고·브랜드 없이. 실제 사건의 증거 사진이 아닌 AI 설명용 배경.

이렇게 보이면 성공

삽화를 생략했거나, AI 표시와 생성 기록이 있는 설명 이미지가 카드 안에 있어요.

이렇게 보이면?

한글이 이미지에 잘못 생기면 지시문에 “글자 없는 배경으로 다시”를 요청하고 글자는 Canva에서 따로 넣으세요.

다운로드한 파일을 업로드 메뉴로 넣고 카드 안에 배치하세요. 요청한 4:5와 저장 파일 치수가 다른 경우 Canva 프레임 안에서 배치·자르기를 확인해요.

ChatGPT의 저장/공유에서 이미지 파일을 사진 또는 파일 앱에 저장해요. Canva 업로드에서 그 파일을 고르고, 원본을 지우기 전에 삽화 표시까지 확인해요.

따라 하기 · PNG/JPG 다운로드 → 모든 카드 확인

PNG/JPG 다운로드 → 모든 카드 확인

지금 하는 일

최종 이미지 파일을 내려받아 다시 열어요.

왜 하는지

편집 화면과 실제 저장 파일에서 줄바꿈·순서가 다를 수 있어요.

따라 하기

해설 선택자: 공유 → 다운로드에서 PNG·전체 장면·원본 1080×1920을 골라요. ZIP이면 압축을 풀고 장면표 행과 같은 순서로 scene-01.png, scene-02.png처럼 이름을 붙여요. 모두 열어 치수·잘림을 확인한 뒤 실습 5 · CapCut 가져오기로 가요. 아래 4:5 카드 저장은 건너뛰어요.

  1. 페이지 목록에서 1~5장 순서를 확인하고 공유 → 다운로드와 비슷한 메뉴를 여세요.
  2. 파일 형식은 PNG(글자 중심 원본) 또는 JPG/JPEG(게시용 사본), 페이지는 전체 5장을 선택해요. 크기는 원본 1080×1350으로 저장하세요. 이 크기는 이번 실습 목표예요.
  3. 여러 장이 ZIP으로 저장되면 압축을 풀어요. 순서대로 card-01.png~card-05.png처럼 이름을 붙이고 원본 파일 크기를 확인해요. JPG를 골랐다면 확장자는 .jpg로 둬요.
  4. 휴대폰에서 모든 장의 제목·예외·출처를 읽어 보세요. 저장 파일을 확대만 하지 말고 실제로 올릴 크기로 봐요. 틀린 장은 Canva 원본을 고치고 다시 내려받아요.
  5. 카드만 만들면 서비스 파일 검수 후 실습 7로 가요. 모션 릴스는 원본 디자인과 이미지를 남겨 두고 실습 5로 이어가요.

메뉴를 찾기 어렵다면 Canva 다운로드 도움말을 확인하세요.

이렇게 보이면 성공

카드 5장(4:5) 또는 장면표와 같은 수의 장면(9:16)이 순서대로 열리고 글자·출처가 읽혀요. Canva 편집 원본도 남아 있어요.

이렇게 보이면?

PDF 한 파일만 있으면 형식을 PNG/JPG로 다시 골라요. 결제가 뜨면 왕관·Pro 요소를 찾아 무료 요소로 교체한 뒤 다시 저장해요.

Windows: ZIP 우클릭 → 모두 추출, 이미지 속성 → 자세히에서 너비·높이를 봐요. macOS: ZIP을 열고 미리보기의 도구 → 속성 보기에서 이미지 크기를 확인해요.

다운로드 위치가 사진인지 파일인지 확인해요. ZIP은 파일 앱에서 압축을 풀고, 사진의 정보/세부정보에서 치수와 장수를 확인해요.

확인할 점 · 무료 요소와 AI 표시

Canva Free는 무료 소재로 디자인·저장을 할 수 있어요. 월 AI 한도는 작업별 공용이라 이미지 장수로 고정하지 않아요. 첫 작품은 삽화 생성을 필수로 잡지 마세요. 소재·폰트는 완성 디자인의 사용 조건을 보고 선택해요.[S318][S320]

AI 삽화 설명은 학습자에게 알리는 표시예요. 인스타의 AI 공개 설정은 최종 이미지·영상·음성에 따라 따로 판단해요. 사실적인 합성 영상·음성은 공유 전 공개 안내를 확인하세요.[S389]

자동화·무료 대안 · 기존 스타터 키트로 만들기

이 경로를 고를 때만 실습 2에서 키트를 설치하세요. 터미널은 명령을 글자로 입력하는 창이에요. 아래 명령은 그 창에서 키트 폴더로 이동한 뒤 실행해요. 합성 연습은 output/first-post, 실제 자료는 output/my-news로 이어가요. 기본 경로의 TXT·Canva 파일을 이 명령으로 바로 읽을 수는 없어요. 키트용 문안·설정을 따로 준비하세요.

카드 다시 만들기

지금 하는 일

검증한 문안을 이미지에 반영해요.

왜 하는지

JSON을 고쳐도 이미지가 자동으로 바뀌지 않기 때문이에요.

따라 하기

  1. 렌더링은 문안·설정을 실제 이미지와 영상 파일로 만드는 작업이에요. 아래 명령은 카드와 릴스를 함께 다시 만들어요. 카드만 게시해도 실습 5의 영상 재생과 실습 6의 영상 검수는 필수예요. 본인 녹음은 생략해도 돼요.
  2. cards/card-01.png부터 표지 → 본문 → 마무리 순서로 열어요. PNG와 같은 내용의 JPEG(.jpg)도 있어요.
  3. 문안은 copy.json, 현재 출력물의 색·음성 설정은 output/first-post/config.json을 수정해요. config.yaml 변경은 새 실행부터 반영돼요.

이렇게 보이면 성공

검수 대기: …/output/first-post/REVIEW.md가 출력돼요. cards/에 생성된 장수만큼 PNG와 JPEG가 있어요. 동봉 예제는 card-01~05, 자료 1건인 내 피드는 card-01~03이에요. copy.json의 scenes 항목 수와 파일 수를 맞춰요.

이렇게 보이면?

  • 변경이 안 보이면 현재 폴더의 copy.json·config.json을 수정했는지 확인하세요.
  • 렌더링은 기존 승인을 지워요. 실패 후에도 새 검수 없이는 게시할 수 없어요.

Windows

macOS

python run_pipeline.py render output/first-post

휴대폰 크기로 모든 장 확인

지금 하는 일

글자·크롭·출처를 카드마다 확인해요.

왜 하는지

첫 장만 좋아 보이고 나머지가 잘리는 문제를 막아요.

따라 하기

  1. 모든 PNG/JPEG에서 제목·요점·출처·합성 고지를 읽으세요. 길면 조건과 출처를 남기며 줄이고 다시 render하세요.
  2. 기본 카드 1080×1350·5장은 동봉 예제 설정이에요. 내 피드의 자료 1건이면 3장이며, 실제 생성된 모든 장을 확인해요. 앱 게시에는 이 파일을 그대로 사용할 수 있어요.
  3. API 입력은 JPEG·최대 8MB·비율 4:5~1.91:1·너비 320~1440px예요.[S004] 실제 앱 선택·미리보기는 실습 7에서 확인하세요.

이렇게 보이면 성공

작은 화면에서도 생성된 모든 카드의 글자·출처가 읽히고 순서가 맞아요. 실제 앱 선택은 실습 7에서 확인해요.

  • 앱 미리보기 크롭이 달라지면 실습 7에서 각 장을 점검하고 게시를 보류해 수정하세요.
