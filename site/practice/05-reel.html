STEP 01 · 본인 내레이션 준비

본인 내레이션 준비

지금 하는 일

본인 대본을 읽어 녹음하거나 무음 연습을 선택해요.

왜 하는지

목소리·음원 권리를 직접 확인할 수 있게 해요.

따라 하기

  1. 기본은 무음과 자막이에요. 목소리를 넣으려면 아래 녹음·내보내기 순서로 본인 목소리를 wav 파일로 저장하세요. 지원 파일을 못 만들면 narration: null·music: null·tts: silent를 유지하고 다음 영상 재생으로 가요.
  2. 현재 출력 폴더의 config.json에서 reel 객체 안의 narration에 녹음 전체 경로를 넣으세요. 아래 필드만 고치고 파일 전체를 덮어쓰지 마세요.
  3. music에는 권리를 확인한 파일만 넣으세요. 녹음을 넣어도 tts는 silent로 둘 수 있어요.
"narration": "C:/Users/내이름/Downloads/my-voice.wav",
"music": null,
"tts": "silent"

이렇게 보이면 성공

무음 연습을 유지했거나, 실제 존재하는 본인 녹음 경로가 현재 config.json에 지정됐어요.

이렇게 보이면?

  • 녹음 파일이 없으면 narration을 null로 두고 무음 연습을 먼저 마치세요.
  • narration 파일을 바꾸면 다시 render·검수해야 해요.

Windows

목소리를 넣을 때만 Audacity 공식 사이트에서 본인 OS용 프로그램을 설치하세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. Audacity의 Audio Setup(오디오 설정)에서 녹음할 마이크를 고르세요. 빨간 녹음 버튼을 누르고 copy.json의 subtitle을 장면 순서대로 읽어요. 정지 버튼을 누른 뒤 재생해서 내 목소리인지 확인해요.[S260]
  2. 앞뒤 무음을 줄이려면 파형에서 남길 부분을 드래그하고 Edit → Remove Special → Trim Audio를 선택하세요. 장면마다 끝나는 시각에 맞춰 읽기 어렵다면 문장을 줄여 다시 녹음하세요.[S262]
  3. File → Export Audio에서 컴퓨터에 내보내기, 파일명 my-voice.wav, 형식 WAV, 저장 위치 Downloads(다운로드)를 고르고 내보내요. 프로젝트 저장 파일은 녹음 WAV와 달라요.[S261]
  4. 파일을 직접 열어 재생한 뒤 아래 전체 경로를 현재 config.json의 reel.narration에 넣으세요. 내 사용자 폴더 이름으로 바꿔요.

경로 예: C:/Users/내이름/Downloads/my-voice.wav

macOS

목소리를 넣을 때만 Audacity 공식 사이트에서 본인 OS용 프로그램을 설치하세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. Audacity의 Audio Setup(오디오 설정)에서 녹음할 마이크를 고르세요. 빨간 녹음 버튼을 누르고 copy.json의 subtitle을 장면 순서대로 읽어요. 정지 버튼을 누른 뒤 재생해서 내 목소리인지 확인해요.[S260]
  2. 앞뒤 무음을 줄이려면 파형에서 남길 부분을 드래그하고 Edit → Remove Special → Trim Audio를 선택하세요. 장면마다 끝나는 시각에 맞춰 읽기 어렵다면 문장을 줄여 다시 녹음하세요.[S262]
  3. File → Export Audio에서 컴퓨터에 내보내기, 파일명 my-voice.wav, 형식 WAV, 저장 위치 Downloads(다운로드)를 고르고 내보내요. 프로젝트 저장 파일은 녹음 WAV와 달라요.[S261]
  4. 파일을 직접 열어 재생한 뒤 아래 전체 경로를 현재 config.json의 reel.narration에 넣으세요. 내 사용자 폴더 이름으로 바꿔요.

경로 예: /Users/내이름/Downloads/my-voice.wav. config.json 문자열 안에는 큰따옴표를 유지해요.

휴대폰 녹음이 m4a라면 WAV로 바꾸기

휴대폰에서 내보낸 본인 녹음을 키트 폴더로 복사하세요. 확장자를 표시하고 원래 확장자는 유지한 채 파일명을 my-voice.m4a로 맞춰요. 아래는 키트에 설치된 FFmpeg로 내용을 WAV로 변환하는 명령이에요. 확장자만 .wav로 바꾸는 것은 변환이 아니에요.[S263]

python -c "import imageio_ffmpeg,subprocess; subprocess.run([imageio_ffmpeg.get_ffmpeg_exe(),'-i','my-voice.m4a','-vn','-c:a','pcm_s16le','my-voice.wav'],check=True)"

Windows는 첫 python을 .venv\Scripts\python.exe로 바꿔요. 기존 my-voice.wav가 있으면 새 이름으로 바꿔 출력하세요. 완성한 WAV를 재생하고 그 전체 경로를 narration에 넣어요. 변환 실패·목소리 미재생이면 narration을 null로 돌려 무음을 유지하세요. 녹음 앱에서 파일로 내보낼 수 없다면 위 PC 녹음 경로를 쓰세요.

STEP 02 · 릴스 재생성과 끝까지 보기

릴스 재생성과 끝까지 보기

지금 하는 일

영상 파일을 다시 만들고 재생해요.

왜 하는지

음성·자막·장면이 실제로 맞는지 파일에서 확인해요.

따라 하기

  1. render 명령으로 다시 만들고 reel.mp4를 처음부터 끝까지 재생하세요.
  2. 기본 예제는 1080×1920·20초·무음과 자막이에요. 녹음을 넣었다면 목소리와 자막을 함께 확인하세요. 자동 음성 정렬은 없어요.
  3. 자막을 다 못 읽으면 먼저 문장을 줄이고 다시 녹음하세요. 영상의 장면 길이는 copy.json의 scenes 수와 config.json의 reel.duration을 함께 확인해요. 동봉 예제는 20초 ÷ 5장면 = 장면당 4초예요. 자동 정렬이 없으므로 완성 영상에서 각 장면이 넘어갈 때의 말끝을 확인해요.
  4. 이미지 슬라이드쇼·이미지 위주 영상·반복 재생 영상·문구 짜깁기는 수익화 금지 형식이에요. 약간의 줌이나 음악을 넣는 것만으로 이 조건을 벗어나지는 않아요.[S012]
확인할 점

이번 MP4는 제작 연습용이에요. 수익화를 계획한다면 콘텐츠 수익화 정책과 협찬 도구 조건을 함께 확인하세요.[S240]

이렇게 보이면 성공

검수 대기: …/output/first-post/REVIEW.md가 출력되고 reel.mp4가 재생돼요. 기본 샘플은 20초·자막·무음이며 선택 녹음은 실제로 들려요.

이렇게 보이면?

  • 기본 무음은 실패가 아니에요. 녹음 선택 시에도 무음이면 현재 config.json의 narration 경로를 확인하세요.
  • 소리·자막 타이밍이 어긋나면 녹음을 대본 장면 길이에 맞춰 다시 편집하세요.
  • 영상이 열리지 않으면 README의 FFmpeg·플레이어 오류 표를 확인하세요.
