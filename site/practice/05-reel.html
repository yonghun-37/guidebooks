이 실습의 흐름

CapCut에서 카드→모션 또는 얼굴 없는 해설 릴스를 만드세요. 카드 경로는 약 35분, 해설은 문안 이후 소리·장면·편집에 약 50분을 잡으세요. CapCut은 기본 편집과 짧은 내보내기부터 시험해요. 자동 자막·TTS가 유료면 아래 무료 대안을 고르세요.[S327][S380]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

왜 하는지

따라 하기

  1. 카드→모션: 실습 4의 핵심 카드 3~5장을 골라요. 무음+읽을 글자로 만들어도 돼요. 본인 녹음은 선택이에요.
  2. 얼굴 없는 해설: 실습 3의 확정 사실과 아래 프롬프트를 ChatGPT 입력창에 붙여 장면표 storyboard.txt와 낭독문 voice-script.txt를 만들어요. 낭독해 약 30~45초가 되도록 줄이고 원문과 대조해요. 장면표의 그림 지시를 실습 4의 해설 분기에 넘겨 9:16 scene-01.png부터 준비하세요. 대본부터 만들고 장면을 만든 뒤 이곳의 편집 단계로 돌아와요.
  3. 가장 간단한 무료 소리는 본인 녹음이에요. 휴대폰 녹음 앱에서 녹음 → 정지 → 처음부터 재생 → 공유/파일로 저장을 골라 voice.m4a 또는 WAV/MP3 원본을 보관해요.
  4. TTS는 글을 음성으로 읽는 기능이에요. 목소리를 녹음하지 않으려면 아래 Vrew 선택 경로를 쓰세요. 실제 사람의 목소리를 흉내 내지 마세요.

선택 · Vrew 무료 AI 목소리로 해설 만들기

Vrew 공식 웹에서 PC 앱을 설치하고 무료 계정으로 시작하세요. 새로 만들기 → 텍스트로 비디오 만들기와 비슷한 메뉴에서 voice-script.txt의 읽을 말만 넣어요. storyboard.txt 표는 넣지 마세요. AI 목소리의 한국어 화자를 고르고 미리듣기로 날짜·단위·부정 표현을 들어요. 발음이 틀리면 읽기 쉬운 글로 수정하고 다시 생성하세요.[S366][S330]

Free는 월 200 공용 크레딧이에요. AI 음성 100자당 1크레딧, 음성 분석 1분당 1크레딧이에요. 예: 대본 500자 = 5크레딧이며 같은 달 다른 작업과 잔여량을 나눠 써요. 앱의 차감 안내를 먼저 보세요.[S388]

생성 후 필요 없는 스톡은 빼고 내 장면을 넣어요. 내보내기 → 오디오 파일과 비슷한 메뉴가 있으면 WAV/MP3를 저장해 CapCut으로 가져와요. 음성만 저장하는 메뉴가 없으면 영상 파일로 저장해 CapCut에서 오디오 추출/분리를 쓰거나 Vrew에서 그대로 편집·자막·MP4 출력까지 마쳐요. 실제 파일을 처음부터 들어 보세요. “장면 1”, 그림 지시, URL을 읽지 않고 낭독문과 뜻이 같으면 성공이에요. 프로젝트도 남겨요.

Vrew는 AI 목소리의 상업 이용을 안내하지만 화자별 조건을 확인해요. Voicevox는 출처 표시 예외가 있어요. 이번에는 한국어 기본 화자를 쓰고 생성 당시 사용 조건을 메모하세요.[S330]

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

무음 모션을 선택했거나, 내 대본과 끝까지 들은 녹음/TTS 파일이 있어요.

이렇게 보이면?

목소리가 뜻을 바꾸면 대본의 발음을 고쳐 다시 녹음·생성해요. 무료 잔여량이 부족하면 본인 녹음을 쓰세요.

녹음 파일은 원본으로 PC에 옮겨요. Vrew는 PC 앱에서 작업하고 파일 내보내기 메뉴를 확인하세요. 같은 PC 폴더에 대본·음성을 모아요.

휴대폰은 본인 녹음을 기본으로 해요. CapCut 텍스트의 TTS/텍스트 음성 변환이 보이면 짧게 생성·출력 조건을 확인한 뒤 선택하세요. 유료면 녹음으로 돌아와요.

지금 하는 일

이미지·음성을 가져와 세로 타임라인에 놓아요.

왜 하는지

4:5 카드를 그대로 꽉 채우면 글자와 출처가 잘려요.

따라 하기

  1. CapCut 공식 웹의 다운로드 또는 공식 앱 스토어에서 설치하고 무료로 시작해요. 로그인 안내가 나오면 본인 계정을 사용하세요. 한국 배포·기본 편집 경로가 있어요.[S326][S327]
  2. 먼저 새 프로젝트 → 가져오기/추가로 본인 이미지 한 장을 넣고 비율/캔버스 9:16을 고르세요. 짧게 내보내 무료 저장을 확인한 뒤 본 작업을 시작해요.
  3. 모션 경로: Canva에서 1080×1920 새 디자인을 만들고 카드 문안을 복사해 세로로 다시 배치해요. 무료 자동 크기 변경을 전제하지 않아요. 새 PNG를 장 순서로 가져오고, 타임라인에서 각 이미지 끝을 끌어 길이를 맞춰요. 연습 목표는 3~5장·20~30초예요.
  4. 화면의 애니메이션/키프레임과 비슷한 메뉴에서 느린 확대 또는 위치 이동 한 가지만 써요. 키프레임은 시작과 끝의 크기·위치를 정하는 표시예요. 아래 PC 연습 순서로 첫 장 한 개부터 완성하세요.
  5. 해설 경로: 실습 4에서 만든 scene-01.png부터 장면표 순서로 가져와요. voice-script.txt로 만든 녹음/TTS를 가져와 음성을 먼저 놓고, 말이 바뀌는 지점에 장면 길이를 맞추세요. B-roll은 설명 중에 보여 주는 보조 장면이에요. 본인 사진·도형을 사용하고 AI 삽화는 실제 현장처럼 제시하지 마세요.
  6. 해설은 오디오/가져오기·기기의 소리와 비슷한 메뉴로 추가해요. 영상으로 받은 TTS는 오디오 분리/추출 후 필요 없는 영상 트랙을 빼요. 처음부터 재생해 장면과 말이 맞는지 확인하세요.
PC · 첫 이미지에 느린 확대 한 번 넣기

CapCut PC에서 하는 연습이에요. 아래 4초·100→105%는 연습값이에요. 글자·출처는 가장자리에서 안쪽에 두세요.

  1. 타임라인의 첫 이미지 클립을 클릭해 선택하고 양 끝을 끌어 길이를 4초로 맞춰요.
  2. 재생 위치를 클립 맨 앞(0초)에 놓아요. 오른쪽 비디오 → 기본 → 변형과 비슷한 메뉴에서 크기/스케일을 100%로 두세요.
  3. 크기 옆 마름모(키프레임 추가)를 한 번 눌러 첫 표시를 만들어요. 타임라인에 마름모가 보이는지 확인해요.
  4. 재생 위치를 클립 마지막 프레임으로 옮겨요. 크기를 105%로 바꾸고 두 번째 마름모를 확인해요. 자동으로 생기지 않으면 같은 마름모 버튼을 눌러 추가해요.
  5. 클립 처음으로 돌아와 재생하세요. 한 번에 커지지 않고 천천히 확대되며, 끝에서도 글자·출처가 모두 읽히면 성공이에요. 잘리면 마지막 크기를 줄여요.

휴대폰: 클립 선택 → 재생선을 시작에 → 마름모 추가 → 재생선을 끝에 → 미리보기에서 두 손가락으로 조금 확대 → 마지막 표시 확인 → 재생 순서예요. 키프레임을 못 찾으면 정지 이미지로 먼저 끝내고 모션만 나중에 더해도 돼요. 공식 도움말에서 keyframe을 찾아보세요.

CapCut PC의 미디어/가져오기로 파일을 넣고 아래 타임라인으로 끌어요. 미리보기의 비율에서 9:16을 골라요. 모바일 전용 템플릿을 찾지 않아도 돼요.

CapCut 홈 → 새 프로젝트 → 사진/동영상 선택 → 추가로 시작해요. 아래 도구의 비율/캔버스에서 9:16을 고르고 사진 길이를 끌어 조절해요. 음성은 오디오 메뉴에서 찾아요.

지금 하는 일

말을 자막으로 바꾸고 틀린 글자를 고쳐요.

왜 하는지

AI 음성 인식도 숫자·사람 이름·“안 된다”를 잘못 들을 수 있어요.

따라 하기

  1. 녹음/TTS가 있으면 텍스트/자막의 자동 자막과 비슷한 메뉴에서 언어를 한국어, 음원은 내 음성 트랙으로 골라 생성해요. 무음 모션은 인식할 음성이 없으므로 텍스트 추가로 카드 핵심을 직접 넣어요.
  2. 처음부터 들으며 각 자막을 눌러 숫자·단위·이름·부정 표현을 고치고, 표시 구간의 양 끝을 끌어 발화와 맞춰요. 문장이 길면 나누고 다음 장면의 글자를 가리지 않게 해요.
  3. 음악은 처음엔 넣지 마세요. 넣는다면 인스타 게시와 상업 사용이 허용된 곡의 사용 조건·표시문·확인일을 저장하고 오디오 메뉴로 가져와요. CapCut의 Commercial Sounds 표시만 보고 인스타에 반출하지 마세요. 허용 플랫폼 밖 사용에는 별도 허락이 필요해요.[S328]
  4. 휴대폰 스피커로 들으며 음악 때문에 말이 묻히면 음악 볼륨을 낮추거나 빼세요. 소리를 끈 상태에서도 핵심을 읽을 수 있는지 확인해요.

PC에서 자막/텍스트 → 자동 자막과 비슷한 메뉴를 찾아 한국어를 선택해요. 생성된 자막 항목과 타임라인을 함께 보며 교정하세요.

  1. 내보내기 또는 화면 위의 내보내기 화살표를 눌러요. 이번 목표는 1080p · 9:16 · 1080×1920 · MP4예요. PC에 형식 선택이 있으면 MP4를 고르고 휴대폰에서는 저장 후 파일 형식·치수를 확인해요.
  2. 이름을 reel.mp4로 정해 저장하세요. 유료 효과/소재/AI 기능 안내가 뜨면 해당 요소를 빼고 다시 내보내요. 원본 프로젝트와 대본·음성·출처를 남겨요.
  3. 저장한 MP4를 앱 밖에서 처음부터 끝까지 재생하세요. 첫/끝 프레임·잘린 글자·자막 오타·소리·의도하지 않은 엔딩·워터마크를 확인해요.
  4. 사실적인 합성 장면이나 실제같은 합성 음성을 썼다면 인스타 공유 전 AI 공개 설정을 확인하세요. 생성 표시·사용 조건 메모도 함께 넘겨요.[S389]
  5. 검수는 서비스 결과물 확인표로 마치고, 실습 7 파일 옮기기로 가세요. 실습 6의 표시 판단도 읽어요. 서비스 파일은 키트의 승인 명령에 넣지 않아요.

본인 내레이션 준비

지금 하는 일

왜 하는지

목소리·음원 권리를 직접 확인할 수 있게 해요.

따라 하기

  1. 기본은 무음과 자막이에요. 목소리를 넣으려면 아래 녹음·내보내기 순서로 본인 목소리를 wav 파일로 저장하세요. 지원 파일을 못 만들면 narration: null·music: null·tts: silent를 유지하고 다음 영상 재생으로 가요.
  2. 현재 출력 폴더의 config.json에서 reel 객체 안의 narration에 녹음 전체 경로를 넣으세요. 아래 필드만 고치고 파일 전체를 덮어쓰지 마세요.
  3. music에는 권리를 확인한 파일만 넣으세요. 녹음을 넣어도 tts는 silent로 둘 수 있어요.
"narration": "C:/Users/내이름/Downloads/my-voice.wav",
"music": null,
"tts": "silent"

이렇게 보이면 성공

무음 연습을 유지했거나, 실제 존재하는 본인 녹음 경로가 현재 config.json에 지정됐어요.

이렇게 보이면?

  • 녹음 파일이 없으면 narration을 null로 두고 무음 연습을 먼저 마치세요.

Windows

목소리를 넣을 때만 Audacity 공식 사이트에서 본인 OS용 프로그램을 설치하세요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말을 확인하세요.

  1. Audacity의 Audio Setup(오디오 설정)에서 녹음할 마이크를 고르세요. 빨간 녹음 버튼을 누르고 copy.json의 subtitle을 장면 순서대로 읽어요. 정지 버튼을 누른 뒤 재생해서 내 목소리인지 확인해요.[S260]
  2. 앞뒤 무음을 줄이려면 파형에서 남길 부분을 드래그하고 Edit → Remove Special → Trim Audio를 선택하세요. 장면마다 끝나는 시각에 맞춰 읽기 어렵다면 문장을 줄여 다시 녹음하세요.[S262]
  3. File → Export Audio에서 컴퓨터에 내보내기, 파일명 my-voice.wav, 형식 WAV, 저장 위치 Downloads(다운로드)를 고르고 내보내요. 프로젝트 저장 파일은 녹음 WAV와 달라요.[S261]
  4. 파일을 직접 열어 재생한 뒤 아래 전체 경로를 현재 config.json의 reel.narration에 넣으세요. 내 사용자 폴더 이름으로 바꿔요.

경로 예: C:/Users/내이름/Downloads/my-voice.wav

  2. 앞뒤 무음을 줄이려면 파형에서 남길 부분을 드래그하고 Edit → Remove Special → Trim Audio를 선택하세요. 장면마다 끝나는 시각에 맞춰 읽기 어렵다면 문장을 줄여 다시 녹음하세요.[S262]

경로 예: /Users/내이름/Downloads/my-voice.wav. config.json 문자열 안에는 큰따옴표를 유지해요.

휴대폰 녹음이 m4a라면 WAV로 바꾸기

휴대폰에서 내보낸 본인 녹음을 키트 폴더로 복사하세요. 확장자를 표시하고 원래 확장자는 유지한 채 파일명을 my-voice.m4a로 맞춰요. 아래는 키트에 설치된 FFmpeg로 내용을 WAV로 변환하는 명령이에요. 확장자만 .wav로 바꾸는 것은 변환이 아니에요.[S263]

python -c "import imageio_ffmpeg,subprocess; subprocess.run([imageio_ffmpeg.get_ffmpeg_exe(),'-i','my-voice.m4a','-vn','-c:a','pcm_s16le','my-voice.wav'],check=True)"

Windows는 첫 python을 .venv\Scripts\python.exe로 바꿔요. 기존 my-voice.wav가 있으면 새 이름으로 바꿔 출력하세요. 완성한 WAV를 재생하고 그 전체 경로를 narration에 넣어요. 변환 실패·목소리 미재생이면 narration을 null로 돌려 무음을 유지하세요. 녹음 앱에서 파일로 내보낼 수 없다면 위 PC 녹음 경로를 쓰세요.

  2. 기본 예제는 1080×1920·20초·무음과 자막이에요. 녹음을 넣었다면 목소리와 자막을 함께 확인하세요. 자동 음성 정렬은 없어요.
