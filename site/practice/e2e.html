(실습) E2E 한눈에 보기

첫 게시까지는 실습 0~7, 매일 생성 설정까지는 실습 9도 마쳐요. 실습 8 API는 선택 심화, 10은 게시 뒤 관찰이에요. 완료한 단계만 체크하고 첫 게시물 주소는 실습 7에 남기세요.

이 실습이 끝나면 내 손에 있는 것: 완료 단계·다음 할 일·첫 게시물 주소

진행 기록은 이 브라우저에 저장해요.

각 체크는 해당 실습과 공유돼요. 저장이 실패해도 현재 페이지에서 계속 체크할 수 있으며 이동 전 개인 메모로 보관하세요. 서버 동기화는 없어요.

선택하지 않은 앱 카드·릴스 업로드와 API는 체크하지 않아도 돼요. 첫 게시까지만 진행한다면 생성 예약도 나중에 이어가요. 매일 생성 설정을 목표로 했다면 실습 9는 필수예요. 실제 게시라면 실습 3의 내 자료 생성은 필수예요. 카드만 게시해도 실습 5의 영상 재생과 실습 6의 전체 검수는 마쳐요. 본인 녹음은 무음 선택으로 대신할 수 있어요. 전체 완료율보다 내가 고른 경로의 결과물을 확인하세요.

자주 묻는 질문 5개

무엇부터 시작하나요?

실습 0부터 시작하세요.

예: 경로를 고르고 계정 → 설치 → 제작으로 이어가세요. 단계로 →

얼마나 남았는지 어디서 보나요?

위의 완료 수와 아래 빈 체크를 보세요.

예: 빈 항목의 단계로 링크를 눌러 남은 작업을 확인하세요. 단계로 →

모든 칸을 채워야 끝나나요?

선택한 경로의 결과물이 있으면 돼요.

예: 카드만 게시했다면 앱의 릴스 업로드·API는 비워 두세요. 매일 생성 설정이 목표라면 실습 9도 마쳐요. 내 자료 생성·영상 재생·묶음 검수는 마친 뒤 게시물 주소를 남겨요. 단계로 →

중간에 멈췄다면 어디서 재개하나요?

마지막 결과물이 있는 단계에서 이어가세요.

예: copy.json이 있다면 문안 확인 뒤 카드 render부터 계속하세요. 단계로 →

체크 기록이 사라지면 어떻게 하나요?

같은 브라우저에서 열고 별도 메모를 확인하세요.
