이 장의 흐름

먼저 답부터

생성 API 키와 Instagram 토큰을 비공개 .env에 보관하고, 공급자 강제 상한과 키트 일·월 상한을 함께 설정하세요.

하린 「출근길 3분 생활 뉴스」를 매일 만들고 싶어요.
정 선배 오늘은 비공개 설정 파일과 월 예산부터 확인해요.

한눈에 보기

지금 하는 일

세 이름을 구분해요

API 키는 서비스 호출 자격, access token은 계정 작업 허가예요.

예: OPENAI_API_KEY는 생성 서비스, IG_ACCESS_TOKEN은 내 인스타 게시에 써요. refresh token은 새 access token을 받는 별도 자격이며 주로 Google OAuth에서 써요.

Instagram Login은 유효한 장기 access token 자체를 갱신해요. Google refresh token을 붙이지 않아요.[A005][A018]

지금 할 일 · 아래 복사 명령 뒤 .env를 로컬 편집기로 여세요.

공급자·로컬 상한을 함께 둬요

예산 알림만으로 자동 중지가 되지는 않아요.

키트 기본 일 $1·월 $10은 바꿀 수 있는 운영값이에요. 생성 전 최대비와 재시도비를 예약하고 usage로 정산해요. 응답 유실 비용은 최대비로 남겨요.

OpenAI는 보통 Limits → Spend → Enforce a hard limit, Gemini는 Spend → Monthly spend cap, Claude는 별도 Workspace → Spend limits에서 확인해요. Cloud budget은 알림이에요.[A081][A030][A031][A115]

지금 할 일 · 자기 계정에서 강제 상한을 확인한 뒤에만 provider_hard_cap_confirmed를 true로 바꾸세요.

보통 이런 이름의 메뉴를 찾아요. 앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 화면에서 비슷한 이름을 찾아 주세요. 못 찾겠으면 공식 문서 링크 모음과 공식 지출 상한 안내를 확인하세요. 버전에 따라 다를 수 있어요.

유효할 때 토큰을 갱신해요

Instagram 장기 토큰은 만료 전에 갱신하세요.

단기 1시간·장기 60일, 갱신은 발급 24시간 이후부터 가능해요. 키트는 발급·만료 시각을 읽고 live 재개 시 조건이 맞으면 갱신해 private 파일에 저장해요.[A005][A083]

만료·철회는 다시 동의해야 해요. 다음 실행의 .env 원본보다 갱신된 private 토큰 파일이 쓰일 수 있어요.

지금 할 일 · IG_TOKEN_ISSUED_AT·IG_TOKEN_EXPIRES_AT에 시간대 오프셋까지 적으세요.

해 보기 · 내 월 생성비

교육용 가정 모형 · USD

JavaScript를 켜면 계산돼요. 기본값: $0.02400/월.

산식: 편수 × [(입력 × 입력단가 + 출력 × 출력단가) ÷ 1,000,000 + 이미지 수 × 0.03375] × (1 + 여유율). 이미지 단가는 1K 출력과 텍스트 입력 100토큰 가정이에요. 이미지 추가 추론·검색·참조 입력, 음성·영상·세금·호스팅·최소 충전은 제외해요. 실제 중단은 키트와 공급자 상한에서 설정하세요.

LLM 기본 단가와 모델별 조건은 출처를 확인하세요. Haiku 표는 입력 10만 토큰 이하, Gemini 표는 조사 시점 가격이에요.[A025][A028][A032]

따라 하기

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

Copy-Item config.example.json config.json
Copy-Item .env.example .env
.\.venv\Scripts\python.exe doctor.py --config config.json
cp config.example.json config.json
cp .env.example .env
python doctor.py --config config.json

이렇게 보이면 성공

config.json과 .env가 생기고 doctor에 일 $1.0, 월 $10.0 상한·mock 준비 완료가 보여요. 값은 로컬에서 직접 편집하고 채팅·공개 저장소에 붙이지 마세요.

편당·월 비용 · 2026년 10월

이 장의 mock 명령은 생성 API 사용료가 $0이에요. 실제 카드의 문안 생성비 가정은 편당 $0.00080 × 월 30편 = $0.02400이에요. 입력 3,000·출력 1,000토큰을 Luna 기본 종량 단가 $0.10/$0.50(100만 토큰당)에 곱했어요. 이미지·음성·재시도 없는 가상 계산이에요.[A025]

세금·환율 수수료·최소 충전·호스팅·전기·추가 검수 호출은 별도예요. 내 편수로 계산하세요.
