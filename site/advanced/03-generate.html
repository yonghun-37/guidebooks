이 장의 흐름

먼저 답부터

RSS에서 원문을 고르고 LLM에는 문안의 모양을 JSON 스키마로 지정하세요. 숫자·이름이 원문에 있는지 검사한 뒤 코드 카드로 넘겨요.

하린 「출근길 3분 생활 뉴스」를 매일 만들고 싶어요.
정 선배 오늘은 원문과 연결된 draft.json부터 확인해요.

한눈에 보기

지금 하는 일

오늘 원문을 자동으로 골라요

권리를 확인한 RSS나 직접 입력한 JSON을 소스로 써요.

RSS는 새 글 제목·본문·주소를 전달하는 목록이에요. 키트는 피드의 description/summary를 읽어요. 링크 본문의 전체 내용을 자동으로 가져오는 수집기는 아니에요.

실제 생활 뉴스에는 확인한 공고 본문을 source.text에 충분히 넣으세요. 동봉 원문은 synthetic=true라 live가 차단돼요.

지금 할 일 · 아래 로컬 RSS 설정으로 같은 생활 뉴스 카드를 만들어 보세요.

"sources": {
  "files": [],
  "rss": [{"url":"sources/insta-feed.xml", "flow":"insta",
    "synthetic":true, "rights_reviewed":false, "category":"생활 뉴스"}],
  "performance_weight": 0.25
}

문안의 모양을 고정해요

JSON은 이름과 값을 짝지어 저장하는 텍스트예요.

draft.json의 scenes는 title·text·duration을 가진 장면 목록이에요. 동봉 예시는 표지 → 대상 → 기간 → 서류 → 다시 확인으로 이어져요.

위 그림의 길이·개수는 키트 기본 규칙이에요. 파싱·스키마가 실패하면 정한 예산 안에서 재시도해요.

지금 할 일 · 생성 결과에 새로운 제도명·금액·신청일을 만들지 않았는지 원문과 나란히 보세요.

생성 API는 하나씩 붙여요

카드의 한글은 템플릿으로 쓰고 이미지는 선택으로 생성해요.

LLM 키 하나와 실제 원문부터 연결해요. 이미지가 필요하면 providers.image=gemini·media.image_api=true를 사용해요. 음성은 Google TTS 또는 본인 녹음, 생성 영상은 Runway 선택이에요.

키트의 이미지 옵션은 장면마다 생성해요. 카드 5장에 각 1장이라면 조사 단가 가정 $0.03375×5 + Luna $0.0008 = $0.16955/편, 30편 $5.0865예요. 이미지 1장을 재사용하는 비교안 $1.4925/월(Sol)은 별도 제작 가정이에요.[A025][A028]

지금 할 일 · 먼저 image_api=false를 유지하세요. API를 바꾸면 모델 이름·지원 schema·단가를 함께 확인하세요.

기능과금 단위·가상 계산

영상Runway gen4_turbo 10초×$0.05 = $0.50/편

따라 하기

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

A2에서 만든 config.json의 sources 항목만 위 내용으로 바꾸세요. 전체 설정을 짧은 조각으로 덮어쓰지 마세요.

.\.venv\Scripts\python.exe pipeline.py run --flow insta --provider mock --mode auto --config config.json --state private/a3
python pipeline.py run --flow insta --provider mock --mode auto --config config.json --state private/a3

내 원문·실제 공급자로 바꿀 때

본인이 확인한 실제 공고를 private/my-sources.json에 넣으세요. 아래 text·URL을 실제 내용으로 채워요. synthetic와 rights_reviewed는 사실·사용권을 확인한 뒤 정하는 값이에요. 동봉 예시를 실제 공고로 바꾸는 표식이 아니에요.

[{"flow":"insta","title":"직접 확인한 생활 뉴스 제목",
  "text":"여기에 대상·기간·서류와 예외 조건이 담긴 실제 공고 내용을 넣어요.",
  "url":"https://example.org/실제-공고로-교체", "entities":[],
  "synthetic":false,"rights_reviewed":true,"category":"생활 뉴스"}]

config.json의 sources.files를 ["private/my-sources.json"], rss를 []로 바꾸세요. 매일 새 공고를 받으려면 권리를 확인한 RSS 객체의 url·category·entities·rights_reviewed를 채워요. 피드가 짧은 요약만 주면 전체 공고를 직접 확보하는 단계도 운영해야 해요.

providers.llm을 openai, models.openai를 gpt-6-luna로 정하고 .env의 OPENAI_API_KEY에 본인 키를 넣어요. media.image_api와 video_api는 false로 시작하세요. 실제 생성 호출은 --live에서만 이뤄져요. A5의 계정·호스팅·강제 비용 상한까지 준비한 뒤 실행하세요.

이렇게 보이면 성공

insta · dry_run과 미리보기 경로가 보여요. source.json에는 생활 뉴스 원문, draft.json에는 같은 제목과 scenes 목록이 있어요. mock은 원문을 정해진 규칙으로 옮겨요. 실제 LLM 요약은 본인 키 연결 후 실행해요.

"title": "청년 지원금, 신청 전 확인할 3가지"
이렇게 보이면?
표시·오류해결할 일
JSON 스키마 검증 실패. 재시도 예산을 소진했습니다.모델 지원 schema·필수 필드·출력 한도를 확인하고 자동 게시를 멈춰요.
드라이런에서는 RSS XML을 로컬 파일로 저장해 지정하세요.위 sources/insta-feed.xml처럼 로컬 경로를 사용해요.
가상 소스 또는 권리 미확인 소스는 live 생성·게시할 수 없습니다.실제 원문과 권리를 확인한 새 소스를 만드세요. 샘플의 표식만 지우지 마세요.

얼마가 드나요

편당·월 비용 · 2026년 10월

이 장의 mock 명령은 생성 API 사용료가 $0이에요. 실제 카드의 문안 생성비 가정은 편당 $0.00080 × 월 30편 = $0.02400이에요. 입력 3,000·출력 1,000토큰을 Luna 기본 종량 단가 $0.10/$0.50(100만 토큰당)에 곱했어요. 이미지·음성·재시도 없는 가상 계산이에요.[A025]

WaveNet 600자 추가는 무료 소진 후 $0.0024/편·월 $0.072예요. 이미지·영상 조합은 아래 차트로 비교하세요.[A025][A028][A038][A037]
