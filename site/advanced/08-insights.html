지금 할 일 · 실제 운영에서 CSV의 availability·unit·collected_at을 함께 확인하세요.

다음 주제를 점수로 고르게 해요

키트는 이미 처리한 원문을 빼고 남은 후보의 점수를 비교해요.

위 점수 그림에서 순서 점수와 분류 성과를 더하는 계산을 확인하세요. 여러 성과가 있으면 log(1+views)의 평균을 써요. 현재 자동 점수에는 저장·공유율을 넣지 않아요.

성과가 없는 분류는 성과 점수 0으로 시작해요. 이 방식은 새 주제를 발명하는 모델이 아니라, 공급된 원문 중 다음 것을 고르는 규칙이에요.

지금 할 일 · 생활 뉴스 분류를 대상·신청 준비 등 운영할 주제로 나누고 sources.performance_weight를 기록하세요.

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

실제 게시물 분석을 읽을 때

게시가 완료된 live 실행 ID와 분석 권한이 필요해요. A5 기본 private/state에서 만든 본인 실행 ID를 넣으세요. 다른 --state를 썼다면 같은 경로를 추가해요.

.\.venv\Scripts\python.exe insights.py RUN_ID --live
python insights.py RUN_ID --live

이렇게 보이면 성공: 지표 CSV 저장 완료가 보여요. mock=False·실제 media_id·단위·수집일을 확인해요. 빈 값은 missing으로 남겨 다음 날 다시 읽으세요. API 지표 준비가 실제 앱 화면과 즉시 같아야 성공인 것은 아니에요.

이렇게 보이면 성공
