편당·월 비용 · 2026년 10월

이 장의 mock 명령은 생성 API 사용료가 $0이에요. 실제 카드의 문안 생성비 가정은 편당 $0.00080 × 월 30편 = $0.02400이에요. 입력 3,000·출력 1,000토큰을 Luna 기본 종량 단가 $0.10/$0.50(100만 토큰당)에 곱했어요. 이미지·음성·재시도 없는 가상 계산이에요.[A025]

세금·환율 수수료·최소 충전·호스팅·전기·추가 검수 호출은 별도예요. 내 편수로 계산하세요.

운영 전환표에 편집 권장 기준을 적었어요. 최초 1~2주 승인제에서 최근 10편 중 9편 통과·미해결 예외 0건을 확인한 뒤 사후 확인으로 넘어가요. 다음 10편 모두 통과·잘못 공개/거부/실행 오류 0건·미해결 예외 0건이면 config의 mode를 auto로 바꿔요. 자동 승격 기능은 없어요.
