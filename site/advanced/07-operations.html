A7 · 매일 실행하고 예외만 알림 받기

이 장에서 만드는 것: OS 예약 파일과 하루 운영 계획

2026년 10월 조사 기준 · 전체 진행표

이 장의 흐름

먼저 답부터

처음엔 로컬 예약으로 돌리고, PC를 계속 켤 수 없으면 상태를 외부에 보존한 뒤 GitHub Actions로 옮기세요. 승인을 기다리는 실행은 종료해도 돼요.

하린 「출근길 3분 생활 뉴스」를 매일 만들고 싶어요.
정 선배 오늘은 OS 예약 파일과 하루 운영 계획부터 확인해요.

한눈에 보기

지금 하는 일

하루를 tick으로 나눠요

tick은 재개·예약 발행·오늘 새 실행을 확인하는 명령이에요.

새 생성은 OS 현지 시각의 지정 시간 이후 하루 한 번이에요. 아래 그림에서 시작·대기·공개 시각을 구분하고 PC 전원·절전·로그인 사용자를 확인하세요.

지금 할 일 · 설치 파일을 생성해 내용을 읽고 실제 등록은 본인 PC에서 하세요.

알림에는 예외 이유를 담아요

Discord는 알림, Telegram은 허용 사용자 승인으로 연결해요.

기본 notification.json에는 event·run ID·상태·미리보기 정보가 남아요. live에서 .env에 알림 자격을 넣으면 전송해요. Telegram은 TELEGRAM_ALLOWED_USER·TELEGRAM_CHAT_ID를 둘 다 정해요.

python pipeline.py telegram --live는 최대 25초 새 응답을 읽고 끝나요. 승인 후 resume 또는 다음 tick이 발행해요. Discord incoming webhook 자체는 승인 결과를 받지 않아요.[A066][A067][A144]

지금 할 일 · 처음엔 로컬 approve를 쓰고 휴대폰 승인 필요 시 Telegram을 붙이세요.

Actions는 상태를 밖에 남겨요

새 runner는 어제 SQLite를 자동으로 기억하지 않아요.

examples/github-actions.yml을 본인 저장소에 검토해 복사해요. 암호화된 private 전체는 미디어와 다른 비공개 R2 bucket에 저장해요. pull → 실행 → 항상 push 순서예요. 같은 상태는 같은 concurrency 그룹으로 직렬 실행해요.

STATE_*·STATE_ENCRYPTION_KEY·공급자/플랫폼 키는 Secrets, 비밀 없는 전체 설정은 KIT_CONFIG_JSON이에요. 저장 실패 후 .lease가 남으면 다음 실행은 차단돼요. 공개 artifact·캐시에 토큰/DB를 넣지 마세요.[A046][A155]

지금 할 일 · 먼저 외부 상태 초기화·암호화 안내대로 로컬 상태를 준비하세요. 기본 live=false를 유지하세요.

전자동 전환: A0의 기준을 확인한 뒤 config.json의 mode를 auto로 바꿔요. 로컬 실제 예약 생성 명령에는 --config config.json --live를 붙이고 새 설정으로 등록하세요. 기존 작업을 멈추고 해제한 뒤 새 작업을 등록해 중복을 막아요. Actions는 본인이 AUTO_KIT_LIVE=true를 설정할 때만 정기 live가 켜져요.

schedule은 default branch에서 실행해요. 현재 공식 문서는 IANA timezone을 지원해요. 예: cron: '17 9 * * *' + timezone: Asia/Seoul 또는 UTC 17 0 * * *. 최소 간격 5분, 지연·누락·공개 저장소 60일 비활성 시 예약 중지를 확인하세요.[A044]

코드 없이 돌리는 선택지

기본은 Python이에요. 화면으로 API를 연결하려면 n8n을 비교하세요. 셀프 호스팅은 소프트웨어와 서버·생성 API 비용을 따로 봐요. Instagram 전용 공식 노드가 안 보이면 HTTP Request로 같은 생성→조회→발행을 구성해요. AI 필드가 없으면 HTTP 본문에 is_ai_generated를 명시해요. 커넥터의 Facebook Login 요건을 Instagram Login에 옮기지 마세요.[A057][A060][A150]

Make Free 1,000 credits/월·최소 15분, Zapier Free 100 tasks/월은 게시 편수가 아니에요. 한 게시물의 여러 단계가 각각 사용량이 될 수 있어요. n8n Cloud Starter는 연 €240(월 환산 €20) 표시이며 생성 API는 별도예요. 가져오기 예시는 Python 실행 환경이 있는 셀프 호스팅용이에요.[A131][A062][A055]

따라 하기

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

.\.venv\Scripts\python.exe -m schedule.install --os windows --flow insta --time 09:17
python -m schedule.install --os macos --flow insta --time 09:17

생성된 install 스크립트를 읽고 출력된 등록 명령을 본인 OS에서 실행하세요. Windows는 Get-ScheduledTask, macOS는 launchctl print로 확인해요. 등록 해제 명령은 생성 파일 끝에 있어요. 아래는 OS 등록 없이 사후 확인·거부를 연습해요.

.\.venv\Scripts\python.exe pipeline.py run --flow insta --provider mock --mode post_review --state private/a7
.\.venv\Scripts\python.exe pipeline.py reject RUN_ID --state private/a7
.\.venv\Scripts\python.exe pipeline.py tick --flow insta --provider mock --mode auto --state private/a7-daily --daily-at 00:00
python pipeline.py run --flow insta --provider mock --mode post_review --state private/a7
python pipeline.py reject RUN_ID --state private/a7
python pipeline.py tick --flow insta --provider mock --mode auto --state private/a7-daily --daily-at 00:00

이렇게 보이면 성공

예약 생성에 예약 파일 생성 완료가 보여요. 사후 확인 run은 scheduled, reject는 rejected예요. tick은 목록에 오늘 새 실행을 한 번만 만들고 같은 날 반복하면 새 실행을 추가하지 않아요. 예시 소스 하나는 이후 날짜에 자동 보충되지 않으므로 실제 운영에는 새 원문 공급이 필요해요.

이렇게 보이면?
표시·오류해결할 일
새 주제가 없습니다당일 공급할 권리 확인 원문을 추가해요. 연습만 새 --state를 써요.
예약 시각이 지났습니다공개 상태·게시 ID부터 확인하세요. 이미 게시된 인스타는 로컬 reject로 삭제되지 않아요.
.lease 미완료 표식예약을 멈추고 최신 DB·게시 ID·비용부터 복구하세요. lease만 지우고 오래된 상태로 재실행하지 마세요.
다른 실행 진행 중로컬/Actions를 동시에 돌리지 말고 잠금이 풀린 다음 tick을 확인하세요.

얼마가 드나요

편당·월 비용 · 2026년 10월

이 장의 mock 명령은 생성 API 사용료가 $0이에요. 실제 카드의 문안 생성비 가정은 편당 $0.00080 × 월 30편 = $0.02400이에요. 입력 3,000·출력 1,000토큰을 Luna 기본 종량 단가 $0.10/$0.50(100만 토큰당)에 곱했어요. 이미지·음성·재시도 없는 가상 계산이에요.[A025]

기존 PC 실행은 생성비 외 전기·인터넷 비용을 확인하세요. 표준 공개 Actions runner는 무료, 비공개 GitHub Free는 월 2,000분 포함이에요. 가상 하루 10분×30일=300분이지만 생성 시간·저장·큰 runner 비용은 별도예요. 상태용 R2도 무료량 초과 과금을 확인하세요.[A045][A048]
