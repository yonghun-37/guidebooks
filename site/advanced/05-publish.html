URL은 파일 자체가 열려야 해요

Meta가 로그인 없이 내려받을 공개 JPEG·MP4가 필요해요.

내 PC 경로·localhost·Drive 미리보기·GitHub blob HTML은 파일 URL이 아니에요. 인증 없는 GET과 MIME·바이트를 확인해요. 키트는 공개 GET 뒤 SHA256도 대조해요.

호스팅은 관문·승인보다 먼저 일어나요. 공개해도 되는 미디어만 올리고 설정·원문·토큰은 비공개로 남겨요.[A006][A007]

지금 할 일 · 교육용은 별도 Pages, 운영은 과금 조건을 확인한 R2 등으로 골라요.

공개 미디어와 비공개 상태 저장소를 분리해요
호스팅설정·확인
local기본 가상 URL · 드라이런 전용
pages별도 교육용 저장소·미디어 브랜치·Pages URL·PAGES_TOKEN. 작은 비민감 미디어용. 상업 운영 무료 CDN으로 쓰지 않아요.
r2공개 미디어 bucket·base_url·비공개 S3 endpoint와 R2 키. 월 Standard 10GB-month 등 무료 범위를 넘으면 과금돼요. r2.dev는 개발용이에요.

한도는 계정에서 읽어요

50·100 중 임의 값을 넣지 말고 응답의 사용량·총량을 읽으세요.

GET content_publishing_limit?fields=quota_usage,config에서 quota_usage는 사용량, config.quota_total은 총량이에요. 캐러셀은 자식 수가 아니라 발행한 부모 게시물로 세어요.[A008][A006]

공식 문서에 이동 24시간 100·50이 함께 있어요. 키트는 조회 실패 시 연기하고 기본 safety_daily_posts=1을 적용해요. 계정값이 더 낮으면 그 값을 따라요.

실제 연결은 승인제부터 해요

드라이런을 live로 바꿀 수는 없어요.

A2 설정·실제 권리 확인 소스·LLM 공급자·공개 호스팅·본인 계정을 준비하고 doctor --config config.json --live --flow insta를 실행해요. --check-remote를 추가하면 실제 한도를 읽어요.

실제 run은 --live를 붙여 새로 만들고 기본 approval에서 waiting_approval을 확인하세요. 생성·호스팅에는 실제 호출 비용이 생겨요. approve 뒤 같은 ID resume --live를 실행하고 done·게시 ID·계정 공개 상태를 확인하세요.

지금 할 일 · 상세 실제 연결 명령을 준비 완료 후 본인이 실행하세요. 이 장에서는 아래 mock만 실행해요.

결과가 불명이면 조회부터 해요

uncertain 상태를 새 게시로 덮지 마세요.

같은 ID resume --live로 기존 컨테이너를 확인해요. 이미 발행됐으나 게시 ID가 없다면 계정에서 ID·문안을 확인한 뒤 pipeline.py reconcile RUN_ID --media-id EXISTING_MEDIA_ID --live로 기록을 연결해요.

기존 ID가 현재 계정·문안과 맞아야 연결돼요. 컨테이너 생성 결과 자체를 잃었을 때도 새 POST를 반복하지 않아요.

따라 하기

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

.\.venv\Scripts\python.exe pipeline.py run --flow insta --provider mock --mode auto --state private/a5
.\.venv\Scripts\python.exe pipeline.py status --state private/a5
python pipeline.py run --flow insta --provider mock --mode auto --state private/a5
python pipeline.py status --state private/a5

준비를 마친 뒤 본인 계정에서 실행

여기부터 본인의 생성·호스팅·게시 API를 실제 호출해요. A3의 실제 원문·권리, A2의 공급자 강제 상한과 .env, 이 장의 계정·권한·공개 호스팅을 모두 준비하세요. config.json의 mode는 approval, providers.llm은 실제 공급자로 설정해요.

설치 명령은 R2 등 선택 연결에 필요한 패키지를 추가해요. doctor는 로컬 설정만 검사해요. 빠진 값이 있으면 표시된 이름부터 채우세요. --check-remote는 실제 계정 한도를 조회하며 토큰 갱신도 일어날 수 있어요. run은 생성·호스팅 후 승인 대기에서 멈춰요.

.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements-live.txt
.\.venv\Scripts\python.exe doctor.py --config config.json --live --flow insta
.\.venv\Scripts\python.exe doctor.py --config config.json --live --flow insta --check-remote
.\.venv\Scripts\python.exe pipeline.py run --flow insta --config config.json --live
python -m pip install --only-binary=:all: -r requirements-live.txt
python doctor.py --config config.json --live --flow insta
python doctor.py --config config.json --live --flow insta --check-remote
python pipeline.py run --flow insta --config config.json --live

이렇게 보이면 성공: doctor의 [error]가 없고, 원격 조회에 사용량/총량이 표시돼요. run은 waiting_approval이에요. 실제 미리보기·원문·공개 파일·대상·표시를 확인한 뒤 아래 RUN_ID를 이번 live ID로 바꿔요.

.\.venv\Scripts\python.exe pipeline.py approve RUN_ID
.\.venv\Scripts\python.exe pipeline.py resume RUN_ID --live
python pipeline.py approve RUN_ID
python pipeline.py resume RUN_ID --live

이렇게 보이면 성공: done과 실제 게시 ID가 남아요. 본인 계정에서 일반 시청 가시성·문안·카드 순서·라벨을 확인하고 E2E의 실계정 항목에 기록하세요. waiting_approval·dry_run·컨테이너 생성만으로 실제 게시 완료를 체크하지 마세요. uncertain이면 기존 컨테이너와 게시 ID부터 확인해요.

이렇게 보이면 성공

dry_run이 보여요. 미리보기 경로의 request-plan.json에는 network_calls: 0, Bearer <REDACTED>, 자식 5개·부모·마지막 media_publish 요청이 있어요. 가상 URL은 실제 게시 주소가 아니에요.

얼마가 드나요

편당·월 비용 · 2026년 10월

이 장의 mock 명령은 생성 API 사용료가 $0이에요. 실제 카드의 문안 생성비 가정은 편당 $0.00080 × 월 30편 = $0.02400이에요. 입력 3,000·출력 1,000토큰을 Luna 기본 종량 단가 $0.10/$0.50(100만 토큰당)에 곱했어요. 이미지·음성·재시도 없는 가상 계산이에요.[A025]

게시 전 생성비와 호스팅을 따로 관리하세요. R2 무료 범위와 초과 요금은 저장량·요청량에 따라 달라요. 예를 들어 0.5MB JPEG 5장×30편은 가상 저장량 75MB(기존 파일·요청·재시도 제외)예요. 이를 월 고정 무료 보장으로 읽지 마세요.[A048]
