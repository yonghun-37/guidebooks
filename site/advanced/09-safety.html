지금 하는 일

권리와 원문을 먼저 남겨요

RSS 공개는 문장·사진 전체를 재사용할 허가가 아니에요.

생활 뉴스는 확인한 공고 링크와 기준일을 남겨요. 원문을 그대로 대량 복사하기보다 신청 대상·기간·서류를 설명하고 독자가 공식 공고에서 확인하도록 연결하세요.

사진·음원·폰트·인물 음성의 이용 조건은 따로 확인해요. 자동화 API 사용도 타인 권리 보호 의무를 없애지 않아요.[A068]

지금 할 일 · 실제 원문을 넣을 때만 synthetic=false·rights_reviewed=true를 설정하세요.

최종 콘텐츠에 맞게 표시해요

AI로 만든 사실적 영상·음성의 공개 판단을 기록하세요.

LLM이 문안만 도운 것과 실제 사건처럼 보이는 합성 사진·음성은 다르게 검토해요. 이 키트는 보수적인 true 예시를 제공하지만 모든 콘텐츠의 정답은 아니에요.

Instagram은 is_ai_generated를 사용하고 캐러셀 부모에만 보내요. 협찬은 AI 표시로 대신하지 못해요. 이 키트 Instagram Login 경로에 협찬 API 필드를 임의로 넣지 마세요.[A006][A154]

지금 할 일 · config.json에서 Boolean 값을 정하고 request-plan.json과 실제 라벨을 대조하세요.

중단·정정·보안 복구 순서를 정해요

잘못된 게시나 키 유출은 추가 실행부터 멈추세요.

사실 오류는 예약 중지 → 기존 게시 ID·문안 확인 → 본인 계정에서 정정/삭제 판단 → 소스·관문 보완 → 승인제 시험 순서예요. 공개한 인스타는 로컬 reject로 지워지지 않아요.

키가 노출됐다면 공급자/Meta에서 폐기·재발급하고 usage·청구·게시 이력·권한을 점검해요. 새 .env·Secrets를 넣고 import-instagram 명령으로 private 토큰 파일도 교체해요. private 파일이 환경변수보다 우선해요. 외부 상태를 쓰면 교체한 파일까지 다시 저장한 뒤 필요한 Git 이력 정리를 해요. 파일 삭제만으로 키가 회수되지 않아요.[A075][A107][A108]

지금 할 일 · 주간에 표본 문안·원문·권리·표시·비용·토큰 만료일을 확인하고 기준 이탈 시 approval로 돌아오세요.

공식 API를 쓴다는 이유만으로 도달이 좋아지거나 나빠진다고 계산하지 마세요. 이 책은 도달 변화 수치를 제시하지 않아요. 계정 제한·스팸 의심 오류가 오면 원인을 확인하고 반복 요청을 멈춰요.[A009]
