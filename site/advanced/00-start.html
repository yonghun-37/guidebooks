지금 하는 일

처음엔 이 조합 하나

카드는 코드로 만들고 LLM만 먼저 연결해요.

「청년 지원금, 신청 전 확인할 3가지」를 대상·기간·서류 카드로 만들어요. 계정과 문안은 직접 만든 가상 연습 예시예요. 실제 제도·금액·마감일을 주장하지 않아요.

설치 후 mock은 키 없이 돌아요. 실제 연결은 본인 Business/Creator 계정의 Instagram Login을 사용해요. Facebook 페이지가 필요 없어요.[A002]

지금 할 일 · 아래 설치 명령으로 카드 5장을 만드세요.

로그인 세 경로: 호스트·권한·토큰을 섞지 않아요

[A001][A003][A084][A112]

편집 권장 기준 · 비율은 통과 편수 ÷ 시도 편수. 플랫폼의 안전 보장 수치가 아니에요
운영 모드사람이 하는 일넘어갈 기준
승인제처음 1~2주, 매번 원문·파일 확인 후 approve최근 10편 중 관문 통과 9편 이상 + 미해결 예외 0건
사후 확인통과한 콘텐츠는 로컬 대기. 공개 전 거부 가능다음 10편 모두 통과 + 수동 거부 0건 + 중복·사실 오류 0건
전자동통과하면 발행. 주간 표본 확인·예외만 처리사실 오류·중복·권한 이상 발생 시 즉시 승인제로 복귀

모드 전환은 위 기록을 보고 사람이 config.json의 mode를 바꿔요. 키트가 스스로 승격하지 않아요. 주간에는 게시물·원문·비용을 표본으로 확인하세요. 사후 확인은 인스타 게시 후 삭제가 아니라, 기본 2시간 로컬 대기 뒤 tick이 발행하는 방식이에요. 기본 시간은 바꿀 수 있어요.

화면은 기기·버전마다 다를 수 있어요. 소요 시간은 설치와 원문 길이에 따라 달라요. 이 심화편은 화면 편집 도구 대신 API·코드만 사용해요.

따라 하기

터미널은 명령을 입력하는 창이에요. 아래 명령은 auto-kit 폴더에서 실행하세요. A0의 설치를 먼저 마치세요. 새 창을 열면 macOS는 source .venv/bin/activate를 다시 실행해요. RUN_ID는 직전 실행이 출력한 실제 ID로 바꿔요.

저장소에서 Code → Download ZIP으로 받고 압축을 푸세요. Python 3.11 이상을 설치한 뒤 auto-kit 폴더를 터미널에서 열어요. Windows는 폴더 주소창에 powershell, macOS는 폴더에서 새 터미널을 여세요. 목록에 pipeline.py가 있는지 확인하세요. 가상환경은 이 키트만의 Python 도구함이에요.

py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements-dev.txt
.\.venv\Scripts\python.exe doctor.py
.\.venv\Scripts\python.exe pipeline.py run --flow insta --provider mock --mode auto --state private/a0
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --only-binary=:all: -r requirements-dev.txt
python doctor.py
python pipeline.py run --flow insta --provider mock --mode auto --state private/a0
