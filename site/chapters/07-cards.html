뉴스카드 디자인 자동화

6장의 copy.json을 표지·본문·마무리로 배치합니다. 예쁜 한 장보다, 휴대폰에서 끝까지 읽히는 묶음을 만듭니다.

이 장의 흐름

?01 · 일상의 질문

“글자를 줄이면 정보도 사라질까요?”

하린은 6장의 문안을 카드에 넣습니다. 요점과 주의사항, 출처를 한꺼번에 큰 글씨로 넣으니 읽을 곳이 보이지 않습니다. 정 선배는 중요한 조건을 지우지 말고, 한 카드에서 답할 질문부터 줄이자고 합니다.

하린“내용을 전부 보여 주려니 화면이 꽉 찼어요.”

정 선배“제목은 질문을 잡고, 본문은 답하고, 출처는 확인할 길을 남기자.”

두 인물과 작업 기록은 가상입니다. 실적이나 성능 시험이 아닙니다.

≡03 · 원리

한 카드에서 답할 질문을 정하기

캐러셀은 여러 이미지를 넘겨 보는 묶음입니다. 이 키트의 템플릿은 표지 cover → 본문 body → 마무리 closing 순서입니다. 표지는 읽을 이유, 본문은 요점, 마무리는 출처와 다음 행동을 맡습니다.

본문의 title은 질문이나 요점 제목, points는 화면에 나올 요점입니다. body만 고치면 본문 카드가 바뀌지 않습니다. 문안과 이후 편집을 일치시키려면 body·points를 함께 고치세요. **핵심 구문**은 강조색으로 바뀝니다. 모든 문장에 강조를 주지 말고 읽을 순서를 정해 보세요.

렌더링은 문안과 배치 규칙을 파일로 만드는 일입니다. 이 키트는 Pillow라는 이미지 도구로 문안과 도형을 그려 PNG와 JPEG를 만듭니다. 학습 기본값은 카드 1080×1350, 동봉 피드는 표지·본문·마무리를 합쳐 PNG 5장입니다. 플랫폼의 유일한 크기나 장수 제한을 뜻하지 않습니다.

글과 바탕의 밝기 차이를 대비라고 합니다. WCAG 2.2 해설은 일반 글자·문자 이미지에 4.5:1, 큰 글자에 3:1과 예외를 설명합니다. 접근성 점검 근거이며 Instagram 추천 점수의 기준이 아닙니다. 아래 모형은 보수적으로 4.5:1을 비교선으로 씁니다.[S121]

사진·폰트는 자산별로 적기

무료 사진이라고 인물·상표의 모든 권리가 해결되지는 않습니다. Pexels는 무수정 판매·보증 암시 등의 제한을 둡니다. 사진을 실제 사건 현장으로 오인하게 쓰지 마세요.[S123]

Playwright·Pillow 코드의 라이선스와 폰트·사진의 권리는 별개입니다. Noto Sans KR의 OFL 안내도 실제 폰트 파일과 대응해 확인해야 합니다. 이 폰트의 조건을 다른 폰트에 적용하지 않습니다.[S093][S094][S095]

자산 기록 예시 — 직접 채우는 편집 메모
파일명 | 만든 사람·원 URL | 확인 날짜·버전 | 라이선스
상업·광고 사용 허락 | 변경·출처 표기 조건 | 증빙 위치
동봉 폰트: assets/fonts/NotoSansKR.ttf → 같은 폴더 OFL.txt 확인
외부 사진: 미사용 / 넣을 때 개별 조건 기록

Canva·CapCut·Vrew의 최신 한국 구독료·무료 자막량과 한국어 품질 순위는 조사에서 확정하지 못했습니다. 다른 편집기로 옮길 때 확인되지 않은 무료량을 예산으로 잡지 마세요.[S127][S098][S100]

↔04 · 시뮬레이터

작은 글자로 밀어 넣으면 해결될까요?

카드 레이아웃 편집기

교육용 가정 모형

Tab으로 이동하고 체크박스는 Space, 슬라이더는 방향키·Home·End, 선택 목록은 방향키로 바꿉니다.

입력을 바꾸면 결과가 나옵니다.

원본 본문 상자는 너비 900px·높이 520px, 한글 한 글자 너비를 글자 크기와 같게, 줄높이는 1.45배로 가정합니다. 글줄 수=ceil(글자 수/floor(900/크기)), 필요 높이=글줄 수×크기×1.45. 화면은 0.3배 축소입니다. 32px 미만은 이 모형에서 정한 작은 글자 경고선입니다. 넘침·작은 글자 경고는 학습용이며 실제 Pillow 줄바꿈·자동 축소 결과와 다릅니다. 대비는 두 단색의 상대 휘도로 계산합니다.

무너뜨리기는 긴 글·큰 글자·낮은 대비를 함께 넣습니다. 글을 줄이고 대비를 되돌려 보세요. 크기만 줄이면 읽기 어려워질 수 있다는 점도 결과에 표시합니다.

◎05 · 실제 사례

공식 예시 읽기: 대비는 장식이 아닙니다

W3C 대비 해설은 옅은 글자와 바탕을 구분하기 어려운 독자를 위해 밝기 차이를 설명합니다. 화면의 큰 글자 예외와 일반 글자 기준을 구분해 읽을 수 있는 공식 자료입니다.[S121]

이 장의 가상 적용 예시는 크림 바탕의 진한 글자 카드입니다. 표지를 꾸미느라 출처까지 흐리게 만들지 말고, 작은 설명부터 읽어 보세요. 이 선택이 도달이나 매출을 올린다는 실험 결과는 아닙니다.

✎06 · 작업실 노트

6장의 문안으로 첫 PNG 묶음 만들기

starter-kit 폴더에서 가상환경을 활성화합니다. macOS/Linux는 source .venv/bin/activate, Windows 명령 프롬프트는 .venv\Scriptsctivate.bat입니다. 아래 python은 이 가상환경의 Python입니다. Linux에서 실행했으며 Windows/macOS 실기동은 미검증입니다. 모든 시간은 실습 배분입니다.

  1. 카드에 보이는 필드 고치기

    실습 배분 12분 · 준비물: 6장의 output/phase5b-manual/copy.json · 기대 결과: 표지·요점·출처의 역할 분리

    텍스트 편집기로 열어 title·body·points를 읽습니다. 본문 points의 한 항목이 한 가지 요점을 말하는지 봅니다. 단위와 적용 조건을 빼서 짧게 만들지 마세요. 마지막 source와 caption의 원출처를 유지합니다.

    python write_copy.py output/phase5b-manual/news.json --validate --output output/phase5b-manual/copy.json

    흔한 오류와 해결: 본문 body만 바꾸면 이미지의 요점이 그대로입니다. points도 함께 편집합니다. 오류가 나면 큰따옴표·쉼표·대괄호를 확인합니다.

  2. 기본 테마로 PNG 만들기

    실습 배분 8분 · 준비물: 검증한 copy.json · 기대 결과: cards의 PNG와 JPEG

    python render_cards.py output/phase5b-manual/copy.json --output output/phase5b-manual/cards

    cards/card-01.png부터 차례로 엽니다. 동봉 합성 피드 기준으로 5장입니다. 같은 이름의 JPG도 생성됩니다. 글이 상자에 들어가지 않으면 렌더러는 축소를 시도한 뒤 오류를 냅니다. 오류를 무시하지 말고 문안을 줄입니다.

    흔한 오류와 해결: “글이 영역을 넘칩니다”가 나오면 points를 나누거나 문장을 줄이세요. 합성 소재 표시와 원출처를 잘라 내지 마세요.

  3. 테마를 바꾸고 비교하기

    실습 배분 10분 · 준비물: config.example.yaml 복사본 config.yaml · 기대 결과: 내 계정 색의 카드

    탐색기/Finder에서 config.example.yaml을 같은 폴더의 config.yaml로 복사합니다. theme: forest를 theme: ink 또는 theme: coral로 고칩니다. 나머지는 유지하세요. 아래 명령으로 다른 폴더에 만듭니다.

    python render_cards.py output/phase5b-manual/copy.json --config config.yaml --output output/phase5b-manual/cards-themed

    새 설정 파일에 theme만 바꾸고 colors: {}는 유지하면 프리셋을 비교할 수 있습니다. 색을 직접 덮어쓸 때는 바탕·글자·강조를 함께 검토합니다.

    흔한 오류와 해결: 다른 위치로 YAML을 옮기면 폰트·소재 상대 경로가 달라집니다. config.yaml은 starter-kit 안에 둡니다. 9장의 기존 실행을 고칠 때는 출력 폴더의 config.json을 수정해야 합니다.

  4. 이미지 슬롯과 권리 기록 확인하기

    실습 배분 10분 · 준비물: 선택 시 본인 사진, 자산 메모 · 기대 결과: 사진 사용 여부와 근거

    기본은 자체 기하 패턴이며 사진 생성 서비스가 아닙니다. 사진을 쓰려면 본인이 확인한 로컬 파일을 준비하고 표지 또는 본문 scene에 image 항목을 추가할 수 있습니다. 경로는 설정 파일 기준입니다. 슬롯을 채우며 중앙이 잘릴 수 있으니 얼굴·글자·권리 표시가 잘리는지 봅니다. 이 실습은 사진 없이 끝내도 됩니다.

    예시 필드 "image": "assets/my-photo.jpg"는 파일을 직접 준비했을 때만 넣습니다. 네트워크 주소를 넣어 자동 다운로드하는 기능은 없습니다.

    흔한 오류와 해결: 파일이 없으면 렌더링이 실패합니다. 시험용 기하 패턴이 필요하면 image 항목을 지우고 다시 실행하세요.

  5. 모든 카드와 게시용 JPEG 열어 보기

    실습 배분 10분 · 준비물: 생성 이미지, 작은 화면 · 기대 결과: 8장으로 넘길 카드 묶음

    표지에서 주제가 보이는지, 본문에서 조건과 출처가 읽히는지, 마무리에서 출처를 찾을 수 있는지 봅니다. 휴대폰 크기로 축소해 한글·강조·줄바꿈·사진 잘림을 확인하세요. 기본 cards 폴더를 8장의 입력으로 사용합니다. themed 결과를 쓰려면 8장의 cards 경로도 맞춥니다.

    흔한 오류와 해결: PNG를 보고 JPG도 같다고 넘기지 마세요. 둘 다 엽니다. 파일이 있다는 사실과 읽기 편하다는 판단은 다릅니다.
