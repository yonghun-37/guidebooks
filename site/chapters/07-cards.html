연습: 1080×1350·5장=표지1+대상1+기간1+서류1+출처1.

03 · 제작 레시피

카드를 만듭니다

연습 약 60분. 가입·생성 대기·재시도는 추가입니다. 0원은 무료 요소·잔여 한도·본인 소재 기준입니다.

뉴스 → 확인한 카드 문안

무엇을
예시 문안: “청년 지원금, 신청 전 3가지”.
입력·출력
원출처 → ChatGPT 요약 → 사람이 대조 → 장별 제목·본문·출처입니다.
시간·비용
아래 단계의 약 30분 · 무료 텍스트.
조건·언제
디자인 전에 7장 복사용 요청을 씁니다.
지금 할 일
cards.txt로 저장하세요.
단계별 입력 → 출력
입력·조작 → 출력시간·비용
원기사 열기·URL/게시일/시행일 메모 → source.txt10분·0원
필요 원문+7장 요청 → ChatGPT 새 대화 → 주장표5분·무료
주장표 ↔ 원문 숫자·대상·예외 대조 → facts.txt10분·0원
facts.txt+5장 역할 → 같은 대화 → cards.txt5분·무료

문안 → Canva·미리캔버스 디자인

무엇을
무료 템플릿에 문안을 넣습니다.
입력·출력
cards.txt → Canva 카드뉴스 검색→템플릿→텍스트 교체→페이지 복제 → 편집 가능한 디자인.[S365]
시간·비용
약 20분 · Canva Free. 미리캔버스 Free로 대체합니다.[S318][S321]
조건·언제
연습은 4:5입니다. 크기 변경은 새 페이지로 옮깁니다.
지금 할 일
표지는 질문, 본문은 한 요점, 마지막은 출처 URL·날짜를 넣으세요.

선택 삽화 → 검수·저장

무엇을
사진 없이 도형으로 완성해도 됩니다.
입력·출력
ChatGPT 이미지 만들기에 아래 요청→이미지 저장→Canva 업로드. 미리캔버스는 AI→이미지 생성에도 설명을 넣습니다.[S374][S323]
시간·비용
검수·저장 약 10분 · 무료 요소면 0원. 삽화 생성·대기는 추가입니다.
조건·언제
한글은 생성 그림 밖에서 입력합니다. 기사 사진·폰트의 상업 사용 조건을 각각 확인합니다.[S320][S392]
지금 할 일
다운로드→PNG/JPG 5장 저장. 순서·치수·출처·잘림을 확인하세요.[S307]
생활 뉴스 카드용 세로 4:5. 익명 도시의 아침 버스 정류장과 업무 건물. 남색·회청색·크림색, 위쪽은 제목 여백. 사람·실제 명소·간판·글자·숫자·로고·브랜드 없이. 실제 사건의 증거 사진이 아닌 AI 설명용 배경.
확인할 점

앱이 업데이트되면 버튼 이름이나 위치가 조금 다를 수 있어요. 최신 앱 화면에서 비슷한 이름의 버튼을 찾아 주세요. 못 찾겠으면 공식 도움말(각주 링크)을 확인하세요. ChatGPT 이미지 무료 장수는 고정 공개값이 없습니다. Canva는 유료 요소를 빼고, 미리캔버스 무료 AI 일 200크레딧은 이미지 200장이 아닙니다. 잔여량을 확인하세요.[S300][S318][S321][S323]
