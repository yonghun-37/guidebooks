처음 볼 숫자와 다음 수정을 정합니다

기록 · 첫 주에는 도달·저장·공유를 봅니다

정의
조회는 본 횟수, 도달은 중복 계정을 뺀 추산 수입니다.[S110][S111]
흐름
게시물 → 인사이트 보기 → 같은 관찰 시점의 값을 기록합니다.[S232]
얼마·기준
가상 예: 같은 계정이 두 번 보면 조회는 두 번, 도달은 한 계정입니다.
조건
처음에는 도달·저장·공유를 기록합니다. 조회는 반복 시청을 읽는 보조 칸으로 둡니다. 이 장의 기록 제안입니다.
언제
처음 게시한 뒤부터입니다. 가상 연습은 게시 후 7일 시점으로 맞춥니다.
지금 할 일
실습 10에서 인사이트를 찾아 원래 지표명을 적으세요.

비교 · 같은 조건에서 횟수와 비율을 함께 봅니다

정의
잘된 게시물은 내가 원한 행동이 더 나타난 게시물입니다.
흐름
포맷·주제·경과 시간·광고 포함 여부를 맞춘 뒤 저장·공유를 비교합니다.
얼마·기준
가상 A: (저장 16+공유 4)÷도달 400×100=5%. B: (20+10)÷1000×100=3%입니다.
조건
이 식은 연습용입니다. 한 사람이 여러 행동을 하므로 행동한 사람의 비율이나 구매율로 읽지 않습니다.
언제
다음 게시물의 편집 방향을 고를 때입니다.
지금 할 일
A는 비율, B는 횟수가 큽니다. 내 목표가 저장인지 공유인지 적고 비교하세요.

수정 · 먼저 게시 상태를 보고 표지를 바꿉니다

정의
조회가 떨어지면 게시·계정 상태를 확인한 뒤 표지 질문 하나를 바꿉니다.
흐름
공개 게시 확인 → 계정 상태 확인 → 표지 질문 수정 → 같은 시점에 다시 봅니다.[S063]
얼마·기준
가상 수정 예: “정책 안내” → “내가 신청할 수 있나요?”로 바꿉니다.
조건
내용 오류·권리 문제는 실험보다 먼저 고칩니다. 단순 재게시보다 직접 설명하는 내용을 만듭니다.
언제
이전과 비슷한 주제를 다시 다룰 때입니다.
지금 할 일
반응이 약한 게시물의 첫 질문을 독자가 쓰는 말로 고쳐 적으세요.
확인할 점

공식 독창성 발표는 사진·캐러셀도 다룹니다. 출처·테두리만 덧붙인 재게시보다 직접 해설을 보태세요. 계정 상태에서 제한과 검토 요청을 확인하세요.[S221][S063]

빈칸 · 측정한 0과 나눠 적습니다

정의
숫자가 없으면 측정 불가 사유를 쓰고, 실제로 표시된 0만 0으로 적습니다.
흐름
게시 여부 → 기간 → 계정 조건·권한 → 지표 지원을 확인합니다.[S109][S110]
얼마·기준
계정 기간은 최근 90일 이내에서 고릅니다.[S235]
조건
미게시 연습에는 조회·도달을 만들어 넣지 않습니다. API의 빈 응답도 측정된 0으로 바꾸지 않습니다.[S109]
언제
숫자가 비거나 메뉴가 보이지 않을 때입니다.
지금 할 일
예: “미게시” 또는 “기간 확인 필요”라고 적고 실습 10의 오류 대처를 보세요.
확인할 점

공개 개인 계정 대시보드 안내와 프로 계정 대상 기간 안내가 섞여 있습니다. 내 프로페셔널 대시보드·인사이트 메뉴를 먼저 확인하세요. 앱의 보내기와 API shares는 이름을 그대로 기록하세요.[S233][S235][S110]
