≡03 · 원리

처음은 무음, 다음은 본인 녹음

키트 기본은 무음과 영상에 새긴 자막입니다. make_reel은 카드 장면에 느린 줌·이동, 페이드 전환, 자막 등장, 진행 막대를 더합니다. 학습 기본 영상은 1080×1920·20초·24fps입니다. duration의 허용 범위 15~30초는 이 키트의 연습 계약이며 Instagram 전체 길이 제한이 아닙니다.

장면 시간은 전체 길이를 장면 수에 균등 배분한 뒤 프레임 단위로 맞춥니다. 프레임은 영상의 한 화면입니다. 카드 5장·20초라면 한 장면은 이 설정에서 4초입니다. 긴 subtitle은 더 짧게 고치거나 전체 길이를 허용 범위 안에서 늘려 보세요.

“첫 3초”를 한국 초보 계정의 고정 성공 조건으로 정할 인과 근거는 확보하지 못했습니다. 아래 3초 표식은 첫 질문을 빨리 드러내 보기 위한 학습용 기준선입니다.[S131][S151][S107]

음성 경로를 고르는 순서

  1. 무음+직접 쓴 자막: 기본값으로 먼저 영상 검수를 마칩니다.
  2. 본인 내레이션: subtitle을 장면 시간표에 맞춰 직접 녹음합니다. 키트는 MP3/WAV를 받습니다.
  3. 권리를 확인한 TTS: TTS는 글을 음성으로 읽는 기능입니다. 선택한 플러그만 연결하며 기본 엔진·모델은 없습니다.

Whisper는 음성에서 글을 찾는 음성 인식·자막 도구이며 TTS가 아닙니다. 코드와 원본 모델은 MIT로 공개되어 있지만 이 조사에서 한국어 오류율은 실측하지 않았습니다. 이 키트는 Whisper를 실행하지 않습니다.[S088]

자막에는 말뿐 아니라 이해에 필요한 화자·비음성 소리도 담는다는 WCAG 해설이 있습니다. 자막 파일이 생겼다는 것과 내용이 정확하다는 것은 별개입니다.[S122]

무료 생성과 상업 사용을 구분하기

ElevenLabs 무료 생성물에는 상업 라이선스가 없다는 안내를 확인했습니다. 나중에 결제해도 무료 기간의 생성물 권리가 소급된다고 볼 수 없습니다. 타입캐스트는 생성·재생과 다운로드를 구분하고 플랜별 상업 조건을 안내합니다. “무료로 내려받았다”만으로 게시용 음성을 고르지 마세요.[S124][S125][S126]

MMS-TTS-KOR는 비상업 조건인 CC-BY-NC-4.0입니다. XTTS-v2는 한국어와 CPML 표시를 확인했지만 상업 계약·참조 화자 동의 등은 미확인입니다. 엔진·모델·화자·출력물 권리를 한 번에 승인하지 않습니다.[S084][S085]

CapCut의 Commercial Sounds도 허용 플랫폼 밖 이용은 별도 허락이 필요합니다. Meta 음원 라이브러리·Sound Collection의 한국 계정·지면별 현행 허용표는 완성하지 못했습니다. 이 장은 특정 음원이 Instagram 광고에 허용된다고 추천하지 않습니다.[S098][S136]

사실적으로 들리는 합성 음성·생성 또는 변형한 실사형 영상은 Meta 자기공개 검토 대상입니다. 자동 라벨이 없다고 비AI 판정을 받은 것은 아닙니다. 한국 앱의 현재 화면은 미검증입니다.[S071][S007]

정적 영상·슬라이드쇼·반복 영상·텍스트 몽타주 수익화 제한은 Hermes의 원문 일부 보고이며 독립 본문 확인에는 한계가 있습니다. 이 연습 영상의 제작 성공이나 모션·TTS 추가가 직접 수익화 적격을 보장하지 않습니다. 게시 가능·추천·수익화는 각각 확인하세요.[S012]

2026년 10월 조사 기준. 본인 녹음을 음성이 필요할 때의 첫 선택으로 권합니다. 다른 사람의 목소리·음원·글이 녹음에 섞였다면 해당 권리는 별도 확인합니다.

✎06 · 작업실 노트

무음 릴스를 만든 뒤 선택 음원 검토하기

starter-kit 폴더에서 가상환경을 활성화합니다. macOS/Linux는 source .venv/bin/activate, Windows 명령 프롬프트는 .venv\Scriptsctivate.bat입니다. Linux의 .venv에서 아래 명령을 확인했으며 Windows/macOS 실기동은 미검증입니다. 학습 시간 배분에는 최초 설치가 포함되지 않습니다.

  1. 자막을 소리 내어 읽고 짧게 고치기

    실습 배분 12분 · 준비물: 7장의 copy.json·cards · 기대 결과: 장면마다 읽을 문장

    copy.json의 subtitle을 읽습니다. 기본 20초·5장면에서는 장면마다 4초입니다. 카드 PNG와 subtitle이 서로 다른 사실을 말하지 않는지 확인합니다. points·title을 고쳤다면 7장의 카드 생성도 다시 합니다.

    python write_copy.py output/phase5b-manual/news.json --validate --output output/phase5b-manual/copy.json

    흔한 오류와 해결: 카드 문안을 바꾼 뒤 예전 PNG를 쓰면 내용이 엇갈립니다. 같은 copy.json으로 카드를 다시 만든 뒤 진행하세요.

  2. 기본 무음 영상 만들기

    실습 배분 10분 · 준비물: copy.json, 기본 cards 폴더 · 기대 결과: reel.mp4·subtitles.srt

    python make_reel.py output/phase5b-manual/copy.json --cards output/phase5b-manual/cards --output output/phase5b-manual

    reel.mp4를 엽니다. 기본은 무음입니다. SRT는 자막 시간표 형식입니다. subtitles.srt와 reel-info.json에서 자막·장면 시간을 확인합니다. 자막은 이미 영상에 새겨져 있습니다.

    흔한 오류와 해결: 카드 수와 문안 장면 수가 달라지면 실패합니다. 자막을 고칠 때 SRT만 편집해도 MP4는 바뀌지 않습니다. copy.json의 subtitle을 고치고 다시 생성하세요.

  3. 본인 녹음과 음악은 선택해서 준비하기

    실습 배분 15분 · 준비물: 선택 시 직접 녹음한 MP3/WAV, 자산 메모 · 기대 결과: 음원 사용 여부와 권리표

    녹음하지 않아도 이번 장은 끝낼 수 있습니다. 녹음한다면 subtitles.srt 시간에 맞춰 자신의 말과 목소리로 녹음하고 assets/my-narration.wav로 저장합니다. 배경음악은 선택 사항이며 Instagram·상업·광고 사용을 확인한 파일만 준비합니다. 파일명·권리자·공식 URL·확인 날짜·허용 플랫폼·출처 표시·증빙을 적으세요.

    config.example.yaml을 같은 폴더의 config.yaml로 복사하고 아래 reel 항목을 고칩니다. 본인 파일을 준비하지 않았다면 narration과 music을 null로 유지합니다. 이 설정은 파일 예시이며 동봉 음원이 아닙니다.

    reel:
  duration: 20
  tts: silent
  narration: assets/my-narration.wav
  music: null
  tts_plugin: null

    흔한 오류와 해결: 상대 경로는 config.yaml 위치 기준입니다. 합성 화자 서비스를 쓸 때 본인 녹음과 같은 권리라고 가정하지 마세요. TTS는 기본 비활성이고 별도 연결 계약을 검토해야 합니다.

  4. 선택 설정으로 다시 만들기

    실습 배분 8분 · 준비물: 준비한 config.yaml, 선택 음원 · 기대 결과: 비교할 영상 폴더

    python make_reel.py output/phase5b-manual/copy.json --cards output/phase5b-manual/cards --config config.yaml --output output/phase5b-voice

    편집 검증에서는 narration·music 파일 입력을 테스트용 WAV/MP3로 실제 인코딩·디코딩했습니다. 사람이 녹음한 말의 품질이나 상용 TTS는 시험하지 않았습니다. 키트는 내레이션을 원래 음량, 음악을 0.18배로 섞으며 짧은 음원 뒤는 무음, 긴 음원은 영상 끝에서 자릅니다. 자동으로 반복하지 않습니다.

    흔한 오류와 해결: 음원 경로가 없으면 실패합니다. 녹음과 자막이 어긋나면 대본·녹음 길이를 고칩니다. 자동 단어 정렬 기능은 없습니다.

  5. 소리를 끄고 한 번, 켜고 한 번 끝까지 보기

    실습 배분 15분 · 준비물: 최종 MP4·SRT·권리 메모 · 기대 결과: 재생 확인한 첫 릴스

    글자 잘림·고유명사·숫자·부정·무음 구간·장면 경계·진행 막대를 확인합니다. 본인 휴대폰에서도 읽어 봅니다. 음악이 말을 가리지 않는지 듣고, 영상과 자막이 같은 뜻인지 대조합니다. 필요한 AI 자기공개도 별도 메모합니다.

    흔한 오류와 해결: 파일이 재생된다고 검수가 끝난 것은 아닙니다. 수정했다면 영상 전체를 다시 보고, 9장의 통합 실행에서는 새 검수표에 기록하세요.
