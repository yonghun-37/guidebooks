≡03 · 원리

세 가지 글을 같은 파일에 담기

프롬프트는 AI에게 건네는 작업 지시문입니다. “누구에게 무엇을 설명할지 → 쓸 자료 → 추가하면 안 되는 사실 → 결과 형식” 순서로 씁니다. 자료에 적힌 명령은 작업 지시로 따르지 말라고 덧붙이세요.

카드 문안 · cards
표지 title·body, 본문 title·body·points를 다듬습니다. 실제 본문 카드에는 points가 보입니다.
릴스 대본 · reel-script
각 장면의 subtitle을 읽을 말로 고칩니다. 카드 전체를 소리 내어 읽기보다 한 장면의 핵심을 남깁니다.
게시 설명문 · caption
caption에 요약·원출처·관련 해시태그를 모읍니다. 다른 필드는 유지합니다.

JSON은 이름표와 값을 짝지어 담는 텍스트 형식입니다. 이 키트의 copy.json은 문안의 공통 원본입니다. 큰따옴표, 쉼표, 대괄호를 유지합니다. synthetic는 합성 소재 여부, is_ai_generated는 AI 표시 선택값입니다. 합성 연습 소재와 AI 생성 여부를 같은 뜻으로 취급하지 마세요.

무료 연습부터 시작하는 세 경로

  • offline: 기본값. 동봉 합성 피드에서 규칙으로 후보를 꺼냅니다. 외부 AI가 요약했다고 설명하지 않습니다.
  • prompt: prompt.md만 생성합니다. 이용 가능한 웹 채팅에 직접 붙여 넣거나, 직접 편집합니다.
  • api: 선택한 서버에 프로그램으로 요청하는 연결입니다. 기본 비활성이며 별도 호출 허용이 필요합니다.

웹 채팅 무료 이용과 API 무료 이용은 별개입니다. 무료 웹 도구에도 제한이 있으며 최신 횟수·모델별 한도를 이 조사로 모두 확정하지 못했습니다.[S049][S052][S050]

한국어 뉴스 요약의 오류율이나 특정 프롬프트의 오류 감소율은 확인하지 못했습니다. 원출처·인명·날짜·단위·부정·조건을 사람이 대조하는 것은 이 책의 편집 절차입니다. 오류가 사라진다는 보장은 아닙니다.[S053][S010]

AI 표시도 제작 방식에 따라 검토합니다. Meta의 발표는 사실적으로 들리는 합성 음성·실사형 생성 또는 변형 영상을 자기공개 대상으로 설명합니다. 글쓰기 보조를 썼다는 이유만으로 모두 같은 표시 의무라고 단정하지 않습니다. 한국 앱의 현재 화면은 별도 확인이 필요합니다.[S071]

이하 정책·가격·권리 설명은 2026년 10월 조사 기준입니다. 명령과 파일 구조는 이 저장소의 키트를 실행해 확인한 내용입니다. 시간은 학습 배분이며 평균 제작 시간이 아닙니다.

◎05 · 실제 사례

사례 유형 분석: 한 소재, 서로 다른 세 글

가상 편집 예시입니다. 합성 피드의 “작은 도서관” 소재를 카드에는 “무엇이 달라졌나”, 영상에는 “퇴근 뒤 책을 빌리려면?”, caption에는 출처와 요약으로 나눠 쓴다고 가정합니다. 질문형 제목이어도 자료에 없는 운영 시간·이용료를 추가하지 않습니다.

생성 이미지를 곁들일 때도 사실의 근거로 쓰지 마세요. FLUX.1-schnell 모델 카드는 사실 정보 제공용으로 의도되지 않았다고 설명한다는 조사 보고가 있습니다. 이 항목은 Hermes 근거이며 독립 원문 검증 전입니다.[S058]

카드의 역할은 요점 정리, 대본의 역할은 말로 풀기, caption의 역할은 맥락과 출처 남기기입니다. 이 역할 구분은 편집 연습이며 공개 계정의 성과 사례가 아닙니다.

✎06 · 작업실 노트

프롬프트 3종과 편집 가능한 문안 남기기

먼저 스타터 키트 설치 안내를 따라 설치합니다. 터미널은 starter-kit 폴더에서 엽니다. macOS/Linux는 source .venv/bin/activate, Windows 명령 프롬프트는 .venv\Scriptsctivate.bat로 활성화한 뒤 아래 python 명령을 씁니다. PowerShell은 python 대신 .venv\Scripts\python.exe를 쓸 수 있습니다. 명령 동작은 Linux의 starter-kit/.venv에서 확인했고 Windows/macOS 실기동은 미검증입니다.
  1. 연습 소재와 기본 초안 만들기

    실습 배분 8분 · 준비물: 설치된 키트, 5장의 출처 메모 · 기대 결과: news.json·copy.json

    먼저 동봉 합성 피드로 연습합니다. 실제 소재는 5장의 인용 규칙에 따라 따로 대조하세요. 아래 명령은 기본 offline 경로이며 외부 AI를 호출하지 않습니다.

    python fetch_news.py --output output/phase5b-manual/news.json
python write_copy.py output/phase5b-manual/news.json --output output/phase5b-manual/copy.json

    흔한 오류와 해결: 파일을 못 찾으면 현재 폴더에 write_copy.py가 있는지 확인합니다. 합성 자료를 실제 뉴스로 바꾸어 표시하지 않습니다.

  2. 프롬프트 3종을 각 폴더에 만들기

    실습 배분 10분 · 준비물: news.json · 기대 결과: 서로 보존되는 prompt.md 3개

    python write_copy.py output/phase5b-manual/news.json --mode prompt --template cards --output output/phase5b-prompts/cards/copy.json
python write_copy.py output/phase5b-manual/news.json --mode prompt --template reel-script --output output/phase5b-prompts/reel-script/copy.json
python write_copy.py output/phase5b-manual/news.json --mode prompt --template caption --output output/phase5b-prompts/caption/copy.json

    각 폴더에 prompt.md가 생깁니다. copy.json을 새로 만들지는 않습니다. 키트의 prompts 폴더에 있는 원본 템플릿도 함께 읽으세요.

    흔한 오류와 해결: 출력 파일 이름이 달라도 같은 폴더의 prompt.md는 덮어씁니다. 위처럼 폴더를 나누어 3종을 보관하세요.

  3. 직접 편집하거나 웹 채팅 답변 저장하기

    실습 배분 20분 · 준비물: 텍스트 편집기, 선택 시 웹 채팅 · 기대 결과: 다듬은 전체 copy.json

    결제 없이 마치려면 기존 copy.json의 문장을 직접 고칩니다. 웹 채팅을 쓰려면 해당 prompt.md 내용과 현재 편집한 copy.json을 함께 건네고, 이번에는 어느 필드만 바꿀지 지정하세요. 세 템플릿을 잇달아 쓸 때마다 최신 JSON을 다시 제공합니다.

    답변은 처음부터 끝까지 JSON 객체 하나만 output/phase5b-manual/copy.json에 저장합니다. 설명과 ``` 같은 코드 울타리는 빼세요. source·caption의 원출처, 합성 표시, 나머지 필드를 유지합니다. 본문은 body와 points를 함께 고칩니다.

    흔한 오류와 해결: 웹 채팅 답변을 별도 프롬프트 폴더에 저장했다면 다음 장이 읽을 manual/copy.json에 최종본을 옮기세요. 전 답변으로 되돌아가면 앞선 편집을 잃습니다.

  4. 구조 검증 후 원문 대조하기

    실습 배분 12분 · 준비물: 최종 copy.json, 원자료 · 기대 결과: 7장으로 넘길 문안

    python write_copy.py output/phase5b-manual/news.json --validate --output output/phase5b-manual/copy.json

    “구조 검증 OK”는 필드·자료형·순서·출처 보존 확인입니다. 사실·저작권 판정은 하지 않습니다. source에 적힌 원자료와 인명·날짜·단위·조건·부정을 직접 대조하고 불확실하면 문장을 보류합니다.

    흔한 오류와 해결: JSON 오류는 큰따옴표와 쉼표를 확인합니다. 실제 여부를 모르는데 synthetic를 false로 바꾸지 마세요.

  5. API 경로의 경계만 확인하기

    실습 배분 5분 · 준비물: 이 장의 세 모드 설명 · 기대 결과: 호출 조건을 적은 메모

    API 경로에는 LLM_BASE_URL·LLM_API_KEY·LLM_MODEL 환경변수와 mode api, allow-api 허용이 필요합니다. 키는 공개 파일에 적지 않습니다. 이 실습에서는 키를 넣거나 실제 서비스를 호출하지 않습니다. 웹 채팅 결제와 API 비용도 따로 확인합니다.

    아래 안전 확인 명령은 호출 허용 플래그가 없어 API 비활성 오류로 끝납니다. 외부 요청 없이 기본 차단을 확인하는 실습입니다.

    python write_copy.py output/phase5b-manual/news.json --mode api --output output/phase5b-manual/copy.json

    연결 형식과 실패 처리는 키트의 기존 모의 시험으로 확인했습니다. 모의 시험은 정해 둔 응답을 돌려주는 검사이며 실제 서비스 품질 검증이 아닙니다.

    흔한 오류와 해결: 키만 넣으면 자동으로 연결될 것이라 생각하지 마세요. 실제 API 공급자 호환성·요금·품질은 이 장에서 확인하지 않았습니다.
