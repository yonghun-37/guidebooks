소재 · 공식 발표부터 찾습니다

정의

흐름
관심 기관 홈페이지 → 새 발표 → 원문 확인 순서로 찾습니다.
기준·예
예: 교육청 공지에서 지역 도서관 이용 변경을 찾습니다.
조건
RSS는 새 글의 제목·링크를 받는 통로이며 재게시 허락이 아닙니다.[S120][S010]
언제
오늘 다룰 질문을 고를 때 봅니다.
지금 할 일
내 주제의 기관 홈페이지를 즐겨찾기하고 발표일·사건일을 적으세요.

권리 · 문장과 사진을 나눕니다

정의
출처를 적어도 복제가 자동 허용되지는 않습니다.[S010]
흐름
사실 확인 → 내 설명 작성 → 남의 표현·사진 이용 근거 확인입니다.
기준·예
예: 기사 사진 대신 확인한 운영 시간을 직접 표로 만듭니다.
조건
인용은 목적·필요한 분량·시장 영향을 봅니다. 안전한 고정 문장 수는 없습니다.[S010]
언제
AI에 자료를 넣기 전과 공개하기 전에 확인합니다.
지금 할 일
사진·캡처의 허락이 없으면 빼고 직접 만든 도식으로 바꾸세요.
확인할 점

사진 속 인물의 초상·개인정보도 확인합니다. 해결하지 못하면 다른 소재를 고르세요.[S081][S078]

공공자료 · 저작물의 표식을 확인합니다

정의
공공기관 자료도 해당 본문과 첨부물의 이용 조건을 봅니다.[S128]
흐름
공공누리 표식 → 상업 이용·변경 조건 → 증빙 저장입니다.
기준·예
1유형은 출처 표시로 상업 이용·변경이 허용됩니다.[S128]
조건
2유형은 비상업, 3유형은 변경 금지, 4유형은 둘 다 제한합니다.[S128]
언제
요약 카드에 본문이나 첨부물을 쓰기 전에 봅니다.
지금 할 일
자료의 표식과 첨부 사진 조건을 각각 메모하세요.

대조·출처 · 원문으로 돌아갈 길을 남깁니다

정의
원문과 사실을 대조한 뒤 마지막 카드와 게시 설명문에 출처를 씁니다.
흐름
발표 기관 → 날짜·수치·단위·조건 대조 → 출처 작성입니다.
기준·예
가상 문구: “자료: 가상 도서관, ‘운영 안내’, 발표일: ○○, 원문: URL”.
조건
기사를 인용했다면 매체·저자·제목도 적고 인용문을 구별합니다.[S010]
언제
글을 다듬은 뒤, 이미지로 만들기 전에 다시 봅니다.
지금 할 일
원문의 문장 옆에 내 요약을 놓고 부정 표현까지 대조하세요.

1. 출처 링크만 쓰면 기사 사진을 복제해도 되나요?

2. 자료와 첨부물에 공공누리 1유형이 적용된다면?
