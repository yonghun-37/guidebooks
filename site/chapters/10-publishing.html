≡03 · 축별 설명

첫 게시와 예약 경로를 고릅니다

앱 · 첫 게시는 파일을 골라 올립니다

정의
처음 한 번 올리는 데 API는 필요 없습니다.
흐름
검수한 파일 → 앱에서 선택 → 표시 확인 → 공유합니다.
얼마·기준
처음에는 완성한 게시물 한 편을 고릅니다.
조건
앱의 파일 선택은 휴대폰에 옮긴 파일을 사용합니다. API는 프로그램으로 게시할 때 고르는 통로입니다.
언제
오늘 첫 게시를 끝내려 할 때입니다.
지금 할 일
앱 게시를 고르고 실습 7로 이어 가세요.

API · 프로그램이 파일 주소를 보냅니다

정의
API 자동 게시는 프로페셔널 계정과 게시 권한이 필요합니다.[S002][S001]
흐름
공개 주소 → 준비 상자 생성 → FINISHED 확인 → 발행합니다.[S001]
얼마·기준
API 이미지에는 JPEG를 씁니다. 내 PC 경로 대신 Meta가 읽을 수 있는 공개 URL이 필요합니다.[S001][S004]
조건
Instagram Login 권한은 instagram_business_basic과 instagram_business_content_publish입니다. Facebook 페이지 연결은 필요 없습니다.[S002]
언제
반복 게시를 프로그램에 맡기려 할 때입니다.
지금 할 일
JPEG와 MP4의 공개 주소 준비를 실습 8에서 확인하세요.
확인할 점

Facebook Login은 연결된 Facebook 페이지가 필요합니다. 외부 고객 계정에 제공하는 Advanced Access는 앱 검수·사업체 인증을 확인하세요. 새 통합 권장 경로 Unified Login은 별도 조건을 읽으세요.[S033][S031]

예약 · 서버에 맡긴 뒤 목록을 확인합니다

정의
앱·Business Suite에 예약 등록을 마치면 내 PC를 꺼도 서버가 게시를 처리합니다.
흐름
앱은 옵션 더 보기 → 이 게시물 예약/이 릴스 예약 → 날짜·시간 → 예약 순서입니다.[S037]
얼마·기준
현재 읽은 앱 도움말은 공개 계정·최대 30일 전·하루 25개를 안내합니다.[S037]
조건
내 PC의 예약 실행은 PC가 켜져 있어야 합니다. 스타터 키트 자체에는 예약 시계가 없습니다.
언제
파일과 표시를 검수한 뒤, 예약 목록에서 대상·시각을 확인할 때입니다.
지금 할 일
예약됨에서 등록 여부를 확인하고, 바꿀 때는 옵션의 일정 조정·삭제를 찾으세요.[S037]
확인할 점

계정별 메뉴와 음원·표시 조합은 예약 화면에서 확인하세요. API 문서는 이동 24시간 한도를 100/50건으로 다르게 적습니다. 적게 운영하고 내 계정의 content_publishing_limit에서 사용량·설정값을 확인하세요.[S001][S003]

실패 · 다시 누르기 전에 게시 여부를 봅니다

정의
실패 알림 뒤 바로 재실행하면 중복 게시가 생길 수 있습니다.
흐름
내 프로필·원격 처리 상태 확인 → 결과 기록 → 다음 실행 여부를 정합니다.
얼마·기준
예: 발행 직후 응답만 끊겼다면 이미 게시됐을 수 있습니다.
조건
키트의 LIVE_ATTEMPT.json은 같은 폴더 재시도를 막는 기록입니다. 지워서 다시 실행하지 않습니다.
언제
응답이 끊기거나 성공 여부가 불분명할 때입니다.
지금 할 일
게시 주소·처리 ID·오류를 메모하고 실습 8의 실패 대처를 읽으세요.

처음 한 번 올리는 데 API가 꼭 필요한가요?

필요 없습니다. 앱으로 파일을 골라 올립니다.

예: 검수한 카드 한 편으로 시작하세요. 실습 7에서 게시 경로를 따라가세요. 자세히 읽기 →

자동 게시에는 어떤 계정과 권한이 필요한가요?

Instagram Login은 프로페셔널 계정과 게시 권한이 필요합니다.

예: 크리에이터 계정에 기본·게시 권한을 준비합니다. 로그인 경로를 메모한 뒤 실습 8로 가세요.[S002] 자세히 읽기 →

내 컴퓨터의 이미지 파일을 그대로 올리나요?

앱은 파일을 고르고, 이 키트의 API는 공개 URL을 보냅니다.

예: 로컬 JPEG를 공개 주소로 준비합니다. 주소가 파일을 여는지 확인하세요.[S001] 자세히 읽기 →

예약하면 컴퓨터를 꺼도 올라가나요?

앱·Suite에 등록한 예약은 PC를 꺼도 서버가 처리합니다.

PC 명령 예약은 PC가 켜져 있어야 합니다. 예약됨에 있는지 확인하고 예정 시각 뒤 실제 게시도 보세요. 자세히 읽기 →

게시가 실패했을 때 다시 누르면 중복되나요?

이미 발행됐다면 중복될 수 있습니다.

예: 응답만 끊긴 경우입니다. 프로필·원격 상태를 확인하고 키트의 시도 기록을 지우지 마세요. 자세히 읽기 →
