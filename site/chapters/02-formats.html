03 · 축별 설명

하나씩 정하고 메모합니다

형식 · 비교는 카드, 움직임은 릴스입니다

정의
처음에는 설명하기 쉬운 형식 하나를 고릅니다.
흐름
독자 질문 → 비교할 정보·보여 줄 동작 → 카드 또는 릴스
얼마·기준
가상 예: 요금 조건 비교는 카드, 버튼을 누르는 순서는 릴스입니다.
조건
캐러셀은 여러 사진·영상을 넘기는 게시물이고, 릴스는 영상입니다.[S068][S066]
언제
제작을 시작하기 전에 고릅니다.
지금 할 일
같은 질문을 카드 제목과 영상 첫 장면으로 써 보고 쉬운 쪽을 고르세요.

추천 · 모르는 독자도 이해하게 만듭니다

정의
공개 계정의 추천 조건을 갖추고, 처음 보는 사람에게 필요한 답을 만듭니다.[S062]
흐름
독자의 질문 제시 → 내 설명·예시 → 계정 상태와 반응 확인
얼마·기준
가상 편집 예: “새 업데이트!”를 “무료 이용자는 무엇이 달라졌나?”로 바꿉니다.
조건
AI 사용만으로 노출이 줄어든다는 보편 근거는 없습니다. 복제·스팸·권리 문제를 확인합니다.[S064][S065]
언제
추천이 줄면 계정 상태의 삭제·기능 제한도 확인합니다.[S063]
지금 할 일
첫 화면에 질문을 쓰고 직접 만든 비교·설명을 붙이세요.
확인할 점

최신 독창성 안내는 사진·캐러셀에도 적용됩니다. 자막·테두리만 붙인 재게시를 피하세요. 추천 조건 충족은 실제 노출 보장이 아닙니다.[S221][S062]

크기 · 이 책의 제작 크기로 시작합니다

정의
카드는 1080×1350px, 릴스는 1080×1920px로 연습합니다.
흐름
핵심 질문 → 설명 카드·영상 → 읽기·재생 확인
얼마·기준
가상 구성: 표지 1장 + 설명 3장 + 요약 1장 = 5장. 릴스는 학습용 15~30초입니다.
조건
앱·API 캐러셀 최대 20개는 상한입니다. 처음부터 다 채울 필요가 없습니다.[S068][S001]
언제
카드·릴스 제작 실습에서 이 크기를 사용합니다.
지금 할 일
카드 실습 또는 릴스 실습을 고르세요.
확인할 점

크기·길이는 교재의 학습 설정입니다. 앱과 API는 규격이 다릅니다. API 이미지는 4:5~1.91:1, 릴스는 9:16 권장입니다.[S004]

실험 · 시각과 태그는 내 기록으로 정합니다

정의
모두에게 맞는 게시 시각과 해시태그 개수는 없습니다.[S131]
흐름
같은 주제·형식 → 시각만 바꿔 게시 → 같은 기간 반응 비교
얼마·기준
가상 첫 실험: 점심과 퇴근 후에 올리고 각각 24시간 뒤 기록합니다. 태그는 주제에 맞는 2개로 고정합니다.
조건
조회는 본 횟수, 도달은 본 계정 수입니다. 광고·집계 기간을 맞춥니다.[S110][S111]
언제
같은 형식을 여러 번 연습한 뒤 비교합니다.
지금 할 일
게시 시각·주제·조회·도달·저장·공유를 적으세요.
확인할 점

시각과 태그 수는 실험용 가정입니다. 결과가 달라도 시각만의 효과라고 결론 내리지 말고 비슷한 주제로 다시 살펴보세요.
