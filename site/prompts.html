대괄호를 내 자료로 바꾼 뒤 복사하세요

AI에 맡길 일과 사람이 확인할 일을 함께 적습니다. 원문 요약 → 직접 대조 → 문안 → 장면 → 편집 순서로 진행하세요. 아래 도서관 문장과 종이 로봇은 가상 연습이며, 비교문은 예상 출력입니다.

  1. 대괄호를 내 URL·발췌·사실표로 바꿉니다.
  2. 서비스 입력창에 붙여 넣고 결과를 표와 파일로 받습니다.
  3. 나쁜 결과 기준에 걸리면 해당 부분만 고칩니다.

아래 분 단위는 연습 일정입니다. 가입·생성 대기·재시도가 길어지면 더 잡으세요. 사실·가격은 모델 답변으로 확정하지 말고 원출처에서 확인합니다.

복사하고 고쳐 쓰기

뉴스 요약 · 먼저 사실표를 받습니다

넣을 곳: ChatGPT 새 대화의 입력창. 검색으로 찾았으면 Sources의 원문부터 엽니다.[S302][S300]

입력 → 출력: 원문 URL·필요한 발췌 → 주장표 → 사람이 원문과 대조한 facts.txt

나쁜 요청·결과

“요즘 핫한 뉴스 요약해서 대박 나게 써 줘.”

“모든 시민에게 매달 책 2권 증정”은 대상·기간·대출을 바꿔 불합격입니다.

좋은 결과 기준

연습도서관 원문에 “11월 2일 하루·성인 회원·추가 대출 2권·예약 도서 제외”가 있으면 네 조건을 모두 표에 남깁니다.

생성 뒤 이 기준과 직접 비교하세요.

시간·비용: 약 5분 + 원문 대조 10분 · 무료 채팅 한도 내 0원.

카드 문안 · 장마다 역할을 줍니다

넣을 곳: ChatGPT에서 확인한 사실표 아래에 이어 붙입니다. Canva에는 나온 문안만 옮깁니다.[S302][S318][S365]

입력 → 출력: facts.txt → 장별 문안 → Canva 텍스트 상자 → 검수한 cards.txt

나쁜 요청·결과

“알아서 멋진 카드 5장 만들어 줘.”

표지 “누구나 매달 2권 무료!”는 본문의 조건과 충돌합니다. 디자인 전에 고칩니다.

좋은 결과 기준

표지: “성인 회원, 11월 2일 추가 대출” / 본문: “예약 도서는 제외됩니다.”처럼 같은 조건을 유지합니다.

생성 뒤 이 기준과 직접 비교하세요.

시간·비용: 문안 약 5분 · 무료 텍스트 범위 0원. 디자인 시간은 따로 잡습니다.

복사하고 고쳐 쓰기

이미지 · 글자는 편집기에서 넣습니다

넣을 곳: ChatGPT 보통 이미지 만들기 또는 Gemini 이미지 생성 입력창. 승인한 그림은 다음 수정에 다시 첨부합니다.[S374][S369][S376]

입력 → 출력: 장면 설명·선택 참조 → 저장 이미지 → 편집기 크롭·텍스트 상자

나쁜 요청·결과

“실제 뉴스 현장처럼 만들고 제목과 가격도 그림에 한 번에 넣어 줘.”

로봇 형태가 컷마다 바뀌거나 한글 수치가 찌그러지면, 기준 그림으로 한 요소씩 수정합니다.

좋은 결과 기준

초록 종이 로봇·빈 상단·선명한 화분이 있고, 제목은 Canva 텍스트 상자로 입력한 결과입니다.

생성 뒤 이 기준과 직접 비교하세요.

시간·비용: 초안·검수 일정 약 10분 + 생성 대기. 무료 이미지는 도구 잔여량 확인; 추가 구독 필수 아님.

복사하고 고쳐 쓰기

릴스 대본 · 실제로 읽어서 길이를 맞춥니다

넣을 곳: ChatGPT 새 대화 또는 검수한 사실표를 만든 같은 대화의 입력창.[S300][S336][S385]

입력 → 출력: 확인한 사실·독자 → storyboard.txt 장면표 → voice-script.txt 낭독문 → 녹음/TTS

표는 storyboard.txt, 읽을 말은 voice-script.txt에 저장하세요. TTS에는 낭독문만 넣고 번호·그림 지시·출처를 읽지 않는지 들어 봅니다. 완성 입력 예와 대조하세요.

나쁜 요청·결과

“30초에 정보 전부 넣고 더 빠르게 읽어 줘.”

“예약 도서도 가능”처럼 부정이 뒤집히거나 낭독이 길면 문장을 줄이고 원문과 다시 맞춥니다.

“11월 2일 방문하나요? 성인 회원은 추가 대출이 됩니다. 예약 도서는 제외되니 먼저 확인하세요.”처럼 말할 문장으로 씁니다.

생성 뒤 이 기준과 직접 비교하세요.

시간·비용: 대본 약 10분 · 무료 채팅 한도 내 0원. 녹음·편집은 추가 일정입니다.

복사하고 고쳐 쓰기

영상 생성 · 한 샷에는 한 동작만 넣습니다

넣을 곳: Flow 새 프로젝트 → 보통 Frames to Video에 기준 그림을 넣고 프롬프트를 붙입니다. 모델·9:16·지원 길이 8초는 화면에서도 선택합니다.[S367][S349][S364][S425]

입력 → 출력: 승인 이미지·동작 설명 → 짧은 MP4 → Clipchamp에서 컷 연결·해설·자막

먼저 기준 이미지 reference.png 만들기

ChatGPT/Gemini 이미지 입력창에 아래를 넣고 결과를 검수해 reference.png로 저장하세요. Flow에서 9:16을 선택하고 이 그림을 시작 프레임으로 첨부합니다.

세로 9:16 설명 삽화. 작은 초록 종이 로봇 하나가 크림색 책상 왼쪽에 서 있고 오른쪽에는 무늬 없는 갈색 화분 한 개가 있어.
로봇은 화분 쪽을 보고 있어. 눈높이 미디엄 샷·고정 카메라·부드러운 아침 창문빛·종이공예.
피사체는 중앙 안쪽, 머리와 화분 전체가 보여야 해. 글자·로고·실존 인물·브랜드 없이.

좋은 기준: 로봇 하나·화분 하나, 동일한 색과 형태, 잘리지 않은 전신·소품. 틀리면 영상 생성 전에 고치세요.

샷 1 → shot-01.mp4

샷 2·3도 같은 기준 그림으로 만드세요

각 샷은 같은 reference.png를 다시 첨부하는 독립 클립이에요. 모델·9:16·8초·빛·카메라는 그대로 두고 한 동작만 바꿔요. 연속 동작으로 자동 이어진다는 뜻은 아니에요. 생성마다 출력 수와 차감량을 보고, 검수 후 아래 이름으로 저장하세요. 세 파일을 편집기에 1→2→3 순서로 넣고, 어긋나는 시작·끝은 잘라요.

넣을 곳: ChatGPT 입력창. 최종 카드 문안·대본과 출처 메모를 넣고, 결과는 게시 화면의 설명란에 옮깁니다.[S302][S389][S362]
