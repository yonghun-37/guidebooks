# 게시 전 편집의 목표를 보여 주는 견본

이 폴더는 **문안·시각 구성·한국어 낭독·자막의 완성 목표**를 보여 줍니다. `samples/insta/`와 `samples/shorts/`는 키 없이 기능을 시험하는 샘플이며, 이 폴더의 파일은 그 기능 시험 결과를 편집해 만든 별도 견본입니다. 실제 계정에 게시하지 않았고 성과 자료도 없습니다. 원고와 디자인은 이 저장소를 위해 새로 작성했습니다. **Codex가 원고를 편집하고 코드를 렌더했으며, 사람이 녹음하거나 사람이 최종 감수한 결과로 표시하지 않습니다.**

## 인스타: 같은 생활 뉴스 소재를 끝까지 편집

「청년 지원금, 신청 전 확인할 3가지」를 네 장으로 정리했습니다. 모든 장에 **가상 공고 · 안내 예시**를 넣었습니다. 실제 제도명·금액·신청일·수급 요건을 만들지 않았습니다. 정책 공고를 대신하는 게시물이 아니라, 공고를 읽을 때 확인할 항목을 정리한 창작 생활정보입니다. 게시 전 실제 공고에 적용하려면 담당 기관의 원문을 별도로 대조해야 합니다.

- `instagram/instagram-01` ~ `04`: 1080×1350, PNG(편집 확인), JPEG(게시 파일), WebP(책에서 보기).
- `instagram/caption.txt`: 함께 읽을 캡션과 가상 예시 고지.
- 편집한 점: 「대상·기간·서류」를 질문으로 바꾼 첫 장 → 항목 하나당 한 장 → 실제 공고에 표시·달력에 기록·목록으로 정리하는 행동으로 끝냅니다. 표제와 본문 크기를 나누고, 공통 여백과 번호를 유지했습니다.

## 쇼츠: 월급날 네 칸 메모

`shorts/payday-four-boxes.mp4`는 **38.667초, 1080×1920, 24fps, H.264/AAC** 영상입니다. 가상 채널 「자취생 10분 생존법」의 기존 월급날 소재를 유지했습니다. 10분은 권장 메모 활동 시간이며 영상 길이가 아닙니다. 정해진 저축 비율·수익·성과를 주장하지 않습니다.

- `script.txt`: 편집한 낭독 대본. 제작 설명을 첫 문장에서 빼고 생활 속 질문으로 시작했습니다. 한 장면에 한 가지 행동만 남겼습니다.
- `voice/01.wav` ~ `08.wav`: 장면별 한국어 합성음. **사람의 녹음이 아닙니다.** 특정 실존 인물을 흉내 낸 음성이나 음성 복제도 아닙니다.
- `narration.flac`: 여백을 포함한 무손실 낭독 원본. 음악·신호음을 넣지 않아 발음에 집중할 수 있습니다.
- `subtitles.srt`, `timeline.json`: 낭독·자막·장면 대응. 음성이 시작되기 0.16초 전에 장면을 열고, 읽은 뒤 최소 0.30초를 두고 넘깁니다. 자막은 영상에도 직접 넣었습니다.
- `poster.jpg`, `scene-01.webp` ~ `08.webp`: 표지와 장면 확인용 프레임.
- `manifest.json`: 길이·규격·음성 설정·최종 파일 SHA-256.

돈 메모의 칸을 설명할 때 해당 칸과 예시가 함께 드러납니다. 한 화면에 두 줄 자막을 두고, 핵심 글은 좌우 100px·상단 200px·하단 320px 이상의 여백 안에 배치했습니다. 이 여백은 이 견본의 디자인 선택이며 플랫폼 전체에 적용되는 공식 규격이 아닙니다.

## 음성과 소재의 권리

2026년 10월 26일 원문을 확인했습니다.

| 소재 | 출처와 조건 | 이 견본에서의 사용 |
|---|---|---|
| 원고·도형·레이아웃 | 저장소용 신규 창작 | 외부 사진·로고·영상·음악을 사용하지 않음 |

모델 라이선스 사본은 `licenses/SUPERTONIC-3-LICENSE.txt`에 보관했습니다. API 키·결제·실계정·유료 서비스는 사용하지 않았습니다. 모델/패키지 최초 다운로드에는 네트워크를 썼고, 음성 합성은 로컬에서 실행했습니다. 이 모델은 공식 보관소로 이전되어 개발·지원이 종료된 상태이므로, **매일 운영할 새 기본 공급자로 권장하려는 예가 아닙니다.** 동봉 음성은 다운로드 없이 재사용할 수 있습니다.

## 재현

저장소 루트에서 `auto-kit`의 기본 의존성과 Noto Sans CJK KR 글꼴을 준비한 뒤 실행합니다. `NOTO_KR_FONT_DIR`에 `NotoSansCJKkr-Regular.otf`와 `NotoSansCJKkr-Bold.otf`가 들어 있는 폴더를 지정하세요.

```bash
python auto-kit/examples/build_editorial.py
```

동봉된 장면별 WAV를 사용하므로 TTS 패키지와 네트워크가 필요 없습니다. 카드·MP4를 다시 만들고 `site/assets/advanced/editorial/`와 `site-shorts/assets/advanced/editorial/`에 WebP·MP4·표지·자막을 복사합니다. 카드만 확인하려면 `--cards-only`를 붙이세요.

음성까지 다시 생성하려는 경우에만 **별도 가상환경**에 선택 패키지를 설치합니다. 기본 `requirements.txt`에는 추가하지 않았습니다.

```bash
python -m pip install supertonic==1.3.1
python auto-kit/examples/build_editorial.py --regenerate-voice --model-dir /tmp/editorial-supertonic-3
```

이 선택 명령은 지정한 revision의 모델을 Hugging Face에서 내려받습니다. 다운로드 위치에 충분한 공간과 쓰기 권한이 있어야 합니다. 동봉 음성은 고정되어 있지만 음성을 새로 합성하면 런타임에 따라 파형이 조금 달라질 수 있습니다. 본 작업의 렌더는 Python 3.10, Pillow 12.1.0, imageio-ffmpeg 0.6.0에서 실행했습니다.

## 실제 확인한 범위

카드 4장과 영상의 8개 장면을 프레임으로 확인했고 MP4 전체 디코딩, 타임라인 길이·자막과 음성 대응, 웹 복사본의 해시를 검사했습니다. `verification.json`에 측정값을 남겼습니다. 동봉 음성을 쓰는 기본 명령을 실제 실행했고, 고정 revision으로 음성 8개를 다시 생성해 이전 WAV와 SHA-256이 모두 일치하는 것도 확인했습니다. 한국어 발음은 로컬 faster-whisper 1.2.1 `small` 모델로 장면별 역전사해 대본과 대조했습니다. 숫자 표기·띄어쓰기·문장부호를 제외한 문안이 모두 대응했습니다. 초안에서 인식이 흐린 두 문장을 고쳐 다시 생성했습니다.

**사람의 청취 검수는 수행하지 않았습니다.** 기계 역전사 일치가 자연스러운 말맛을 모두 보장하지는 않습니다. 게시 전 재생해 호흡·강조·낭독 속도를 확인할 책임은 남아 있습니다. 이 견본은 신호음 시험에서 한국어 낭독과 실제 자막·장면을 맞추는 다음 목표를 보여 줍니다.
