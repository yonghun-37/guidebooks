[BX032](SOURCES.md#bx032) [BX101](SOURCES.md#bx101). PDF 파일명20260917과 문서 표지2024.12를 구별한다. 본문에서 확보한 최종승인/대가성 문구를 채택하되 별도 API 신규 요건이 없다는 결론을 만들지 않는다. 로그인 후 API 안내를 저장할 때 시행일·계정 구분·실적 집계기간·판매액/수수료·취소차감·한도 단위·초과 조치까지 기록하게 한다.

무효 클릭·자동실행·가리는/커버 배너·무단 후기 도용을 금지하는 가이드와 자가구매 실적 불인정을 확인했다. 자동실행 금지를 AI 글 전체 금지 또는 전체 허용으로 바꾸지 않는다. [BX032](SOURCES.md#bx032)

네이버 어필리에이트 약관의 PC/모바일 웹 미디어 정의는 외부 활용의 일반 근거지만, WordPress 단독 가입/모든 캠페인 허용까지 보장하지 않는다. 가입할 등록채널·활동 제한 매체·캠페인 지정채널을 대조한다. 네이버 쇼핑 검색 API는 제휴 링크 발급 API가 아니다. 링크프라이스는 웹사이트 등록·광고주별 승인 경로가 명시된 대안이다. [BX034](SOURCES.md#bx034) [BX102](SOURCES.md#bx102) [BX103](SOURCES.md#bx103)

해외 한 줄 비교: Amazon Associates 미국 안내는 가입 뒤180일 안에 적격판매3건 후 심사하며 개인 구매는 제외한다. 한국 제휴의 승인 기준으로 복사하지 않는다. [BX128](SOURCES.md#bx128)

## 불확실·상충과 권장 결론

- [BXF-029](FACT-SHEET.md#bxf-029) · **미확인**: 과거 가이드(PDF 본문 2021.07)의 Search 10/Report 50/기타 100회(각 1시간)는 과거값이다. 2026 현행 쿼터·별도 최근실적 요건·가격 캐시/표시 조건은 공개 현행 원문에서 확정하지 못했다. 콘솔 확인 전 live API를 켜지 않는다.
- [BXF-030](FACT-SHEET.md#bxf-030) · **확인**: 공식가이드는 상품·딥링크·리포팅 API 기능과 수동 링크/배너 경로를 안내한다. 현재 HMAC 요청정의·검색/딥링크 엔드포인트 세부는 계정의 Open API 가이드에서 대조한다. 판매자 Open API를 제휴API로 대체하지 않는다.
- [BXF-033](FACT-SHEET.md#bxf-033) · **확인**: 네이버 약관은 PC/모바일웹 등 미디어에 제휴링크를 게재하는 일반 근거가 있다. 등록채널 자격과 외부WordPress 게시허용은 다르며 제한매체·캠페인지정채널은 별도다. WordPress단독가입 경로는 미확인이다.

## 교과서·키트 반영
